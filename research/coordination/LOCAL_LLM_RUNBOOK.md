## 3. Standing operations (details: `.claude/skills/ops/SKILL.md`)

**Commits.** Pathspec only (never `-A` or `.`). Commit through the gates. On `main` commit ONLY this file:
`git add research/coordination/LOCAL_LLM_RUNBOOK.md && git commit -m "runbook: <what>"`. Never push: `sim-sync.timer`
publishes `main` (RULINGS push-credential, private-repos); name `<branch> @ <sha>` in your RESULT line instead. A
gate refusal on infra (sync, provisioner, a stale tool on your branch): clear it yourself (RULING pivot-1102 (c),
`tools/agent_sync_branch.sh` per RULING sync-branch); a gate refusal on content: NEEDS STOP with its message.
**Pool (CPU).** `bash tools/pool_queue.sh add '<line>' --checked '<task>: <why> ; mem_gb=<gb> ; max_age_h=<N>'` at a
provisioned revision (RULING compute-placement). Every line carries `max_age_h` (at most 240). Re-queue a dead line
once, verbatim; a mem_ok or capacity refusal is not a death (RULING memok-1025). A pool-canary refusal is NEEDS STOP.
Live dispatcher state: `journalctl -u sim-pool-dispatch`, never `research/queue/dispatch.log` (dead file).
**GPU (W).** `bash tools/gpu_remote.sh add '<cd clean committed checkout && cmd>'`; status `bash tools/gpu_remote.sh
status`. Hand the card over at the end of the run that queued jobs: commit, WORKLOG "yielding for <jobs>", then
`bash tools/gpu_remote.sh yield --max-hours N` as the last command. Owner gaming (`game on`) pauses W: expected, not
a failure (RULING game-mode-pauses). Model unreachable mid-run: no retry loop; WORKLOG it and end the run.
**Results.** Land arriving files under `research/findings/raw/...` with their `.prov.json` sidecars as pure data
commits. Every verdict you write is PROVISIONAL until Claude checks it; numbers only from the registered scorer.
**Units.** `systemctl status sim-pool-dispatch.service sim-sync.timer` (host units, user `sim`; you cannot restart
them). A failed unit: NEEDS "[units] <unit> <state>".
