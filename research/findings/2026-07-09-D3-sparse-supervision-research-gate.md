# D3 sparse-supervision research gate — learning the transition δ from weaker-than-per-step supervision (the residual credit wall)

**Date:** 2026-07-09
**Type:** read-only deep-research gate (dispatched subagent scout + controller re-read of the load-bearing sources).
**Trigger:** the rung-3 end-label boundary (`2026-07-09-D3-endlabel-supervision-boundary.md`) — end-label-ONLY supervision does NOT length-generalize; learning the transition from weak supervision is the residual.

## The reframe (the strongest single finding — controller-verified by reasoning)
Rung-3 supervised only the **2-way property** at the endpoint = **1 bit**. The running K-way state needs **≈log₂K bits** to identify (S3: 2.58, A5: 5.9). One endpoint bit cannot pin the K-way state, so BPTT/straight-through through a *scrambling* latent walk has no learnable target → DEEPER ≈ chance. **This is information-theoretic, not a tuning failure.**

The load-bearing enabling fact (from the D3 GO): **δ is length-INDEPENDENT** — it is learned perfectly from *short* sequences (step-delta 1.000 from train-lens 1/2/3), and the depth-generalization is entirely the drift-free re-discretized rollout. So "learn δ from weak supervision" reduces to: **supply ≈log₂K bits of learning signal at SHORT lengths without handing per-step intermediate states.** The current teacher-forcing (`discrete_attractor_rnn`→`collect_triples`, `_d3_group_composition_derisk.py:359`) hands per-step states s₁…s_L; the mechanisms below remove that.

## Ranked, cheap-first (with the sources to re-read before building)
- **★ RANK 1 — K-way FINAL-STATE-only supervision + short-length curriculum.** Supervise ONLY the K-way state at each short sequence's FINAL step (not intermediate, not the 2-way property). Near-provably sufficient: length-1 endpoints fix δ(ident,·)=g₁; once learned, the model's own rollout pins s₁, so length-2 endpoints supply an effective (s₁,g₂)→s₂ over ALL s₁ → the full table is recoverable from length-1+2 endpoints alone. Genuinely LEARNED (intermediate states are the model's own straight-through rollout), NOT per-step taught. Analogy: Sutton-Barto Ch 8 Dyna (model δ learned by supervised next-STATE prediction from experienced transitions). **Cheapest, single-variable vs the GO, near-provably GO → building FIRST** (`_d3_weak_supervision_derisk.py`; decisive isolation `--supervise state` vs `--supervise property`=rung3).
- **RANK 2 — dopamine-TD actor-critic + eligibility + reverse replay (the project's own machinery).** Kandel 6e Ch 38 pp. 944–945 (eligibility trace + phasic-dopamine teaching signal); Schultz 1998 pp. 13–14 (a predictive/bootstrapped critic beats end-of-trial reward, and the advantage grows with sequence length); Kandel Ch 5 pp. 101–102 (forward+reverse SWR replay, 10–20× compression); Mattar-Daw 2018 (each replayed transition = one TD backup). Project reuse: three-factor `Δw=lr·RPE·eligibility` (`sim/bridge.py:7411`), eligibility accumulation/decay (`:7136`/`:7299`), `run_swr_replay_phase`/`run_concept_replay_phase` (`consolidation_trainer.py`). **HONEST caveat (a deliverable, not a build target):** eligibility+replay solve TEMPORAL credit, not STRUCTURAL credit; on this task intermediate-state value is flat (a mixing walk) → predicted BOUNDARY (same wall as end-label BPTT). Replay's genuine value (data-efficiency of learning from OBSERVED transitions) only helps once the state is observable → RANK 3.
- **RANK 3 — self-supervised state-tied-observation prediction (the deepest, most emergent).** Homomorphism-AutoEncoder (Keurti et al. ICML 2023, arXiv:2207.12067 §Prop.1 + the 2→128-step length-gen result): one learned operator ρ(g)=exp(φ(g)) per symbol; matrix product composes → homomorphism BY CONSTRUCTION → length-generalizes; supervised ONLY by (obs, action, next-obs), NO state labels; prediction-ALONE collapses to identity (needs a reconstruction anchor). TEM (Whittington et al. Cell 2020): action-conditioned recurrent operator = δ, sole loss = next-SENSORY-observation prediction, requires state-dependent observations. Ni et al. ICLR 2024 (arXiv:2401.08898): the ZP self-prediction objective collapses to the constant map unless anchored by state-carrying info. Project anchor: the committed spiking HTM Temporal-Memory next-symbol predictor (Bouhadjar-Diesmann 2022, `fused_htm_permanence_update`). **The emergent version — build after RANK 1;** decisive control = state-INDEPENDENT observation (o=f(input)) → collapse.

## The unification
In the information-theoretic limit RANK 1 and RANK 3 are identical: both supply ≈log₂K bits about the state at short horizons (RANK 1 as a supervised endpoint STATE label — cheapest; RANK 3 as a self-supervised state-tied OBSERVATION — most emergent), and both ride the already-GO drift-free re-discretized rollout to arbitrary depth. The reframe: "learn δ from a 1-bit end-label through a scrambling walk" is the WRONG target — it is exactly the regime biology also cannot do; the fix is a richer (log₂K-bit) short-horizon signal, supervised (RANK 1) or self-supervised-via-observation (RANK 3).
