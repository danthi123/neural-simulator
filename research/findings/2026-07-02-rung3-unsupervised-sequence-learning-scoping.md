## 1. Diagnosis — why the pivot

Across FIVE independent rung-3 probes (target-based recurrent credit; proper e-prop first-order eligibility; RFLO random-feedback; a discrete next-symbol task; and Predictive Alignment, Asabuki-Clopath 2025), the robust result was the same: on toy **rate**-recurrent tasks, a FIXED random recurrent reservoir + a locally-trained readout ("reservoir computing" / echo-state network / cortex-as-reservoir / Maass liquid-state-machine — a recurrent net whose internal weights are left at their random init while only the output map is trained) is a very strong, perturbation-robust baseline, and SUPERVISED local recurrent-WEIGHT training (adjusting the internal recurrent weights toward a target trajectory or next-symbol map with a local rule) does **not** beat it — it degrades or interferes (Predictive Alignment collapsed FASTER than the fixed reservoir as the number of trajectories grew: catastrophic interference in the single shared plastic recurrent matrix). Conclusion recorded in `2026-07-02-emerge8-predictive-alignment-BOUNDARY-and-the-5-probe-reframe.md`: chasing supervised recurrent-credit value on toy rate tasks is a false economy.

The reframe: biology's sequence cortex does not train recurrent weights toward an externally supplied target trajectory. It **self-organizes** sequence structure from streaming experience via LOCAL plasticity (Hebbian/STDP + inhibition/winner-take-all + nonlinear dendrites), with NO teacher — which is also this project's master directive (emergent, self-organizing, single-substrate, from streaming experience). The anchor mechanism, which recurred throughout the arc as EMERGE-7's positive control and Task-B template, is the spiking Temporal-Memory network of Bouhadjar, Wouters, Diesmann & Tetzlaff (2022). It performs UNSUPERVISED high-order sequence learning + context-specific prediction + autonomous replay in a spiking network with structural Hebbian plasticity, dendritic action potentials, and lateral inhibition — **no target, no error signal, no recurrent-weight-toward-trajectory training**. This is a different mechanism class from everything rung-3 has tested, and it sidesteps the exact dead-end the 5 probes hit (see §2 caveat).

**Terms (defined once):** *high-order sequence* = a sequence where predicting the next element requires more than the current element (needs the history/context); the canonical construction is two sequences that share a middle sub-sequence (e.g. `{A,D,B,E}` and `{F,D,B,C}` share `D,B`), so at the branch point the immediate context is identical and only the earlier context (`A` vs `F`) disambiguates. *dendritic action potential (dAP)* = a nonlinear all-or-none dendritic event (NMDA/Ca²⁺ plateau) that produces a long-lasting (~50-500 ms) somatic depolarization without itself firing the soma — here it encodes a *prediction* ("this neuron expects to be activated next"). *Winner-take-all (WTA)* = fast lateral inhibition that lets only the already-predicted (depolarized) neurons win, silencing the rest → sparse, context-specific activation. *Permanence* = a synapse's maturity variable; below a threshold the synapse is functionally silent (weight 0), above it the synapse is "mature" with a fixed weight — this is *structural* plasticity (synapse creation/pruning), not weight-magnitude learning.

## 2. The Bouhadjar-Diesmann 2022 mechanism, in detail (verified from the PMC full text)

**Verified citation (exact):** Bouhadjar Y, Wouters DJ, Diesmann M, Tetzlaff T. "Sequence learning, prediction, and replay in networks of spiking neurons." *PLoS Computational Biology* 18(6):e1010233, 21 Jun 2022. DOI [10.1371/journal.pcbi.1010233](https://doi.org/10.1371/journal.pcbi.1010233). PMC9273101; PMID 35727857. arXiv preprint 2111.03456. (According to PubMed; DOI link included per its attribution terms.) Read: abstract + full Methods + Results prose (the MathML equations were stripped to fragments in the fetched text, so the exact LaTeX is not quoted verbatim below; the rule is described precisely from the prose + parameter tables, and each such claim is labeled as prose-verified rather than equation-verbatim).

It is a **continuous-time spiking implementation of the Temporal Memory (TM) component of Hierarchical Temporal Memory (HTM)** — porting Hawkins/Ahmad's discrete-time TM to biophysically interpretable LIF neurons.

**Architecture.**
- `M` excitatory subpopulations, one per possible sequence element (a "receptive field" / stimulus preference). Default: `n_E = 150` excitatory neurons per subpopulation; `1` inhibitory neuron per subpopulation; all-to-all E↔I *within* a subpopulation; inhibitory neurons mutually unconnected.
- Excitatory→excitatory ("EE") connectivity is **sparse, random, and POTENTIAL**: each E neuron has a fixed random in-degree drawn once; a potential synapse is either *immature* (weight 0, no effect) or *mature* (fixed weight). Potential connection probability `p = 0.2` (chosen near the minimum that still guarantees the divergent-convergent motifs needed to carve sequence-specific paths; higher `p` promotes overlap and slows context formation). EE weights are the ONLY plastic connections; E↔I and external→E are static.
- Each element is delivered by a strong, **supra-threshold external spike** to its whole subpopulation → before learning, every neuron in the stimulated subpopulation fires (non-sparse).

**Neuron / dendrite.** LIF soma + a single distal dendritic branch with an explicit nonlinearity: when the dendritic current exceeds a threshold `θ_dAP`, it is instantly clamped to a plateau current for a fixed duration → a long-lasting somatic depolarization (the dAP = the "predictive state"). `θ_dAP` is set so that the coincident firing of `~15` (parameter `γ`) mature-connected presynaptic neurons reliably triggers a dAP. A dAP does NOT by itself fire the soma (in prediction mode); it depolarizes it, so that a subsequent external input makes those predicted neurons fire *slightly earlier* than non-predicted ones.

**The learning rule (structural Hebbian STDP + dAP-rate homeostasis; prose-verified, Methods "Plasticity dynamics").** Each EE synapse `j→i` has a permanence `P_ij(t) ∈ [P_min, P_max]`. It is silent until `P_ij ≥ θ_P` (maturity threshold), then jumps to a fixed weight `W`. The permanence evolves by three LOCAL terms:
1. **Potentiation (additive STDP, all-to-all pairing):** on a postsynaptic spike, `P` increases by `λ⁺ · x_j(t)`, where `x_j` is the presynaptic spike trace (bumped +1 per presynaptic spike, exponential decay τ). An indicator restricts potentiation to post-lag-pre time lags in a window `(Δt_min, Δt_max)` — this deliberately excludes near-synchronous pairs, so it does NOT grow synapses *within* a subpopulation or *between the first elements of different sequences* (both fire synchronously). The potentiation update is lagged by a purely dendritic delay.
2. **Depression:** each presynaptic spike decrements `P` by a constant `λ⁻` (prunes connections not supporting the learned order → suppresses false positives).
3. **dAP-rate homeostasis (the load-bearing context term):** `P` growth is scaled by `λ_h · (z* − z_i(t))`, where `z_i` is a low-pass-filtered postsynaptic **dAP** activity (not spike activity) and `z* = 1` is the target. Growth is *boosted* when a neuron's dAP rate is below target and *suppressed* above it. With `z* = 1` and the homeostasis time constant tuned to the sequence-ensemble duration, each neuron is driven to become predictive (generate a dAP) AT MOST ONCE per pass through the sequence set.

**How HIGH-ORDER CONTEXT self-organizes with NO teacher (Results "Sequence learning and prediction" + Fig 6/7).** This is the crux. Three ingredients combine:
- **Random permanence heterogeneity** breaks the symmetry: connections with higher initial permanence mature first, so for each ordered pair of subpopulations a *particular* small random subset of postsynaptic neurons becomes predictive.
- **Hebbian potentiation alone is NOT enough** — because the shared element (e.g. `D` appearing in both `{A,D,B,E}` and `{F,D,B,C}`) initially fires *all* its neurons and would grow overlapping, context-blind connections. This is exactly the interference the reservoir-vs-credit arc kept hitting.
- **The dAP-rate homeostasis + depression + minimal density BREAK the overlap.** Because homeostasis forces each neuron to become predictive at most once per sequence set, the neurons that get "used up" predicting `D`-after-`A` cannot also be the ones predicting `D`-after-`F`. So the network is *forced* to allocate DISJOINT subsets of `D`-neurons and `B`-neurons to the two contexts. The result: after learning, `A,D,B` activates a different sparse subset in `D` and `B` than `F,D,B` does, so `B`-in-context-A predicts `E` while `B`-in-context-F predicts `C` — high-order context is carried purely by WHICH sparse subset is active, an emergent property of local competition, never a supervised target. Validated: sequence set II (five 5-element sequences, order-3) converges in ~40 unsupervised episodes; an order-10 pair (`{A,D,B,G,H,I,J,K,L,M,N,E}` vs `...,C`) is learned.

**How PREDICTION and MISMATCH emerge.** After learning, presenting an element makes its subpopulation fire; the mature EE synapses drive dAPs (predictions) in the correct sparse subset of the *next* subpopulation. When the next external input arrives, the predicted (depolarized) neurons fire first → their advanced spikes drive the subpopulation's inhibitory neuron → WTA silences the non-predicted neurons → **sparse** response = "prediction met." If the input does NOT match the prediction, no subset is pre-depolarized, WTA cannot engage in time, and the WHOLE subpopulation fires (non-sparse) = **mismatch signal**. Sparsity itself is the correctness readout; the "prediction error" metric is the fraction of non-sparse (mismatched) responses.

**How REPLAY emerges.** Switch to "replay mode" by raising excitability (lowering the somatic threshold — biologically a neuromodulator / top-down attention / sleep depolarizing wave). Now a dAP's plateau depolarization ALONE is enough to fire the soma. So a single cue element → predicts the next subset → that subset now *fires* (not just depolarizes) → predicts the next → ... the network autonomously walks its own learned path, context-specifically, in the correct order. No external drive after the cue.

**What is local / spiking (the whole point):** every update uses only pre/post spike traces + the postsynaptic dAP trace available AT the synapse. No backprop, no weight transport, no error signal, no target, no readout. Fully online + continuous (no train/test split). Implemented in NEST as LIF + a single nonlinear dendritic compartment.

### Why this genuinely sidesteps the reservoir-vs-credit dead-end (mandate item 2)

The 5-probe dead-end was specifically about training a **shared plastic recurrent weight matrix toward a supervised target**, which suffers catastrophic interference and loses to a fixed reservoir. Bouhadjar does something categorically different:
- **It does not train recurrent weights toward any target.** There is no target trajectory and no error. Plasticity is a local Hebbian+homeostatic *structural* rule; "success" (prediction accuracy) never feeds back into learning (explicitly stated: "the learning process is entirely unsupervised, i.e., the prediction performance does not affect the learning").
- **It avoids interference by ALLOCATION, not by fitting a shared matrix.** The dAP-rate homeostasis + minimal random connectivity carve DISJOINT sparse sub-paths per context out of a random skeleton. Different contexts recruit different neurons, so more sequences ⇒ more allocated paths, not more conflict in one shared matrix. (This is the direct antidote to Predictive Alignment's "single shared plastic M pulled toward many conflicting attractors" collapse.)
- **The "reservoir" role is preserved and legitimate:** the random potential connectivity IS a fixed random skeleton (echo-state-like), but the plasticity *selects a sparse sub-graph* of it per context rather than reweighting the whole thing. It composes the reservoir's strength (free random substrate) with sparse structural learning (context allocation) — the best of both, and it is what the 5-probe conclusion implicitly pointed at ("the useful recurrent dynamics come free from the random init"; here we additionally *carve* them).

Honest caveat (do not oversell): Bouhadjar is not a rate-trajectory regressor and was never benchmarked against a reservoir on the same rate task — it solves a *discrete symbolic* next-element prediction problem. The claim is "it sidesteps the dead-end because it is a different, self-organizing formulation of the sequence problem," NOT "it beats a reservoir at the reservoir's own rate-regression game." The right comparison is the Markov-floor + lesion panel in §4, not a head-to-head vs an echo-state regressor.

## 4. Recommended cheap-first de-risk (numpy, CPU, multi-seed)

**Goal question:** does a Hebbian-STDP + WTA-inhibition + dendritic-plateau spiking network SELF-ORGANIZE high-order, context-specific next-element PREDICTION from a streaming corpus, with NO teacher — and does context accuracy provably beat a Markov floor + collapse under lesion?

**Task (reuse the existing construction verbatim).** Use `research/findings/raw/_fork2_predesign_markov_floor_check.py`'s `make_overlap_sequences` — this is literally Bouhadjar sequence-set-I generalized: `n_seq` sequences of form `[cue_i] + [shared middle of length L] + [branch_i]`, e.g. `n_seq=2, L=4` → `{c0, m0,m1,m2,m3, b0}` and `{c1, m0,m1,m2,m3, b1}`. That script already PROVES (pure counting) that any order-`k ≤ L` Markov predictor is at chance at the branch step (the last `k` symbols are the identical shared middle), while a full-context oracle is 1.0. Start with `n_seq=2, L=4` (Bouhadjar's set-I complexity), then scale to `n_seq=4, L=8` and the five-sequence set-II analogue for the multi-seed GO.

**Mechanism to implement (minimal faithful Bouhadjar).** `M` = vocab subpopulations of `n_E ≈ 150` LIF-rate-or-spiking neurons + 1 inhibitory unit each; sparse random potential EE connectivity `p=0.2` with per-synapse permanence `P∈[P_min,P_max]`, heterogeneous init; maturity threshold `θ_P` (below → weight 0); the three-term local rule (additive STDP potentiation windowed to exclude synchronous pairs · constant presynaptic depression · dAP-rate homeostasis toward `z*=1`); a single nonlinear dendritic branch with plateau threshold `θ_dAP` set so `~γ=15` coincident mature inputs trigger a dAP; subpopulation WTA via the local inhibitory unit; supra-threshold external one-hot element drive. Prediction mode (dAP depolarizes) + a replay-mode check (raise excitability → autonomous walk). Numpy is fine at this scale; a rate/event approximation of the LIF+dAP is acceptable for the de-risk provided the WTA + dAP-plateau nonlinearity + the three-term structural rule are faithful (those are the load-bearing pieces).

**Metric.** Branch-step (divergent-position) next-element prediction accuracy — accuracy at the position where the shared middle ends and the branch must be predicted, scored ONLY at that context-disambiguating position (matches EMERGE-7's divergent-position scoring + Bouhadjar's mismatch/sparsity readout: a *sparse, correct-subset* response = correct prediction; a non-sparse response = mismatch).

**Anti-cheat panel (all mandatory):**
- **(a) Markov floor.** Branch accuracy MUST exceed the order-`k≤L` Markov predictor's accuracy (provably ~`1/n_seq` chance by the construction — already proven by `_fork2_predesign_markov_floor_check.py`; re-report it alongside the model number). This is the airtight "it really carried high-order context" control.
- **(b) Dendritic / WTA lesion → collapse.** Remove the dAP nonlinearity (make dendritic integration linear) OR disable the WTA inhibition; either must collapse branch accuracy toward the Markov floor. This proves the dAP-prediction + sparse-allocation mechanism is load-bearing, not incidental reservoir dynamics. (Bonus: lesion the dAP-rate homeostasis specifically → context-specificity should collapse via subpopulation overlap even if plain Hebbian sequence-following survives — the paper's Fig 7 result.)
- **(c) NO-teacher is the DELIVERABLE, not a cheat.** There is no target and no error path in the rule; "self-organizes context-specific prediction from streaming exposure alone" IS the GO condition. (Assert in-code that no label/target/error variable enters any weight/permanence update — the analogue of the arc's `used_transpose is False` guard.)
- **(d) Multi-seed 42/43/44** (min; extend to 6-seed per the standing rule before any generalization claim). Report per-seed branch accuracy + Markov floor + lesion.
- **(e) Learnability / positive control.** The full-context oracle in the same harness = 1.0 (task solvable WITH context), and the network reaches near-oracle branch accuracy on the SIMPLEST case (`n_seq=2, L=4`) before scaling — guards against declaring BOUNDARY on an unlearnable task (the EMERGE-7 grokking mis-design lesson).

**GO / BOUNDARY / INCONCLUSIVE criteria.**
- **GO:** branch accuracy ≥ ~0.9 on `n_seq=2,L=4` AND materially above the Markov floor on `n_seq=4,L=8`, unanimous across seeds 42/43/44, WITH lesion (b) collapsing it to ≈ floor AND no-teacher (c) satisfied. (Bouhadjar reports 0 prediction error on sets I & II, so ≥0.9 is a reasonable, non-inflated bar.)
- **BOUNDARY:** the mechanism self-organizes sequence-FOLLOWING but not context-SPECIFICITY (branch accuracy stuck at the Markov floor while non-branch accuracy is high) across seeds despite faithful implementation + the paper's homeostasis tuning — i.e. the dAP-homeostasis allocation does not carve disjoint contexts on our substrate. Document precisely which term fails (likely the homeostasis time-constant tuning).
- **INCONCLUSIVE:** learnability control (e) fails (oracle < 1.0 or the network can't even do `n_seq=2,L=4`), or a tuning artifact is suspected → retune `θ_dAP`, `γ`, `p`, homeostasis τ before verdict (do NOT thrash — bounded retune, then call it).

## 5. Honest risks + fallback

- **Homeostasis-tuning fragility (biggest risk).** The paper explicitly tunes the homeostasis time constant `τ_h` to the sequence-ensemble duration (`440 ms` for sets I/II) and warns that too-fast learning "overwrites the permanence heterogeneity essential for context specificity." Our de-risk must respect this; a naive fixed τ or too-high λ⁺ could collapse context-specificity and produce a false BOUNDARY. Mitigation: mirror the paper's parameter table; treat τ_h as task-coupled; run the (e) learnability control first.
- **Rate-vs-spike approximation.** A numpy rate approximation of LIF+dAP may not reproduce the *timing*-based WTA (predicted neurons fire "slightly earlier" → win). If the rate version can't produce the sparse/non-sparse distinction, escalate to an event/spike-timed numpy implementation (still cheap at 150-neuron scale) before calling BOUNDARY — the WTA timing is load-bearing.
- **"Different problem" objection.** This solves discrete symbolic next-element prediction, not rate-trajectory generation. That is a FEATURE for communication/language (discrete tokens), and it is the honest master-directive framing (self-organize structure from a symbol stream), but it means we are changing the rung-3 success definition from "generate a target trajectory" to "self-organize context-specific symbol prediction." Flag this explicitly to the owner.
- **Fallback if #1 BOUNDARYs on our substrate:** (i) add the plastic-input extension #2 or the coherent-noise #3 only if the base learns; (ii) the contrast baseline #4 (Maes hybrid) confirms whether a supervised readout on a self-organized backbone is needed; (iii) worst case, the honest deliverable is a characterized BOUNDARY naming which local term (almost certainly the dAP-homeostasis allocation) fails on point-neuron/two-compartment hardware — itself a real finding, and the two-compartment on-chip precedent (§3) suggests the dendritic compartment is exactly what makes it work, pointing straight at rung-4.

## 6. VERDICT

**Build the spiking Temporal-Memory network of Bouhadjar-Diesmann 2022 (mechanism #1) as the rung-3 pivot** — a fully-unsupervised, fully-local, spiking Hebbian-STDP + dendritic-plateau + WTA network that self-organizes high-order context-specific sequence prediction and replay — de-risked cheap-first on the existing overlapping-sequences task with the Markov-floor + dendritic/WTA-lesion + no-teacher anti-cheat panel; it genuinely sidesteps the reservoir-vs-recurrent-credit dead-end because it carves disjoint sparse sub-paths out of a fixed random skeleton by local competition rather than training a shared recurrent matrix toward a target.
