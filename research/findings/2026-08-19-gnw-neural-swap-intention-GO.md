## What this closes
The GNW thought-swap was already neural on both ends: the recurrence-weaken swap (`2026-08-19-gnw-recurrence-weaken-swap-GO.md`, GO 6/6) EVICTS the incumbent neurally (Rung-2d short-term depression drains its own recurrent E→E loop below the sustain knee → self-collapse), and the neural vacancy gate (`2026-08-19-gnw-neural-vacancy-gate-GO.md`, GO 6/6) ADMITS the challenger neurally (occ occupancy interneurons → gate_k disinhibition → gate_k→pattern_k). Both findings' honest limit #2 was the SAME last host piece: the swap TRIGGER — the "swap-now" STD boost — was a FIXED-duration top-down command (`std.set_boost(inc, BOOST)` for `boost_steps`), a host DECISION of WHEN to swap. Per the BRAIN-BASED-ONLY standard, admission/decision control between sensation and action is a shortcut. This finding replaces the fixed schedule with a spiking mismatch/salience population whose FIRING sets the boost, so the DECISION to swap is made by neurons. The whole chain is now neural: mismatch/salience (WHEN) → STD eviction (OUT) → disinhibitory vacancy gate (IN).

## The mechanism (a novelty/mismatch comparator; disinhibition veto; explicit wiring; NO `sim/` edit)
Two per-pattern pools are ADDED to the exact neural-vacancy-gate substrate (workspace / norm_pool / thal / occ / gate; disjoint supra-critical uniform recurrence w=34):
- **mm_k** (60 excitatory mismatch/salience detectors per pattern): receives the sensory PROPOSAL for content k as an excitatory drive ("k is proposed, with salience == the drive strength"). A feed-forward comparator — a measured w=0..32 sweep showed within-assembly recurrence saturates the salient response (~0.17, refractory-limited) while RAISING the non-salient response, i.e. it NARROWS the salience gap, so mm is left feed-forward for the cleanest separation.
- **pred_k** (40 inhibitory prediction/held-content interneurons per pattern): excited by workspace pattern_k (`pattern_k → pred_k`, E_TO_I). When content k is CURRENTLY HELD, pred_k fires and TONICALLY INHIBITS mm_k (`pred_k → mm_k`, I_TO_E, w=20 — mirrors the vacancy gate's occ→gate; >40 inverts via Izhikevich depolarization-block relief). So mm_k fires IFF (k is proposed with salience) AND (k is NOT the held content) == a SALIENT MISMATCH between the proposal and the current thought.

**The trigger:** each step the mismatch population's firing RATE sets the per-spike utilization boost on the workspace recurrence — `eff_boost = min(MAX_BOOST, BOOST_GAIN * mm_rate_window)` (gain 1.0, cap 0.16) — a salience/novelty read-out that raises the release probability U of the held loop (the Mongillo/Tsodyks resource variable), so the CURRENTLY-FIRING (incumbent) coalition depletes below the sustain knee and self-evicts. It is applied to every coalition loop, but only the FIRING one depletes; the moment the challenger is admitted and HELD, pred fires, mm goes silent, the boost falls to 0 and the new thought holds — the trigger SELF-TERMINATES when the proposal becomes the held content. NO host read of any workspace/collapse state gates the boost (grep-checkable: the only assignment is `eff_boost = min(MAX_BOOST, boost_gain*mm_win)`; the `if eff_boost>=0.10` is a read-only `trigger_step` diagnostic).

Once mm has triggered the eviction, the neural VACANCY GATE admits the proposal into the freed slot, UNCHANGED from the vacancy-gate finding (the proposal drives gate_k every step; occ disinhibition opens it only on vacancy).

Biology: hippocampal/cortical NOVELTY-MISMATCH comparison — a match-mismatch detector fires to novel (unpredicted) input and is suppressed by a matching prediction (**Lisman & Grace 2005**, *Neuron* 46:703, hippocampal-VTA novelty loop; **Vinogradova 2001**, *Prog.Neurobiol* 45:523, CA1/CA3 comparator; **Kumaran & Maguire 2007**, *J.Neurosci* 27:8517, hippocampal match-mismatch). Predictive-coding mismatch = feed-forward drive minus a matching top-down prediction (**Bastos et al. 2012**, *Neuron* 76:695). Salience/novelty drives a phasic destabilization of WM (**Dehaene & Changeux 2011**, *Neuron* 70:200 — an ignited state must be destabilizable and "spontaneously replaced by another"). Disinhibitory gating: **Chevalier & Deniau 1990**, *TINS* 13:277; **Pi et al. 2013**, *Nature* 503:521. Eviction: **Mongillo, Barak & Tsodyks 2008**, *Science* 319:1543. Corpus-first (`before_you_build.sh`) + the source check were run and logged BEFORE building.

## Why it works (the diagnosis)
The prior swap rungs made WHEN-to-swap a host schedule: a fixed boost fired regardless of whether the input warranted a swap. The missing companion process (CLAUDE.md's wall reframe) was the biological DECISION — a novelty/salience comparison that gates the destabilization. Restoring it as a spiking comparator makes the swap conditional on the world: a salient mismatch fires mm and destabilizes the current attractor; a matching or weak proposal does not. Because the comparator reads the HELD content (via pred) and self-silences the instant the proposal becomes held, the trigger is self-limiting — it destabilizes exactly one incumbent and releases as the new winner stabilizes, the marginally-stable replaceable state Dehaene-Changeux require, now entered on the substrate's own read of "this input is new and salient."

## Honest limits / remaining scaffolds (named, not claimed closed — this is a runner-level de-risk)
1. The coalitions, gate/occ pools, and the new mm/pred pools are hand-wired dense frozen populations (disjoint cliques), not self-organized.
2. What is now NEURAL end-to-end: the swap DECISION (mm mismatch/salience comparison, vetoed by the pred held-content read), the eviction (recurrence depression), the vacancy read (occ), and the admission (gate→pattern). What remains HOST: (a) the STD eviction EFFECTOR is a host-computed faithful model of synaptic-resource depletion written into the loop weights each step (the engine's native STP is a banked foot-gun) — UNCHANGED from both base findings; (b) the mm→eviction COUPLING is a host rate read-out (`eff_boost = gain * mm_rate`), a neuromodulator-like linear map from the salience population's firing to the loop's release-probability — the DECISION (whether/when there is any boost) is fully the mm spikes, but the read-out itself is host arithmetic, not a synapse (there is no engine primitive for "presynaptic firing raises U of other synapses"); (c) thal tonic and the world's sub-threshold sensory PROPOSAL.
3. **Content routing is per-pattern labeled-line, not learned/composed:** each proposal drives its own gate_k / mm_k / pred_k, so the challenger's IDENTITY is the world's proposal (legitimate) and arbitrary content needs the corresponding labeled line (the base findings' limit #1).
4. **The non-salient margin is the tightest anti-cheat:** <!--derived-->the non-salient boost peaks at 0.042–0.067 across seeds (per-seed `residual.nonsalient.boost_max` in the 6-seed artifact), i.e. within ~0.03 of the ~0.10 collapse knee. The salient/non-salient separation is a factor ~4 in boost (0.16 vs ~0.06).
