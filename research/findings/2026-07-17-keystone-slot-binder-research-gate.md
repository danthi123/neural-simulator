# RESEARCH-GATE — Gap-#2 Spiking Closure: A Self-Organizing, Fully-Spiking, One-Brain Slot Binder

## (1) DIAGNOSIS — what must self-organize, and why it beats the ~2 cap

**The ~2 cap is not a "binding is hard" limit — it is the signature of the wrong storage primitive.** Every refuted rung of the store-side path (EDGE-5 rung-2 raw STP → P2 *below* chance; rung-3 value-specific potentiate/depress → weak ~2; rung-3/3b error-correcting delta write → decisively refuted, delta ≈ additive at both KV=4/P≤4 and KV=8/P=8) sums all P bindings into **one shared weight matrix / value pool**. Capacity is then set by superposition SNR — the classical Hopfield/Hebbian √-law and the Bouchacourt-Buschman overlapping-random-projection failure mode — which is ~2 usable binds before crosstalk swamps the read. **This is a property of "one register accumulating binds," not of binding.**

**What must self-organize (two coupled things):**

1. **The slot competition itself** — for each incoming (role × filler) conjunction, a *distinct, near-orthogonal sparse slot* must be **selected by competition** (recurrent/lateral inhibition kWTA that *discovers* the winner), not summed into a shared substrate. This is DG pattern-separation (Marr 1971; O'Reilly-McClelland 1994 CLS) / Rumelhart-Zipser competitive learning / Földiák anti-Hebbian decorrelating inhibition / O'Reilly Leabra kWTA. Capacity then converts from **SNR-limited (~2) to slot-count-limited (combinatorial in a sparse code)**, so P≥3…K holds with inter-binding cosine ≈ 0 by construction — separate slots never share a value pool, so there is no additive saturation.

2. **The competition's threshold / set-point** — the winner-count must stay fair and recruitable **without a hand-set FS-WTA cut** (that path was explicitly **BANKED at RUNG-6e/6f** per the emergence bar). The set-point must be *learned and self-maintained*: HTM homeostatic boosting (Cui-Ahmad-Hawkins 2017), BCM sliding-θ (Bienenstock-Cooper-Munro 1982), Turrigiano synaptic scaling (2008), or Diehl-Cook adaptive spiking threshold (2015). This is the enabling condition — without it, competitive learning collapses to a few "hog" units (dead-unit problem) and re-superposes bindings, re-imposing the ~2 ceiling.

**Why this beats the cap, stated precisely:** binding #3 lands in a *fresh decorrelated slot* instead of adding crosstalk to a shared sum. Read cross-talk stays flat because the slot codes are near-orthogonal (K-of-N sparse). The store's capacity is the number of separable competitive slots, which grows with pool size — not the ~2 that additive superposition allows.

**The residual is COMPOSITION, not a new `sim/` mechanism.** Every piece is BUILT and reusable at GO status but sits in a separate runner; none have been composed into one on-bridge binder. That composition IS the gap. The record has already **refuted the alternative** (store-side write rule, EDGE-5 4-rung conclusion) and **redirected the capability** to exactly this slot binder (keystone-2, drift-#12 catch).
