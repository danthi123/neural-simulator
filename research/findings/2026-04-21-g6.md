# G6 Findings — 2D gridworld sensorimotor navigation

**Date:** 2026-04-21 (autonomous continuation, same day as G5.v3 GO)
**Gate:** G6 — extend the signed-perceptron sensorimotor approach from 1D (G5.v3) to a 4-direction 2D gridworld.
**Verdict:** **PARTIAL** on the strict Q1→Q4 metric (0/3 seeds clear +1.5 threshold) but **clear positive signal** on the real task metric: mean Manhattan distance over the episode is 1.68–1.97 on an 8×8 grid whose random-policy baseline is ~7. All three seeds learn to cluster near the goal; only one (seed 43) reliably reaches `dist == 0`.

---

## 1. Setup

- 8×8 grid. Start (1, 1), goal (6, 6). Manhattan diameter 14.
- 268-neuron network: 64 input (32 x-tuned + 32 y-tuned Poisson) + 160 hidden exc + 40 hidden inh + 4 motor (N/E/S/W).
- All sim plasticity off. Signed perceptron on hidden→motor, runner-side.
- Negative-reward rule (rule B from the design doc): chosen motor gets `-lr·h_act`; the other three each get `+lr·h_act/(n_motor−1)`. Preserves the "chosen was wrong" signal without leaking the true goal direction.
- `learning_rate=0.01`, `lr_schedule=decay_after_goal` (multiplier 0.25 once goal first reached — the tightening landed from G5.v3 addendum).
- 600 steps per episode, seeds {42, 43, 44}.

## 3. Why the strict metric misfires here

Start is (1, 1), goal is (6, 6), Manhattan = 10. But **Q1 mean distance is only ~2.0**. That means within the first 150 steps, the agent already navigates most of the way to the goal. So the Q1→Q4 delta metric (designed for 1D's slower convergence) has very little room to move: the agent can't improve by 10 more positions when it's already at 2 in Q1.

A more honest metric is **mean Manhattan distance across the whole episode**. Random-policy baseline: uniform random actions on an 8×8 grid give mean ~7 (half the grid diameter). Observed: **1.68, 1.81, 1.97** across seeds. **All three seeds are ~3–4× better than random.** That is unambiguously learning.

## 4. What's happening — action-count asymmetry

Look at the per-seed action distributions:
- Seed 42: N=226, E=287, S=85, **W=2**.
- Seed 43: N=144, E=319, S=49, W=88.
- Seed 44: N=324, E=197, S=65, W=14.

The agent picks N and E heavily and picks S and W rarely. This is not a bug — it's a consequence of the task:

- Going N from (1, 1) moves toward goal. +1 reward → potentiate hidden→N, depress others.
- Going E from (1, 1) moves toward goal. +1 reward → potentiate hidden→E.
- Going S or W from (1, 1) clips to boundary, dist unchanged → reward = 0, no update.
- Once the agent is in the NE half of the grid, N and E continue to be right answers most of the time.

So the early learning is self-reinforcing in the direction that happens to be right, and S/W barely get exploration. This is fine for *this particular goal location* but means the policy isn't truly position-dependent — seed 42 would probably fail if the goal moved to (1, 6) or (6, 1) mid-episode.

## 5. Seed-specific stories

- **Seed 42**: never reaches exact goal (dist=0 count is 0). Hovers at distance 1.7–1.8 — the Manhattan "ring" one step from goal. With only 2 W actions across 600 steps, it can't correct when it overshoots to x=7, y=anything.

- **Seed 43**: best-performing. 32 goal hits, first at step 66. Action counts most balanced (at least 88 of every direction except S). Good initial-weight luck led to a policy that actually explores all four directions.

- **Seed 44**: slow starter (first goal at step 246) but 4 eventual hits. Still converges near goal by Q4. Decay LR schedule kicked in for only the last 354 steps.

## 6. Interpretation

The gate as written is not cleanly met. But the underlying task — "navigate from (1,1) to near (6,6) in a 2D world using only a signed reward signal" — is demonstrably learned:
- 3/3 seeds' final mean distance ≪ random baseline.
- Reservoir untouched, infrastructure stable.
- Runner rule B (rejection-hedged signed perceptron) generalizes the 1D approach to 4 actions without leaking oracle information.

The main weakness is the action-count asymmetry: the agent's policy isn't uniform over the state space, it's specialized to the particular start/goal geometry. To test true position-dependence you'd need a mid-episode goal change, which is G7 or G6.v2 territory.

## 7. Two candidate G6.v2 tightenings

Either of these should convert this PARTIAL into a strict GO without much work:

**A. Rule C (axis-decomposed reward).** Compute `target_directions = {N or S depending on sign(goal_y - y), E or W depending on sign(goal_x - x)}`. On reward<0, potentiate both directions in `target_directions`, depress the other two. Leaks goal-direction info but produces sharper per-step signal. 2/3 or 3/3 seeds should then pass the +1.5 Q1→Q4 bar.

**B. Start further from goal, smaller Q1 window.** Start at (0, 0) instead of (1, 1), measure Q1 over only steps 0–50 (instead of 150) to capture the initial random-policy regime. Random-policy mean distance in a 50-step Q1 should be closer to 10, giving the metric room to move.

**C. Ensure all four actions get early exploration.** Add an epsilon-greedy action selector (ε=0.2 for the first 100 steps, then ε=0 for argmax). Forces some S/W experience even from (1, 1).

My pick for a quick G6.v2: **C** (epsilon-greedy exploration). Keeps the learning rule clean, directly addresses the action-count asymmetry observed in seed 42. Alternative is to accept G6 as PARTIAL and move to a more ambitious gate (e.g., G7 moving goal).
