## What 2.4 is (and what it deliberately is NOT)

A competent speaker tracks what is **mutually known** (common ground) vs what only **they** know (private), and
tailors what they SAY to it — don't re-explain what the listener already knows; volunteer what's new (Clark &
Brennan 1991 grounding; Duff & Brown-Schmidt 2012 — common ground is hippocampal/declarative; Stephens-Silbert-
Hasson 2010 speaker-listener coupling is its inter-brain signature). **Audience design = volunteer PRIVATE,
suppress/acknowledge SHARED.** It needs **no recursive belief reasoning** — only a single-bit-per-fact listener
model (shared vs private) + a read at response time.

**HONEST BOUNDARY (NOT claimed):** this is the *minimal* slice — a one-bit-per-fact listener model — NOT full
theory-of-mind / false-belief (the recursive Bayesian agent-modelling wall; a divergent BELIEF store / Sally-Anne;
RSA implicature). Those remain the deferred, research-gated frontier above this (front-2 §3/§6). We claim
audience design, not a "ToM".

## The mechanism it COMPOSES (the proven polarity/negation tag — no research gate)

`RFPhasorComposer` already binds a **polarity** role (AFFIRM/NEGATE) onto a stored fact, cleaned ONLY against a
2-word tag codebook (`pol_words`, `rf_phasor_composer.py:159-162, 528-544, 802-822`), and reads it back at query
time (`ask_yes_no` → 'yes'/'no'). Common-ground is the **same pattern at a new role**: a SHARED/PRIVATE tag bound
onto each fact (cleaned only against `cg_words = ['SHARED','PRIVATE']`) on a dedicated `commonground` role (so it
composes independently of negation), read at response time to decide audience design. PLUS the no-confab moat: a
never-stored cue reads tag=None (abstain — the *clarification trigger*, not a guess); never fabricate a fact OR a
tag.

The tag bind/unbind run through the parent's RF resonate-and-fire ops (`_bind` / `_unbind_phases` → `_resonate`),
so on the spiking substrate the tag is bound/read **in spikes** — exactly as the validated polarity tag is.

## An actual audience-design example (the real composer, seed 42)

```
Listener model:           dog go north [SHARED]   cat run south [PRIVATE]
                          dog look river [PRIVATE]  cat stop east [SHARED]

describe 'dog':  [acknowledge] "as you know, dog go north"     ← SHARED → don't re-explain, acknowledge
describe 'cat':  [volunteer]   "cat run south"                 ← PRIVATE → volunteer (it's informative)

per-fact volunteer decision (tracks the tag):
  dog go north   [SHARED ] → SUPPRESS (shared → already known)
  cat run south  [PRIVATE] → VOLUNTEER (private → tell)
  dog look river [PRIVATE] → VOLUNTEER
  cat stop east  [SHARED ] → SUPPRESS

moat: read_common_ground(dog,stop,small) = None  (never stored → no fabricated tag; query abstains)
```
`research/runners/common_ground_composer.py --console`.

## Result — 6 seeds (42/43/44/100/101/102), balanced 4-SHARED / 4-PRIVATE corpus, D=64

Audience-design score = fraction of facts whose VOLUNTEER/SUPPRESS decision matches correct audience design
(tell private, suppress shared). On a balanced 50/50 corpus a **tag-blind** speaker (must tell-all OR suppress-all)
maxes at **0.50** (it gets one class right, the other wrong). Chance for the moat tests = abstain.

| metric (6-seed aggregate) | value | meaning |
|---|---|---|
| **audience design (read the bound tag)** | **1.000** | volunteer private + suppress shared, every fact, every seed |
| no-tag baseline (best of tell-all / suppress-all) | **0.500** | gap **+0.500** ≫ the +0.25 bar — the tag is what makes audience design possible |
| **PERMUTED-tag** (read a scrambled fact's tag) | **0.464** (≈ chance) | the behavior follows the REAL tag, not chance |
| **LESION the tag** (sever the role read → None) | **0.500** | degrades to the tag-blind baseline — the tag is **load-bearing** |
| tag fidelity (the bound tag reads back) | **1.000** | the SHARED/PRIVATE marker recovers faithfully (the polarity-read mechanism) |
| **moat — no fabricated tag** (full-SVO never stored) | **0 FA** | a never-stored fact reads tag=None — incl. right-cue/wrong-patient ('dog go cold' vs stored 'dog go north') |
| **moat — query abstains** (unstored (agent,action)) | **0 FA** | the underlying who/what query abstains on an absent cue |

Every seed is identical: real 1.000, no-tag 0.500, permuted ≈ chance (0.41–0.50), lesion 0.500, tag fidelity 1.000,
moat 0/0. **6/6 GO.**

## Reading it honestly (the burned-project bar)

- **The anti-cheats ARE the result.** An audience-design score a tag-blind policy also achieved would be vacuous.
  Here the real read beats the no-tag ceiling by **+0.50** (the maximum possible on a balanced corpus); the
  **permuted-tag control collapses to chance** (the decision follows the *real* tag); **lesioning the tag drops it
  exactly to the tag-blind baseline** (the tag is decisively load-bearing); the moat never fabricates a tag or an
  answer.
- **Why the no-tag ceiling is 0.50, not chance.** A tag-blind speaker on a 50/50 SHARED/PRIVATE corpus can only
  apply a fixed policy: tell-everything gets the 4 private right (0.5), suppress-everything gets the 4 shared right
  (0.5). It *cannot do better* without reading the tag — which is exactly the point: audience design REQUIRES the
  listener model. The +0.50 gap is the whole capability.
- **The moat became the clarification trigger.** A never-stored fact reads tag=None and `should_volunteer` returns
  None — i.e. "I don't have a listener model for this" → an abstain/clarify branch, never a fabricated tag. This is
  the same no-confab discipline the project enforces, extended to the tag (per
  [[feedback_moat_not_hard_lossy_memory_ok]] the abstain is informative, not mute).
- **Honest scope.** A one-bit listener model (shared vs private) over well-separated concepts. NOT a divergent
  belief store (Sally-Anne), NOT implicature/RSA — those are the deferred recursive-agent-modelling walls. The tag
  is host-SET at store time in this de-risk (the listener model is given, as the de-risk grounds it); a LEARNED
  common-ground ledger (updated at each accepted contribution, Clark grounding) is the natural follow-on. The
  *mechanism* (bound tag + read + audience design + moat) is what is validated here, and it is brain-based (the
  RF bind/read), not a host shortcut.
