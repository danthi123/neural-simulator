# GNW N-organ ignition bus — a default-OFF SHADOW path added to production `brain_chat` (the one-substrate first wiring, host NOT yet replaced)

## What this closes (faculty-map T1-1, Phase-C first wiring)
The audit's #1 structural lever is that the co-resident organs in the production chat are combined by HOST PYTHON, not by the substrate: `ChatBrain.gate()` (reached from `webapp/server.py::brain_chat`) snapshots a spiking recall, a reverse-binding VERIFY and a router fallback and fuses them with an `if recalled == p` (design: `docs/plans/2026-08-13-gnw-norgan-bus-production-wiring.md`). The de-risked GNW N-organ ignition bus (`research/runners/_gnw_norgan_bus_derisk.py`, finding `2026-08-13-gnw-norgan-ignition-bus-substrate-combines-N-organ-reads.md`, 6/6 GO) proved the SUBSTRATE can combine N>=3 subthreshold organ reads via consensus-ignition + shared-inhibition WTA + re-entry. This finding WIRES that bus into production — as the SAFE FIRST step: a default-OFF SHADOW path that re-derives the host decision and reports agreement, WITHOUT removing the host orchestration.

## The wiring (additive, default-OFF, byte-identical when off)
- `webapp/gnw_bus_shadow.py` (new, reuse-by-import of `build_workspace_bridge` / `_ignite_and_read` / `norgan_hop` / `D_SUB_UNANIMITY` / `_pick_decoy` from the de-risk runners — NO `sim/` edit). `shadow_report(chat, question, host_gate_svo)` takes the SAME real organ reads `gate()` combines and routes them through ONE warm spiking workspace: organ A = spiking RECALL `composer.query_patient(a,v)` (gate organ 1); organ B = VERIFY re-check (gate organ 3); organ C = reverse-binding VERIFY `composer.query_agent(v, cand) == a` (a genuinely distinct substrate read). Three corroborating subthreshold votes ACCUMULATE on the patient's slot and IGNITE it; a decoy carries one vote and is WTA-suppressed; a primary-recall miss = no ignition = abstain (the moat becomes a substrate property). The committed spiking winner is the bus's decision, compared to the host's.
- `webapp/server.py::brain_chat` (single-fact `rich=False` path): when the env flag `BRAIN_GNW_BUS` is truthy, after the host `gate()` runs, the handler calls `shadow_report` and attaches a `gnw_bus` block (host-vs-bus decision + agreement). DEFAULT-OFF: with the flag unset the guard short-circuits BEFORE any import, `gnw_bus_info` stays `None`, and the response carries NO `gnw_bus` key — byte-identical to today. The host `gate()` is never modified or bypassed; the shadow is read-only and can only RE-DERIVE the host decision (moat-safe; it can add abstentions, never invent a fact). The bridge is process-cached (built once on the first enabled turn, kept warm across turns).

## Verified — numpy-CPU, through the REAL production stack (`research/findings/raw/_gnw_bus_shadow/production_verify.json`, runner `research/runners/_gnw_bus_shadow_production_verify.py`)
The runner builds the REAL production ChatBrain (`webapp.server._build_chat_brain("tiny-demo", ...)`, rf recall) and drives the EXACT shadow code path the handler runs (`gate_svo = chat.gate(msg); shadow_report(chat, msg, gate_svo)`), plus a real-handler on/off comparison. VERDICT GO:
- **(A)+(C) AGREEMENT + MOAT: 9/9 = 1.000.** On 5 stored turns the bus IGNITES the exact patient the host recalls (`dog chase -> cat`, `cat eat -> fish`, `brain use/learn/store -> spikes/words/memory`; organ reads all three agree). On 4 abstain turns (`dog eat`, `cat chase`, `fish fly`, `ball roll`) the host withholds AND the bus withholds (primary-recall miss -> no ignition) — the substrate reproduces the no-confab moat.
- **(B) LESION-LOAD-BEARING (the production honest-negative).** For `cat eat -> fish`: the intact bus commits `fish`; the bus built with the workspace assembly self-recurrence zeroed (`bus_combine(lesion=True)`) COLLAPSES to `None` (cannot ignite); the forward-recall reflex (`composer.query_patient`, never routed through the workspace) STILL returns `fish`. The dissociation proves the SUBSTRATE, not a residual host read, is doing the combination.
- **(D) BYTE-IDENTICAL-WHEN-OFF (real `brain_chat` handler).** A turn with the flag OFF carries no `gnw_bus` key; with the flag ON every OTHER response field (answer / recalled_svo / verified / abstained / all Gate-B organ blocks) is byte-identical to the off response. The host still authors the answer.
- **Canonical smoke unregressed.** `brain_chat_tui --smoke` (which never touches `server.py`) is unaffected — the wiring is confined to `server.py` (additive, flag-gated) + two new files; `ChatBrain.gate()` is untouched.

## Honest status — what this is and is NOT
This is a SHADOW/verification wiring, DEFAULT-OFF. It PROVES the substrate can combine the live organs' reads via ignition and reproduce the host decision; it does NOT yet replace the host orchestration. Per the wiring design's flip criterion (`docs/plans/2026-08-13-gnw-norgan-bus-production-wiring.md` §4) the bus stays **de-risked / shadow**, NOT **closed**, until: the 6-seed de-risk holds AND `gate_via_bus` reproduces the host decision on the full console fixture across all seeds AND the lesion collapses in the production ChatBrain (done here for the shadow) AND the byte-identical-when-off + moat-superset tests pass — after which the default flips ON and the host `if recalled == p` is demoted. RESIDUALS (the reason this is a first wiring, not closure): (1) the host `gate()` STILL authors the production answer — the bus only shadows it; (2) organ B (VERIFY re-check) is the same forward-recall call as organ A, so the effective distinct consensus is recall + reverse-VERIFY (faithful to `gate()`, whose organ 1 and organ 3 are the same `what_does` call), with reverse-VERIFY the one genuinely-independent substrate read — it agreed on 5/5 production facts here, but a fact whose reverse binding is non-unique would make the bus more conservative than the host (a moat-strengthening abstention, not a confabulation); (3) the shadow is wired on the single-fact (`rich=False`) path where `gate()`'s combination is directly exposed — the rich multi-sentence path is a follow-on; (4) the workspace bridge is a co-resident P1.2 build (rides the one-brain merge, burn-down #1).
