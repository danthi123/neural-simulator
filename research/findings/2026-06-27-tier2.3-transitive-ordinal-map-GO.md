## 1. What was built (the mechanism, option a)

A 7-item total order **A>B>C>D>E>F>G**. Train **ONLY** the 6 adjacent premise pairs (A>B, B>C, …, F>G). Infer the order of the **15 held-out, never-trained non-adjacent pairs** (B?D, C?F, A?G, …) by **comparing the two items' learned map positions** — the order is read from the learned GEOMETRY, not from a stored edge.

- **The embedding (the learned ordinal axis).** A **Betasort-style ASYMMETRIC ordinal update** (Jensen 2015; Ciranka 2021 *Nat Hum Behav*): each adjacent (Hi, Lo) presentation nudges Hi UP and Lo DOWN, the LOWER member updated by `asym=0.5` × the higher's amount. The asymmetry is what makes the learned axis **transitive** rather than merely associative (a symmetric/associative objective gives the documented associative-model failure: chance on non-adjacent pairs). Near-degenerate random start → the structure is **learned**, not wired. This is a **change of objective** on the project's rate-Hebbian population-code machinery, not a new substrate.
- **The comparison (on real spikes).** The two items' positions become input currents into a clean **Wang-2002 / Usher-McClelland TWO-POOL spiking accumulator** on a real `SimulationBridge` — two NMDA-recurrent excitatory pools (`acc_X`, `acc_Y`) with mutual FS cross-inhibition (`fs_X→acc_Y`, `fs_Y→acc_X`), OU membrane noise. This is the **same mechanism family** as the GO nav commit-burst (`2026-06-19-spiking-decision-default-on-GO.md`), reduced to two competitors. The pool driven by the higher position wins; the decision **margin** = the spiking rate difference `|cx−cy|/(cx+cy)`.

## 2. The decisive evidence — THE SYMBOLIC-DISTANCE EFFECT

**Why it is the whole point.** A lookup table / memorized edge-set has a *binary* truth value per pair → a **flat** accuracy/margin-vs-distance curve. A co-occurrence-similarity artifact (the retracted mechanism) orders by raw overlap, unrelated to ordinal distance → no monotone rise. A learned **metric map**, read by comparison, produces accuracy AND margin that **increase monotonically with ordinal distance** (adjacent pairs HARDEST, far pairs EASIEST) — the empirical, neurally-measured signature (Park 2020; Nieder rank neurons; the hippocampus-TI distance studies). A monotone-rising curve is a **positive, falsifiable signature** that a metric map exists and is being read.

Strictly increasing — the map's intrinsic distance signature. (Host accuracy is a degenerate flat 1.0 because the oracle is noiseless; the accuracy-distance effect lives on the spiking path below.)

## 4. Honest scope, caveats, residuals

- **What this is:** transitive inference over a **single trained ordinal axis** of 7 items (the classic 5–7 item TI ladder; Park used 16), realized as a learned 1-D map + a spiking comparator, with the symbolic-distance effect as the believability anchor. Reuse-by-import; **NO `sim/` edit**.
- **The host accuracy curve is flat at 1.0** (rho_acc = 0) — NOT a failure: the noiseless host oracle is a perfect comparator, so its distance effect lives in the *margin* (the graded confidence). - **The lesion is a noisy single-scramble per seed** (0.07–0.87 across seeds; 7! has permutations that happen to preserve much order). At zero representational noise the spiking accumulator is so reliable that accuracy ceilings at 1.0 (the distance effect then lives only in the margin); the noise is the faithful Nieder-tuning-overlap mechanism that surfaces the accuracy effect.
