# Zero-shot NEURAL composition: never-taught combinations recalled from primitives seen elsewhere (6-seed GO)

**2026-08-09.** Target: the DEFINITIVE test of the compositional lever — the one advantage a fixed
(non-compositional) generator provably cannot have. The compositional generator (`e4417698d`, PARTIAL-GO) stores
`P=K1+K2` PRIMITIVE engrams (sub-linear `O(sqrt(N))`) and regenerates a fact by NEURAL SUPERPOSITION of its two
primitive spiking-readout outputs. Its honest headline negative there: at small low-rank `N` it is NOT a retention
WIN over a fixed generator, because low-rank facts fit a fixed readout too. **ZERO-SHOT COMPOSITION separates them:
regenerate + recall a combination NEVER taught as a fact, from primitives each seen only in OTHER combinations.**

**Verdict: GO, 6/6 seeds, both grids.** Held-out (zero-shot) recall: **compositional 1.00** vs the two floors near
chance — fixed non-compositional generator (v2) **0.03 / 0.06**, flat `O(N)` instance store **0.03 / 0.00** (chance
0.040 at 5x5, 1/36 at 6x6). Taught-set (seen) recall 1.00 (sanity — it still recalls what it was taught). The
composition is NEURAL (lesion on the held-out facts localises perfectly), 0 stored raw patterns, ruler untouched,
substrate byte-identical, `sim/` clean.

This is the mission core made mechanical: **compositional generalization = the composer, biologized.** The
spiking-superposition generator IS a biological VSA bundling composer, and it generalizes to unseen bindings the
way a per-item store cannot.

## What was built (brain-based, no sim/ edit, additive)

`research/runners/_teacher_loop_zeroshot_composition_derisk.py` — reuse-by-import of the compositional generator
+ its compositional WORLD + neural `regenerate()` + the lesion-localisation check
(`_teacher_loop_compositional_generator_derisk`), the fixed v2 generator as the FLOOR
(`GenerativeReplayNetV2`), the scaling teacher machinery (`_corrective_batch`, `N_ACT`), and the byte-identical
+ `sim/`-clean asserts (`_teacher_loop_cls_two_store_derisk`). No `sim/` edit.

- **Held-out split (coverage-preserving).** `_heldout_split(K1,K2,m,seed)` greedily holds out a cell ONLY if its row
  and column each keep >= 1 taught cell — so every held-out primitive (its `a` AND its `b`) still appears in >= 1
  TAUGHT combination. 5x5: 5 held out; 6x6: 8 held out. Deterministic per seed.
- **Three arms, taught on the TAUGHT set ONLY:**
  - `compositional_gen`: learns one primitive engram per distinct attribute value; held-out `(a,b)` regenerated by
    NEURAL SUPERPOSITION of primitive-`a`'s and primitive-`b`'s spiking readouts.
  - `noncompositional_v2` (FLOOR): the fixed generator addresses facts by CLASS INDEX; a held-out class was never
    trained → untrained near-anchor readout → chance.
  - `flat` (FLOOR): an `O(N)` raw-engram buffer keyed by class index; no entry for a held-out class → it can only
    ever output a TAUGHT fact → best strategy is a uniform guess = chance.
- **Recall = arm-symmetric.** Every arm produces a reconstruction; recall = regenerate the percept, then
  NEAREST-PROTOTYPE identify it among ALL `N` true prototypes (chance `1/N`). Measured for BOTH the taught set
  (sanity) and the held-out set (zero-shot).

## The composition at test is NEURAL (not a host algebra)

Held-out regeneration calls `CompositionalGenerator.regenerate(a,b)`
(`_teacher_loop_compositional_generator_derisk.py:239-254`): two `self._elig(addr)` spiking-reservoir forwards
(`_res._forward_record(_res._query_code(addr))` → whitened spike eligibility) and a SUM of the two leaky-readout
population outputs on disjoint channel blocks — bundling/superposition, never a lookup. The lesion check runs on
the HELD-OUT facts specifically: zeroing primitive `a`'s engram breaks ONLY the A block (delta 1.63) and spares
the B block (delta 0.00); zeroing `b` breaks ONLY the B block (1.75) and spares A (0.00). Each block is carried
by a distinct neural engram → the zero-shot percept is genuinely COMPOSED by spikes.

## Why the floors are at chance (the honest reason it works)

v2 and flat both address memory by FACT IDENTITY (class index). A held-out combination is a distinct item they
never saw; there is no constituent path from "primitive `a` and primitive `b`, each seen elsewhere" to the item.
The compositional generator's store IS the constituents, so a never-seen binding is one superposition away. This
is exactly the TERMS condition for `compositional`: the design DISTINGUISHES constituent-construction from a
per-item code, and the fact set is not disjoint-constituent (a single primitive does not identify the cell — you
need both). The zero-shot split is that distinguishing test.

## Anti-cheats (all asserted in the artifacts)

- taught/held-out DISJOINT; every held-out primitive seen in >= 1 taught combo; NO leakage (the held-out fact
  index never entered any training path — `env.proto` of a held-out fact is read only by the test-time
  nearest-prototype RULER). All True, all seeds.
- composition NEURAL (lesion localises on held-out); 0 stored raw patterns (`compositional_stored_raw_patterns==0`);
  ruler untouched (`compositional_used_ruler==False`).
- `cfg.seed` byte-identical substrate (asserted in-data, not `actual_seed_used`); de-clamped `bdsp_wmax=1e9`;
  `git diff main -- sim/` empty; backend numpy recorded.
- honest-negative diagnostic wired (a comp miss is classified low-cos = binding interference vs high-cos = code
  collision); 0 misses on every seed, so neither failure mode fired.

## Scope / what this does and does not claim

- It DOES show the spiking-superposition composer generalizes zero-shot to never-taught bindings while the two
  non-compositional stores sit at chance — the definitive compositional advantage, 6/6, two grids.
- It does NOT claim a retention win at scale (that is the sub-linear-store leg, `e4417698d`); the world is a
  clean concat-of-primitives (host-legit render), so the composition is near-exact — the point being that ONLY the
  compositional code can exploit the shared structure, not that the world is hard.
- Next: a NOISIER / non-linearly-mixed composition world (primitives interacting on shared channels) to stress the
  superposition, and routing zero-shot held-out facts through the slow-cortex consolidation loop (not just
  generator-nearest-prototype) to show downstream recall inherits the composed engram.
