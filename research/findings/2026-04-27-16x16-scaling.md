# 16×16 Spatial Scaling Test — system scales but recipe needs re-tuning

**Date:** 2026-04-27 (Item 2 from session priority list)
**Status:** **PARTIAL** — architecture scales cleanly (1251 neurons, 70K synapses on 16×16), but the curriculum recipe tuned for 8×8 underperforms baseline at the larger scale.

## TL;DR

Tested whether the recommended recipe (sensory + hippo + curriculum) generalizes
from 8×8 to 16×16 grid. Architecture scales fine; recipe doesn't beat baseline.

| Grid | Baseline (heuristic only) | Recipe (sensory+hippo+curriculum) | Recipe vs baseline |
|---|---:|---:|---|
| 8×8 (6-seed) | 5.88 | 4.63 | -21.3% (recipe wins) |
| 16×16 (3-seed) | 4.44 | **5.26** | **+18.5% (recipe loses)** |

Per-seed 16×16 recipe:
- seed 42: sum 6.20
- seed 43: sum 3.56 (still very good!)
- seed 44: sum 6.04
- avg: 5.26 ± 1.21

## Why the recipe doesn't scale (default params)

Several factors:
1. **Sparser learning per cell.** 256 hippo cells (vs 64 on 8×8) but same training
   time. Each cell fires less often; weight growth per cell is slower.
2. **Larger task distances.** Phase 1 goal flip on 16×16 is from (14,14) to
   (1,14) — agent must travel ~13 units west. The cumulative readaptation
   challenge is larger.
3. **Same warmup_steps (600)** but more places to "explore". Curriculum's
   benefit is proportionally smaller.
4. **Heuristic naturally scales better.** The heuristic "if gx > x: cortex_E"
   provides equally clean signal at any grid size. Plastic layers don't get
   the same scale-invariance.

## What worked

- **Smoke test passed** (16×16 builds with 1251 neurons / 70619 synapses, no
  crashes, correct goal scaling).
- **Seed 43 actually improved over baseline** (sum 3.56). Architecture is
  capable; just inconsistent at 16×16 default params.
- **Heuristic-driven baseline is fine on 16×16** (sum 4.44, comparable to
  8×8 baseline 5.88). The fundamental architecture works at scale.

## Architecture changes for scaling

```python
# CLI flags:
--grid-size 16
--n-hippocampus-per-layer 256

# Place/goal cell layouts auto-scale:
hippo_pref_x[i] = (i % side) * scale  # side=sqrt(n), scale=(grid_size-1)/(side-1)
hippo_pref_y[i] = (i // side) * scale

# Goal positions scale automatically:
far     = (grid_size-2, grid_size-2)  # was (6,6) on 8x8
far_west = (1, grid_size-2)           # was (1,6)
sw      = (1, 1)                       # was (1,1)
far_se  = (grid_size-2, 1)             # was (6,1)
```

## Decision

- The recipe is now configurable for any grid size via CLI flags. Default
  is 8×8 (preserves backward compat).
- For 16×16+, need re-tuning — likely longer warmup_steps, longer total
  n_steps, possibly higher learning rate or higher initial input weights.
- Don't recommend the recipe at 16×16 without re-tuning. Use baseline.
- Future work could explore: scale-invariant tuning, adaptive curriculum
  duration, or cell-density independent of grid_size.
