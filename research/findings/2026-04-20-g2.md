# G2 Findings — Sim-local plasticity bends the learning curve

**Date:** 2026-04-20 (autonomous continuation)
**Gate:** G2 — does sim-native STDP improve features epoch-over-epoch vs the v3 frozen-reservoir baseline?
**Verdict:** **NO-GO on the strict gate criterion.** One pass of STDP gives a big lift over the v3 baseline (87.5% vs 71.3%), but subsequent epochs erode it slightly (87.5 → 85 → 85 → 82.5 → 80). So "more STDP training" does *not* bend the curve up on this task with this rule. Rich finding, not a clean pass.

---

| 1 | 0.720 | 1.663 | [1.35, 1.92] | 22.1 Hz |

Curve is **essentially flat at 0.68** — the v3 baseline level for these initial weights. Weights saturated to mean ~1.65 by epoch 0 and barely move after.

### G2.b — asymmetric STDP (A+ = 0.012, A- = 0.010), homeostasis flag on (gated off in practice)

| Epoch | test_acc | W mean | W range | hidden rate |
|-------|----------|--------|---------|-------------|
| 0 | **0.875** | 2.064 | [0.83, 2.87] | 66.1 Hz |
| 1 | 0.850 | 2.077 | [0.87, 2.84] | 70.0 Hz |
| 2 | 0.850 | 2.070 | [0.84, 2.87] | 70.3 Hz |
| 3 | 0.825 | 2.068 | [0.79, 2.88] | 69.4 Hz |
| 4 | **0.800** | 2.068 | [0.79, 2.87] | 70.2 Hz |

Curve bends **downward** (−7.5 pp from epoch 0 to epoch 4). But absolute level is much higher than G2.a because of asymmetric STDP's LTP bias: weights grew wider (range [0.79, 2.87] vs [1.20, 1.96]) and hidden rate tripled (70 Hz vs 22 Hz), giving LogReg much more informative features.

## 2. Why homeostasis didn't fire

I set `enable_homeostasis=True, homeostasis_target_rate=0.003` (3 Hz target). It had no effect because `SimulationBridge._run_one_simulation_step` sets `_homeostasis_gated = False` when an experiment engine is running. That gating was added for the biological-experiment suite to prevent the associative-conditioning US-neuron saturation; it's correct for that use case but blocks research runners from using homeostasis during training.

Not fixing here — respecting the "don't ruin biological science work" constraint. A future pivot would be to add a runner-opt-in flag that bypasses the gate.

## 3. Interpretation — why the curve bends down in G2.b

Plausible mechanism: initial STDP-driven weight changes during epoch 0 create class-selective receptive fields (hidden neurons specialize to the patterns presented). On each later epoch, the same neurons are presented the *same* patterns again, but now their post-firing state encodes the prior specialization. Pre-before-post pairings become less informative (both are already correlated with the input pattern), and the symmetric LTD term progressively depresses weights that carry true class signal, pulling features back toward a generic pattern.

Put another way: STDP's "first pass" discovers class-relevant weights. Without a task-level signal to reinforce those specifically (vs. spurious co-activity), continued exposure washes them out.

## 4. What G2 tells us for G3+

- STDP **improves features** relative to frozen reservoir (87.5% vs 71.3% baseline).
- STDP **does not continue improving** features with more epochs under the current rule.
- The gate criterion "test_acc climbs" is not met, but the *absolute* test accuracy with STDP on (85%+) is well above the G1 GO threshold of 55%.

For G3 (persistence), this is fine: we save a checkpoint mid-training, resume, and confirm the trajectory matches. Whether the trajectory is flat or declining, the persistence test is about whether the resumed run tracks the clean run.

For a future G2.v3, options (not pursued today):
- **R-STDP with SIGNED eligibility traces.** Current sim eligibility is unsigned `|delta_w|`, which limits reward-based learning. Would require a bridge modification.
- **Homeostasis during training.** Requires bypassing the experiment-engine gate.
- **External perceptron delta on the readout-relevant synapses.** We've been re-training LogReg each epoch — the *LogReg* improves, but that's external and doesn't count as sim-local learning.
