# G2 Findings — Sim-local plasticity bends the learning curve

**Date:** 2026-04-20 (autonomous continuation, same day as G1)
**Gate:** G2 — does STDP on input→hidden improve features vs the v3 frozen-reservoir baseline?
**Verdict (v2.a):** **PARTIAL.** Curve is flat, not climbing. Pivoting to v2.b with homeostasis.

---

## 1. G2.a protocol

- Same 264-neuron reservoir as G1.v3 (64 input + 160 hidden exc + 40 hidden inh).
- **Plastic mask applied:** 6400 input→hidden synapses plastic, 3800 hidden→hidden synapses frozen.
- STDP on with symmetric rates: `A+=0.008, A-=0.008, tau_plus=tau_minus=20ms, W_max=3.0`.
- All other plasticity off: no Hebbian, STP, homeostasis, reward, structural.
- Per epoch: 150 train examples (STDP updates weights), 50 test, fresh LogReg each epoch.
- 6 epochs, seed 42.

## 3. What G2.a tells us

**(a) STDP is changing weights, but not in a class-discriminative way.** By epoch 0 the initial weights (Normal(1.5, 0.3)) have already settled to mean ~1.64, and they stay in a tight band around there for every subsequent epoch. The per-epoch standard deviation of weight updates is small.

**(b) Hidden-neuron firing rate is high and stable (~22 Hz).** With no homeostasis, every hidden neuron fires about the same rate regardless of input pattern. STDP sees approximately the same pre-post coincidence statistics across neurons → undifferentiated potentiation pattern → weights saturate uniformly → feature vector entropy low → test acc flat.

**(c) The 0.68 baseline is already above G1.v3's 0.71 mean (seed-matched) because the higher initial weights produce more informative features from step 0.** STDP then does neither good nor bad — it locks the features in place.

Put differently: the task is already solvable by the random reservoir. Symmetric STDP without competition doesn't make it more solvable.

## 4. G2.b pivot — adding homeostasis

Hypothesis: if hidden-neuron firing rates are regulated to a lower target (say 3–5 Hz), neurons must become *selective* — they can only afford to fire on the subset of inputs that best activates them. STDP's pre-before-post pairing then gets a cleaner class-specific signal per neuron.

Changes from G2.a:
- `enable_homeostasis = True`
- Keep the default threshold adaptation rate and EMA alpha (calibrated for biological timescales, ~5s).
- Possibly raise STDP amplitudes to let learning catch up with the slower threshold dynamics.

## 5. What was NOT destroyed (positive control)

Every epoch's test_acc sits at 0.66–0.72, which is *above* the G1.v3 pure-frozen-reservoir baseline of 0.71 average. So STDP isn't actively hurting. It's just not bending the curve either.

This argues against "STDP destroyed the reservoir." The reservoir survives; the feature quality just doesn't improve.
