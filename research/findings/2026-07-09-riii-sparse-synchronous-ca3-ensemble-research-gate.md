## (MOVE a) ISOLATE THE TRUE RESIDUAL — sparsity vs synchrony vs both

The prior finding established the two symptoms: (i) SPARSITY 35-47% of 150 CA3 cells fire (a distributed code, not the ~2-5% Marr sparse code), and (ii) members fire <14% of steps and ASYNCHRONOUSLY. It called both "the ensemble dynamics." This gate pins the SINGLE ROOT CAUSE.

**The smoking gun — CA3 receives only excitation:**
- `ca3` region: `exc_fraction=0.85, internal_density=0.0` (`text_minimal_isolation.py:712-719`). The 15% inhibitory CA3 cells physically exist in the slice but `internal_density=0.0` means they form **no internal synapses** — dead weight. CA3 has no intrinsic E-I loop.
- Pathways INTO ca3: `dg→ca3` mossy, density 0.10 / weight 8.0, EXCITATORY (`:1110-1115`); `ca3→ca3` recurrent, density=`ca3_recurrent_density` / weight=`ca3_recurrent_weight`, EXCITATORY (`:1125-1131`). **No inhibitory pathway targets ca3.** (Grepped exhaustively; the only FS basket in the loop is `dg_pv_basket`, which targets DG, not CA3.)
- The harness amplifies this: `run()` defaults `ca3_density=0.5, ca3_weight=6.0` (`_riii_ca3_attractor_diag.py:21`), whereas the builder default is `ca3_recurrent_density=0.30, ca3_recurrent_weight=1.5` (`text_minimal_isolation.py:225-226`). So the diagnostic runs recurrent excitation ~1.7x denser and ~4x stronger than the region's own design point — maximally de-sparsifying.

**Why this single cause produces BOTH symptoms.** With no inhibition to oppose it, the dense recurrent excitation is a positive-feedback amplifier: an initial mossy-driven seed (~15 cells) recruits its recurrent partners, which recruit theirs, spreading to 35-47% of the pool (the sparsity failure). And because cells cross threshold whenever their accumulating excitation happens to peak — with nothing to reset the population together — they fire at scattered times (the asynchrony). A feedback-inhibition (E→I→E) loop is the ONE mechanism that fixes both at once: the interneurons fire *proportional to the excitatory population*, so they (a) shut down all but the strongest-driven cells → a fixed small active count (sparsity / soft k-WTA), and (b) impose a global silence-then-release rhythm → the survivors fire in synchronous volleys (PING gamma). 

**Conclusion (move a):** the residual is not "sparsity" or "synchrony" as two separate problems — it is **one missing circuit element, CA3 feedback inhibition**, whose two consequences are the two observed symptoms. This is the honest, single-variable reframe the cheap-first ladder attacks.

## (MOVE b) REFRAME — how real biology makes a sparse, synchronous CA3 ensemble

**Kandel 6e Ch 54 (READ in full-text, pp. 1357-1361):**
- Pattern separation / sparse code (pp. 1359-1360): "*expansion recoding, in which distinct firing patterns are formed through the projection of a limited number of inputs onto a larger population of synaptic target cells*" — DG makes the code sparse & orthogonal, then delivers it to CA3. Catalog **D.12** makes the sparsity quantitative: "*DG granule cells (very sparse activity, ~2-5%)*" with "*strong feedforward inhibition for sparsification*" (feature-catalog.md:1227-1231; Kandel pp 1357-1360).
- Pattern completion / CA3 LTP (pp. 1360-1361): Marr 1971 — "*when a memory is encoded, neuronal activity patterns are stored as changes in connections between active CA3 cells*"; retrieval reactivates "*the entire original neural ensemble ... because of the strong recurrent connections between the cells of the ensemble.*" CA3-NMDA-KO abolishes recurrent LTP → partial-cue recall fails but full-cue spared. **The store is Hebbian LTP among cells that are ACTIVE TOGETHER** — the biology's binding rule is co-activity, exactly the project's `hebbian_symmetric`/`hebbian_rate_window`. It requires the members to *be* active together.
- Note Kandel's main text emphasizes DG-delivered sparsity + CA3 recurrent LTP; the *inhibitory* enforcement of CA3 sparsity is treated at the circuit level (basket/PV feedback) in the primary literature below — the sim's gap is precisely this un-modeled CA3 feedback inhibition.

**Theta-gamma synchronization is biology's answer to "members fire asynchronously" (catalog N.15 + N.19, Buzsáki *Rhythms of the Brain* Cycles 9 & 12):**
- **N.19 (PING gamma), Bz Cycle 9 pp 231-261:** gamma frequency is set by the **decay time of GABA_A inhibition (~10-25 ms → 40-100 Hz)**; gamma synchrony provides "*a temporal window for feature binding — neurons firing within the same gamma cycle are co-grouped*"; and — decisively — "*the gamma cycle and the STDP window are matched in duration ... the substrate that lets gamma-bound assemblies actually form synaptic links.*" Its behavioral validation is literally the thing failing here: "*drive two non-overlapping pyramidal sub-populations into separate gamma cycles; STDP should strengthen within-group synapses but not between-group.*" (feature-catalog.md:1028-1035). PING gamma is EMERGENT from an E→I→E loop — it is what a CA3 feedback-inhibition pool self-generates.
- **N.15 (theta-gamma multiplex), Bz Cycle 12 pp 350-353; Lisman-Idiart 1995:** each theta cycle hosts 7-9 nested gamma cycles, each carrying one synchronous cell-assembly. Per-cycle synchronization is *the* biological mechanism that makes an assembly's cells fire in the same short window (feature-catalog.md:992-999).

**Reframe:** the project has been testing "can a Hebbian rule bind this distributed async code?" (No — no rule can.) The biology never asks that. It (1) makes the code SPARSE with feedback inhibition, and (2) makes the sparse set fire SYNCHRONOUSLY within a gamma cycle — and THEN the co-activity Hebbian rule (which the project already has, correct) binds it. The fix is to supply the missing circuit that produces the sparse synchronous code, not to keep tuning the rule.

## (MOVE, external literature) THE STANDARD FIX in spiking CA3 autoassociator models

**Kopsick, Ascoli et al. 2024 — "Formation and Retrieval of Cell Assemblies in a Biologically Realistic Spiking Neural Network Model of Area CA3" (PMC10996657 / bioRxiv 2024.03.27.586909).** The direct analog. Extracted mechanism:
- **Sparsity:** assembly sizes 50-600 of ~74,000 PCs (γ = 0.067-0.8%, optimal ~275 ≈ √N) — i.e. **<1% sparse**, orders below the project's 35-47%. Connection prob PC→PC 0.055 (sparse recurrents; note the project's harness runs 0.5).
- **Synchrony is MANUFACTURED at encoding:** "*patterns lasted the length of a gamma cycle (20 ms) ... within an overarching theta cycle (200 ms)*"; the selected assembly PCs receive an "*injected current [triggering] a randomized train of four spikes during a 20 ms time window.*" They do NOT rely on the members happening to co-fire — they DRIVE them together in a gamma window.
- **Binding rule = symmetric STDP, τ=20 ms** (`Δw = A·e^−|Δt|/τ`). Result: "*synaptic weights between members of different assemblies and between PCs that did not belong to any assembly were similar to before training*," while within-assembly weights potentiate. **This is byte-for-byte the project's `hebbian_symmetric` rule** — it succeeds there ONLY because the members fire inside one 20 ms window.

**"Selective inhibition in CA3: A mechanism for stable pattern completion through heterosynaptic plasticity" (2024, PMC12244581):**
- **Global/uniform inhibition FAILS** to produce or distinguish sparse engrams. Assembly-SELECTIVE feedback inhibition is required.
- Mechanism: "*DG inputs activate specific inhibitory neurons that suppress most excitatory cells; the surviving excitatory neurons and co-active inhibitory neurons form an assembly*"; E→I heterosynaptic plasticity binds interneurons to their engram. Two-component: selective inhibition (minimize interference) + recurrently-driven global inhibition (stabilizes → sparse firing). Engram ~10 excitatory cells; ~85% of E cells encode only 1-2 items (sparse).

**STDP cell-assembly review (PMC3240237, "STDP, Hebbian cell assemblies, and temporal coding by spike synchronization"):** all STDP variants grow bidirectional assembly connectivity ONLY given "*coarsely synchronized inputs such that spikes of the neurons within a cell assembly get synchronized on a time scale of 5 to 50 ms.*" The synchrony window is quantified — it is one gamma cycle.

**In-project corroboration (not just external):** EMERGE-41 already established that on THIS spiking substrate "*the k-WTA SELECTION is spiking rank-order (Thorpe latency) coding + FS lateral inhibition*" (CLAUDE.md). So the biological k-WTA that produces sparsity IS feedback inhibition here — and a host-side numpy k-WTA would be a BRAIN-BASED-ONLY shortcut (acceptable only as a diagnostic upper bound, never the deliverable). The project also has a validated FS-interneuron gamma generator (`run_benchmarks.py --benchmark gamma-oscillations`), so PING gamma is within the substrate's demonstrated range.

**Standard fix, stated plainly:** sparse code by feedback (and selective) inhibition + synchronous encoding within a gamma window (either emergent from the same inhibitory loop = PING, or imposed by a gamma-windowed encoding drive) → then symmetric/rate co-activity STDP binds the sparse synchronous set. The project already has the last piece; it is missing the first two, which are the SAME circuit.
