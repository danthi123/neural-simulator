## 1. THE OP — what the four walls actually share (and where they DIVERGE)

The task framing asserts the four walls reduce to "the same multiplicative-inverse op." **Re-examined rigorously, they reduce to TWO ops, and the distinction is the whole point of this scope** (the prior `2026-06-17-dendritic-substrate-frontier-scoping.md` and `-productive-syntax-scoping.md` both make this split; I verified it against the wall-findings).

### 1.1 The genuinely shared structure: a role-dependent, content-addressed *interaction* a point neuron sums away
Every wall is a failure to apply an **input-specific, multiplicative interaction** at the sub-threshold stage. A point neuron (`v,u` Izhikevich; `v,w` AdEx; `V,m,h,n` HH) computes ONE `total_input_current_pA` by **summing** all synaptic input at a single soma before the spike decision (`bridge.py::_run_one_simulation_step`, current-accumulation phase ~line 5956). Summation is **linear and commutative** — it cannot compute a product of two input streams, nor a quantity that depends on *which other inputs are co-active*. The two ops that need exactly this:

### 1.2 OP-A — dendritic DIVISIVE normalization (the decorrelation/whitening family)
- **The math:** remove the shared common mode by **dividing** each input by an input-specific inhibitory gain: `r_h = x_h / (σ + g_h)` (D1's algebraic form) ≡ shunting steady-state `V = x/(g_leak + g_inh)` (D1.6's biophysical form). This is a *division*, not a product-of-two-signals.
- **Why a point neuron can't:** a single somatic inhibitory pool applies ONE global `g` to all inputs → cannot down-weight the high-frequency common hubs *specifically* (Mikulasch-Priesemann PNAS 2021; falsifiably stated as the D1 point-neuron control, `+0.052` vs dendritic `+0.845`).
- **Walls it owns:** (1) whitening/decorrelation, (3-partly) the *code-similarity* half of nested composition. **This is the DIVERSE op — NOT "multiplicative inverse."**

### 1.3 OP-B — dendritic MULTIPLICATION / superposition-inverse (the binding/bundling/agreement family) — **THIS is the task's actual target**
- **The math (the precise statement of the shared op for walls 2/3/4):** unbinding role *t* from a **superposition** `bundle = Σ_i (uᵢ ⊗ wᵢ)` requires applying the **role-specific inverse** `bundle ⊗ u_t⁻¹` → recovers the matching filler `w_t`, all other facts become noise (`2026-06-16` §"the localization"). `⊗` is an **element-wise PRODUCT** (a multiplication of two *content* streams — the role code and the bound vector), and `u_t⁻¹` is a **role-dependent reciprocal scaling**. A point neuron with a **shared linear** unbind `act = bundle @ W` provably **cannot** implement a *role-dependent* multiplicative scaling of the bound vector — it is structurally incapable, independent of capacity (`D_h`) or training (single-pair or bundle-aware). Demonstrated: additive bind `0.193`, learned-linear-inverse `0.056` (breaks even single-attribute), fixed-±1 self-inverse `0.989` (`2026-06-16` capability map).
- **Why a dendrite CAN:** a dendritic branch computes a **supralinear product** of co-located synaptic inputs — the NMDA-spike "two-layer subunit" (Poirazi-Brannon-Mel 2003): a cluster of inputs on ONE branch produces a regenerative plateau `≫` the same inputs scattered across many branches. That branch-local product IS the `role ⊗ bound` multiplication a single summing soma cannot form. The apical compartment as a *separate integration site* (Larkum BAC) gives a second, gating input stream — the substrate for `gate × content` (multiplicative coupling), which is the conditioning every binding op needs.
- **Walls it owns:** (2) multi-attribute bundling [`bundle ⊗ u_t⁻¹`], (3) arbitrary nested-composition depth [binding composites-of-composites = repeated `⊗`; the `2026-06-02` hierarchical-320 null `0.000` at seed 42 = superposition cross-talk growing with nesting], (4) non-adjacent agreement [unbind a feature from a deep bundle = the *same* `bundle ⊗ feature⁻¹`]. **These three ARE the "same multiplicative-inverse op" — and it is OP-B, the product/coincidence op, NOT OP-A the divisive op.**

### 1.4 The crux correction to the task framing (load-bearing)
The task lists whitening (#1) alongside bundling/nesting/agreement (#2/#3/#4) "as the same op." **They are NOT.** #1 is OP-A (division/normalization → the D2 divisive-gain arc, already built + found non-load-bearing on spikes). #2/#3/#4 are OP-B (product/superposition-inverse → the coincidence-plateau, built-but-never-wired-as-binding). **The project has been building the wrong-half dendritic mechanism for the binding goal** (D1/D2 = the divisive op, which addresses decorrelation, which the PPMI reframe then showed point neurons reach anyway). **The binding op (OP-B) — the one walls 2/3/4 actually share — has its primitive ALREADY ON THE BRIDGE (`fused_coincidence_plateau`) and has never been de-risked as a binding mechanism.** This is the precise, un-exploited opening.

## 2. THE TWO UNLOCKS — separated (and which to target FIRST)

The task asks to separate (a) dendritic MULTIPLICATION-as-binding from (b) dendritic CREDIT-ASSIGNMENT-as-learning-rule. They are genuinely orthogonal and the project's existing stack supports them differently.

### (a) Dendritic MULTIPLICATION as the binding/decorrelation primitive — **the higher-leverage FIRST target for the four walls**
- **What it is:** the supralinear branch-local product (OP-B above). The "binding/superposition-inverse" lever for walls 2/3/4.
- **D2 support TODAY:** the **coincidence-plateau** (`fused_coincidence_plateau`) IS a dendritic-multiplication primitive on the bridge — a per-neuron, all-or-none switch on the COUNT (or weighted sum, `coincidence_weighted_drive`) of *coincident clustered* inputs, with NMDA dual-exponential kinetics + Mg²⁺ self-limiting. It already cites Poirazi-Brannon-Mel / Major-Larkum-Schiller / Branco-Clark-Häusser. **But the D2 two-compartment *neuron* (`sim/dendritic_neuron.py`) does NOT compute a binding product** — it computes a Larkum BAC *threshold-lowering* (apical depol lowers soma threshold, `theta_eff = theta_high − gain·|v_apical|`) for *credit assignment*, and the on-bridge D2 Phase-1 edit (`enable_dendritic_divisive_gain`) is the *divisive* op (OP-A). **So the multiplication-as-binding primitive exists (coincidence-plateau) but is unwired for binding; the two-compartment neuron supports gating/credit-assignment, not the binding product.**
- **Why FIRST:** it directly attacks the *exact* op walls 2/3/4 share, the primitive is already built+guarded (weeks not months), and the cheap A/B (§4) cleanly decides it.

### (b) Dendritic CREDIT ASSIGNMENT (Sacramento / Guerguiev-Richards) — the SCALING / sample-efficiency unlock (owner's "biggest unlock" hypothesis) — **defer; it is a different problem**
- **What it is:** apical dendrites carry top-down error; a LOCAL rule (`ΔW ∝ apical-gated mismatch × pre`) makes the cortex approximate backprop *without weight transport, without separate phases* — Sacramento, Costa, Bengio, Senn, **NeurIPS 2018** (arXiv 1810.11393); Guerguiev-Lillicrap-Richards 2017 (segregated dendrites). This is a *learning-rule* unlock (better credit assignment → fewer samples → deeper learnable networks), NOT a binding-op unlock.
- **D2 support TODAY:** **this is the piece D2 most directly supports.** `sim/dendritic_neuron.py` = the Guerguiev-Lillicrap-Richards segregated-dendrite neuron (basal forward + FIXED-RANDOM apical feedback alignment + BAC); `sim/dendritic_plasticity.py::urbanczik_senn_update` = the *exact* error-gated feedforward primitive Sacramento/Mikulasch need (`mismatch = soma − φ(v_basal)` or apical-projected target × `soma(1−soma)`, local, no weight transport); `sim/dendritic_mlp.py` = GLR2017 feedback alignment, GPU via `sim.backend`. **But this whole stack is pure-numpy, OFF-bridge, and a *prior dendritic credit-assignment arc terminated in a sound-instrument VOID*** (`2026-05-17-dendritic-credit-assignment-NEGATIVE.md`, `2026-05-18-dendritic-fairscale-SOUND-instrument-VOID-strongest-triangulation.md` — the instrument was sound, the result void on a CIFAR-scale credit-assignment question). **The #2c feedback-alignment de-risk for the binder backward pass was also seed-unstable** (`2026-06-16`: 0.528 mean, 0.917 seed42 / 0.083 seed43 collapse — needs e-prop eligibility traces).
- **Why DEFER:** credit-assignment is a *deeper, higher-variance, separately-failed* question that does NOT address the four walls (which are *representational/binding*, not *credit-assignment* failures). The owner's "biggest unlock" intuition is plausible for *scaling* the cortex, but it is the wrong lever for the *binding* walls this scope targets, and its prior VOID + the seed-unstable feedback-alignment make it the riskier first bet. **Target (a) first; (b) is the next scoping pass IF binding is unlocked and the bottleneck shifts to sample-efficiency.**

**Bottom line on the two unlocks:** **(a) multiplication-as-binding is the higher-leverage FIRST target** (it owns the four walls' shared op, its primitive is already built, weeks-scale, low-variance cheap A/B); **(b) credit-assignment is the deferred scaling unlock** (D2 supports it most directly, but it's a different problem with a prior VOID).
