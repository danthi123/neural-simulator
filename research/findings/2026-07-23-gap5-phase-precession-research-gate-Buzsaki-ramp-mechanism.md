## The load-bearing mechanism (what the source actually says)

1. **Sequence compression is the target phenomenon (Dragoi-Buzsáki 2006, fig 11.14).** Within one theta cycle, place cells with overlapping fields fire in a TEMPORAL ORDER matching their spatial order — "the cell that fires on the earliest phase represents a place field whose center the rat will reach first." The seconds-scale real sequence is **compressed** into a tens-of-ms phase sequence within the theta cycle; adjacent-field distance ≈ the inter-spike delay (~60 ms). This compressed order is "just perfect for the short time window needed for STDP" (Skaggs 1996 / Mehta 1997) → it is the substrate that ties a sequence into an episode, and **forward associations are stronger than backward** (matches the forward-asymmetric store gap#5 built 6-seed GO).

2. **The ordering mechanism is a DENDRITIC DEPOLARIZING RAMP — the "single-cell pacemaker" (Kamondi et al. 1998), NOT dual-oscillator interference.** Buzsáki explicitly refutes pure interference three ways: (a) interference explains only *single-spike* precession, not the rate increase; (b) it predicts ALL cells share one precession slope — **false**, slopes vary with field size / input strength; (c) the **Zugaro et al. 2005 reset experiment** — single-pulse CA3-collateral stim resets theta + silences all cells ~200 ms, yet the *recovered* spikes reappear at the SAME phase as control → precession is **not interrupted by an oscillator reset**, which pure interference cannot explain. The refined model: a ~1 s dendritic depolarizing ramp (from the spatial/cue input, as the rat approaches field center) makes the cell oscillate **slightly faster than the background theta**, so its spikes **advance in phase each successive cycle**; stronger input → faster intrinsic oscillation → steeper precession → earlier phase + higher rate.

3. **Theta-paced perisomatic (basket) inhibition is the PHASE REFERENCE** — "the trough serves as an attractor," the reference against which the ramp-driven spikes precess. This is exactly candidate #3's "theta onto the BASKET" (the reference clock), not theta onto the excitatory cells.

4. **The cue INITIATES a readout sequence whose ORDER is set by the CA3 recurrent dynamics** — Zugaro's interpretation of why reset doesn't interrupt: "the nondisturbed grid cells in the entorhinal cortex … can initiate the readout sequence **determined by the dynamics of the CA3 recursive network**." ⇒ this is precisely gap#5's "per-theta detonator cue + forward-asymmetric CA3 links carry the transition," and it explains WHY ignition failed: the order does not come from bursting an assembly — it comes from **ramp-driven phase advance against the theta-basket reference**, with the forward-asymmetric CA3 store setting *which* assembly is next.
