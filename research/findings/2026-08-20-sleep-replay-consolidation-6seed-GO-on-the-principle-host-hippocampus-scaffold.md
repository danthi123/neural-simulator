# GO (6-seed): offline sleep-replay consolidation defeats sequential forgetting — on the PRINCIPLE; the hippocampus is still a host scaffold

Artifact: research/findings/raw/sleep_replay_aggregate_6seed_n10.json

**One line.** For LEARN-THROUGH-USE, memories acquired sequentially must survive interference. This de-risks whether
OFFLINE self-replay during idle "sleep" (teacher + world ABSENT) consolidates them into the shared spiking cortical
readout. **6-seed aggregate GO on the systems-consolidation PRINCIPLE — with the honest caveat that the hippocampus is
still a host store, so this validates the principle, not yet the brain-pure mechanism.**

## Genuinely distinct from the 2026-08-03 cortical-consolidation NO-GO (not conflated, not ignored)
The two 2026-08-03 findings (`replay-cortical-consolidation-calibration-NO-GO` v1/v2) tested a DIFFERENT experiment: a
SPIKING hippocampus (real CA3 recurrence + CA1→cortex indexing, spiking replay volleys) forming an HC-INDEPENDENT
cortical trace, measured by HC-disabled recall — and found it fragile (intact recovery ~0.03–0.07, 16× seed variance).
This runner scaffolds the hippocampus with host computation and tests only the systems-consolidation PRINCIPLE
(interleaved replay beats sequential interference) on the shared e-prop readout. So the cortical NO-GO neither
auto-condemns this nor is irrelevant — it marks exactly the residual: replacing the host store with a reliable spiking
CA3 autoassociator is the unfinished, harder step.

## The host-shortcut, flagged honestly (brain-based-only standard)
The cortical consolidation itself IS synaptic — e-prop moves the spiking `OnBridgeEpropNet` feedforward weights. But
the `Hippocampus` is entirely HOST computation, a documented shortcut: `encode = np.mean(X, axis=0)` in a Python list
(no CA3 attractor, no synaptic engram); `generate_replay = engram + noise·N(0,1)` (numpy, not a spiking circuit doing
pattern completion). "Teacher/world ABSENT during replay" is true + grep-verifiable (`_self_replay_consolidate` has no
`env` param, never calls `env.draw`), but "self-generated by the BRAIN" would overclaim: the replay pattern is numpy
from a host-stored mean, not neurons/synapses. So the GO is on the PRINCIPLE; the brain-pure mechanism is the next rung.
