## Strategic synthesis

**Three cross-cutting roots** (fix the root, fix many leaves):
1. **The dense-Qwen-in-sparse-float64-complex-CSR mismatch** feeds O-1 + O-2 + O-6 (speed) AND H-4 (hardware) AND I-2/H-1 (the off-bridge faculty's on-bridge cost). The CSR format was built for the composer's sparse O(D) bind/unbind; the dense LLM wants a dense low-precision GEMM. Fixing storage advances the speed AND neuromorphic axes at once.
2. **Built-but-default-OFF spiking replacements** — C-2/H-6 (sequencer), C-3/H-5 (cleanup WTA), C-4 (reciprocal unbind, already on for OneBrain), C-5 (learned assoc), H-7 (substrate store), and N-1/N-2 (nav limbic core). Each is a **default-flip + a validation pass**, not new research. The only blockers are a small-vocab over-abstention (needs the sequencer fold+scale) and the GREEN_INERT confound (purity, not behavior).
3. **Host-DESIGNED structure** (H-2) underlies C-1/H-3 (the bind algebra), N-4 (the grounding projection), N-5 (the Gabor bank), and the consolidated-ANN weights — the deepest categorical blocker; the target is developmental self-organization, likely dendrite-tied.

**Cheap vs deep — the actionable split:**
- **[cheap] — engineering + default-flips (no new science):** the on-GPU forward (O-1) + dense matvec (O-2) + KV cache (O-3); the spiking default-flip pass (C-2/C-3/C-4/C-5, H-5/H-6/H-7) after the sequencer fold+scale; the nav limbic-core purity flip (N-1/N-2); drop the imaginary CSR + f32/dense (H-4); the on-device tuple-gen (O-7).
- **[deep] — research / dendritic / months:** FHRR→learned cortex (C-1/H-3); host-designed-structure→developmental self-organization (H-2); off-bridge-LLM→on-bridge functional integration (I-2/H-1); functional nav+conv integration (I-4) + parser→composer synaptic (I-5) + limbic→composer deep (I-7); the dendritic frontier (B-1 place-value δ, B-3 TD); the SC sustained-loop (B-2); generative integration into the one brain (I-9); the neural discourse-planner for substantive conversation (C-6).

**Biggest 3 overall** (by leverage toward the artificial-life / one-brain / hardware goals):
1. **Functional one-brain integration (I-4 + I-1 + I-2)** — the halves are co-located with zero cross-synapses, the brain's own ops hand off via host round-trips, and the language faculty is a separate PyTorch model. The owner's "real one brain" is the persistent interacting spiking loop; I-✓ (spoken-instruction) is the working template, I-7 (DA→composer) the wired-but-opt-in start.
2. **The host-designed structure + the FHRR idealization (H-2 + C-1/H-3)** — the deepest categorical blocker for both biology and a clean neuromorphic port; the dendritic-substrate-gated learned-cortex frontier.
3. **The storage/perf root (O-1 + O-2 + H-4)** — the cheapest high-impact win: a dense low-precision forward unlocks usable wall-clock AND the natural hardware representation in one move, no sim/ edit for the host-forward version.

**Net state:** the conversational half is ~fully spiking + consolidated on one substrate (with the default-flip residuals above); the navigation half is spiking at the MECHANISM level but host in the deployed low-level default and only CO-LOCATED (not functionally integrated) with conversation; the language faculty + the bind algebra + the dense-weight storage are the deep frontiers. Of the master-ledger's 24 cognitive ops: ~7 CLOSED-fully, ~11 spiking-but-opt-in/residual, ~3 in-flight, ~3 characterized boundaries.
