# GNW N-organ ignition bus — FLIPPED from shadow to the DEFAULT organ-combination on production `brain_chat`

## What this moves (faculty-map T1-1, Phase-B — the one-substrate step)
The audit's #1 structural lever is that the co-resident organs in the production chat were combined by HOST PYTHON, not by the substrate: `ChatBrain.gate()` (reached from `webapp/server.py::brain_chat`) snapshots a spiking recall, a reverse-binding VERIFY and a router fallback and fuses them with an `if recalled == p`. The de-risked GNW N-organ ignition bus (`research/runners/_gnw_norgan_bus_derisk.py`, finding `2026-08-13-gnw-norgan-ignition-bus-substrate-combines-N-organ-reads.md`, 6/6 GO) proved the SUBSTRATE can combine N>=3 subthreshold organ reads via consensus-ignition + shared-inhibition WTA + re-entry. The 2026-08-13 SHADOW step wired it default-OFF (finding `2026-08-13-gnw-norgan-bus-shadow-wired-into-production-brain-chat.md`, 9/9). This finding PROMOTES it to the DEFAULT combination: the substrate now authors the decision, replacing the host `if recalled == p`.

## The flip (additive, default-ON, escape-flagged, byte-identical-when-covered)
`webapp/server.py::brain_chat` calls `gnw_bus_shadow.install_bus_gate(chat)` — an idempotent wrapper on `chat.gate`. Each turn the wrapper runs the ORIGINAL gate (the (agent, action) extraction/comprehension + recall + the acquisition/anaphora/open-ended side effects — all UNCHANGED), then re-authors the COMBINATION verdict through the bus: the three real organ reads (forward recall + a VERIFY re-read + a reverse-binding VERIFY) write subthreshold votes into ONE warm spiking workspace; three corroborating votes ACCUMULATE and IGNITE the patient slot (a decoy is WTA-suppressed); the ignited patient IS the answer, no ignition IS the abstain (the moat as a substrate property). Both the single-fact path and the DEFAULT rich path funnel their direct recall through `chat.gate`, so the flip covers the default turn. ESCAPE: `BRAIN_GNW_BUS_HOST=1` reverts to the original host gate() (byte-identical to pre-flip production); `BRAIN_GNW_BUS_LESION=1` is the honest-negative lever; `BRAIN_GNW_BUS` is now ONLY the observability flag (default-OFF -> no `gnw_bus` key -> byte-identical response). Reuse-by-import of the de-risk workspace/hop — NO `sim/` edit.

## The flip gate — earned on a BROAD real-query panel through the REAL handler
`research/runners/_gnw_bus_default_flip_verify.py` builds the REAL production ChatBrain (numpy-CPU, rf recall) and, for every panel query, compares the ORIGINAL host gate() decision to the bus-authored decision. Result (cites `research/findings/raw/_gnw_bus_shadow/default_flip_verify.json`):
- **BYTE-IDENTICAL 22/22** across every class — stored 5/5, self/identity 3/3, unstored 4/4, inconsistent 4/4, open-ended 2/2, acquisition 2/2, anaphora 2/2. On the stored queries the three organs all vote the same patient (`reads=['cat','cat','cat']`) and the slot ignites; on unstored/inconsistent the reads miss and nothing ignites. The substrate reproduces the host decision EXACTLY, so the flip changes the MECHANISM, not the behaviour. <!--derived-->
- **NO MOAT REGRESSION** — every unstored/inconsistent query still ABSTAINS on BOTH host and bus (`moat_ok=True`). <!--derived-->
- **LESION-LOAD-BEARING on the ANSWER** — with the bus authoring, a lesion (workspace self-recurrence zeroed) makes the consensus unable to ignite, so the combined ANSWER collapses to abstain (intact commits the patient), WHILE the forward-recall reflex (`composer.query_patient`, never routed through the workspace) still returns it. Attribution to the workspace ignition = 1.0. <!--derived-->
- **ESCAPE byte-identical** — through the REAL `brain_chat` handler, `BRAIN_GNW_BUS_HOST=1` (host) is byte-identical to the bus default on the covered panel (answer, recalled_svo, abstained, verified, activity — all identical, no `gnw_bus` key). The owner can revert instantly. <!--derived-->

The read-only organ probes save+restore `composer.last_trace` so the surfaced `activity` stays the gate's forward-recall trace (an earlier run diverged ONLY on this debug field; the bus must not perturb observable state — fixed and re-verified).

## What the anti-cheats establish
- BYTE-IDENTICAL across classes (not just stored): a host shortcut that only reproduced answers would still diverge on abstains/acquisition/anaphora; matching ALL 22 shows the substrate reproduces the WHOLE decision surface.
- LESION collapses the ANSWER (not just a shadow block): under the shadow, a lesion collapsed only the audit read-out; now it collapses the DELIVERED answer while the reflex survives — the production proof the substrate ignition is doing the combination.
- ESCAPE byte-identical: the flip is reversible with no behavioural cost, so it is a MECHANISM change, verified, not a behavioural gamble.

## Honest scope + residual (this is a scoped flip, honestly bounded)
1. **The host gate() CODE still runs.** The wrapper calls it for the (agent, action) extraction and the acquisition/anaphora/open-ended side effects; its `if recalled == p` combination result is COMPUTED-then-OVERRIDDEN, not deleted. So the DECISION is the substrate's by default, but the host combination code is not yet retired. Full retirement = a `ChatBrain.gate_via_bus` that never computes the host combination (design §3, the named follow-on). Per `docs/TERMS.md` this is **wired + on-by-default**, NOT **scaffold-retired**.
2. **Covered class = a routable recall combination.** Turns the bus does not cover fall back to the host decision unchanged: open-ended GENERATION (a flagged `HypothesisSVO` guess — not a recall combination) and a turn with no substrate query (self/identity/short — no (agent, action) to route). Extraction/comprehension stays the host's neural parser/heuristic; only the COMBINATION moved.
3. **Reverse-binding veto is the mapped divergence class.** Organ C (reverse VERIFY) could veto a fact with an AMBIGUOUS reverse binding, collapsing a host answer to abstain — a divergence to SCOPE to host, never to force. None exists in the tiny-demo (every reverse binding is unique -> 22/22). A brain with an ambiguous reverse binding is the follow-on probe.
4. **Co-residency.** The N organs are corroborating relational reads of one composer + the reverse-binding VERIFY (as the keystone used 2). A genuinely heterogeneous non-composer organ (a spiking surprise/familiarity monitor, the P0.3 affect organ) as one of the N votes is the named follow-on rung.
