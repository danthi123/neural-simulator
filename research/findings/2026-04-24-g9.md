# G9 Findings — Sim-native R-STDP sensorimotor learning

**Date:** 2026-04-24
**Gate:** Session B.2 — the biology-compliant replacement for G6/G8's runner-side perceptron
**Question:** Can sim-native three-factor learning (STDP + eligibility + reward) replicate G6's
fixed-goal learning AND unlock G7/G8's moving-goal readaptation failure?
**Verdict:** **NO-GO on moving goal with either action selection.** Sim-native R-STDP
matches G6 on the fixed-goal baseline (pipeline validated) but fails the G7 readaptation
gate:
- **argmax** action selection: **0/3 seeds pass.** Phase-2 finalQ aggregate 6.65 (random
  baseline ~7), action distribution essentially identical between phases — the policy
  doesn't shift.
- **first_spike** WTA action selection: **1/3 seeds pass** (seed 43 P1 finalQ 2.89,
  uniform action distribution). Seeds 42/44 fail, seed 42 catastrophically (P1 finalQ
  8.51, worse than random). First-spike helps some configurations and hurts others.

H2 (architectural limit) is not dissolved by three-factor learning or soft action selection
alone. The slow LTP-based weight revision can't flip argmax decisions fast enough after
phase-1 specialization, and first-spike's noise both enables exploration and undermines
consolidation.

**Session C activates**: neuromodulatory synaptic-gain gating as a complementary *fast*
mechanism. See `2026-04-24-session-c-plan.md` for the design, `neuromod-gain` branch for
implementation and tests.

---

## 1. Context

G8 (findings 2026-04-24-g8.md) concluded that **H2 (architectural limit) is the binding constraint**
on moving-goal readaptation, not H1 (missing information). The runner-side architecture
(cliff-edged argmax action selection + per-step credit assignment + direct weight writes) cannot
escape phase-1 specialization even with a biologically-plausible PFC-like goal-context input.

The recommended path forward: port learning to the sim's own R-STDP pathway (signed eligibility
trace, merged at commit `1d70a3f`), and add a softer action-selection rule (first-spike WTA).
Both changes are biology-forward:

- **Three-factor learning** (Fremaux & Gerstner 2016) = local STDP eligibility + global reward
  gate. Canonical cortico-striatal mechanism (Schultz 1998; Reynolds & Wickens 2002).
- **First-spike WTA** (Thorpe et al. 2001) = lateral-inhibition winner-take-all. Real motor
  circuits resolve actions in ~20-50 ms via strong lateral inhibition silencing losers.

## 2. Implementation

`research/runners/g9_runner.py` (443 lines). Key design choices:

**Sim-native learning.** `enable_stdp=True`, `enable_reward_modulation=True`. The reservoir
(input→hidden and hidden→hidden) is marked `plastic=False` in the wiring plan, so
`inject_explicit_wiring` sets `cp_synapse_plastic_mask` to freeze those synapses. Only
hidden→motor (the `plastic=True` group) participates in STDP events. Eligibility trace
accumulates signed weight changes (post-`1d70a3f` signed-eligibility semantics).

**Reward delivery.** Per trial: run 150 ms of stimulus with `current_reward_signal = 0`
(pure STDP accumulation), decide action by argmax or first-spike, compute reward from
ΔManhattan distance, then set `current_reward_signal = ±1` and run `reward_hold_steps=10`
extra sim steps so the sim's reward modulation path (`bridge.py:3862-3890`) applies the
three-factor `Δw = lr · reward · eligibility` update over a non-trivial window.

**Tight eligibility tau.** `reward_eligibility_tau_ms = 500` (vs default 1000). More
dopamine-realistic; downstream plasticity window is 300-500 ms in striatum
(Yagishita et al. 2014).

**Action selection.**
- `argmax`: spike-count argmax in [50, 150] ms — G6/G8-compatible for direct comparison.
- `first_spike`: earliest-firing motor neuron within the readout window. Falls back to
  random if no motor fires.

## 4. Moving-goal readaptation (the real test)

G7 NO-GO baseline: Phase 2 finalQ {6.27, 3.09, 6.64}, seeds {42, 43, 44}. Gate: ≥ 2/3 seeds
Phase 2 finalQ < 3.0.

### 4.1 G9 argmax (sim-native, no first-spike WTA) — FAILS

| Seed | P0 finalQ | P0 at_goal | P1 finalQ | P1 at_goal | P0 actions | P1 actions |
|------|-----------|-------------|-----------|-------------|------------|------------|
| 42   | 1.77      | 0           | **6.84**  | 0           | [82, 188, 30, 0]  | [87, 180, 33, 0]  |
| 43   | 1.52      | 23          | **6.28**  | 0           | [58, 160, 27, 55] | [81, 140, 21, 58] |
| 44   | 1.99      | 0           | **6.83**  | 0           | [197, 89, 11, 3]  | [169, 102, 27, 2] |
| **agg** | **1.76** | 7.7       | **6.65**  | 0           | — | — |

**Verdict: complete readaptation failure.** Phase 2 final-quarter mean distance = 6.65
(random baseline ~7). Action distribution between phases is **nearly identical** for all
three seeds — the policy didn't shift at all after the goal moved. This is *worse* than
G7's baseline (P1 aggregate 5.33), which is surprising.

Diagnosis: sim-native learning with argmax shares the same cliff-edge problem as G6/G8.
The 500 ms eligibility trace + per-step LR=0.01 can move weights by ~0.03 per 300 phase-2
steps — same order as the runner-side budget. argmax keeps picking the same motor, which
keeps accumulating same-direction eligibility, which negative reward now depresses but
still not fast enough to flip the ranking.

Surprising detail: G9 argmax is *worse* than G7 baseline (6.65 vs 5.33). Likely cause: G7's
`reset_epsilon_on_goal_change=True` + epsilon_start=0.3 gave it some phase-2 exploration.
G9 has no epsilon-greedy (relies on sim noise for exploration), which is insufficient when
weights are saturated.

### 4.2 G9 first_spike (sim-native + first-spike WTA) — 1/3 SEEDS PASS

| Seed | P0 finalQ | P0 at_goal | P1 finalQ | P1 at_goal | P0 actions | P1 actions |
|------|-----------|-------------|-----------|-------------|------------|------------|
| 42   | 4.41      | 1           | **8.51**  | 0           | [88, 107, 88, 17]  | [69, 130, 87, 14]  |
| 43   | 3.76      | 2           | **2.89**  | 11          | [58, 79, 70, 93]   | [65, 85, 57, 93]   |
| 44   | 1.56      | 13          | **5.97**  | 0           | [96, 107, 65, 32]  | [105, 103, 56, 36] |
| **agg** | **3.24 ± 1.22** | 5.3 | **5.79 ± 2.30** | 3.7 | — | — |

Only seed 43 passes the gate. Its action distribution is remarkably uniform
(P1: [65, 85, 57, 93]) — the first-spike mechanism produced natural exploration that
enabled readaptation. BUT the same noise hurt phase-1 consolidation for seeds 42 and 44
(P0 finalQ 4.41 and 1.56 are worse than argmax's 1.77 and 1.99).

Seed 42 under first_spike is the pathological case: Phase-1 finalQ=4.41 indicates
incomplete learning, Phase-2 finalQ=8.51 is *worse than random*. The agent was stuck in
a feedback loop where noisy action selection prevented consistent reward, which prevented
the sim's three-factor learning from producing any useful signal.

### 4.3 Combined verdict

Across conditions: **argmax 0/3 pass, first_spike 1/3 pass**. Neither clears the 2/3
threshold. The hypothesis that changing action selection alone would unlock readaptation
is falsified.

Importantly: sim-native R-STDP *does work* (fixed-goal validation in §3). The issue is
specifically the combination of slow weight learning + cliff-edged argmax vs noisy
first-spike — neither is on the right timescale for fast policy reversal.

**Conclusion:** H2 (architectural limit) requires a *second* faster mechanism to
complement slow LTP. Session C's neuromodulatory gain gating is the next step (design
doc: `2026-04-24-session-c-plan.md`; implementation on `neuromod-gain` branch).

## 5. Verdict

**Session B.2 gate: NO-GO.** Sim-native three-factor learning (STDP + eligibility + reward
modulation) is biologically canonical and does work for simple fixed-goal tasks, but alone
it cannot cross the H2 architectural limit identified in G7/G8. The moving-goal readaptation
gate (Phase-2 finalQ < 3.0 in ≥ 2/3 seeds) is not cleared.

Key positive: the sim-native pipeline is validated. The signed-eligibility commit
(`1d70a3f`) + plastic-mask infrastructure + reward-modulation path all compose correctly,
produce learning that matches the runner-side approach on G6 baseline, and will form the
substrate for Session C.

## 6. Implications

1. **Slow learning alone is insufficient for rapid re-policy.** 300 phase-2 steps × LR 0.01
   × eligibility magnitude ~0.01 gives a maximum weight delta of ~0.03 per synapse,
   comparable to G6/G7's runner-side budget. The bottleneck is structural.

2. **Action-selection softness trades consolidation for exploration.** argmax is deterministic
   (good for consolidation, bad for readaptation); first_spike is noisy (good for readaptation
   on lucky seeds, bad for consolidation on unlucky seeds). Neither is uniformly better.

3. **Session C is the principled next step.** Neuromodulatory gain gating operates on a
   10-100 ms timescale, complementing the minutes-long LTP timescale. When reward flips
   sign, recently-active synapses' gain drops transiently — letting alternative motors win
   without waiting for LTP to remodel the weights. Biology provides the analogue (dopamine,
   acetylcholine via GPCRs; Disney & Reynolds 2014; Surmeier et al. 2007). Implementation
   on `neuromod-gain` branch.

4. **Session B.2 deliverable is the sim-native runner, not readaptation.** G9 is the
   biology-compliant baseline that Session C will build on. It replaces G6/G8's runner-side
   perceptron hack with canonical three-factor learning, at the cost of ~0.3 Manhattan
   units aggregate mean-distance gap (G9 2.14 vs G6 1.82 on fixed goal) — acceptable for
   the biological-fidelity gain.
