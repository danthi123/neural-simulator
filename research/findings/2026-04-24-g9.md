# G9 Findings — Sim-native R-STDP sensorimotor learning

**Date:** 2026-04-24
**Gate:** Session B.2 — the biology-compliant replacement for G6/G8's runner-side perceptron
**Question:** Can sim-native three-factor learning (STDP + eligibility + reward) replicate G6's
fixed-goal learning AND unlock G7/G8's moving-goal readaptation failure?

## 1. Context

G8 (findings 2026-04-24-g8.md) concluded that **H2 (architectural limit) is the binding constraint**
on moving-goal readaptation, not H1 (missing information). The runner-side architecture
(cliff-edged argmax action selection + per-step credit assignment + direct weight writes) cannot
escape phase-1 specialization even with a biologically-plausible PFC-like goal-context input.

The recommended path forward: port learning to the sim's own R-STDP pathway (signed eligibility
trace, merged at commit `1d70a3f`), and add a softer action-selection rule (first-spike WTA).
Both changes are biology-forward:

- **Three-factor learning** (Fremaux & Gerstner 2016) = local STDP eligibility + global reward
  gate. Canonical cortico-striatal mechanism (Schultz 1998; Reynolds & Wickens 2002).
- **First-spike WTA** (Thorpe et al. 2001) = lateral-inhibition winner-take-all. Real motor
  circuits resolve actions in ~20-50 ms via strong lateral inhibition silencing losers.

## 2. Implementation

`research/runners/g9_runner.py` (443 lines). Key design choices:

**Sim-native learning.** `enable_stdp=True`, `enable_reward_modulation=True`. The reservoir
(input→hidden and hidden→hidden) is marked `plastic=False` in the wiring plan, so
`inject_explicit_wiring` sets `cp_synapse_plastic_mask` to freeze those synapses. Only
hidden→motor (the `plastic=True` group) participates in STDP events. Eligibility trace
accumulates signed weight changes (post-`1d70a3f` signed-eligibility semantics).

**Reward delivery.** Per trial: run 150 ms of stimulus with `current_reward_signal = 0`
(pure STDP accumulation), decide action by argmax or first-spike, compute reward from
ΔManhattan distance, then set `current_reward_signal = ±1` and run `reward_hold_steps=10`
extra sim steps so the sim's reward modulation path (`bridge.py:3862-3890`) applies the
three-factor `Δw = lr · reward · eligibility` update over a non-trivial window.

**Tight eligibility tau.** `reward_eligibility_tau_ms = 500` (vs default 1000). More
dopamine-realistic; downstream plasticity window is 300-500 ms in striatum
(Yagishita et al. 2014).

**Action selection.**
- `argmax`: spike-count argmax in [50, 150] ms — G6/G8-compatible for direct comparison.
- `first_spike`: earliest-firing motor neuron within the readout window. Falls back to
  random if no motor fires.

Interpretation: G9 produces learning comparable to G6 on the fixed-goal baseline — mean
distance ~2 (random baseline ~7), weights move from initial 1.0 toward ~1.9 mean (LTP-biased,
consistent with positive-reward-dominant regime), and the agent does occasionally reach the
goal. Seed 42 under G9 has a degenerate "no W" action distribution ([129, 410, 61, 0]) —
the agent learned to move only NE, which is sufficient to reach goal (6,6) from (1,1) but
requires no W actions. This is a mild specialization quirk, not a learning failure.

**Takeaway for pipeline validation**: sim-native three-factor learning works. The eligibility
trace + reward modulation pathway is correctly wiring up hidden→motor weights. Session B.2
infrastructure is sound; the moving-goal test can now answer the H2 question definitively.

## 4. Moving-goal readaptation (the real test)

G7 NO-GO baseline: Phase 2 finalQ {6.27, 3.09, 6.64}, seeds {42, 43, 44}. Gate: ≥ 2/3 seeds
Phase 2 finalQ < 3.0.

### 4.1 G9 argmax (sim-native, no first-spike WTA) — FAILS

| Seed | P0 finalQ | P0 at_goal | P1 finalQ | P1 at_goal | P0 actions | P1 actions |
|------|-----------|-------------|-----------|-------------|------------|------------|
| 42   | 1.77      | 0           | **6.84**  | 0           | [82, 188, 30, 0]  | [87, 180, 33, 0]  |
| 43   | 1.52      | 23          | **6.28**  | 0           | [58, 160, 27, 55] | [81, 140, 21, 58] |
| 44   | 1.99      | 0           | **6.83**  | 0           | [197, 89, 11, 3]  | [169, 102, 27, 2] |
| **agg** | **1.76** | 7.7       | **6.65**  | 0           | — | — |

**Verdict: complete readaptation failure.** Phase 2 final-quarter mean distance = 6.65
(random baseline ~7). Action distribution between phases is **nearly identical** for all
three seeds — the policy didn't shift at all after the goal moved. This is *worse* than
G7's baseline (P1 aggregate 5.33), which is surprising.

Diagnosis: sim-native learning with argmax shares the same cliff-edge problem as G6/G8.
The 500 ms eligibility trace + per-step LR=0.01 can move weights by ~0.03 per 300 phase-2
steps — same order as the runner-side budget. argmax keeps picking the same motor, which
keeps accumulating same-direction eligibility, which negative reward now depresses but
still not fast enough to flip the ranking.

Surprising detail: G9 argmax is *worse* than G7 baseline (6.65 vs 5.33). Likely cause: G7's
`reset_epsilon_on_goal_change=True` + epsilon_start=0.3 gave it some phase-2 exploration.
G9 has no epsilon-greedy (relies on sim noise for exploration), which is insufficient when
weights are saturated.
