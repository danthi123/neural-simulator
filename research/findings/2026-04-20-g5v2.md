# G5.v2 Findings — Reward-modulated sensorimotor loop

**Date:** 2026-04-20 (autonomous overnight)
**Gate:** G5.v2 — add goal-directed reward to G5; does the brain navigate toward the goal over an episode?
**Verdict:** **NO-GO.** Agent pinned at x=0 (left boundary), mean distance 11.76 / 12. Reward modulation with the sim's *unsigned* eligibility trace is not a signed-pair-aware learning rule — any consistently-negative reward depresses all recently-plastic synapses equally, producing a learn-to-be-silent degenerate attractor.

---

## 1. Setup

Same 266-neuron reservoir as G5. Changes:
- Hidden→motor layer is **plastic** (via the per-synapse mask added in G2+).
- STDP on, symmetric rates A+=A-=0.010.
- `enable_reward_modulation=True`, `reward_learning_rate=0.05`, `reward_eligibility_tau=500ms`.
- Per step: 150 ms stimulus (reward=0, eligibility accumulates) → action → env update → 50 ms reward window (reward = 1 − 2·dist/max_dist ∈ [−1, +1]).
- Goal = 12, start = 8, positions ∈ [0, 15].
- 400 steps, seed 42.

## 2. Results

| Metric | Value |
|--------|-------|
| Mean distance over episode | 11.76 / 12 |
| Per-quarter distances | [11.37, 11.83, 11.91, 11.92] |
| Q1 − Q4 improvement | **−0.55** (distance got *worse*) |
| Steps at goal | 0 |
| Mean reward | −0.568 |
| Trajectory mean x | 0.24 |
| Plastic-weight mean over time | 0.79 → 0.64 → 0.51 → 0.44 → 0.38 → 0.34 → 0.31 → **0.28** |

Agent was stuck at x=0 for almost the entire episode. Plastic weights drifted from 0.79 to 0.28 — **reward modulation uniformly depressed the weights** because reward was consistently negative.

## 3. Root cause — unsigned eligibility in this sim

`SimulationBridge` STDP block:
```python
self.cp_eligibility_trace[stdp_active_indices] += cp.abs(weight_changes)
```

The eligibility trace accumulates **|ΔW|** (absolute value), not signed ΔW. Reward then modulates:
```python
weight_updates = cfg.reward_learning_rate * reward_prediction_error * self.cp_eligibility_trace[:actual_nnz]
self.cp_connections.data += weight_updates
```

So for a negative reward, *every* recently-plastic synapse gets its weight reduced uniformly. There's no signed discrimination — no way to say "your pre-before-post pair should be depressed, your post-before-pre pair should be potentiated."

With a systematically-negative reward (agent never reaches goal), every plastic synapse drifts toward zero. Motor output becomes silent. Tie-break returns 0 = left. Agent stays at x=0. Reward stays negative. Loop.

This is exactly the degenerate attractor we see.

## 4. Options for G5.v3 (not pursued today)

1. **Signed eligibility.** Change the STDP block to store ΔW (signed). This makes R-STDP into true three-factor learning. But: changes semantics of the sim's existing reward-modulation path — the biological associative-conditioning / R-STDP-gridworld experiment presets depend on the current unsigned behaviour. Not touching it without running the full biological regression suite.
2. **Baseline-subtracted reward with directional cue.** Use `reward - baseline` where baseline tracks recent reward. Would require a sliding-baseline in the runner, not the bridge. Helps if reward range is asymmetric; doesn't fix the unsigned-eligibility fundamental.
3. **Explicit reward-gated plasticity in the runner.** Don't use the sim's reward channel. Instead, after each action, externally potentiate the actual-action synapses if reward good, depress if bad. This is the G1.v2 perceptron style but applied to the motor-action layer. Cleanly avoids the unsigned-eligibility issue.
4. **Larger, bursting reward on specific events** (e.g. reward = +5 *only* when at goal, else 0). Combined with eligibility decay, this would look more like classical R-STDP with sparse rewards. But same fundamental asymmetry — a positive reward still potentiates everything uniformly.

Most promising for a quick G5.v3: **option 3** (external reward-gated plasticity in the runner). Keeps the sim clean, gives signed per-synapse updates based on which motor neuron actually fired.

- The negative result is *informative*: it pinpoints an architectural ceiling of the sim's existing reward-modulation path.
