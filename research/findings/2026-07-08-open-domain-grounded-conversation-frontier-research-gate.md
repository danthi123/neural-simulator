## 2. REFRAME — how real biology + the real field do open-world completion (and which map to spikes vs the LLM)

The load-bearing reframe: **the four "beyond-the-inventory" faculties are not four separate engines. They are the
SAME distributed-code substrate the project already has (overlapping/shared codes + a next-state predictor + replay),
run in a COMPLETION/MAPPING mode instead of a RETRIEVAL mode.** This is the exact shape of the EMERGE-26 inheritance
win ("the ONLY change is the code encoding") and the 2026-07-02 open-world-semantics gate, extended one level.

### 2a. Semantic completion = spreading activation / feature completion (Collins-Loftus; Rogers-McClelland; catalog D.13)
Collins & Loftus 1975: activating a concept **spreads activation to associated concepts along weighted links**;
accounts for priming, typicality, the fan effect. The field's honest caveat (Kumar 2022 *Topics Cogn Sci* review):
classical spreading activation "lacks a mechanism for LEARNING the associative structure from experience — the
network is hand-built." **The project has exactly the missing piece the classical model lacks:** the stream cortex
LEARNS the associative weights from the corpus (co-occurrence codes, `corr(M,C)` GO), and the SVO store IS a learned
associative graph. Rogers & McClelland 2004 (*Semantic Cognition*, PDP) is the mechanistic upgrade: meaning is a
distributed activation pattern; **"feature completion"** — given a partial concept, the network fills in the missing
features by settling — is inference-by-completion, and it **generalizes to novel concepts** through shared distributed
representation (the same shared-code structure the emergent clusters already have). Catalog **D.13 (CA3 pattern
completion; Marr 1971; Kandel Ch 54 pp 1342, 1360–1361):** "partial or noisy retrieval cue activates a stored
attractor that converges to the full pattern." ⇒ **Reframe #1: spreading-activation completion = the stream cortex's
learned associative codes + a settling/propagation read-out.** It is a spiking mechanism the substrate can do; it
converts "I was never told X's properties" into "X is coded near {A,B,C}, which have properties {p,q} → X likely has
{p,q} (hedged)." **Maps to spikes.**

### 2b. Analogy = structure-mapping, realizable as VSA parallelogram (Gentner; Eliasmith/Furlong; Komer-Stewart)
Gentner's structure-mapping (SME; Gentner & Forbus 2025 retrospective, *Curr Dir Psychol Sci*): analogy aligns
RELATIONAL structure, not surface features. The field's neural realization is **VSA/hyperdimensional**: "Analogical
Reasoning Within a Conceptual Hyperspace" (arXiv 2411.08684, 2024) computes category analogies by the **parallelogram
`x = (c ⊛ a⁻¹) ⊛ b`** — bind/unbind/superpose on complex hypervectors, "phase encodes neuronal spike timing,"
decoded by a **resonator network** (O(M) factoring). Furlong & Eliasmith 2024 bridge VSA ↔ generative models. **This
is EXACTLY the project's FHRR composer algebra** (`unbind` at `rf_phasor_composer.py:388`; bind/bundle; the
resonator-decode is the composer's cleanup). ⇒ **Reframe #2: analogy is `unbind→transform→apply→cleanup` on the
composer's own spiking ops** — ALREADY VALIDATED as sound (`2026-06-27-tier2.1-analogy-NEGATIVE`: acc 1.000 on clean
ADDITIVE relational codes, lesion + permuted-relation collapse to floor). **The HONEST NEGATIVE there was NOT the
mechanism — it was the CODE:** the production learned/bundled codes carry *similarity* but not the *second-order
additive relational* structure analogy needs (delta-alignment +0.0015 ≈ random). **Maps to spikes IFF the relation is
carried as a clean phase offset** — and `2026-06-27-regimeB-corpus-mined-axis-GO` proves the project can MINE a
clean relational axis from the corpus (the size ordinal, symbolic-distance signature, permuted-mining collapses). So
the path is: mine the relational axis from the corpus → clean relational codes → the validated parallelogram works.
**Surpassable-cheaply, with the code-provenance anti-cheat foregrounded (this is the 2026-05-14 over-claim zone).**

### 2c. Schema / script default-filling = the successor-representation / next-state predictor over a relational graph (Schank; Stachenfeld; TEM)
Schank & Abelson 1977 scripts (restaurant frame) "answered questions… but were limited to manually constructed
frames" — the same hand-built limitation as classical spreading activation. The modern reframe (Spens & Burgess 2023;
schema-based active inference, arXiv 2601.18946; *Nat Rev Neurosci* 2024 "Schemas, RL and mPFC"): a schema is a
LEARNED generative/predictive model; **the successor representation** (Stachenfeld-Botvinick-Gershman 2017,
*Nat Neurosci* — place cells encode expected future state occupancy) makes multi-hop reachability latent in a
one-step predictor, so **a next-state predictor over a relational graph IS an implicit schema-inference engine.**
The HTM temporal-memory cortex the emergent stack is built on IS a high-order next-state predictor. ⇒ **Reframe #3:
schema default-filling = running the HTM next-state predictor over the learned relational graph to predict the
UNSTATED-but-typical continuation** ("enters restaurant → [predict] sits → orders → eats"). **Maps to spikes** (the
predictor is already the substrate's core op); the residual is a small script corpus to learn the transitions from.

### 2d. Imaginative recombination = hippocampal replay training a generative model (Schacter/Addis; Spens-Burgess; catalog G.09)
Catalog **G.09 (imagination / future simulation as constructive memory; Kandel Ch 52 pp 1300–1302):** "recombines
stored elements to simulate future events; same network for remember-last-trip and imagine-next-trip
(Schacter/Addis/Buckner)." Spens & Burgess 2023 (*Nat Hum Behav*): **hippocampal replay TRAINS a generative model**
that yields "semantic memory, imagination, episodic future thinking, RELATIONAL INFERENCE and schema-based
distortions." "Generative replay underlies compositional inference in the hippocampal-prefrontal circuit" (*Cell*
2023). ⇒ **Reframe #4: imaginative recombination = replay-driven offline recombination of stored parts** — the
biology-native engine that turns episodic pieces into inferable/novel structure. **The project has the replay
machinery** (NREM scaffolding + the Bouhadjar excitability-replay roll-out used for EMERGE generation). **Maps to
spikes**, but is the DEEPEST/most-open of the four; do it AFTER 2a–2c.

### 2e. RAG / open-book QA — the one that is intrinsically the (minimized) generator's job, PLUS the half the project already owns
RAG (Lewis 2020) = a small parametric generator + a NON-parametric retrieval store; retrieval "supplements the LM with
external knowledge, reducing hallucination." The field-consensus split: **retrieval supplies the FACTS (breadth,
grounding, low-hallucination); the generator supplies the FLUENT WORDING.** ⇒ **Reframe #5: the project's VSA
store + no-confab moat + parser-verify IS the hard, distinctive, low-hallucination HALF of a RAG that most RAG
systems LACK** (they retrieve but still confabulate; the moat is a *verified* retrieval). The FLUENT-wording half is
R1 (the minimized generator) — **intrinsically the LLM's job, a scaffold to minimize, not a spiking mechanism to
simulate.** Memory-augmented nets (NTM; Memformer) and open-book QA confirm: the read/write external store is the
learnable substrate part; the coherent free-text emission is the generator's. **The retrieval half maps to the
substrate (already built); the generation half is the minimized generator.**

**Net of §2.** The current framing ("open-domain = a hard separate faculty") over-scopes it. The biology + field say:
**analogy, schema-filling, spreading-activation completion, and imaginative recombination are all the SAME distributed
substrate (overlapping codes + next-state predictor + replay) run in a completion/mapping mode** — and the substrate
has all three ingredients. **Open GENERATION and open-domain BREADTH-as-world-knowledge are the parts that are
intrinsically the minimized generator's job (RAG split) — scaffolds to minimize, not simulate.** The genuinely-new
spiking frontier is (c) open-world inference, and it is cheap.

### (a) ★ CHEAPEST + HIGHEST-VALUE — SPREADING-ACTIVATION SEMANTIC COMPLETION (graded-confidence, not hard abstain)
- **Mechanism.** A novel/partial cue does not match a stored fact → instead of a hard abstain, PROPAGATE activation
  through the brain's LEARNED associative codes (stream-cortex co-occurrence + the SVO store) to the cue's nearest
  neighbours, and offer their shared properties as a HEDGED completion ("I wasn't told about X, but X is coded near
  {frog, fish} — it probably swims"). This is CA3 pattern completion (D.13) over the learned semantic graph, i.e.
  spreading activation with the associative weights LEARNED (the piece classical Collins-Loftus lacks).
- **Citation.** Collins & Loftus 1975 (spreading activation); Rogers & McClelland 2004 (feature completion,
  generalizes to novel concepts); **catalog D.13 CA3 pattern completion (Marr 1971; Kandel Ch 54 pp 1342, 1360–1361)**;
  the moat directive `feedback_moat_not_hard_lossy_memory_ok` (a graded hedge is a legitimate PLUS, not a
  moat-weakening — abstain becomes "here's my best guess, flagged as a guess").
- **Reusable machinery.** The stream-cortex codes (`_phaseB_onbridge_stream_cortex`; the 1024-word emergent codes);
  the SVO relational store + `query_chain` neighbourhood scan (`rf_phasor_composer.py:721`); the unified console's
  routing (`_realcorpus_unified_talkable_console.py`). The propagation = a settling/kWTA over the code-similarity
  graph the codes already define.
- **Cheap-first de-risk.** For a HELD-OUT concept never taught a property but co-occurring in the corpus with taught
  concepts, ask "does X <property>?" → completion returns the neighbourhood-majority property with a confidence
  score. GO: held-out completion accuracy ≫ chance AND clearly hedged; **anti-cheats:** (1) **deranged-neighbourhood**
  (random wrong neighbours → completion collapses to chance — the learned codes are load-bearing); (2)
  **disjoint-code MOAT** (a concept with NO learned neighbours → completion returns "I genuinely don't know," NOT a
  fabricated guess — the moat still fires for the truly-isolated); (3) **confidence-calibration** (the hedge
  confidence tracks neighbourhood tightness: tight cluster → confident, sparse → "just guessing"); (4) 6-seed.
- **Moat argument.** The moat is PRESERVED and UPGRADED: it becomes graded (per the owner directive). A completion is
  emitted ONLY when the cue has learned neighbours AND is flagged as inference-not-fact; a truly-disjoint cue still
  hard-abstains. It can never assert a fabricated fact as certain (the confidence flag + the disjoint-abstain guard).
- **`sim/` edit:** NONE (settling/kWTA over existing codes + console routing).
- **Why first:** it most directly converts "bounded inventory → talk about the ADJACENT unknown," reuses the two most
  validated assets (stream codes + store), and is the cheapest airtight anti-cheatable probe.

### (b) SCHEMA / SCRIPT DEFAULT-FILLING via the HTM next-state predictor over the relational graph
- **Mechanism.** Run the emergent HTM temporal-memory predictor (already the substrate's core) over the learned
  event/relational graph to predict the UNSTATED-but-typical continuation of a partially-described situation
  (successor-representation-style multi-hop reachability latent in a one-step predictor). "The X entered the shop →
  [predict typical] bought → left."
- **Citation.** Schank & Abelson 1977 (scripts); Stachenfeld-Botvinick-Gershman 2017 *Nat Neurosci* (successor
  representation → generalization/inference); Whittington 2020 TEM (factorize structure × content → transfer);
  *Nat Rev Neurosci* 2024 "Schemas, RL and mPFC". Catalog D.02 (relational binding), D.21 (cognitive-map inference).
- **Reusable machinery.** The EMERGE-14 HTM on-bridge learner (`_emerge14_stageC_onbridge_learning`) + its
  next-state prediction; the SVO store as the relational graph; the transitive-ordinal axis learner (regimeB).
- **Cheap-first de-risk.** Teach a small event corpus (a few scripts with typical orderings); test whether the
  predictor infers the UNSTATED typical next event for a held-out partial script. **Anti-cheats:** permuted-script
  (scramble event order → prediction collapses); dAP-lesion; held-out scripts; the "atypical override" test (a
  stated exception beats the default-filled typical — like cancellation). 6-seed.
- **Moat argument.** A default-filled continuation is flagged as a TYPICAL-EXPECTATION (schema inference), never a
  stated fact; a stated exception overrides it (the cancellation machinery already validated). Confabulation-safe by
  the typical-vs-stated flag.
- **`sim/` edit:** NONE (reuse the predictor). Do after (a).

### (c) ANALOGICAL TRANSFER via the VSA parallelogram on CORPUS-MINED relational codes
- **Mechanism.** `x = (c ⊛ a⁻¹) ⊛ b` (Komer-Stewart / the conceptual-hyperspace parallelogram) on the FHRR composer's
  own spiking bind/unbind — BUT on CLEAN relational codes MINED from the corpus (the regimeB axis discipline), not the

- **Citation.** Gentner & Forbus 2025 (SME); "Analogical Reasoning Within a Conceptual Hyperspace" arXiv 2411.08684
  (2024); Furlong & Eliasmith 2024 (VSA ↔ generative); Komer & Stewart 2020 (arXiv 2010.06746, SPA analogy recipe);

- **Reusable machinery.** `rf_phasor_composer.py` `unbind`/bind/bundle/cleanup; `factored_relation_analogy.py`;
  `_regimeb_corpus_mined_axis_derisk.py` (the mining discipline); `_corpus_svo_extract.py` (attested-fact provenance).
- **Cheap-first de-risk.** Mine ONE clean relation axis from the corpus (e.g. part-of, or the size ordinal); build
  clean additive relational codes on it; run the parallelogram for held-out A:B::C:? analogies. **Anti-cheats
  (foreground the 2026-05-14 over-claim precedent):** (1) **lesion (skip the transform)** → collapses to memorization
  floor (already validated); (2) **permuted-relation** → collapses to floor (validated); (3) **CODE-PROVENANCE** —
  the relation must come from corpus-mined structure, not a hand-built axis (permuted-mining collapses, per regimeB);
  (4) 6-seed with the harder controls, per the standing "never gate on a weak control" lesson.
- **Moat argument.** The cleanup + a similarity threshold: an analogy that lands on no clean concept ABSTAINS
  (no fabricated analogy); the analogy is flagged as inference.
- **`sim/` edit:** NONE. Do after (a)/(b); the honest scope is that analogy works only where the corpus supports a
  clean minable relation — a genuine boundary, honestly named.

### (d) MULTI-REFERENT DISCOURSE via WTA biased-competition (the one specified missing dialogue mechanism)
- **Mechanism.** Winner-take-all biased-competition inhibition between ≥2 held referent attractors so a bare pronoun
  binds the salient/grammatically-cued one (the specified fix from the two converging NEGATIVEs).
- **Citation.** `2026-06-17-multireferent-disambiguation-NEGATIVE` (recency + salience-boost both failed → WTA

- **Cheap-first de-risk.** Two held referents + a bare pronoun + biased-competition inhibition → the cued referent

- **Moat argument.** Empty/ambiguous WM abstains rather than guessing a referent (moat preserved).
- **`sim/` edit:** likely NONE (reuse lateral inhibition). Secondary to (a)–(c).

### (e) IMAGINATIVE RECOMBINATION via replay-driven offline recombination (deepest, deferred)
