## EXECUTIVE SUMMARY (read this first)

The central hypothesis is **CONFIRMED with one important qualification.** The navigation agent's characterized cold-start — a weak attractive pull but no precise goal-localization, resisting reward-bootstrap, fixed scaffolds, and adaptive weaning — is, at root, a **wrong-pathway** problem. The project routes navigation through `retina → V1 → V2 → IT → cortex_X`, which is the **ventral "what" / object-recognition stream** (catalog E.12; Kandel 6e Ch 24). But precise, spatially-graded, action-driving goal-localization in biology is a function of the **dorsal "where/how" stream** (V1→MT→MST→posterior-parietal/LIP; catalog E.13; Kandel Ch 25), the **superior colliculus** innate retinotopic salience/orienting map (catalog A.07/H.25; Kandel Ch 35), and the **hippocampal place/grid system**, whose CA1 place-cell population forms a **goal-convergent vector field** that points to the goal from any location and *re-points when the goal moves* (Ormond & O'Keefe, *Nature* 2022). IT is an object recognizer optimized to be **viewpoint- and location-INVARIANT** — i.e. it deliberately discards the position information navigation needs; asking it to localize is asking the one cortical area built to *throw away* "where" to provide "where." The qualification: the gridworld goal is an object the agent must *both recognize and localize*, and biology uses the two streams *together* (the ventral stream identifies the valued goal, the dorsal stream localizes it and drives the action toward it), so the fix is to **add the missing "where" pathway alongside the existing "what" pathway**, not replace IT.

The recommendation is a **two-layer, cheap-first build that maximally reuses what already exists and composes exactly with the already-biologized BG output (N8 GPi→thal disinhibition) and spiking decision (N6 accumulate-then-commit):**

- **Layer 1 (the de-risk, cheapest): an innate superior-colliculus orienting reflex** that replaces the hand-coded coordinate heuristic. The SC is a *non-learned, hard-wired* retinotopic salience map that triggers reflexive orienting/approach toward salient stimuli (Nature Comms 2025 "preference-independent saliency map"; Basso & May review). Biologically it is **released by SNr/GPi disinhibition** (catalog A.07/H.25) — *the project already built exactly this disinhibition gate in N8.* So a SC orienting reflex is **not a cheat** — it is the textbook innate scaffold (a tectal orienting response, present in lamprey, that bootstraps before cortex matures), and it can be wired so its drive is read FROM the retinotopic image (a salience blob's retinal position → a cardinal push), with **no coordinate access**. It also supplies the missing teaching signal: SC→VTA dopamine (Nat Comms 2022) links orienting-to-salience to the corticostriatal RPE the gauge found had "no teacher."

- **Layer 2 (the durable learned circuit): a dorsal/where read-out** — a small retinotopic-position population (the salience blob's *location* in the visual field, a parietal/PPC-style egocentric code) feeding `cortex_X`, so the learned navigation pathway reads a representation that *preserves* position (unlike IT). This is the actual fix to "IT can't localize." It can reuse the project's existing-but-coordinate-fed `ppc_goal_input`/`sensor_place_readout` regions (catalog G.05 explicitly notes the goal-cells region "is closer to PPC than PFC") by re-sourcing them from vision instead of coordinates.

**Cheapest first step (falsifiable, before any sim/ change):** a SC-orienting-reflex smoke test — replace the coordinate heuristic-teacher with a reflex whose push is computed from the *retinotopic salience-blob position* (centroid of the rendered goal in the V1/retina image), no `(gx,gy)` read. Gate: the actual cheat-5 multi-goal navigation score (NOT a proxy), with the coordinate-heuristic as the cheat-on baseline and a no-op (reflex-off) control, multi-seed (≥3 then 6). If the reflex alone navigates (it should — it is the same information the heuristic uses, but legitimately sensed), the cold-start's "no innate teacher" half is solved biologically; then Layer 2 makes the *learned* `where→cortex_X` mapping self-sufficient (the N1 weaning target), and the O'Keefe goal-vector-field flexibility directly attacks the N6 goal-change residual. Anti-cheat throughout: the orienting drive must derive only from the retinotopic image (salience position), never from host coordinates; gate on nav score; multi-seed. **This is the single cheapest biologically-grounded path and it reuses the N8 disinhibition gate, the visual_cortex.py retina/V1 front-end, the transmission_gate routing, and the existing PPC-like goal region — most of the build already exists.**

## 1. DIAGNOSIS — is ventral-IT routing the root cause?

### 1.1 What the architecture actually does (verified against code, not notes)

`build_bg_brain_regions` in `g11_bg_runner.py` wires the visual path as a **pure ventral stream**:
`retina (2048) → cortex_v1_simple (8192) → cortex_v1_complex (2048) → cortex_v2 (512) → cortex_it (128) → cortex_{N,E,S,W}` (`g11_bg_runner.py:1796–1904`). The final hop, **`cortex_it → cortex_X`** (zero-init, STDP-grown after a warmup; `g11_bg_runner.py:1887–1904`), is the pathway the owner's findings identify as the one that cold-starts. `sim/visual_cortex.py` confirms the front-end is Hubel-Wiesel V1 Gabors → phase-pooled complex cells → V2 → IT, "For v1 we skip V4 (no color)… cortex_it → cortex_X motor planning" (module docstring, lines 10–22). **There is no dorsal stream anywhere** — a grep for `mt`/`mst`/`ppc`/`parietal`/`dorsal` region names in the nav runner returns **zero** structural matches (the only `ppc_goal_input`/`sensor_place_readout` regions are the coordinate-fed hippocampus stub, `g11_bg_runner.py:957–977`, not a visual where-stream).

So at the architecture level the hypothesis is **structurally true by construction**: the only learned perception→action route is through IT, an object-recognition area.

### 1.2 Why this is the root cause — IT is built to DISCARD "where"

The ventral stream's defining computational signature is **viewpoint- and position-invariant object identity**: "IT cells fire to specific objects across viewpoint" / "viewpoint invariance" (catalog **E.12**; Kandel 6e Ch 24 ~p 568–587). Invariance to position is the *feature*, not a bug — it is what lets you recognize an apple anywhere in the visual field. But precise goal-localization needs the *opposite*: a representation that **preserves and grades with** the goal's spatial position. The two-streams literature is explicit that this division of labor is fundamental: "features related to object recognition are primarily encoded in the ventral–temporal 'what' pathway, while spatial relationships among objects are primarily encoded in the dorsal–parietal 'where' pathway… the What stream recognizes valued objects while the Where stream directs appropriate goal-oriented actions towards them" (two-streams review syntheses; Goodale & Milner). The dorsal stream specifically "deals with the size, geometrical structure, **location**, and disposition of a goal object, mediating the visual control of skilled actions" (Goodale 2013, *Dev Med Child Neurol*).

**This is the precise mechanism of the owner's characterized boundary.** The gauge finding (`2026-06-06-perceptual-bootstrap-gauge-BLOCKED.md`) says the agent "can sense 'the goal is roughly over there' but never pinpoint it." That is exactly what a position-invariant IT code yields: IT (after pooling away position through V1-complex max-pooling and V2/IT spatial generalization) can report "a goal-like object is present" (a weak undifferentiated pull) but has thrown away the graded retinotopic position needed to drive the *correct cardinal* with the precision required to land on the goal. Reward+exploration can't recover information that the architecture deletes upstream — which is why 6000 steps of corticostriatal learning stayed flat at the ~5-cell floor (gauge BLOCKED), and why neither the fixed critical-period scaffold (`2026-06-06-N1-critical-period-scaffold-TRACTABLE.md`, non-monotonic/seed-fragile) nor adaptive weaning (`2026-06-07-N1-adaptive-wean-multiseed-NEGATIVE-bank.md`, 1/3) could robustly consolidate a self-sufficient mapping: they were trying to teach a durable `IT→cortex_X` localizer through a bottleneck that doesn't carry localization.

### 1.3 What biology actually uses for precise perception-driven goal-localization

Three systems, all present in the catalog, all currently **missing or mis-wired** for navigation:

1. **Dorsal "where/how" stream** (catalog **E.13**, status *missing*; Kandel Ch 25 ~p 593–600): V1→MT/V5 (motion/direction)→MST (optic flow/self-motion)→**posterior parietal cortex / LIP** (egocentric spatial coordinates, visuomotor transformation). PPC lesion → **optic ataxia** ("can see but can't act" — the exact phenotype of "senses the goal but can't reach it"). This is the cortical pathway that converts a seen target's *location* into an action vector.

2. **Superior colliculus / optic tectum** (catalog **A.07** = SNr→SC orienting, and **H.25** = SC topographic "where to look/go next" map; Kandel Ch 35 ~p 875–882): an **innate, hard-wired retinotopic salience map** that triggers reflexive orienting/approach toward salient stimuli — "computes a salience map of locations and prioritizes the most behaviorally salient locations as targets for action, including orienting responses" and a **"preference-independent" (i.e. innate, not learned) saliency map** in mouse SC (Nat Comms 2025). Phylogenetically older than cortex (present in lamprey; catalog A.07). **Crucially it is released by SNr/GPi tonic-inhibition disinhibition** (catalog A.07/H.25: "Receives BG (SNr) tonic inhibition; selection by SNr disinhibition") — *the exact gate the project already biologized in N8.* This is the **innate scaffold** the gauge's prescription called for ("an innate salient-goal-approach reflex — a tectum/SC orienting response — more biological than the coordinate heuristic").

3. **Hippocampal place / grid / head-direction system** (catalog **D.06/D.07/D.08**; O'Keefe-Nadel; Mosers). The decisive recent result: **CA1 place cells form a goal-oriented vector field** — "the population vector field converged on the goal, providing a strong navigational signal," with "convergence sinks (ConSinks) centred near the goal location," and "changing the goal location led to movement of ConSinks and vector fields towards the new goal" (Ormond & O'Keefe, *Nature* 2022, DOI 10.1038/s41586-022-04913-9). This is a *learned, allocentric, goal-pointing* spatial code — the highest-precision biological goal-localizer, and its flexibility under goal-change is exactly what the moving-goal benchmark stresses.

### 1.4 Strong vs weak points of the hypothesis (rigor — not just agreeing)

**Where the hypothesis is STRONG:**
- *Architectural*: there is literally no "where" pathway; navigation's only learned route is through a position-invariant object recognizer. (verified, §1.1)
- *Mechanistic*: IT's invariance directly predicts "weak pull, no localization" — the observed phenotype. (§1.2)
- *Convergent with the project's own diagnosis*: the gauge already prescribed "sharper goal-localization in IT OR an innate SC orienting reflex." This review supplies the biology for *why* and *how*.
- *The catalog independently flags all three gaps*: E.13 dorsal stream *missing*, G.05 PPC *missing* (and notes the goal-cells region "is closer to PPC than PFC"), A.07/H.25 SC *missing*, D.06 place cells *partial/sensor-driven-not-allocentric*. The owner's boundary sits exactly on the catalog's largest perception gaps.
- *It composes*: the SC orienting reflex is released by SNr disinhibition = the N8 gate already built; SC→VTA supplies the DA teaching signal the gauge said was absent.

**Where the hypothesis is WEAK / needs qualification:**
- **The goal IS an object** the agent must recognize, so *some* ventral involvement is legitimate. Biology uses both streams together ("What recognizes the valued object, Where localizes and acts"; two-streams syntheses). The fix is **add Where alongside What**, not delete IT. In the current toy world there's one goal type, so recognition is trivial and the *entire* deficit is localization — but keeping IT future-proofs multi-object worlds.
- **Small grids may not need grid cells.** Grid cells (D.07) provide a context-invariant metric for *path integration over large environments / shortcutting*; on an 8×8 grid with the goal in view, a retinotopic salience position is sufficient and far cheaper. Grid cells are a *scaling* answer, not the *cold-start* answer. (Don't over-build.)
- **Place cells are also partly a scaling/flexibility answer.** The O'Keefe goal-vector field is the *gold-standard* localizer and directly addresses goal-change, but it requires a real trisynaptic loop (D.03) + allocentric inputs; that's a heavier lift than a SC/dorsal read-out and is better staged *after* the cheap SC+dorsal front-end proves the diagnosis.
- **The dorsal stream proper (MT/MST) is about MOTION/optic-flow.** A static gridworld render has no motion; so a *full* MT/V5 build is overkill. The load-bearing dorsal component here is the **PPC egocentric-position read-out** (target location in the visual field → action), not motion energy. Frame Layer 2 as "PPC-style retinotopic position read-out," not "build MT."
- **Risk that the SC reflex re-imports a coordinate cheat.** It is only legitimate if its drive derives from the *retinotopic image* (salience-blob position in pixels), never from `(gx,gy)`. This must be an explicit anti-cheat control (§4).

**Net diagnosis:** Ventral-IT routing **is** the root cause of the precise-localization failure. The principled fix is a **dorsal/where + collicular-orienting front-end added alongside IT**, gated by the BG disinhibition the project already has. Place/grid cells are the next-tier (scaling/flexibility) answer, not required to break the cold-start.

## 2. RANKED MENU OF BIOLOGICALLY-GROUNDED ARCHITECTURES

Ranked by *cheapest-biologically-grounded-path-that-breaks-the-cold-start* first. Each notes grounding, composition with N8 (GPi→thal disinhibition) + N6 (spiking decision), and tractability.

### Rank 1 (RECOMMENDED — cheapest, highest-ROI) — Innate superior-colliculus orienting reflex (the legitimate replacement for the coordinate heuristic)
- **Mechanism:** A non-learned retinotopic salience map (read the goal-blob's centroid position in the retina/V1 image) → a hard-wired reflexive push into the cardinal `cortex_X` toward the salient location. Released/gated by SNr-GPi disinhibition (so it is a *real* BG-gated orienting response, not an unconditional override). Innate, fades as the learned circuit matures (developmental scaffold).
- **Grounding:** Catalog **A.07** (SNr→SC orienting, lamprey-conserved), **H.25** (SC topographic "where-to-go-next" map, released by SNr disinhibition); Kandel 6e Ch 35 p 875–882, Ch 38 p 938–942. Innate/non-learned salience: "preference-independent saliency map in mouse SC" (Nat Comms 2025, DOI 10.1038/s42003-025-08006-x); "SC computes a salience map… orienting responses toward objects" (Basso/May & SC reviews); innate approach circuits (lateral SC → ZI prey/approach). Teaching-signal link: **SC→VTA dopamine** modulates DA neurons projecting to dorsolateral striatum and "controls orienting response" (Nat Comms 2022, DOI 10.1038/s41467-022-28512-4) — supplies the RPE the gauge found missing.
- **Composes with N8/N6:** *Perfectly.* The SC orienting drive enters at `cortex_X`, upstream of the already-biologized cascade; the SNr-disinhibition gate is the very mechanism N8 built (`--genuine-thal-disinhibition`, GPi-tonic + D1-release; `2026-06-06-N8N6-combined-readout-GO.md`). The N6 accumulate-then-commit decision reads the clean thalamic winner exactly as today. The reflex *adds an upstream input* and changes nothing downstream.
- **Why it breaks the cold-start:** It is the textbook **innate scaffold** that the N1 weaning arc was hand-faking with the coordinate heuristic. It legitimately senses the same "go toward the salient blob" signal *from vision* (no coordinates), so it both navigates AND teaches the learned `where→cortex_X` mapping (via SC→VTA DA), turning the chicken-and-egg ("no reward → no teacher → no learning") into a solved bootstrap.
- **Cost/tractability:** **LOW.** Reuses `sim/visual_cortex.py` rendering + retina; the "salience centroid → cardinal push" is a few lines of host code reading the *image* (same legitimacy bar as a sensed beacon). The disinhibition gate already exists. Likely *no `sim/` edit* (additive runner flag, like the existing cue-reflex but sourced from retinotopic salience instead of `(gx,gy)`). This is the de-risk in §4.

### Rank 2 (the DURABLE learned fix) — Dorsal/PPC retinotopic position read-out feeding `cortex_X`
- **Mechanism:** A small population encoding the **egocentric retinotopic position** of the salient goal in the visual field (the salience-blob location, a coarse 2-D map / population code), projecting plastically to `cortex_{N,E,S,W}`. This is the "where" representation that *preserves position* (unlike IT), so STDP+reward can learn a *precise* position→action mapping. Frame as PPC/LIP egocentric read-out, not full MT.
- **Grounding:** Catalog **E.13** (dorsal where/how; PPC = egocentric coordinates; lesion→optic ataxia), **G.05** (PPC spatial planning — and the catalog's own note: "Goal-cells region in g11_bg_runner is closer to PPC than PFC"); Kandel Ch 25 p 593–600, Ch 34 p 826–832. The "What+Where together" division: dorsal carries "size, structure, **location**… for visual control of action" (Goodale 2013).
- **Composes with N8/N6:** Same as Rank 1 — it injects at `cortex_X`, upstream of the cascade; downstream N8/N6 unchanged. It is the *learned* counterpart that Rank 1's innate reflex scaffolds and then hands off to (the N1 "wean the teacher, keep the learned circuit" goal — but now the learned circuit reads a *localizable* code, so consolidation should be durable where `IT→cortex_X` was not).
- **Why it breaks the cold-start:** Directly fixes §1.2 — gives the learned pathway a position-graded input. This is what makes the post-wean agent *self-sufficient* (the thing the fixed/adaptive scaffolds couldn't achieve through IT).
- **Cost/tractability:** **LOW–MEDIUM.** Can reuse the *existing* `ppc_goal_input`/`sensor_place_readout` regions by **re-sourcing them from the retinotopic salience map instead of coordinates** (the wiring `*_to_cortex_X` plastic pathways already exist, `g11_bg_runner.py:964–977`; only the *drive* changes from `(x,y)/(gx,gy)` to sensed blob-position). Pairs naturally with Rank 1 (reflex teaches it). Possibly no `sim/` edit.

### Rank 3 (scaling/flexibility, not the cold-start) — Hippocampal place-cell goal-vector field (reuse the existing hippocampus)
- **Mechanism:** A real trisynaptic loop (EC→DG→CA3→CA1) producing allocentric place cells whose CA1 population forms a **goal-convergent vector field** (ConSinks at the goal), read out to `cortex_X`. Goal-vector re-points when the goal moves — the gold-standard flexible localizer.
- **Grounding:** **D.06** place cells (O'Keefe 1971; Kandel Ch 54 p 1361–1366), **D.21** cognitive-map theory, **D.22** locale-vs-taxon; **Ormond & O'Keefe, Nature 2022** (goal-oriented vector fields, ConSinks, re-point on goal-change). The **D.22** entry is strikingly on-point: it maps the project's BG cascade to the **taxon** (egocentric, incremental-STDP, slow-to-re-acquire) system and the hippocampus to the **locale** (allocentric, one-trial, fast-re-acquire) system, and predicts the *most informative test is goal-change*: "locale should re-acquire fast, taxon slow." **This is precisely the N6 residual** (`2026-06-06-N6-decision-biologized-CONCLUSION.md`: the spiking decision's cost is "concentrated entirely in the post-goal-change phases") — the current agent is *taxon-only*, so its goal-change lag is the expected signature of a missing locale system. A place-cell goal-vector read-out is the biologically-correct cure for that residual.
- **Composes with N8/N6:** Read-out to `cortex_X` (upstream of cascade); N8/N6 unchanged. The project *already has* the trisynaptic regions in `text_minimal_isolation.py` `build_biological_brain_regions(enable_hippocampus_consolidation=True)` (EC/DG/CA3/CA1 + a `ca1→place_cells` readout; validated for pattern separation/completion in `2026-05-11-P1-trisynaptic-loop-validation.md`) — but they live in the *conversational/memory* builder, not the nav runner, and the place cells are coordinate/landmark-driven, not allocentric-from-vision.
- **Why it's Rank 3 not Rank 1:** Heavier lift (port the trisynaptic loop into the nav runner; drive place cells from *vision/self-motion* allocentrically per the D.06 supplemental criterion, not from coordinate sensors; build the goal-vector read-out). It is the **best** localizer and the **right** goal-change fix, but it should be staged *after* the cheap SC+dorsal front-end proves the diagnosis and clears the cold-start. It is the *scaling/flexibility* tier.
- **Cost/tractability:** **MEDIUM–HIGH.** Reuses substantial existing machinery (trisynaptic builder, place-cell readout) but requires allocentric vision-driven place fields (currently sensor-driven — the catalog's standing D.06 discrepancy) + a goal-vector read-out + multi-seed validation of remapping.

### Rank 4 (do NOT build now) — Full MT/MST motion-energy dorsal stream, grid cells, head-direction cells
- **Why excluded for the cold-start:** MT/MST (E.14) is about *motion/optic-flow*; the static gridworld render has none. Grid cells (D.07) are a large-environment metric/path-integration mechanism — overkill on 8×8 with the goal in view. HD cells (D.08) need a heading population. All are legitimate *future scaling* additions (and well-catalogued), but none addresses the *cold-start* and each is a substantial build. **Explicitly de-prioritized** to avoid over-building (the owner's repeated "don't gold-plate / probes must match the deployed need").

## 4. RECOMMENDED APPROACH — the single cheapest biologically-grounded path, with a falsifiable de-risk

**Recommendation: Rank 1 (innate SC orienting reflex) as the de-risk, then Rank 2 (dorsal/PPC retinotopic read-out) as the durable learned circuit. Stage Rank 3 (place-cell goal-vector) only after Ranks 1–2 clear the cold-start.** This is the cheapest path that (a) is biologically principled, (b) reuses the N8 disinhibition gate + visual front-end + existing PPC-like region + transmission_gate, and (c) composes with N6 unchanged.

### CHEAP-FIRST DE-RISK (run before committing to a full build — falsifiable smoke test)

**The test:** Replace the coordinate heuristic-teacher (N1, `g11_bg_runner.py:4071–4097`, drives `cortex_X` from raw `(gx,gy,x,y)`) with an **innate SC orienting reflex whose push is computed from the retinotopic salience-blob position** — i.e. find the goal-blob centroid *in the rendered retina/V1 image* (`visual_cortex.py` render), convert its offset-from-center into a cardinal push into `cortex_X`, gated by the N8 SNr-disinhibition. **No `(gx,gy)` read** — only the image.

**Falsifiable prediction / gate:** On the **actual cheat-5 multi-goal navigation score** (sum of per-phase final-quarter mean distance; LOWER better — the real benchmark, NOT a proxy), the SC-reflex agent should navigate *comparably to the coordinate-heuristic baseline* (because it uses the same information — "go toward the salient goal" — but legitimately sensed from vision). 
- If it **navigates** → the cold-start's "no innate teacher" half is solved *biologically* (a tectal orienting response, not a coordinate cheat); proceed to Rank 2 (the durable learned read-out) + wean the reflex via `transmission_gate`.
- If it **fails** (e.g. the salience blob is too coarse after rendering, or the reflex can't drive a clean cardinal) → the diagnosis that "the information is there in the retinotopic image, just not in IT" is **refuted for this render**, and the next step is the N2 render fidelity / a sharper salience read-out — a cheap pivot, learned before any heavy build.

**Why this is cheap:** it is the existing `--cue-reflex` pattern (`g11_bg_runner.py:4099–4134`) but with the drive **re-sourced from retinotopic salience instead of `(gx,gy)` bearing** — likely an additive, default-off runner flag with **no `sim/` edit**. It reuses the render, the retina, and the N8 gate. One seed smoke (~minutes at grid-8), then ≥3 seeds.

### ANTI-CHEAT CONTROLS IT NEEDS (non-negotiable, same rigor as the conversational arc)
1. **The gate is the actual nav score** — cheat-5 multi-goal sum-finalQ, not a perception proxy. (matches the audit's "gate on the benchmark, NOT a proxy".)
2. **No coordinate leakage** — the orienting drive must be derived *only* from the rendered retinotopic image (salience-blob position in pixels); assert no `(gx,gy)`/`(x,y)` enters the reflex. A coordinate read here would silently re-import N1. (This is the single biggest correctness risk.)
3. **Baselines:** the coordinate-heuristic-ON config (the cheat-on "before") **and** a no-op reflex-OFF control (visual cortex alone, the known ~5-cell floor) — the reflex must beat the floor and approach the heuristic.

## Net for the nav arc

The perceptual cold-start (N1/N2/N7), characterized across three honest negatives, is a **wrong-pathway** problem: navigation is routed through the position-*invariant* ventral "what" stream (IT), which by design discards the localization signal navigation needs. The principled, biology-grounded, catalog-backed fix is to **add the missing "where" front-end** — cheapest-first an **innate superior-colliculus orienting reflex** (the legitimate, textbook replacement for the coordinate heuristic-teacher, *released by the SNr/GPi disinhibition the project already biologized in N8*, and supplying the SC→VTA dopamine teaching signal the bootstrap gauge found absent), then a **dorsal/PPC retinotopic position read-out** (the durable learned localizer, re-sourcing the project's existing PPC-like goal region from vision), with the **hippocampal place-cell goal-vector field** (Ormond & O'Keefe 2022; catalog D.06/D.21/D.22) staged later as the scaling/flexibility tier and the biologically-correct cure for the N6 goal-change residual. The de-risk is a falsifiable SC-orienting smoke test on the real nav score with strict no-coordinate-leakage controls, reusing the existing render + retina + N8 gate + transmission_gate — most of the build already exists, and it composes with N6 unchanged.
