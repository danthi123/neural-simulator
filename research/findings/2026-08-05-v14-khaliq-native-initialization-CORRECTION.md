# Khaliq source-native initialization correction

## Decision

Do not describe the Khaliq/Raman comparator as an exact unmodified source-code
transfer. Its author-supplied `seqinitial` equations produce a negative blocked
state at every preregistered voltage and do not produce a stationary state of
the source kinetic graph.

The source transition graph remains eligible as a separately labelled
`kinetic_graph_stationary` comparator. That comparator must initialize from
the stationary distribution of the declared 13-state graph, disclose that
this differs from native `seqinitial`, and cannot claim source-code
initialization equivalence. No transition, rate, conductance, or temperature
parameter may be changed.

| 0 mV | -7.013e-2 | B | 8.330e-6 |
| +30 mV | -2.774e-1 | B | 5.013e-6 |

The clamp retained every voltage to floating-point precision, and each native
state vector summed to one. The negative `B` occupancy therefore is not a
voltage-control artifact or a normalization failure. Every voltage violates
the preregistered nonnegativity rule, and every one-step change exceeds the
`1e-8` stationarity threshold. The preregistered classification is
`SOURCE_NATIVE_INITIALIZATION_DEFECT`.

## Source explanation

The NMODL `seqinitial` block contains two equations that differ from the
declared kinetic graph: the `O`/`B` row adds both flux terms instead of using
opposite signs, and one `I3` row uses `I4*bi3` where the graph implies the
reverse `I4*b13` transition. This finding establishes executed behavior and
does not infer which source line was intended.

Graph-equilibrium initialization is biologically coherent because it is the
stationary occupancy of the unchanged channel-state transitions at the assay
holding voltage. It is nevertheless a project assay convention, not a claim
about the source package's native initialization.

## Consequence

The successor execution contract must:

1. rename the Khaliq arm to identify graph-stationary initialization;
2. bind this finding and oracle receipt;
3. keep Khaliq temperature absent because `rsg.mod` has no temperature term;
4. bind Balbi to the source package's 22 C setting;
5. preserve independent Labro and Desai arms and the Labro room-temperature
   uncertainty envelope;
6. continue to forbid conductance fitting, topology hybridization, and Stage 2
   integration before complete source-current gates pass.
