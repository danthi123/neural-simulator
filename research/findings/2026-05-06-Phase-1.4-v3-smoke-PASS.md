## What this validates

The fundamental Path F premise: **biology-grounded learning preserves
old knowledge when learning new vocabulary**. After training 4
primaries (north/east/south/west) and then training 4 NEW synonyms
(up/right/down/left) WITHOUT any primary exposure during Phase B,
primary accuracy went UP, not down.

Mechanism (best understood interpretation):
- Each primary and its synonym share a motor pool target
  (north + up -> motor_N)
- Phase B training events strengthen motor_N's recurrent dynamics
  (cortical canon recurrence amplifies all incoming activity)
- Stronger motor pool dynamics -> better differentiation of all
  inputs targeting that pool, including primaries from Phase A

The pattern was visible at v1 as well (with broken arch):
- v1: 14% post-A, 18% post-B = 129% retention
- v3: 33% post-A, 38% post-B = 115% retention

Across both, primary retention > 100%. No catastrophic forgetting
visible in any of our v1/v3 runs.

## v1 -> v3 iteration history

| Version | Phase A | Retention | Diagnosis |
|---|---|---|---|
| v1 (scale-up arch) | 14% | 129% | Architecture wrong: scale-up was for 8-word synonyms; 4-word vocab gave under-trained motor pools below chance |
| v2 (standard arch, no NMDA) | 25% | (didn't run Phase B) | NMDA missing: BREAKTHROUGH config used `enable_nmda=True`; default was False. NMDA bistability is critical for embodied Hebbian binding |
| v3 (standard arch + NMDA) | 33% | **115%** | All config matches validated Tier 1 v2 BREAKTHROUGH |

Lesson: replicate validated baseline EXACTLY, then deviate only with
clear rationale. NMDA looked like an architectural detail but is the
critical training mechanism.
