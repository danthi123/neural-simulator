## The (B) target (what's still numpy after A)
`core_sim_composition.py` `bind_fact`: spiking binds per role give `(o,f)`; then numpy superposition `bon += o`,
numpy ON/OFF opponency `onoff(bon-boff)`; stored as a numpy (ON,OFF) vector in `self.kb` (a Python list). The memory
is not in the substrate.

## Decisive verdicts
1. **Engram fidelity: BINARIZED, not graded — engram is OUT for graded storage.** An engram = a sparse SET of cells
   (a binary tag set by an encoding threshold) + an attractor basin; reactivation is threshold-gated pattern
   completion. The stored info is WHICH cells fired, not per-cell graded amplitudes; the downstream graded pattern is
   regenerated by the network's recurrent dynamics from the binarized tag. `commit_engram_tag(top_k)` keeps only the
   K highest-rate neurons (a binarization) → an engram-per-fact would silently re-binarize the dense ON/OFF
   superposition the unbind needs. (arXiv:2506.01659 2025; Sci.Adv. PMC11296340 2024; Liu 2012; Josselyn-Tonegawa
   Science 2020.) Engram is fine as a discrete INDEX/address into a per-fact store, NOT as the graded storage.
2. **The crux is SOLVED at this shape:** Choo OSE held a superposition of position⊗item bindings in a spiking gated
   integrator (D=50, recalled by unbind+cleanup); Crawford-Gingerich-Eliasmith 2016 held **117,659 facts** as
   role⊗filler superpositions at **D=512**, each in a ~20-neuron cleanup population, recalled by spiking unbind +
   cleanup (2.5M neurons). My case (M=2-4 bindings/fact, D≈800-2048, vocab≈320) is comfortably inside the
   high-fidelity regime.
3. **Capacity (Frady-Kleyko-Sommer 2018):** reading a component from a superposition needs SNR `s²=4[ln(D-1)-ln 2ε]`;
   for vocab≈320, `s²≈4·ln 319 ≈ 23 → s≈4.8`; at D≥800 with M=4 the achieved SNR clears this several-fold. NOT
   capacity-limited within a fact. Channel capacity ~0.5 bits/neuron; `N ∝ M·ln(vocab)`.
4. **Dense Hopfield is overkill / risky** (iterative retrieval, fuzzy-combination smear for poorly-separated items);
   classical Hopfield is wrong for dense superpositions (0.14N, smears). The **NEF cleanup/associative memory IS a
   single-shot associative memory** (Universal Hopfield Networks, Millidge 2022: cleanup-by-similarity = Hopfield
   retrieval, same separation→projection template) — the same family as the A cleanup I just validated.

## Recommended mechanism — two-store NEF (mirrors CUE / Crawford spiking-WordNet)
1. **Per-fact graded HOLD (active fact)** = a gated NEF integrator (`spa.State` / `InputGatedMemory`):
   - recurrent transform = IDENTITY, feedback gain **= 1.0** (`W_ii = e_i d_i'`), input scaled by τ (`W_ij = τ e_i d_j'`);
     an inhibitory WRITE-GATE (difference ensemble) writes then holds. `feedback_synapse ≈ 0.1 s` (NMDA-like).
   - **Superposition in-network**: drive each role's spiking-bind output into the SAME State with the gate open →
     rate-summation accumulates `Σ_roles (role⊗filler)` on the shared bank (replaces `bon += o`).
   - **Opponency in-network**: a fixed transform decoding `bon − boff` + a thresholded/normalizing nonlinearity (ON/OFF
     lateral inhibition) — replaces `onoff(bon-boff)`.
   - Fidelity ∝ 1/N (Singh-Eliasmith 2006); a line attractor needs gain EXACTLY 1.0 (under-gain decays ∝(1-c)^n,
     over-gain diverges — Timing-over-Tuning 2014); NEF sets gain analytically so you start at the right point.
2. **The ~30-fact KB STORE** = an NEF cleanup/associative memory — one small dedicated population (~20 neurons) per
   fact, the fact's bound vector in STATIC weights; cue → thresholded similarity → clean stored vector. **Zero
   cross-fact crosstalk; capacity linear in #facts.** Do NOT superpose all 30 facts into one vector (crosstalk floor +
   no addressing). Recall a fact = address it (subject cue / engram-style discrete index) → cleanup emits its clean
   bound vector → spiking-unbind → the (A) NEF cleanup → filler.

## Biology cross-check
Persistent-activity WM (the gated State; prefrontal, Singh-Eliasmith) holds the ACTIVE fact; CA3 autoassociation +
cortical associative memory (the NEF cleanup store) is the long-term KB. Activity-silent fast-weight WM (Mongillo
2008; Stokes 2015) motivates "fact in weights" — its faithful realization is the CUE Association-Matrix-Learning
weight store (one-shot, no catastrophic forgetting), which collapses into the same per-fact-store recommendation.

## Implementation caveat
The NEF gated-State / cleanup weights are normally produced by Nengo's solver (encoders/decoders → connection
weights). To put them on the core Izhikevich bridge: either (a) precompute the NEF weight matrices
(`W_ii=e_i d_i'`, `W_ij=τ e_i d_j'`, cleanup similarity weights) offline and inject as fixed pathways, or (b)
approximate the identity-feedback hold + thresholded cleanup with the existing region/pathway + FS-inhibition
primitives. The math above gives the exact weights to target.

## De-risk-first plan (the A pattern)
1. **De-risk the substrate STORE fidelity (the crux):** store ONE fact's bound vector in a per-fact substrate store
   (the bound vector imprinted in a memory population's weights, Crawford-style) AND retrieve it; spiking-unbind every
   role; compare to the numpy-held bound vector's unbind (parity per role, multi-seed). GATE: substrate-held recall
   supports unbind at numpy parity. (High prior confidence per Choo/Crawford.)
2. Then the in-network superposition + opponency (the two linear pieces) on a shared bank.
3. Build into the composer opt-in (like `enable_spiking_cleanup`), no-regression on the capability matrix at D=2048.
