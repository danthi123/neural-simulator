## (1) DIAGNOSIS

### Why recency and salience-boost both went NEGATIVE (the two converging 2026-06-17 negatives)

Both failed for **one structural reason**: the plain `SpikingLoopContextBuffer` holds each referent in an **INDEPENDENT attractor** (`loop_weight=0`, `internal_density=0`) with no cross-referent coupling, and reads out an **instantaneous scalar with no competition**. Consequently:

- **Recency (0/3)** carries no position signal in a rate read — it is a uniformly-decaying rank, and it is only **ONE term** of discourse salience. It provably fails when a re-realized subject must outrank a more-recent object.
- **Salience-boost (fails at 4×)** adds a **fixed additive offset** to one independent attractor. Additive drive neither **suppresses** the competitor nor **normalizes** the field; with 3+ referents a fixed offset cannot guarantee a unique winner and cannot self-scale.
- A **third** converging negative — the **symmetric shared-inhibition WTA (0/6 order-flip)** (`2026-06-17-biased-competition-wta-multireferent-derisk.md`) — removes common-mode from *everyone* and cannot invert a pre-existing per-pattern excitability asymmetry.

The 2026-07-08 REFRAME sharpened this: when a predicate-compatibility SIGNAL cleanly separates referents, a **linear temporal integrator of that signal = 1.000** and a fixed-threshold LCA *underperforms* (0.48→0.19, worse with K) because it makes **premature noise-driven commits**. The missing ingredient was the **right SIGNAL**, plus a **self-calibrating** commit — not "more inhibition."

### What must SELF-ORGANIZE (the emergence-bar residual)

The built stack already beats all three negatives, but two things in it are still **host / hand-designed**, so it does not yet clear the emergence bar (`feedback_spiking_structure_must_self_organize.md`):

1. **The content SCORING** — *which* referent to bias — is still host lookup (`content_bias_target`: ANIMACY × VERB_SELECTS lexicons) or per-step-supervised (D3 Cb Δ teacher). The brain-based target is a **LEARNED synaptic feature-compatibility map** computed by neurons.
2. **The WTA wiring itself** — the `sel_X` / `sel_FS_X` accumulator pools + cross-inhibition — is **hand-installed** via `set_pathway_weights(add_missing=True)` with hand-tuned `alpha<1` and weights. Per the emergence bar this structure should **develop from local wiring rules**, not be installed.

Plus two open **capability** residuals:
3. **The all-COMPATIBLE / feature-silent case** (two same-animacy/number/gender candidates, agreement silent) — the content helper correctly **abstains** (moat-safe) because feature-compatibility ties. This is exactly where a bare pronoun must bind by **composite discourse salience** (recency + role/subjecthood + topicality), which the current buffer does not rank.
4. **The buffer's own 5/6 seed-100-class fragility** — an extreme intrinsic-asymmetry the fixed bias can't flip. The failure mode is an **ABSTENTION (None)**, not a confabulation, so **the moat holds through it**.

**The reframe that guides ranking:** stop trying to *resolve the antecedent* and instead *let an already-salient peak win an underspecified, self-calibrating biased competition*. Salience must be **(a) a graded, self-reinforcing composite** (Grosz-Sidner backward-looking center Cb, fusing recency + role + repeated mention) and **(b) resolved by a self-calibrating inhibitory competition** (divisive normalization / adaptive-threshold WTA) that guarantees exactly one winner for any competitor count — never a fixed additive boost and never a hand-tuned threshold.

### #2 — Centering-Cb priority map read by DIVISIVE NORMALIZATION (the self-calibrating selector for the all-compatible case)

- **Mechanism.** Hold each referent as a graded persistent-activity bump whose **height = discourse priority** (= Cb, the highest-ranked realized entity, subject-preferred, which *continues* across utterances). The bare pronoun injects **nonspecific uniform** readout drive; the winner is the peak selected by **divisive normalization** — each referent's activity ÷ the **pooled sum** of all referents' activity. Feed the buffer's `bias_concept` from D3's already-GO Cb tracker; read it through a divisive-normalization pool.
- **Why biology-grounded + spiking + self-organizing + one-brain.** Divisive normalization is the **canonical self-calibrating cortical computation** (Carandini-Heeger); realized as **feedback inhibition where one FS/graded pool sums total map activity and divides each bump's gain** — the substrate's existing graded-inhibition + `input_mean_adapt` path already implements divisive-like gain control. The threshold **is the pool's own summed activity**, not a hand-set number (this is precisely the self-calibration the task demands). Priority TERMS self-organize: recency from natural bump decay, topicality from STP, subjecthood from a learned parser-role gain. dlPFC persistent-activity WM holds the bumps on one bridge.
- **Why it beats the negatives.** A boost that raises *everyone* leaves the normalized ratio unchanged (kills the salience-boost failure mode); the Cb "continue" rule keeps a re-realized subject salient over a more-recent object (kills the recency failure mode — D3 recency baseline 0.000 vs Cb-track 0.970).
- **Reusable machinery.** D3 `discrete_attractor_rnn` (tracks Cb, length-generalizes 0.97, 6-seed); dlPFC WM loop; the `sel_FS_X` selective-inhibition pool **repurposed as the divisive denominator**; bridge graded-inhibition + `input_mean_adapt`; `MultiTurnAgent._resolve_biased` `focus_bias_source` hook (already stubbed).
- **De-risk.** Add the shared divisive-inhibition stage across the D3 held slots; drive the race with the Cb height. GO bar: on **feature-silent same-animacy** discourses, binds the Cb referent above chance and above recency; no-bias → chance/abstain; feature-flip (swap which referent is Cb via discourse) flips the winner.
- **Risk.** Truly co-equal referents → normalized peak ties → **correct behavior is ABSTAIN** (moat), not a fabricated pick; the `no-bias→chance` control (2026-07-08 = 0.33 at K=3) must hold. Over-high pool gain can over-suppress a genuinely-salient-but-low-activity referent — tune `sigma` so the denominator floors.

### #3 — Grosz-Sidner discourse attentional STACK = the D3 two-gate push/pop register (salience = top-of-stack)

- **Mechanism.** Attentional state is a **stack of focus spaces**; the salient referent is the **top of the active focus space**. A segment boundary (connective + NEW named subject) PUSHES; a discourse-pop (connective + pronoun/return) POPS back to the suspended center. A bare pronoun binds the current top; after a pop it binds the **earlier (resumed) protagonist** — exactly the D3 two-gate event register already built.
- **Why biology-grounded + spiking + self-organizing + one-brain.** Already **fully spiking**: two persistent slow-NMDA attractors on one bridge, push and pop as attractor→attractor transfer via `sim/regions.py` `transmission_gate` + PBWM separate input/output gating (O'Reilly-Frank 2006). **The gates were LEARNED, not hand-set** — by hippocampal-replay + clean-error credit (replay recovers the held slot to 109% of BPTT, one-step local credit, no BPTT). Each slot has its own inhibitory pool so the pop reads without erasing (0.974).
- **Why it beats the negatives.** Recency provably fails *across a subordinated segment* (the most-recent referent is the embedded one, but the correct antecedent after segment-close is the popped superordinate center); the stack pops it off. Binding is a **structural transmission-gate** (which slot is read), not additive drive.
- **Reusable machinery.** The D3 event register end-to-end (`_d3_event_pop_gate_derisk.py`, `_d3_event_gated_copy_spiking_derisk.py`); `set_transmission_gate`; the D3 `MultiTurnAgent` production wire.
- **De-risk.** Nested-segment discourse (embed a clause, then pop): GO bar = pronoun after pop binds the resumed protagonist above recency; register-lesion (frozen focus) → 0.000; boundary/return-cue detector fires RETURN-specifically (D3: 0.845 on pops / 0.031 on boundaries).
- **Risk.** The stack is discrete — it handles nested structure but does **not by itself rank several co-present referents within ONE focus space** (that is #2's job). Best composed **with** the priority-map, not instead of it. A mis-detected boundary pushes spuriously.

### #4 — Theta-gamma phase-multiplexed WM with HOMEOSTATIC self-calibrating commit (solves capacity/merging + the tuned-threshold failure)

- **Mechanism.** Hold K referents in **distinct gamma sub-cycles** within one theta cycle (Lisman-Idiart) so they do not merge; encode salience as **theta phase order** (the prioritized item leads — Siegel-Warden-Miller). The pronoun probes at the leading phase; the selector is a **homeostatic-threshold FS-WTA** whose commit threshold **adapts to the pool's running mean firing** (Turrigiano), not a fixed number.
- **Why it beats the negatives + the 2026-07-08 LCA finding.** Directly fixes the fixed-threshold LCA's premature noise commits (the documented 0.48→0.19 degradation): a homeostatic threshold self-calibrates the commit, no per-K retuning. Phase-multiplexing holds K referents as **separate** salience-ordered codes, not one merged bump whose winner is the seed-dependent intrinsic attractor (the exact failure the negatives hit).
- **Reusable machinery.** The **EMERGE-85** theta-gamma WM buffer + stack-match (catalog N.15, already spiking); `fused_homeostasis_update` / `cp_neuron_firing_thresholds`; `sel_FS_X` gamma FS-WTA; the `OrderedPositionWM` gamma-slot buffer in `MultiTurnAgentV2`.
- **De-risk.** ≥4 held referents at varied salience; GO bar = binds the phase-leading (most-salient) referent, homeostatic commit does not fire on noise, capacity honestly bounded at ~7.
- **Risk.** Phase-coding resolution is **dt-bound** (repo flags rank-order coding as tied at dt=1.0); beyond ~7 items slots merge (the honest biological limit). Supplies SEPARATION + a self-calibrating commit but still needs #2's composite priority to SET which slot leads.

### #5 (self-organizing salience SUBSTRATE, composes under #2/#4) — Topicality via short-term synaptic facilitation

- **Mechanism.** Salience is carried in the **STF (calcium) state** of each referent assembly (Mongillo-Barak-Tsodyks activity-silent WM). Each mention facilitates that assembly; a topical (repeatedly-mentioned) referent accumulates the strongest facilitation; the pronoun's nonspecific pulse re-ignites the most-facilitated referent fastest.
- **Why it beats recency.** Facilitation accumulates over **mentions** (a subject named 3× beats a once-mentioned more-recent object) — the topicality term recency provably lacks, and the term that makes the Cb "continue" rule work. Multiplicative on the referent's **own** synapses → converts to a decisive reactivation-latency difference under a shared probe, not tonic additive activity.
- **Reusable machinery.** Bridge STP is **already in the step loop** (`fused_stp_decay_recovery`, `stp_U/tau_d/tau_f`, `enable_per_type_stp`) — **inherently self-organizing, zero hand-tuning of a salience number**; the D3 "strength × duration" law already noticed the more-often-written slot carries larger residual `g_nmda` — that IS this facilitation trace, just not yet used as the disambiguation salience.
- **De-risk.** Same-recency, different-frequency referents: GO bar = binds the higher-frequency referent; equal-frequency → abstain.
- **Risk.** Facilitation decays (`tau_f` ~seconds) — within-window topicality only; ties → abstain. Best as the self-organizing recency+topicality **term feeding #2's priority map**, not a standalone selector.

### Mandatory anti-cheats
1. **Validate-by-function (equal-salience discriminator stays neutral).** An **equal-compatibility** pair (two candidates the verb licenses equally) must stay **neutral / abstain** — a graded map that resolved a genuine tie would be a regression. (Mirrors the Route-C `equal-value-neutral` control.)

5. **Self-calibration control (proves the bias isn't hand-tuned).** The map is **learned** — retrain from a different init/seed and confirm the compatibility ordering re-emerges from co-activation statistics, not from a frozen lexicon. Confirm no hand-set threshold in the read: the moat gate stays the existing `≥1.3× runner-up AND re-presentable above held_floor` (competition-relative, not an absolute salience number).
