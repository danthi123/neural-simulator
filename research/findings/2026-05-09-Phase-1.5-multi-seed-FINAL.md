## What was robust in failure

**Two distinct failure modes, BOTH consistent across all 3 seeds:**

### Failure mode 1: interference (0.39 ± 0.05, 0/3 pass)

Interleaved 8-word synonym training: in each event a random word is
presented + its motor pool is teacher-stimulated. Pass criterion:
mean accuracy ≥ 0.50 AND no individual word below chance (≥ 0.25).

Seed 42 per-word breakdown showed `right` at 8% (well below chance) —
catastrophic forgetting of one specific word. Other words 24-56%.
Mean across the 8 = 0.34.

The other seeds (43, 44) score similarly low (0.40, 0.45) with the
same pattern. Variance is tight (std 0.05) — this isn't seed-luck;
it's a STRUCTURAL inability to bind 8 INTERLEAVED words at this dose
+ architecture.

**Hypothesis pre-staged:** events_per_word=200 may be under-training
relative to the validated Tier 2.1 BREAKTHROUGH config (400). The
v400 chain script (`scripts/chain_phase_1_5_to_v400_interference.sh`)
auto-fires `phase_1_5_interference_only_v400` for fast (~70 min)
single-seed confirmation. **Note:** chain script attempted to fire at
06:35 but the running webapp lacked the new `phase_1_5_interference_only_v400`
preset (per-server-restart staleness, autonomous-runs principle #9);
needs manual re-fire.

### Failure mode 2: long_tail (0.23 ± 0.06, 0/3 pass)

Imbalanced frequency: 4 common words at 200 events each, 4 rare words
at 10 events each (events_per_word // 20). Pass criterion: rare-word
accuracy ≥ 0.30 (5pp above chance 0.25).

Per-seed:
- seed 42: common 47%, rare 17%
- seed 43: common 63%, rare 28%
- seed 44: common 55%, rare 23%

Common-word binding partially works at the validated dose; rare-word
binding does not. 10 events ≈ 3 sec of human speech — biology has
the same few-shot limit. Real critical periods last months.

**Hypothesis pre-staged:** the rare-word path uses a hardcoded 300 pA
motor teacher (vs ~1500 pA in run_three_factor common training).
Combined with `// 20` ratio, two knobs may dominate. New CLI flags +
`phase_1_5_long_tail_relaxed` preset (rare-ratio=4, teacher=1500 pA)
test both relaxations together (~50 min single seed).

## Bug discovered while aggregating

The auto-generated multi-seed doc at 08:02 (pre-fix) reported long_tail
as **3/3 PASS** — incorrect. Root cause: `np.mean(...)` returns
`numpy.float64`, the comparison `numpy_scalar >= 0.30` produces
`numpy.bool_`, and `json.dumps(default=str)` doesn't natively serialize
`numpy.bool_` so it stringifies to `"False"`. The aggregator's
`b.get("pass", False)` then returned the STRING `"False"`, which is
truthy in Python.

**Fixed in same commit:**
- `continual_eval_suite.py` long_tail return: explicit `bool(...)` cast
- `phase_1_5_aggregate.py`: defensive string-to-bool coercion handles
  pre-fix JSONs without re-running them
- `tests/test_phase_1_5_aggregate.py`: 2 new regression tests covering
  string `"False"` and `"True"` cases

After re-aggregation with the fix: long_tail correctly reports 0/3 pass.

## Master plan implications

The Phase 1.5 milestone "BIOLOGY-GROUNDED CONTINUAL LEARNING VALIDATED"
was scoped as: 4-benchmark suite mean ≥ 0.70 across 6 seeds at scaled
arch. The 3-seed mean is 0.629 ± 0.056 — robustly below threshold.
Even if the v400 chain confirms the interference under-training
hypothesis (lifting 0.39 → 0.50), the math:

```
(0.95 + 0.94 + 0.50 + 0.23) / 4 = 0.655   — still below 0.70
```

To clear 0.70, BOTH interference AND long_tail need to lift:

```
(0.95 + 0.94 + 0.50 + 0.43) / 4 = 0.705   — passes (long_tail at 0.43)
```

Long_tail at 0.43 means rare-word accuracy 43%. That's plausible if the
relaxed-dose preset (rare-ratio=4 → 50 events, teacher=1500 pA) helps,
but not assured without testing.

**Recommended pragmatic next step:**
1. Run `phase_1_5_interference_only_v400` (single seed, ~70 min) — if
   interference lifts to ≥ 0.5, hypothesis confirmed.
2. Run `phase_1_5_long_tail_relaxed` (single seed, ~50 min) — if rare
   acc lifts to ≥ 0.30 (or better, ≥ 0.43), few-shot is dose-bound
   not architectural.
3. If both pass at relaxed config: re-run full
   `phase_1_5_unified_scaled_v400` multi-seed (~5 hr × 3 seeds = 15 hr)
   for the milestone gate.
4. If either fails at relaxed config: demote Phase 1.5 from "milestone
   gate" to "tier report" — the foundation (Phase 1.4 BRANCH A + Phase
   1.3 + Tier 2.1 12-word) STILL HOLDS for sequential continual learning.
   Phase 1.5 just probes harder benchmarks (interleaved + few-shot)
   that are distinct research challenges, not architecture validation.
