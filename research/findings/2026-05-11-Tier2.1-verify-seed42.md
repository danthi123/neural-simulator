**Primary directions (north/east/south/west) PASS cleanly (88, 88,

or wrong mapping. This matches the 2026-05-06 BREAKTHROUGH finding:
synonym vocab has structurally harder embeddings because
`vocab_to_drive_pattern` is hash-based — "north" and "up" have
unrelated lang_input patterns despite being semantic synonyms.

## Recipe

```bash
python -m research.runners.bio_three_factor \
    --biological --embodied-hebbian \
    --synonym-mode \
    --apply-topographic-bias --enable-motor-fs \
    --n-events-per-direction 400 \
    --n-lang-input 4096 --n-motor-per-action 1000 \
    --n-motor-fs-per-action 120 \
    --seed N --out-stats research/findings/raw/g11_bg/tier2_1_seed${N}.json
```

Architecture: 4-word vocab Tier 1 SCALED UP — n_lang_input 4096
(vs 2048), n_motor_per_action 1000 (vs 500). 12K total neurons,
~5M synapses. Wall clock ~12 min on RTX 3090.
