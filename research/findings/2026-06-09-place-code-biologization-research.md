## 0. TL;DR (the decision this doc forces)

The N9 negative is **not** a value-learning failure — the critic fires and learns V. It is a **place-INPUT** failure: the critic reads a **host-rendered DENSE 2-D Gaussian** (`vs_place_context`, density 0.8, 200 cells, σ=4.0 over 32×32) through a **dense convergent projection**, and a dense convergent read of overlapping bumps is *position-blind* — the cell enters the B.02 up-state *wherever any bump exists*, set by which afferent cells randomly wire on (peaks at the grid center, NOT the goal), so it cannot grade by LOCATION. **The smoking gun is in the project's own probes:** the 1-D `snc_stageb_critic_probe_place.py` ALREADY got place-grading **3/3** (V(near) ≫ V(far)) — because there NEAR (0.85) and FAR (0.15) drive **non-overlapping** sparse Gaussian bumps over only 40 place cells read by 60 striosome cells, so different locations potentiated *different* critic synapses. The dense 2-D nav read collapsed exactly that distinctness. **The fix is therefore two coupled things, BOTH of which the catalog and the project's existing machinery already supply:**

1. **A self-organized SPIKING place code with LOW pairwise ensemble overlap per location** — built by feeding the *legitimate egocentric landmark/boundary sensors* (the agent SENSING the world, BRAIN-BASED-legal) through the **already-built, already-validated trisynaptic loop** (EC→DG sparse→CA3/CA1; catalog D.03/D.12/D.13, `build_biological_brain_regions(enable_hippocampus_consolidation=True)`). DG's feed-forward inhibition (EC→PV-basket→DG) is *exactly* Marr expansion-recoding pattern separation (D.12) — it makes nearby locations DISTINCT sparse ensembles. This is the canonical Hartley-Burgess **boundary-vector-cell → competitive-learning → place-cell** mechanism, and it is the catalog's own stated cure for the D.06 shortcut ("the project's `--landmarks` place cells are *sensor-driven not allocentric*… a true place cell should still fire after some cues are removed").
2. **A SPARSE / topographic striatal read-out + per-ensemble value learning** so different locations potentiate *different* critic sub-populations — the 1-D-probe regime that worked, **NOT** the dense convergent blob that failed. "FAR" critic neurons then stay silent because their place inputs were *never potentiated* (no convergent floor to fire them position-blindly).

The whole point of the N9 negative is that **a neural place code is necessary but not sufficient — position-specificity must survive the READ-OUT.** So this doc solves BOTH ends, and the cheap-first de-risk explicitly gates on BOTH (distinct ensembles per location AND NEAR≫FAR through the critic on CuPy).

**Recommended first step:** the smallest CuPy test that (a) the trisynaptic/landmark place code produces **distinct sparse CA1 ensembles per location** (pairwise cosine LOW across locations, stable within), and (b) a **SPARSE-read** MSN-D1 critic on that code then **grades NEAR≫FAR ≥3×** and learns V — *before* any nav build. All runner-side; the only candidate `sim/` touch is decoupling the existing `landmark_to_place` self-org pathway from the `enable_hippocampus` flag (a one-line runner-side guard, NOT a `sim/` edit — verified below).

## 1. Diagnosis — why the dense blob is position-blind, and the cleanest faithful cure

### 1.1 The exact failure (from the N9 de-risk, not re-litigated)

The N9 de-risk pinned it cleanly (`2026-06-09-N9-convergent-upstate-derisk.md`):
- **The dense NON-plastic A1 up-state arm is POSITION-BLIND.** `_n9_matched_pos.py`: with `n_active` MATCHED (85 vs 85 active place cells), two positions fire the critic at **1.79 Hz vs 16.79 Hz** (~10× apart) — the split is set by *which ensemble's synapses onto the critic happen to be stronger* (random structure), **not** by location.
- **`_n9_placegrade_probe.py`:** critic rate tracks `n_active` (how many afferent cells are active), peaking in the **grid center** (~120 cells → ~29 Hz) and falling at the corners — a "how many cells are on" blob, not a value-of-location.
- **The irreducible tension within the dense mechanism:** gate-1 (fire at init) *requires* A1 to fire the critic from a place bump; but A1 firing the critic from *any* bump means it fires at FAR too → gate-2 fails. Lowering A1 to silence FAR also silences NEAR (A1 is position-blind). No A1 weight (16→32 swept) clears both. NMDA (Option B) made it *worse* (deepens the up-state at both locations).

### 1.2 Why the 1-D probe SUCCEEDED where the 2-D nav FAILED (the decisive contrast)

The project already has a value-of-LOCATION that works — `snc_stageb_critic_probe_place.py`, **3/3** seeds on V-LEARNED-SPATIAL (V(near) rises across training AND ends higher than FAR) + the GABA_B gap (`2026-06-08-striatal-value-critic-firing-research.md`). The difference is **the place-code geometry + read-out density**, and it is the entire lesson:

| | 1-D probe (PASSED 3/3) | 2-D nav `vs_place_context` (FAILED 0/3) |
|---|---|---|
| place cells | **40**, σ=0.12 over [0,1] | **200**, σ=4.0 over 32×32 |
| NEAR vs FAR ensembles | bumps ~6σ apart → **non-overlapping** subsets | dense bumps → **heavily overlapping** (and a convergent blob sums them) |
| read-out | place(40) → striosome(60), modest | **dense (density 0.8)** convergent → striosome(80) |
| mechanism | different locations → different place cells → **different striosome synapses** potentiate; FAR cells never fire (their inputs never grew) | convergent floor fires the critic *wherever* a bump exists → **position-blind up-state** |

**The cure is to make the 2-D nav place code behave like the 1-D probe: SPARSE, DISTINCT-per-location ensembles, read SPARSELY** so per-location value lives in per-location synapses. Pattern separation (D.12) is precisely the biological operation that produces "distinct sparse ensembles for nearby inputs," and the project has it built.

### 1.3 The faithful place-code mechanism (catalog + literature)

A self-organized spiking place code that is position-specific is the textbook **boundary-vector-cell (BVC) / object-vector-cell → competitive place-cell** model (O'Keefe & Burgess 1996; Hartley et al. 2000; Burgess et al.), validated in the project's own catalog:
- **D.09 (border/object-vector cells):** "landmark sensors in `g11` provide distance + direction to landmarks, which is **functionally object-vector encoding at the sensor stage**." → The agent's `landmark_sensors` (egocentric distance+bearing to a fixed landmark, `g11_bg_runner.py:5139-5152`) ARE the BVC/OVC input. This is **legitimate environment sensing** (the body sensing the world), the BRAIN-BASED-legal channel.
- **D.06 (place cells):** the discovery + O&N theoretical foundation. The catalog explicitly states the project's `--landmarks` place cells are *sensor-driven not allocentric* and that the cure is a real self-organized field that survives partial cue removal. **D.06 is the exact shortcut this doc removes.**
- **D.12 (pattern separation):** DG granule cells (~2–5% sparse) receive convergent EC perforant input on a *larger* population; feed-forward inhibition orthogonalizes similar inputs (Marr expansion recoding). **This is the operation that turns overlapping landmark codes into DISTINCT sparse per-location ensembles** — the thing the dense `vs_place_context` lacks. Already built: EC→`dg_pv_basket`→DG FFI (`text_minimal_isolation.py:1100-1109`), DG validated at cosine 0.218 from input 0.800 (`validate_trisynaptic_loop.py`, P1 finding).
- **D.13 (pattern completion):** CA3 recurrent autoassociator (Marr 1971). Gives the place cell the O&N "fires after some cues removed" property — the allocentric-stability test the dense code fails. Already built + validated (CA3 cosine 0.748).
- **Hartley/Burgess competitive learning (literature):** "place cells develop localized place fields by **competing for boundary-vector-cell inputs**… competitive learning → spatial selectivity." In the sim, this competition is realized by the DG sparsity (FFI) + STDP on the landmark→place pathway (already gated `landmark_to_place`).
- **BTSP (Bittner & Magee 2017, Science; literature):** CA1 place fields form **in a single trial** via plateau-potential-gated potentiation of inputs arriving seconds before/after a complex spike — a non-Hebbian, seconds-wide, asymmetric rule. This is the *fast* place-field-formation alternative (one traversal → a field), and it dovetails with the project's plateau machinery (the catalog has Cav1.2/1.3 L-type plateau potentials, `J.*`/B-cluster; the NMDA-plateau up-state is already in the sim). BTSP is **not** required for the first de-risk (the slow STDP+DG path is enough), but it is the principled upgrade if single-traversal field formation is wanted (Option C below).

### 1.4 The read-out that survives — sparse/topographic, per-ensemble value (the load-bearing other half)

N9 proved a neural place code is necessary but **not sufficient**: position-specificity must survive the value cell's read. The faithful read-out is **NOT** the dense convergent blob (which manufactures the position-blind floor) but the **van der Meer & Redish / Lansink** hippocampus→ventral-striatum anatomy: HC place cells (subiculum) project to VS, where **"ramp" value cells read place input and fire anticipatory, place-locked value at decision points** (literature confirmed: Lansink 2009, hippocampus leads VS; van der Meer & Redish 2009; the subiculum→VS projection selectively impacts reward-related VS neurons; van der Meer 2010 triple-dissociation). The key property: a VS value cell reads a *sparse, place-specific* HC ensemble, so DA-gated potentiation at the goal grows synapses **from the goal ensemble specifically** — and FAR critic neurons stay silent because *their* place inputs were never potentiated and there is no convergent floor to fire them anyway. This is exactly the 1-D-probe regime.

Concretely, the read-out must satisfy:
- **Place-specific (sparse) afferent**, not a dense convergent blob: a CA1/place ensemble with LOW overlap across locations (D.12 guarantees this).
- **Plastic, DA-δ-gated** place→critic synapses (the existing A2 arm), so per-location value is per-synapse. **No (or weak) non-plastic convergent floor** — the floor is what made A1 position-blind. The critic can instead reach its up-state from the *learned* place→value synapses once they grow at the goal (the cell starts silent FAR, learns to fire NEAR), or from a *sparse* (not dense) convergent arm that only the goal ensemble drives.
- **Optionally, lateral inhibition / WTA among critic sub-populations** (FS interneurons, the deprecated-but-available motor-WTA pattern, or `--enable-msn-lateral-inhibition`) to sharpen "this location's critic cells, not that location's."

### 1.5 Residual honesty (what is legitimate vs what is still a shortcut)

- **LEGITIMATE (environment sensing, BRAIN-BASED-legal):** the `landmark_sensors` egocentric (distance, bearing) render — the body sensing a landmark in the world (D.09 object-vector input). This is identical in kind to the retina rendering the agent's visual field; it is the world→sensory-surface step the directive explicitly permits. The place-field FORMATION on top of it (EC→DG→CA3→CA1 + STDP/BTSP) is **neural**, and the value read-out is **neural**. ✅
- **STILL A SHORTCUT (to be removed by THIS work):** the host-rendered ALLOCENTRIC Gaussian `vs_place_context` (`vs_drive = max_pA·exp(−d²/2σ²)` over a HAND-TILED `linspace` grid, keyed directly off the agent's true `(x,y)`; `g11_bg_runner.py:5117-5120, 3438-3451`). This injects the *answer* (the allocentric position) as a hand-drawn population — a perception cheat. Replacing it with a self-organized code driven only by egocentric landmark sensing is the deliverable.
- **POSITION-LEAK ANTI-CHEAT (must be controlled):** when the self-organized code is driven by `landmark_sensors`, the agent's `(x,y)` must enter the brain **ONLY** through the egocentric sensor render (distance+bearing to the landmark), **never** as a direct allocentric bump. The de-risk's "is it actually self-organized vs hand-wired" control (§4) checks this: ablate the landmark sensor → the place cells must DEGRADE (a hand-wired allocentric bump would not). And a single landmark gives only a *ring* of ambiguity (distance alone is not position); ≥2 landmarks (or landmark+boundary) are needed for a unique 2-D fix — flag this honestly (single-landmark place fields are annular; the de-risk should use ≥2 landmarks or a landmark+wall for genuine 2-D place specificity, matching D.09's "border cells anchor to geometry").
- **Already-neural, NOT in question:** the GABA_B value subtraction (`enable_gabab`, SHIPPED, byte-verified); the SNc δ in deployment (`--spiking-snc`); the convergent-up-state firing + A2 DA-gated LTP (the N9 wins). This doc changes only the *place input* and its *read-out density*.

## 4. Cheap-first de-risk — the smallest CuPy test of BOTH halves

**The N9 lesson is load-bearing: a neural place code is necessary but NOT sufficient — it must survive the read-out.** So the de-risk has TWO gated stages, and **MUST run on CuPy** (`SIM_BACKEND=cupy`; numpy is disqualified for this MSN regime — the aliasing artifact lived exactly here). Replicate the deterministic-nav regime (OU/conductance-noise/global-homeostasis/heterogeneity/STP OFF, the `g11_bg_runner.py:3340-3344` knobs). Keep it tiny (CPU-sized region counts) but run it on GPU. Serial; do not disturb the webapp GPU PID.

### Stage 1 — the place code is genuinely self-organized + position-specific (distinct sparse ensembles)
Build the landmark-driven place layer (Option A trisynaptic, or Option B minimal). Tag the place/CA1 ensemble (engram API) at K test locations spanning the grid.
- **Gate 1a (DISTINCT per location):** mean pairwise **cosine between different locations' ensembles < ~0.3** (and Jaccard low) — the dense `vs_place_context` fails this; the 1-D probe and DG separation pass it. Use ≥4 locations incl. NEAR-goal and ≥2 FAR.
- **Gate 1b (STABLE within a location):** re-traversing the SAME location → cosine of its ensemble across visits **> ~0.7** (D.13 completion; the field is a real attractor, not noise).
- **Gate 1c (SPARSE):** each location's active fraction ~2–10% (D.12 sparse coding), NOT a dense blob.

### Stage 2 — a SPARSE-read MSN-D1 critic grades NEAR≫FAR on that code, and learns V (CuPy)
Feed the Stage-1 self-organized code into `striosome_value` via the A2 plastic DA-δ-gated arm (sparse afferent; drop/sparsify the dense A1 floor). Run the `_run_critic_warmup` value-leads-reward protocol.
- **Gate 2a (FIRE):** critic fires at the **goal** ≥ ~5 Hz on CuPy (the N9 FIRE gate, on the new sparse code).
- **Gate 2b (PLACE-GRADED — the load-bearing one):** trained critic **NEAR ≥ 3× FAR**, and FAR ≈ 0 Hz. *This is the gate the dense blob capped at 1.2–1.4. The sparse-distinct code + sparse read is the hypothesis that this opens.* Use ≥2 FAR locations.
- **Gate 2c (LEARNS V — LTP from realistic init):** the near-ensemble plastic weight grows from init AND grows more than the held-out FAR ensemble (w_near/w_far ≥ ~2×). FAR critic cells stay silent because *their* inputs never potentiated.
- **Gate 2d (ACTOR-NOT-PERTURBED):** actor cortex rate within ±10% of a critic-absent twin (the N9 gate; the place/critic feed ONLY the critic).
- **Gate 2e (VALUE IS NEURAL — GABA_B lesion):** zero the GABA_B mask → the state-specific SNc gap vanishes (carried by GABA_B, not host arithmetic). `current_reward_signal=0` through the subtraction.

### Anti-cheat controls (all decisive here)
- **(self-organized vs hand-wired — THE key control for this work):** **ablate the landmark sensor** (zero `landmark_sensors` drive) → the place ensembles must **DEGRADE / lose position-specificity** (gate 1a/1b FAIL under ablation). A hand-wired allocentric bump would be unaffected — this proves the code is *learned from sensing*, not the host Gaussian in disguise. Conversely, a *partial* cue removal (drop one of ≥2 landmarks) should leave the field mostly intact (D.06/D.13 "fires after some cues removed" — the allocentric-stability signature the dense code lacks).
- **(place-shuffle — separates "value of LOCATION" from "fired on any strong drive"):** train with the place-ensemble labels permuted relative to position → gate 2b must FAIL (no grading) under the shuffle. The N9 doc flagged this control had nothing to ablate while gate-2 failed in the TRUE case; here it becomes live once Stage 2 passes TRUE.
- **(position-leak audit — BRAIN-BASED honesty):** assert the agent's `(x,y)` enters the brain ONLY via the egocentric landmark render, never as a direct allocentric injection. Grep the nav-loop for any `cp_external_input_current[... place ...] = host_Gaussian(x,y)` into the critic's afferent — must be ABSENT in the self-organized config. (Single landmark → annular ambiguity; require ≥2 landmarks for a 2-D fix.)
- **(CuPy regime fidelity — load-bearing, from N9):** assert backend==cupy AND OU/conductance-noise/global-homeostasis OFF; hard-fail otherwise (a silent numpy fallback VOIDs the gate).
- **(no-threshold-collapse provenance):** critic fires with global homeostasis OFF and no per-region homeostasis mask on the critic — it fires from convergent/learned synaptic current, not threshold drop.

### Graceful-FAIL contract
Stage 1 fails (place code not distinct/stable, or not degraded by sensor ablation) → fix the place layer (Option A↔B, more landmarks, stronger DG FFI) before touching the critic. Stage 1 passes but Stage 2 gate 2b fails (sparse-read critic still can't grade ≥3× — e.g. the genuine fire-vs-grade tension: the sparse afferent can't clear rheobase at the goal without a convergent floor that re-blinds it) → escalate to Option C (BTSP/plateau read-out) or a sharper read-out (FS-WTA among critic cells); if that also fails → Option D (bank the negative; a graded location-value through an MSN-D1 needs a richer read-out). **The de-risk must NOT rescue a failure by re-injecting the host allocentric Gaussian, re-adding the dense position-blind A1 floor, lowering the threshold, over-driving the actor's shared pathway, or running numpy.**

### Decision rule
Stage 1 (≥3 CuPy seeds, gates 1a-c) AND Stage 2 (≥3 CuPy seeds, gates 2a-e + anti-cheats) PASS → proceed to the nav 6-seed A/B (flagship + `--spiking-snc --enable-neural-critic` on the self-organized place code). FAIL → Option C/D as above. An honest nav regression is still a deliverable.

## 6. Honest bottom line

The N9 negative is a **place-INPUT** problem, not a value-learning one: the critic fires + learns V, but it reads a **host-rendered dense allocentric Gaussian through a dense convergent projection**, which is **position-blind** (fires the up-state wherever a bump exists, peaking at the grid center). The project's own 1-D probe already produced a *value-of-location* (3/3) precisely because there the place ensembles were **sparse + non-overlapping per location** and read **sparsely** — so different locations potentiated different critic synapses and FAR cells stayed silent. The faithful cure, fully supported by the catalog (D.06 place cells, D.09 object-vector/BVC input, D.12 pattern separation, D.13 completion, D.16 DA-stabilized fields) and the literature (Hartley-Burgess BVC→competitive place cells; Bittner-Magee BTSP single-trial fields; van der Meer/Redish/Lansink HC→VS place→value read-out), is to **self-organize a sparse, distinct-per-location SPIKING place code from the legitimate egocentric landmark sensors through the already-built, already-validated trisynaptic loop, and read it into the critic SPARSELY (the A2 plastic DA-gated arm, no dense position-blind floor)** — removing the D.06 + `vs_place_context` allocentric shortcut while keeping the egocentric landmark render (legitimate environment sensing) and the (already-neural) value learning + GABA_B subtraction. It is **runner-side** (Option A; the only candidate `sim/` touch — BTSP — is a deferred fidelity upgrade, not required to prove the thesis). The decisive de-risk is two CuPy-gated stages — **(1) the place code is genuinely self-organized + distinct-per-location + degrades on sensor ablation**, then **(2) a sparse-read MSN-D1 critic grades NEAR≫FAR ≥3× and learns V** — with a self-organized-vs-hand-wired control and a position-leak audit that the dense path never had. **Recommended first step:** build Stage 1 alone (`_placecode_selforg_derisk.py`, reusing the positional-binding engram-cosine harness + the validated DG separation, driven by ≥2 landmark sensors), on CuPy, ≥3 seeds — the cheapest decisive move on the blocker, with zero `sim/` edits. If Stage 1 passes, chain Stage 2 (the N9 critic on the new code); if either genuinely fails on CuPy, escalate to BTSP/sharper-read-out (Option C) then the honest negative (Option D).
