# RESEARCH GATE — KEYSTONE: a self-organizing, fully-spiking, one-brain binder over the brain's OWN correlated codes (gap #4 ⊕ #2, ONE gate)

## 1. DIAGNOSIS — the precise residual

The two walls are already decomposed to a single point in our own record, and the survey converges (biology section + ML section + code-op section, three independent framings) on the same conclusion: **the composer's demand for an exact-inverse algebra over decorrelated atoms is a category error.** No brain computes `bundle = Σ(uᵢ⊗wᵢ)` then `unbind = bundle⊗u_t⁻¹`. That framing is *why* both walls look unsolvable, because it forces one code + one linear op to do two incompatible jobs (near-orthogonal for a clean linear inverse vs. correlated for generalization).

The genuine residual, stated exactly:

- **Everything except one relationship is already closed.** Filler codes are LEARNED on spikes (PPMI stream cortex, +0.518, generalizes 0.86). The bind OP is already SPIKING (RESONATE_AND_FIRE complex synapses, or the 8-neuron Izhikevich AND-bank). Role codes are developmentally-cheap random draws (a genome-style seed draw the project already accepts). RUNG-2 already showed the fixed self-inverse coincidence bind does **systematic held-out extrapolation on spikes, 6/6 at 12×12** vs full controls.
- **The entire host residual has shrunk to ONE algebraic tie:** `unbind_weight = conj(bind_weight)` — the exact-inverse FORM, computed in Python and injected. That is the *only* non-self-organized, non-spiking, non-developmental piece left.
- **The two walls are the SAME residual seen twice.** Bundling (#2): a summed superposition has no exact inverse on point neurons (additive 0.193, learned-linear-inverse 0.056). Correlated-codes (#4): every learned/local *decorrelation* rule FAILED (spiking DG, fixed random projection, Földiák all floor at between-cos ~0.488; MDGL off-diagonal is a DECISIVE spiking-negative — averaging adds magnitude, not sign-correct direction) — **and reaching near-orthogonality would destroy the generalization correlation buys.**

**So what must self-organize:** a binder whose (a) WRITE superposes multiple role-filler bindings over *correlated* learned fillers without crosstalk, and whose (b) READ recovers a filler *without a host-injected conjugate-inverse tie* — realized on the dendritic spiking substrate, learned from experience. The decisive strategic move (all three survey sections): **do not decorrelate the codes; change the BIND OP to a content-addressed conjunctive product that has no linear superposition-inverse to break on correlated fillers, and either (i) make the WRITE error-correcting so crosstalk cancels, or (ii) let the assembly be sparse-conjunctive so there is no summed superposition to invert at all.**

- **Biology/self-org/spiking:** The primitive is ALREADY spiking on the D2 bridge — `fused_coincidence_plateau` (sim/kernels.py:252, guarded `enable_coincidence_detection`, byte-inert off) with NMDA dual-exp + Mg²⁺ kinetics; `coincidence_weighted_drive` for the weighted subunit. ### #2 — Delta-rule error-correcting fast-weight write on the RF complex-synapse store (the self-organizing binder)
- **Mechanism:** Bind = outer-product write into a fast-weight (synaptic) matrix `W`: role `k` × filler `v`; unbind = `W·k`. The **DELTA rule** makes it error-correcting: before adding, read the stored `v_old = W·k`, then `W += β(v_target − v_old)kᵀ`. This "erase-then-write" removes *exactly* the crosstalk that Hebbian/Hadamard binding accumulates on correlated, non-orthogonal roles — the mechanism by which DeltaNet beats vanilla additive fast weights. Bundling is native (the matrix superposes many `k·vᵀ`); the delta correction MANAGES superposition capacity by correction rather than by orthogonality.
- **Biology/self-org/spiking:** self-organizes online from the stream (no BPTT, no weight transport). The fast-weight matrix IS short-term synaptic plasticity/eligibility (already in-repo); the `v_target − W·k` error is a two-compartment read (apical carries `v_old`, basal `v_target`) — and **the committed Urbanczik-Senn / M2.6 clean-error channel the repo already uses IS a delta-rule instance.**
- **Wall surpassed:** BOTH — error-correction is the direct self-organizing fix for the correlated-code crosstalk (#4) AND manages superposition interference (#2).
- **Reuse:** RF complex synapses (`cp_rf_w_re/im`) as the fast-weight store; STP + eligibility-trace + plasticity-gate machinery; the committed Urbanczik-Senn clean-error credit channel; D2 two-compartment for the local error read.
- **De-risk:** on the SAME correlated-code held-out bundling harness as #1, add the delta correction to the RF write; single variable = delta-on vs delta-off (plain Hebbian outer product); 6-seed; anti-cheat = permuted-role + decorrelated-code control (§3 pattern).
- **Honest risk:** the write is sequential (a settling read before each write); on point neurons `v_old` is a rate code (rate-code-SNR wall) — mitigate with population read + NMDA integration (both validated in-repo). Not a single-shot exact inverse.

### #3 — Sparse-conjunctive assembly + one-shot BTSP (the CLS gold standard: no superposition to invert)

- **Honest risk:** capacity scales with #conjunctive cells (no √D compression) and binding is associative/lossy, not exact-invertible — but the owner has explicitly ruled the no-confab moat a PLUS not a hard gate and lossy learned memory acceptable (`feedback_moat_not_hard_lossy_memory_ok`), which is precisely this trade. Multi-fact interference + read-out fidelity are the genuine unknowns.
