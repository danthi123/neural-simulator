# 2026-05-09 — Phase 1.5 interference benchmark under-training hypothesis

**Status:** Partial finding mid-flight (Phase 1.5 multi-seed seed 42 still
running, on long_tail). Captured now to avoid loss in conversation
summarization.

## Headline observation

Phase 1.5 multi-seed at scaled arch, seed 42, 3 of 4 benchmarks complete:

| Benchmark | events/word | score | threshold | verdict |
|---|---|---|---|---|
| sequential_expansion | 200 | 0.88 | 0.7 | ✓ PASS |
| retention_over_time | 200 | 0.87 | 0.7 | ✓ PASS |
| interference | 200 | **0.34** | 0.5 | ✗ FAIL |
| long_tail | 200 | (running) | 0.3 (rare) | ⏳ |

**Interference is the only failing benchmark.** sequential_expansion +
retention_over_time pass cleanly (>0.85). The score is also above the
25% chance floor for 4-action interference, so it's not catastrophic —
the binding signal exists, just below the 0.5 mean-accuracy bar.

## Hypothesis: events_per_word=200 is under-training for interference

The Phase 1.5 suite passes `--events-per-word 200` to all 4 benchmarks.
However:

- **Tier 2.1 BREAKTHROUGH** (the validated 8-word synonym result, 5/6 +
  6/6 aligned, 2026-05-06) used **400 events/word**.
- **Phase 1.3+Tier 2.1 combined CONFIRMED** (3/3 GO, 91% / 128%
  retention, 2026-05-08) used **200 awake events/word + 100 sleep
  replay events/word** with consolidation cycles, but the awake
  training is structurally different (chunks + sleep gates).

For the interference benchmark specifically:
- Trains all 8 synonym words INTERLEAVED in one pass
- 8 words × 200 events = 1600 paired events
- The validated Tier 2.1 config: 8 words × 400 events = 3200 events
- Interference is presumably the HARDEST of the 4 benchmarks (no
  curriculum, no consolidation, no separation of phases) and likely
  needs MORE events/word than sequential, not fewer.

If the hypothesis is right, raising events_per_word to 400 for the
interference benchmark (or for the entire suite) should lift the
score from 0.34 to >=0.5.

## What this changes about the master-plan milestone

The Phase 1.5 suite mean threshold is **>= 0.7 across all 4
benchmarks** for "BIOLOGY-GROUNDED CONTINUAL LEARNING VALIDATED".

Current 3-benchmark mean: (0.88 + 0.87 + 0.34) / 3 = **0.697** —
already at the threshold. Final outcome depends on long_tail:

- long_tail = 1.0 → mean (0.88+0.87+0.34+1.0)/4 = **0.7725** PASS
- long_tail = 0.8 → mean = 0.7225 PASS (margin tight)
- long_tail = 0.7 → mean = 0.6975 borderline FAIL
- long_tail = 0.5 → mean = 0.6475 FAIL

So this seed alone is a PARTIAL — depends on long_tail. The full
3-seed batch still has seeds 43 and 44 to chain.

## Proposed follow-up (after Phase 1.5 batch completes)

1. **Re-run the suite with --events-per-word 400** at the same scaled arch
   on a single seed. ~6-7 hrs single-seed. If interference lifts to >=0.5,
   the hypothesis is confirmed and we have a path to a 4/4 GO suite.

2. **Targeted interference-only re-run** at varied event counts (200,
   300, 400) to find the threshold. 3 runs × 35 min = ~1.5 hrs.

3. **If raising events/word doesn't help interference**: investigate
   architectural causes (e.g., interleaved training inherently needs
   more capacity than the n_motor=1000 currently used; or the
   embodied-Hebbian rule has a known per-word floor that limits
   interleaved binding).

## Why document this now

Per autonomous-runs principle #6 (anti-shortcut discipline):
- "Document negative findings honestly. Negative results are real findings."
- This is a partial-NEGATIVE that contains real information about the
  parameter regime where Phase 1.5 succeeds vs fails.
- Risk if not documented: future autonomous arcs treat the eventual
  multi-seed result as the whole story, missing the events/word
  hypothesis. The Phase 2 resumption plan reads "if Phase 1.5 passes,
  go to 16-word smoke" — but if it passes only at 400 events/word,
  the 16-word smoke needs to use 400 too.
