## 2. Protocol (v3)

- **Dataset**: `research/datasets/tiny_patterns.npz` — K=4 classes, 64-dim Poisson rate vectors ∈ [1, 40] Hz, noise σ=4 Hz, 200 train / 50 test. Trivially linearly separable (logreg on raw rates hits 100% test).
- **Network**: 264 neurons total.
  - 64 input neurons (trait 0, Poisson-driven via `RATE_VECTOR_POISSON`).
  - 160 hidden excitatory (trait 0).
  - 40 hidden inhibitory (trait 1).
  - All Izhikevich RS (2007 formulation, default params).
- **Wiring** (built by `research/runners/g1_v3_runner._build_reservoir_plan`):
  - Input → hidden: 50% density per input (32 random hidden targets each), weight Normal(1.5, 0.3). ~1920 synapses.
  - Hidden → hidden (recurrent): 10% density per neuron, weight Normal(0.3) if excitatory pre / Normal(0.8) if inhibitory pre. ~8280 synapses.
  - **Total 10,200 synapses** injected via `SimulationBridge.inject_explicit_wiring`.
- **Forward pass per example**:
  - 200 ms stimulus (1000 pA × 2 ms pulses per Poisson event so Izh RS inputs actually fire).
  - 100 ms gap (stimulus off; reservoir equilibrates).
  - Feature = hidden-neuron spike counts in [50, 200] ms of the stimulus period. 200-dim feature vector.
- **Classifier**: `sklearn.linear_model.LogisticRegression(max_iter=2000, C=1.0)` trained on (features, labels) pairs. One-shot fit — no epochs.
- **Seeds**: 42, 43, 44.
- **All sim plasticity disabled** (STDP off, Hebbian off, structural off, homeostasis off, reward off, STP off). The sim is a fixed feature extractor; learning lives entirely in the external logistic regression.

Key sim tuning:
- `propagation_strength = 1.0` (default 0.05 assumes ~1000 converging synapses; we have ~32).
- `inhibitory_propagation_strength = 1.0` (same rationale).
- `ou_std_current_pA = 60` (modest background noise).
- No plasticity, no homeostasis — the reservoir is a fixed random-weight feature machine.

## 3. What killed v1 and v2 — full post-mortem

### v1: teacher-forced STDP (68-neuron direct mapping)

Teacher 400 pA on correct-class output during 200 ms stimulus. STDP (A+=0.012, A−=0.010) on 256 input→output synapses.

- Two probes, seed 42 only. Test accuracy stuck at 0.16–0.28 across 5 epochs. Margin degraded over epochs (−0.03 → −0.20).
- **All predictions collapsed to classes 0 and 1.** Classes 2 and 3 were never predicted.
- Weight-vs-class-mean correlations near zero:
  ```
  W[k] vs class_means[k] for k in {0,1,2,3}: -0.049, -0.095, +0.020, -0.043
  ```
- Per-output weight sums uniform (13.7, 13.2, 12.5, 12.1) — every output potentiated equally.

Root cause: lateral inhibition (mag 1.0, prop=0.05 ⇒ effective −2 pA on non-correct outputs) too weak to silence non-correct outputs, so every class's teacher drove potentiation onto every output's synapses → uniform inflation, no class selectivity.

### v2: external perceptron co-activity (same 68-neuron network)

All sim plasticity disabled. Per example: forward pass → softmax(out_counts) → error = target − softmax → dW[k,i] = lr × error[k] × input_activity[i], applied directly to `cp_connections.data`.

- Three probes with varying prop_strength (0.05 → 1.0 → 3.0), weight init, lateral inhibition, learning rate.
- Every probe: test accuracy 0.20, margin identically 0.00. **All predictions = class 0.**
- Margin = 0 means every output spike count is 0 — outputs never fire at test time.
- When outputs are all silent, softmax is uniform [0.25, 0.25, 0.25, 0.25], error averages to zero across balanced classes, no weight movement.

Root cause (the real one): **sim's default propagation_strength=0.05 is calibrated for networks with ~1000 converging synapses per neuron.** With only 64 inputs per output:
- At prop=0.05, W=0.3: steady-state g_e ≈ 0.019 nS, current ≈ 1 pA. Subthreshold.
- At prop=1.0, W=0.3: g_e peak ≈ 0.97 nS, current ≈ 58 pA. Still below Izh RS rheobase (~60 pA at rest; ~100 pA to cross the quadratic subthreshold barrier).
- At prop=3.0, W=0.3: g_e peak ≈ 2 nS, current ≈ 120 pA. Marginal. Outputs fire occasionally but lateral inhibition + the quadratic leak pushes them back below threshold.

The 68-neuron "tiny direct mapping" is structurally wrong for this simulator. The sim needs either (a) large networks with many converging synapses (1K+ neurons, hundreds of convergence per neuron) or (b) aggressively non-default propagation parameters.

v3's 264-neuron reservoir uses option (b) + more convergence and runs correctly.

## 4. The two "dataset/sim sanity check" wins along the way

1. **Dataset sanity**: `LogisticRegression` on raw 64-dim rate vectors → 100% train + 100% test. The classification is linearly separable; any reasonable feature extractor should reach high test.

2. **Input-firing calibration**: the `RATE_VECTOR_POISSON` pattern with default `spike_current_pA=250, spike_duration_ms=1` under-fires Izh RS by 6× (3.25 Hz actual vs 20 Hz target). Fixed by `1000 pA × 2 ms`, which tracks 5–40 Hz linearly. This fix carries forward to v2/v3 and is now the reference config in the runners.

## 6. Caveats

1. **Learning rule is external** (LogisticRegression, not a sim-local rule). This satisfies the letter of G1 ("dataset → encoder → sim → decoder → loss with measurable learning") but not the spirit of "the sim is doing the learning." G2 must put a local rule back in the loop — likely either `enable_stdp=True` on the input→hidden projection or training the readout via R-STDP on a new output layer.
2. **Reservoir is fixed** (no plasticity during G1). G2 can add reservoir plasticity.
3. **Trivially linearly separable dataset.** G4 gets the harder data.
4. **No persistence yet** (G3 territory): each seed starts fresh. G3 tests that a mid-training checkpoint can be resumed and continues improving.

## 7. Next step — G2 design brief

Make the sim's own plasticity contribute to learning. Two candidate designs:

### G2.a — STDP on input → hidden, frozen readout
- Start with v3's network and tuning.
- Enable STDP on the input→hidden projection with sensible bounds.
- Train the readout on features extracted from epoch 0 (before STDP), then measure test accuracy.
- Run N more epochs with STDP on, re-train readout each epoch, measure test accuracy.
- If STDP is producing better features, test accuracy should grow across epochs.

### G2.b — R-STDP on a new output layer
- Same reservoir.
- Add 4 plastic output neurons reading the reservoir.
- Replace LogisticRegression with the sim's reward-modulated STDP: after each example, compute argmax, set `current_reward_signal = +1` if correct else `−1`.
- Run multiple epochs and show the learning curve bending upward.

G2.b is closer to "brain learns from its own experience"; G2.a is a cleaner science experiment.

Either way, G2's success criterion: test accuracy at epoch N > test accuracy at epoch 0 by a statistically-significant margin, replicated across 3 seeds.
