# G1 Findings — Dataset → Encoder → Sim → Decoder → Loss

**Date:** 2026-04-20
**Gate:** G1 — minimum viable trainable pipeline
**Verdict:** **NO-GO (current architecture).** The scaffolding (dataset, encoder, decoder, runner, bridge injection) works end-to-end. The dataset itself is trivially linearly separable (logistic regression: 100% test). Two plasticity variants failed because the sim's default parameters are calibrated for networks of thousands of neurons with sparse convergence, not 64-input → 4-output direct mapping. Pivot to G2 with a reservoir architecture (hundreds of hidden neurons + external linear readout).

---

## 1. Protocol

- **Dataset**: `research/datasets/tiny_patterns.npz` — K=4 classes, 64-dim Poisson rate vectors, rates clipped to [1, 40] Hz, noise σ=4 Hz. 200 train / 50 test. Dataset seed `0xD47A5E7` fixed.
- **Network (v1 & v2)**: 64 Izhikevich-RS input + 4 Izhikevich-RS output. 256 input→output synapses, 12 fixed output→output lateral-inhibition synapses.
- **Per example**: 200 ms stimulus (`RATE_VECTOR_POISSON`) + 100 ms gap. Readout = spike counts in [100, 200] ms of stimulus.
- **Decoder**: argmax over per-output spike counts, tie-break lowest index.
- **Seeds**: 42 only (probe-level — a full 3-seed sweep was not warranted because single-seed probes never bent).

## 2. Dataset sanity

`sklearn.linear_model.LogisticRegression(max_iter=1000)` fit on raw rate vectors achieves **100% train + 100% test accuracy**. The classification problem itself is trivial; the sim is the bottleneck.

## 3. v1 — Teacher-forced STDP

**Design**: 400 pA constant teacher current on the correct-class output neuron during each 200 ms stimulus window. STDP (`A+=0.012, A−=0.010`) on input→output synapses, W∈[0, 1.5]. Expected that teacher-forced post-firing + input pattern pre-firing would cause class-specific potentiation.

**Results (seed 42)**:

| Probe | Params                                            | Epoch 4 test acc | Margin    | W max |
|-------|---------------------------------------------------|------------------|-----------|-------|
| 1     | spike_pA=250, spike_ms=1                         | 0.20             | −0.20     | 1.23  |
| 2     | spike_pA=1000, spike_ms=2 (fixed input firing)   | 0.20             | −0.04     | 1.32  |

Test confusion matrix (all probes): predictions collapse into classes 0 and 1. **Classes 2 and 3 are never predicted.**

**Weight-vs-class-mean correlations** (probe 2, seed 42, 2 epochs × 100 train):
```
W[0] vs class_means[0]:  -0.049
W[1] vs class_means[1]:  -0.095
W[2] vs class_means[2]:  +0.020
W[3] vs class_means[3]:  -0.043
```
Weight vectors are **not correlated with their class means**. Per-output weight sums are nearly uniform (13.7, 13.2, 12.5, 12.1) — every output received the same aggregate potentiation.

**Diagnostics**:

1. *Under-firing input neurons (bug).* `spike_current_pA=250 × 1 ms` is below Izhikevich-RS threshold. Empirical 20 Hz target → actual 3.25 Hz (15% efficiency). Fixed by switching to `1000 pA × 2 ms` which tracks 5–40 Hz linearly.

2. *Lateral inhibition too weak to silence non-correct outputs.* Per-spike g_i increment ≈ 0.7 nS × `inhibitory_propagation_strength=0.105` = 0.073 nS. Integrated current on non-correct outputs ~−2 pA. Insufficient to prevent crosstalk — non-correct outputs still fire occasionally during off-class training and pick up their pattern.

3. *A+ > A− causes monotone weight inflation.* All synapses drift upward; differential signal drowns.

## 4. v2 — Perceptron co-activity (external update)

**Design**: Sim plasticity entirely disabled. Forward pass only. Per example, compute input spike counts and output spike counts, apply perceptron delta `dW[k, i] = lr * (target[k] − softmax(out)[k]) * in_norm[i]` directly to the plastic input→output weights in `cp_connections.data`.

**Results (seed 42)**:

| Probe | Params                                                      | Epoch 2 test acc | Margin |
|-------|-------------------------------------------------------------|------------------|--------|
| 1     | prop=0.05 (default), W init=0.30, lat_inh=0.5              | 0.20             | 0.00   |
| 2     | prop=1.0, W init=0.10, lat_inh=0.1, lr=0.01                | 0.20             | 0.00   |
| 3     | prop=3.0, W init=0.30, lat_inh=0.1, lr=0.003               | 0.20             | 0.00   |

All predictions collapse to class 0. **Margin = 0 means every output spike count is 0.**

**Diagnostic — the real blocker**:

The sim's `propagation_strength` default is 0.05 — calibrated for networks where each neuron has thousands of converging synapses. With only 64 inputs per output:

- At `prop=0.05, W=0.3`: steady-state g_e ≈ 0.019 nS. Current ≈ 1 pA. Outputs never fire.
- At `prop=1.0, W=0.3`: g_e ≈ 0.64 nS peak. Current ≈ 38 pA. Still below Izh RS rheobase (~60 pA at rest, ~100 pA to cross the quadratic subthreshold barrier).
- At `prop=3.0, W=0.3`: g_e ≈ 2 nS peak. Current ≈ 120 pA. Marginal. Even here, outputs rarely fire because lateral inhibition + quadratic leak pushes them back.

Without outputs firing, there is no output spike count. Without output spike counts, the softmax is uniform. Without a non-uniform softmax, the perceptron error averages to zero across balanced classes → no weight movement. The sim's **forward pass is broken for this size of network**, so no amount of external learning rule can recover.

## 5. Why G1 is NO-GO for the current architecture

The core issue is not the plasticity rule, the teacher design, or the lateral inhibition — it's that the **sim's default propagation parameters + the Izhikevich RS neuron's stiff subthreshold dynamics combine to make a 64-input network silent**. The task was essentially:

> "Make 64 excitatory inputs drive a downstream neuron to fire."

…which the sim cannot do with its default parameters calibrated for 1K+ input convergence.

Even raising `propagation_strength=3.0` (60× default) gets outputs *barely* to fire, and the margin is tight enough that any inhibition or variation kills output firing again.

## 6. Pivot design — G1.v3 (reservoir + external readout)

Move to the reservoir computing / liquid state machine paradigm:

- **64 input neurons** (same as v1/v2).
- **~500 hidden neurons**: Izhikevich mixed RS+FS, sparse random recurrent connectivity (~5% density), `enable_watts_strogatz=True` with the sim's default connection generator. This uses the sim **in its calibrated regime** — 500 neurons × 100 connections each × default propagation_strength.
- **Input → hidden projection**: plastic or fixed weights.
- **No output neurons inside the sim.** Readout is *external*.
- **Readout**: collect hidden-neuron spike counts per example (500-dim feature vector). Train a linear classifier (`sklearn.LogisticRegression` or a hand-rolled perceptron) on (features, label) pairs.
- **Prediction**: classifier's argmax.
- **Loss**: classification error (0/1), cross-entropy for smooth tracking.

This sidesteps all the issues that killed v1 and v2:
- Sim runs in its calibrated regime (no prop_strength hacks).
- Hidden reservoir does non-linear spatio-temporal feature extraction.
- Linear readout is known-trainable (dataset is linearly separable on RAW rates, should be linearly separable on sim features too).

If the reservoir version gets >55% test across 3 seeds, G1 is GO and we proceed to G2 (replacing the external classifier with a sim-native learning rule, or adding recurrent feedback).

## 7. Out of scope for this pivot

- Tuning the current 68-neuron architecture further. The parameter space is too hostile; sunk cost.
- Per-synapse plastic mask. Not needed for reservoir (no sim-side learning on reservoir).
- MNIST / real data. Save for G4.
- Sensorimotor loop. Save for G5.
