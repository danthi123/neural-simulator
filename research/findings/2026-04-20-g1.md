# G1 Findings v1 — Teacher-Forced STDP on Tiny-Pattern Classification

**Date:** 2026-04-20
**Gate:** G1 — minimum viable trainable pipeline
**Verdict:** **NO-GO.** The scaffolding (dataset, encoder, decoder, runner, bridge injection) works end-to-end, but the chosen training rule (teacher-forced single-layer STDP with lateral inhibition) does not induce class-specific selectivity on K=4 Poisson-pattern classification. Pivot to R-STDP (G1.v2) before declaring the gate either way.

---

## Protocol

- **Dataset**: `research/datasets/tiny_patterns.npz` — K=4 classes, 64-dim Poisson rate vectors, rates clipped to [1, 40] Hz, noise σ=4 Hz. 200 train / 50 test. Dataset seed 0xD47A5E7 fixed.
- **Network**: 64 Izhikevich-RS input + 4 Izhikevich-RS output. 256 plastic input→output synapses, initial weights Uniform(0.05, 0.15), W_max=1.5. 12 fixed output→output lateral-inhibition synapses (weight 1.0, routed through inhibitory trait).
- **Per example**: 200 ms stimulus (per-neuron `RATE_VECTOR_POISSON`) + 100 ms gap. Readout = spike counts in [100, 200] ms of the stimulus period.
- **Training signal**: 400 pA constant teacher current on the correct-class output neuron for the 200 ms stimulus window.
- **Decoder**: argmax over per-output spike counts. Tie-break to lowest index.
- **Seeds**: 42 only (probe-level — a full 3-seed sweep was not warranted since the single-seed probe didn't bend the curve).

## Two bugs found and fixed during diagnosis

1. **Under-firing input neurons.** With `spike_current_pA=250, spike_duration_ms=1.0`, a Poisson event delivered 250 pA for 1 ms, which is insufficient to drive Izhikevich RS neurons through threshold. Empirically, a 20 Hz Poisson-rate target produced only ~3.25 Hz input firing rate (~15% efficiency). Fixed by switching to `spike_current_pA=1000, spike_duration_ms=2` — empirically tracks 5–40 Hz linearly. Probe 2 above ran with the fix.

2. **Test-time dead output neurons.** Probe 1 never predicts classes 2 or 3 because their output neurons never fire during testing. Probe 2 shows the same pattern. Explanation below.

## Root-cause diagnosis — why teacher-forced STDP fails on this task

The teacher current is supposed to force pre→post timing coincidences for the correct class's output neuron, so that STDP potentiates class-specific input→output pathways. Instead, we observe **uniform potentiation across all output neurons**, with zero class-specific correlation.

Two interacting failure modes:

**A. Lateral inhibition (magnitude 1.0) is too weak to silence non-correct outputs during training.** Per-spike inhibitory conductance is ~0.7 nS after propagation scaling. At 20 Hz firing on the correct output → sustained g_i ≈ 2.8 nS. Driving force at V=−60, E_inh=−75 gives only ~−42 pA on the non-correct outputs. Input-driven excitation (total ~60–100 pA once weights grow) overwhelms inhibition, so non-correct outputs continue to fire occasionally. When they fire, their input→output synapses pair with the currently-presented class's pattern → crosstalk potentiation.

**B. A+ > A− causes monotone weight inflation.** Even with only partial crosstalk, the net LTP bias (`A+=0.012, A−=0.010`) pushes all weights upward whenever pre and post co-fire. After a few epochs the weight floor is well above 0.4 and the weight ceiling is near the cap. Differential class information is drowned by the uniform LTP floor.

The two modes compound: (B) gives every synapse a large baseline, which in turn raises the input drive on non-correct outputs, which makes (A) worse.

## Next step — G1.v2

Keep every module; swap training rule.

- **No teacher current.** Output neurons fire based on input weights alone. Bootstrap with slightly higher initial weights (0.25–0.4) so at least some output firing happens early.
- **R-STDP (three-factor learning).** Each example: present stimulus, measure output argmax prediction, compute reward: +1 if correct, −1 if wrong, 0 otherwise. Set `core_config.current_reward_signal` for a short post-example window; let the existing `fused_eligibility_trace_decay` + reward modulation do the weight update.
- **Keep lateral inhibition at magnitude 1.0.** R-STDP doesn't need WTA during training — it needs bootstrap firing and a reward signal.
- **Reduce STDP LTP bias:** `A+=0.010, A−=0.010` (no asymmetry), so eligibility traces are driven by coincidence and reward does the class-assignment work.
- **Success threshold unchanged:** mean test acc > 55% across 3 seeds, each seed ≥ 45%, monotone learning curve.

If G1.v2 still doesn't bend the curve, the next pivot is to a **reservoir + linear readout** (existing sim supports `TrainingMode.RESERVOIR_READOUT`). But R-STDP is the simpler change from here.
