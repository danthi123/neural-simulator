# G8 Findings — Goal-context channel probe on moving-goal task

**Date:** 2026-04-24
**Gate:** G8 — diagnostic probe, NOT a go/no-go gate
**Question:** Does adding a biologically-plausible "goal-context" input channel (PFC-like top-down signal) enable the G7 NO-GO agent to readapt when the goal moves?
**Protocol:** G7's moving-goal scenario (goal jumps at step 300), 3 seeds × (goal-context enabled vs ablation)
**Verdict:** **H2 confirmed (with partial H1 contribution).** Goal-context channel does not
enable consistent readaptation: aggregate Phase 2 final-quarter mean distance is 4.06 Hz
Manhattan with context vs 4.81 without — a small improvement (~0.75 Manhattan units) but
nowhere near the < 3.0 threshold, and 2/3 seeds still have catastrophic phase 1→2 regression.
The runner-side signed perceptron + argmax architecture is the binding constraint, as
predicted. **Session B.2 should proceed with sim-native R-STDP + softer action selection**
(first-spike WTA), not additional input engineering on the runner side.

---

## 1. Motivation — what G7 left undecided

G7 was NO-GO across three rule variants (B, B+eps-reset, C). The agent specialized to the
phase-1 goal and couldn't shed that policy fast enough when the goal moved. Two competing
explanations, both consistent with the observed data:

**(H1) Missing-information.** The hidden layer never sees the current goal. It can only learn
a single input-sensor-state → motor-action mapping. When the goal moves, the "correct" mapping
for the same sensor-state inverts, and the perceptron can't represent this context-dependence
at all — no amount of LR or exploration tuning can fix missing input.

**(H2) Architectural limit.** The cliff-edged argmax action selection + per-step credit
assignment creates a weight-specialization attractor. Even with goal information, 300 steps
aren't enough LR × time to flip the decision boundary.

If G8 (goal-context channel added) *readapts*, it's (H1) and we have a biology-compliant
path forward (PFC working memory). If G8 *still fails*, it's (H2) and Session B.2 needs to
address the action-selection mechanism (first-spike WTA instead of argmax) and the learning
rule (sim-native R-STDP with signed eligibility, already merged).

## 2. Biology framing

The goal-context channel is a stand-in for PFC top-down persistent activity:

- PFC holds goal representations via recurrent persistent firing (Fuster 1973, Goldman-Rakic 1995).
- PFC projects to premotor / motor areas (e.g. via PFC→SMA→M1), biasing motor plans by goal context.
- In rodents, PFC-to-M2 projections modulate action selection in goal-directed navigation
  (Warden et al. 2012, Kim et al. 2016).

Rather than build a full recurrent PFC circuit in the sim (which would be a separate multi-week
engineering effort), G8 uses a simpler proxy: an **input channel with Gaussian-tuned Poisson
rates encoding the current goal location**, using the exact same encoding scheme as the sensory
channel. This simulates the *output* of a working-memory PFC circuit without the circuit itself.

If G8 passes, the follow-up work is to replace this input-stream proxy with a real recurrent
PFC submodule (a small population with strong self-excitation tuned to maintain persistent
activity for 100-500 ms after a cue). That's a clean biology-forward path.

## 3. Implementation

`research/runners/g8_runner.py` extends G6/G7 with:

- **128 input neurons** = 64 sensory (32 x-tuned + 32 y-tuned) + 64 goal-context
  (32 gx-tuned + 32 gy-tuned). Same Gaussian tuning curves, sigma=1.5, rate_peak=30 Hz.
- **200 hidden** (160 exc + 40 inh), same as G6/G7.
- **4 motor** (N, E, S, W), same as G6/G7.
- **Plastic layer**: hidden → motor, signed perceptron (same rule as G6/G7).
- **Ablation flag**: `goal_context_enabled=False` sets goal-context rates to floor only
  (1 Hz uniform — functionally zero information), making G8 behaviorally equivalent to G6/G7.

Both sensory and goal-context inputs project to the hidden layer with the same density (0.5)
and weights. The hidden layer must *learn* to integrate them via the reservoir structure
(recurrent mixing); we don't explicitly wire context-dependent gates.

Smoke tests (`tests/test_g8_runner_smoke.py`, 2 tests, ~21 s):
- `test_g8_smoke_with_goal_context`: 30-step run, verifies reservoir doesn't drift.
- `test_g8_smoke_goal_context_disabled`: ablation runs without errors.

## 4. Results

### 4.1 Moving-goal scenario

Start: (1, 1). Goal 1: (6, 6) for steps 0-299. Goal 2: (1, 6) for steps 300-599.
Manhattan distance (6,6)→(1,6) = 5, similar magnitude to G7.v1's (6,6)→(2,5) shift.

Epsilon-greedy: `epsilon_start=0.1, epsilon_end=0.0, decay=150 steps`,
`reset_epsilon_on_goal_change=True`. LR: `0.01`, `decay_after_goal` (×0.25 after first goal).

### 4.4 Comparison vs G7 baseline

G7.v1 (no goal-context, no reset_epsilon) phase-2 finalQ: seeds {6.27, 3.09, 6.64}, aggregate
mean ≈ 5.33. G8 ablation is consistent with that (4.81, seeds match qualitatively: seeds 42/44
stuck, seed 43 partially adapts). The `reset_epsilon_on_goal_change=True` in G8 seems to
modestly help vs G7 {6.52, 4.52, 6.65}, consistent with G7.v2's finding that eps-reset alone
was insufficient.

### 4.5 Where does goal-context help?

Per-seed delta (goal_context_on P1 finalQ minus goal_context_off P1 finalQ):

| Seed | Δ (negative = goal-context helps) |
|------|-----------------------------------|
| 42   | 3.00 − 5.44 = **−2.44** (goal-context helps — agent inches toward new goal) |
| 43   | 2.33 − 2.31 = **+0.02** (indistinguishable) |
| 44   | 6.84 − 6.69 = **+0.15** (goal-context slightly hurts) |
| **mean** | **−0.76** (small net improvement, but not significant at n=3) |

Seed 42 is interesting: **with** goal-context, the agent's N-dominant degenerate policy
actually ended up *accidentally* near the new goal (1, 6), since (1, anywhere near 6) is
the new target. This inflates the apparent benefit of goal-context for seed 42. Adjusting
for this accidental hit, the real signal is seed 43 (tie) and seed 44 (small hurt). So
the goal-context channel is **not** rescuing the architecture.

### 4.6 Phase 1→2 direction

The more revealing metric: does Phase 2 finalQ < Phase 1 finalQ (i.e., readaptation
happened at all)?

| Condition       | Seed 42 | Seed 43 | Seed 44 | Readapted ≥ 2/3 seeds? |
|-----------------|---------|---------|---------|------------------------|
| goal_context_on | 4.00 → 3.00 ✓ (spurious, see §4.5) | 3.88 → 2.33 ✓ | 1.75 → 6.84 ✗✗✗ | Technically yes, one is spurious |
| goal_context_off| 3.76 → 5.44 ✗ | 1.69 → 2.31 ~ | 1.52 → 6.69 ✗✗✗ | No |

Only seed 43 under either condition shows a real readaptation pattern. That's the same seed
that was the outlier in G7.v1/v2/v3. There's something seed-specific about 43's reservoir
that makes it more plastic; it's not a rescue, it's an artifact.

## 5. Verdict

**H1 (missing information) is not the primary constraint.** Goal-context does help seed 42
arrive at the new goal by a spurious NE→NW alignment, and marginally changes aggregate
P1 finalQ from 4.81 to 4.06. But it does not produce the kind of clean, seed-independent
readaptation that would close the gate.

**H2 (architectural limit) is the binding constraint.** The cliff-edged argmax + per-step
credit assignment + weight-specialization attractor survives the addition of perfectly
informative goal-context inputs. Seeds 42 and 44 remain stuck in their phase-1 policies
regardless of context.

This is a **decisive probe result**: Session B.2 does not need to invest in PFC-analogue
input engineering. It needs to change the learning rule and action selection.

## 6. Implications for Session B.2

Two coupled changes, both biology-forward:

### 6.1 Learning rule: runner-side perceptron → sim-native R-STDP

The signed-eligibility branch (merged in `1d70a3f`) already provides the sim-native R-STDP
path. What's missing is the *runner* using it instead of bypassing it. Specifically:

- Set `core_cfg.enable_stdp = True` and `core_cfg.enable_reward_modulation = True` in G6-style
  runners.
- Per step: set `cfg.current_reward_signal = +1 / 0 / -1` based on `Δ Manhattan distance`.
- Remove the runner's direct `cp_connections.data += delta` update loop.
- The sim's own 500ms eligibility trace handles credit assignment temporally.

**Biological plausibility:** this is canonical three-factor learning (Frémaux & Gerstner 2016).
Eligibility = "synapse recently active," reward signal = "dopamine burst" (phasic DA on
reward, phasic dip on punishment), modulated Δw = learning. 500 ms tau is dopamine-realistic
(Schultz 1998).

### 6.2 Action selection: argmax → first-spike WTA

Argmax over 100 ms integrated motor counts is the cliff-edge. First-spike WTA — "the motor
whose first spike after stimulus onset is earliest wins" — has three advantages:

1. **Softer.** Early in learning, spike counts are small and argmax is essentially arbitrary;
   first-spike time is equally noisy, but noise acts as *natural exploration*. No need for
   explicit epsilon-greedy scheduling.
2. **Biologically canonical.** Real motor circuits implement WTA via strong lateral inhibition
   that silences losers. The first-to-spike wins because its output inhibits the others
   before they can fire. Thorpe, VanRullen, Gautrais (2001) argued this is the dominant
   mechanism in fast visual classification.
3. **No reward-signal lag.** Argmax requires the full readout window (100 ms) to decide.
   First-spike WTA decides as soon as *any* motor neuron fires, typically within 20-40 ms
   of stimulus onset. Shorter trial time → more trials per unit simulation time.

The Session B.2 runner should offer both `action_selection="argmax" | "first_spike"` as a
flag, so we can A/B test them.

### 6.3 Combined expected outcome

If B.2 `argmax` + sim-native-R-STDP alone doesn't close readaptation, fall back to the
stronger combo: `first_spike_wta` + sim-native-R-STDP. If that fails too, Session C (Path 2,
neuromodulatory gating on synaptic gain) becomes the branch investigation.

The 500 ms eligibility window with sign-preserving Δw gives the sim's reward path a chance
to *cancel* phase-1-specialized weights when phase-2 reward flips sign, which the runner-side
per-step rule could not do (each step's delta is applied immediately and committed).
