## 0. Terms (defined once — no undefined acronyms)

- **point neuron** — a neuron with ONE membrane state (Izhikevich `v,u`; AdEx `v,w`; Hodgkin-Huxley `V,m,h,n…`): all synaptic input is summed at one somatic compartment before the spike decision. The project's substrate.
- **graded code / graded embedding** — a real-valued (rate / sub-threshold) representation where *similar concepts get similar codes* (small cosine distance), the prerequisite for inferring "cat is like a dog." Opposite of a decorrelated/orthogonal code (used for binding).
- **co-occurrence count** — how often two words appear together in a window of text. A `concept × context-hub` count matrix `C` is the raw distributional-semantics signal.
- **PMI / PPMI (positive pointwise mutual information)** — `PMI(a,b) = log( P(a,b) / (P(a)·P(b)) )`; `PPMI = max(0, PMI)`. It is **LOG-compression of the count PLUS division by the marginals** (down-weighting high-frequency words). The measure that recovers the category structure the project's Hebbian learn cannot (host +0.532 vs brain −0.008, Option-C Stage-B).
- **marginal** — the row/column total of `C` (`P(a)` = how common word `a` is, ignoring partners). "Divide by the marginal" = down-weight common words.
- **wide dynamic range** — inputs spanning many orders of magnitude (here: informative category-hub counts ~4 vs common-hub counts ~40, a ~130× span across the full matrix); a fixed spike threshold silences the low end and saturates the high end.
- **divisive normalization (Carandini-Heeger)** — `R_i = D·x_i / (σ + Σ_j x_j)`: divide each unit's drive by a pool sum. The canonical cortical gain-control / dynamic-range operation.
- **similarity matching (Pehlevan-Chklovskii)** — an unsupervised objective that learns an output code whose pairwise similarities MATCH the input's pairwise similarities, optimized by LOCAL Hebbian (feedforward) + anti-Hebbian (lateral) rules; produces a similarity-PRESERVING embedding. Has a demonstrated SPIKING realization.
- **successor representation (SR)** — a predictive code: each state is represented by its expected future visitation of other states; states with similar successors get similar codes → generalization. The hippocampal/entorhinal predictive-map theory (Stachenfeld-Botvinick-Gershman 2017).
- **Mikulasch-Priesemann limit** — the peer-reviewed result (PNAS 2021) that a point neuron with a single global inhibitory pool cannot whiten correlated inputs; decorrelation is an analog/pre-spike (dendritic) computation. The project's documented decorrelation boundary, hit five independent ways.

## (a) Headline verdict

**The principled mechanism for a learned, generalizing, spiking graded cortex is a SIMILARITY-PRESERVING online algorithm whose INPUT is logarithmically compressed and marginally normalized — i.e. a spiking realization of "factorize the PPMI matrix."** Two facts converge to make this specific and not a guess: (1) the host method that demonstrably recovers the structure (PPMI+SVD, +0.532/+0.957) IS, by the Levy-Goldberg 2014 theorem, *the same object* that the word-embedding gold standard (word2vec / GloVe) learns — word2vec implicitly factorizes a (shifted) PMI matrix, and GloVe factorizes a *log-count*-shifted PMI matrix; so the target is well-defined and the LEARNED route to it is known; and (2) there is a **demonstrated spiking network that learns a similarity-preserving embedding with LOCAL learning rules** — Pehlevan 2019, "A Spiking Neural Network with Local Learning Rules Derived From Nonnegative Similarity Matching" (integrate-and-fire units, manifold learning), which is precisely the missing "learned spiking-cortical embedding that produces graded codes on neurons" the dual/CLS pipeline has flagged for months. **The single cheapest de-risk:** an afternoon-scale numpy toy on the project's EXACT Option-C failing case (the `learn_W_homeostatic` corpus + the independent `S_true` taxonomy + the host PPMI+SVD ceiling + the permuted controls) that asks whether **(i) log-compressing the input drive (drive ∝ `log1p(count)`) and (ii) replacing the saturating Hebbian recurrent with a similarity-matching (Hebbian/anti-Hebbian, fixed-point) update** lets the **POINT-neuron** substrate recover `Pearson(S_learned, S_true) ≫ 0` and generalize to held-out neighbours — with the un-compressed raw-count Hebbian control reproducing the ≈0 failure. The log-compression / PPMI-neural track is **the right track AND only a PARTIAL fix on its own**: log-compression is the *input* half (it un-silences the low-count informative signal and is exactly what makes a point neuron viable per the D2 correction), but the *learning* half (a non-saturating, similarity-preserving rule) is independently required — the project's own diagnosis already proved a saturating Hebbian learn destroys the structure *before any read-out*, so log-compression alone, fed to the existing saturating recurrent, will not suffice. **Top reusable machinery:** the Option-C harness (`option_c_stageB_fair_test.py` + `learn_W_homeostatic` + the host pre-gate + `S_true` + `structure_recovery` + `architecture_generalization` + permuted controls), the committed dendritic stack as an OPTIONAL second arm, and STP / synaptic-scaling as the biological frequency-normalizers. **Honest cost:** the de-risk is an afternoon of CPU; the on-substrate learned-embedding build is the dual/CLS pipeline's last unbuilt, **months-scale** piece — but the de-risk's intermediate value is decisive either way (it tells the owner whether the point neuron + log-compression + similarity-matching closes the Option-C gap, OR whether the dendritic D2 build is genuinely required).

## (b) Diagnosis — the real obstacle is the wide-dynamic-range / threshold-silencing coding problem, and log-compression is the input fix (necessary, not sufficient)

### (b.1) What the arc has established (the precise state of play)

Three project results, read in full, pin the obstacle:

1. **The structure IS in the data; the LEARN destroys it (not the read-out).** `2026-06-11-learned-graded-embedding-diagnosis.md` is decisive: the spiking-Hebbian recurrent `W` is a **saturated near-uniform blob** — `Pearson(W, raw_counts) = +0.062` (essentially uncorrelated), off-diag mean 0.864 / CV 0.27, recurrent mean 0.998 / max 44.8, 2.40M of 2.46M possible edges filled. Applying PPMI/divisive-normalization *to the learned W* recovers nothing (+0.039) because **there is no graded structure left in W to recover**. The host PPMI+SVD on the *raw counts* still hits +0.932/gen 1.000. Root cause: "20 store-cycles of co-firing dense overlapping sparse patterns with NO normalization, NO competition, NO LTD/decay → nearly every pool→pool weight grows to a similar value." The corroborating smoke (2 cycles → `Pearson(W,counts)=+0.724`; 20 cycles → +0.062) shows this is **training-driven saturation**. ⇒ the read-out is exonerated; the **learning rule** is the bottleneck.

2. **On the spiking substrate, the firing THRESHOLD + readout INTEGRATION already remove the common mode the dendritic gain was designed for.** `2026-06-14-D2-phase1-DONE-phase2-frontier.md` ⚠️ CORRECTION: a clean-readout control (window 100, n_readout 1000) gives point-neuron +0.167 / gen 0.422 vs dendritic +0.042 — the point neuron recovers structure on its own once it integrates, and the gain *hurts*. The earlier "gain confirmed" was a **noisy-readout denoising artifact**. The deeper, regime-independent limit it isolates: under *faithful raw-count drive*, the spiking **rheobase threshold SILENCES the low-count category hubs** — exactly the low-frequency informative signal — while common hubs dominate; a baseline lift un-silences them but dilutes the common mode so neither mechanism robustly produces a strong graded code from raw counts.

3. **The new lead (unconfirmed): log-compression un-silences the low end on a point neuron.** From the prompt: with **`drive ∝ log1p(count)`** the gain-INDEPENDENT POINT-neuron cortex produces a strong graded code (single-seed gen 0.844, Pearson +0.287 vs host +0.957). And critically — **PPMI, the host method that works, is itself `log` of normalized counts.** This is the bridge between (1), (2), and the fix.

### (b.2) Why this is a coding problem, and what biology does about it

The obstacle is a **representation** problem, identical in form to a textbook sensory-coding problem: how does a unit with a fixed spike threshold and a saturating output represent an input that spans ~130× (rare-informative ~4 to common ~40), so the **low-frequency informative** signal survives alongside the **high-frequency common** signal? Biology's answer is overwhelmingly **logarithmic compression at transduction, plus divisive normalization for gain control** — and the catalog confirms the project has these as known-missing or partial:

- **Logarithmic / Weber-Fechner encoding is the universal wide-dynamic-range code.** The retina compresses ~10⁹ of light intensity via Weber-law background adaptation (catalog **K.* photoreceptor**, lines 3997–4009: "Naka-Rushton intensity-response curve, light/dark adaptation ~10⁹ dynamic range… Weber-law-like background adaptation"); the cochlea is logarithmic in sound intensity (decibels); cortical magnitude representations are logarithmic — **prefrontal "number neurons" code numerosity on a logarithmic axis** (Nieder & Dehaene 2003, *The neural basis of the Weber-Fechner law: a logarithmic mental number line*, TICS), retinal/foveal visual space is log-compressed, and hippocampal internally-generated time is logarithmically compressed (bioRxiv 2021.10.25.465750). **The principled reading: a co-occurrence/context vector is a magnitude signal spanning a wide range, and the brain's canonical representation of a wide-range magnitude is logarithmic.** So `drive ∝ log1p(count)` is not a hack — it is the Weber-Fechner transduction the substrate's upstream encoding should perform, and the new lead's single-seed positive is exactly what that predicts.

- **Divisive normalization (Carandini-Heeger) is the cortical gain/dynamic-range control.** Catalog G.* / E.15 (top-down gain modulation, lines 1511–1517: the neuromodulator subsystem "can apply scope-targeted gain modulation"); H.08 (Renshaw recurrent inhibition = gain control); the M-current / SK-BK spike-frequency adaptation entries (lines 3324–3385) are the *adaptation* arm of dynamic-range control, captured phenomenologically by Izhikevich `u` / AdEx `w` / homeostatic threshold today. Divisive normalization removes a *shared multiplicative* common mode (the variance-equalization HALF of whitening) — it is the right primitive for the **marginal** (common-frequency) arm, but on its own it is *scalar* gain, not the per-pair decorrelation binding needs (the project's own "divisive-norm cleanup 0.84" NEGATIVE, CLAUDE.md). For the **graded-embedding** question, scalar common-mode suppression is exactly what is wanted (suppress the common frequency, keep the residual), which is why divisive-normalization-on-the-input is a legitimate *partial* fix — but the D2 correction showed the spiking threshold already does much of this, so its marginal value is regime-dependent.

### (b.3) Is log-compression / PPMI-neural the fix, or a partial fix? — PARTIAL, and the missing half is the learning rule

**PPMI = log(compression) + marginal(normalization).** The new lead supplies the **log** half at the input. That demonstrably un-silences the low-count signal and makes a **point neuron** (with its threshold + integration) recover a graded code from a *forward pass of given counts* — the D2 correction's mechanism explains why (threshold = presence-binarizer, integration = common-mode averaging; log-compression lifts the low end above rheobase so it participates). **But two gaps remain before this is a LEARNED, generalizing cortex:**

1. **The marginal-normalization half.** `log1p(count)` compresses but does not divide by `P(a)P(b)`. A frequent-but-uninformative word still has a large `log1p(count)`. PPMI's power over plain log-count is the marginal division (down-weighting common words); GloVe's own derivation factorizes a *log-count matrix shifted by the marginals* (Levy-Goldberg; Pennington-Socher-Manning). So the input encoding likely needs **log-compression AND a marginal/divisive-normalization** (a frequency-dependent down-weighting). The biological substrate for the marginal arm: **short-term synaptic depression** (high-frequency presynaptic sources deplete → automatic frequency-dependent normalization — Tsodyks-Markram; Abbott-Varela-Sen-Nelson "synaptic gain control"), and/or divisive feedforward inhibition (the fly antennal lobe computes exactly this, Olsen-Wilson; catalog E.19 olfactory). This is the arm the committed `enable_dendritic_divisive_gain` (the per-source EMA gain `g_i = σ/(σ + a_i)`) was BUILT for — see §(d) — though the D2 correction found it not load-bearing *for the spiking forward pass*; whether it helps *inside a learned rule* is open.

2. **The learning half (the decisive gap).** Even with a perfectly compressed+normalized INPUT, the project's diagnosis (b.1.1) proved that a **saturating Hebbian recurrent destroys the structure during learning** — `Pearson(W,counts)=+0.062` *before any read-out*. A learned graded cortex must use a **non-saturating, similarity-preserving learning rule**, not the current un-normalized Hebbian growth. This is the half the log-compression lead does NOT address, and it is independently confirmed as load-bearing. **⇒ log-compression/PPMI-neural is the right INPUT track and a genuine partial fix; the complete mechanism is log-compressed-input + a similarity-matching (or predictive/contrastive) LEARNING rule.** The next section ranks the learning rules.

### (b.4) The crucial reframe vs the dendritic doc

The dendritic doc and the D1 GO concluded "per-compartment divisive gain is the escape." The D2 correction **retired that for the gain's necessity** on the spiking substrate. This doc's reframe: **the obstacle was never *only* the missing per-input gain — it is (input) the wide-dynamic-range representation of the count vector AND (learning) the saturating Hebbian rule.** Log-compression addresses the input cheaply on the EXISTING point-neuron substrate (no `sim/` edit — it is an upstream encoding choice, the world/body's job of rendering the drive); a similarity-matching learning rule addresses the learning. **This makes a large part of the solution achievable WITHOUT the months-scale dendritic `NeuronModel` build** — which is the single most important strategic update for the owner: the D2 dendritic build may be *sufficient* but the D2 correction suggests it may not be *necessary* if log-compression + a better learning rule close the gap on the point neuron. The de-risk in §(e) tests exactly that fork.

## (c) Ranked, biologically-grounded options for the LEARNED graded embedding

All four below assume the **input is log-compressed (and ideally marginally normalized)** per §(b) — that is the shared input front-end, cheap and substrate-free. They differ in the LEARNING rule that produces the graded embedding.

### Option L1 (RECOMMENDED FIRST — the cheap-first de-risk target) — SIMILARITY-MATCHING (Pehlevan-Chklovskii), the biologically-plausible online algorithm that PROVABLY produces a similarity-preserving embedding, with a demonstrated SPIKING realization

- **Mechanism.** Optimize a *similarity-matching* objective: the output codes' pairwise similarities match the (log-compressed) input's pairwise similarities. Optimized by **local rules** — Hebbian feedforward (`ΔW_ff ∝ y·x`) + **anti-Hebbian lateral with a fixed-point/decay term** (`ΔM_ij ∝ y_i·y_j − M_ij`, the single most important difference from the project's *saturating* rule — the `−M_ij` decay gives a fixed point at `M_ij = ⟨y_i y_j⟩`, so the recurrent does NOT fill to a uniform blob). Output is a similarity-PRESERVING (graded, generalizing) embedding. The nonnegative variant (NSM) additionally clusters/sparsifies.
- **Why it is the lead.** It is the *named cure* for the project's exact diagnosed failure (saturating Hebbian → uniform W): `2026-06-11-learned-graded-embedding-diagnosis.md` §"explicit next step" recommends precisely "Oja / BCM / contrastive-predictive Hebbian, a non-saturating rule," and `2026-06-06-decorrelation-blocker-deep-research.md` §3/§7 independently identifies "give the lateral rule a fixed point (`c_ij−p²` / `−M_ij`)" as the missed upgrade vs the project's unstable Földiák rule. Similarity-matching is the principled framework both point to.
- **Biological grounding.** Pehlevan, Sengupta, Chklovskii 2018 (*Why do similarity matching objectives lead to Hebbian/anti-Hebbian networks?*, Neural Computation) — local Hebbian/anti-Hebbian rules derive from the objective; Hu-Pehlevan-Chklovskii 2014 (online NMF clusters + discovers sparse features); **Pehlevan 2019 (*A Spiking Neural Network with Local Learning Rules Derived From Nonnegative Similarity Matching*, ICASSP/arXiv 1902.01429) — integrate-and-fire units, local rules, manifold learning = a similarity-preserving embedding ON SPIKING NEURONS**; the 2026 follow-up (*Similarity Matching Networks: Hebbian Learning and Convergence Over Multiple Time Scales*, arXiv 2506.06134).
- **Spiking-realizability.** **HIGHEST of the four** — it is the only candidate with a *published spiking implementation* (Pehlevan 2019, integrate-and-fire), and its rules are exactly the bridge's machinery (plastic feedforward + a plastic lateral inhibitory pool + homeostasis). The known caveat (`2026-06-06` §7): the lateral weights converging to a precise saddle solution under Dale's law + finite spiking precision is the open risk; the Dale-compliant spiking descendant (King-Zylberberg 2013) reached RMS-correlation 0.13 (not full whitening) — but the **graded-embedding question does NOT need full whitening** (it needs similarity-PRESERVATION, the easier target), so this caveat is far less binding here than for the binding/decorrelation question where it was originally raised.
- **Fit to this sim.** HIGH. Reuses the brain-region framework + a plastic FS lateral pool; the *only* change vs the current `learn_W_homeostatic` is the lateral-rule fixed point + the log-compressed input. **This is option (e) below.**

### Option L2 (strong alternative / complement) — SUCCESSOR-REPRESENTATION-style predictive (temporal-difference) learning of state similarity

- **Mechanism.** Learn a *predictive* code: each concept is represented by its expected future co-occurring concepts (the SR `M = Σ γ^t T^t`). Concepts with similar successors (similar contexts) get similar codes → generalization, directly. Learned online by a **TD rule** (`δ = [s_t] + γ·M[s_{t+1}] − M[s_t]`), which is biologically grounded (dopaminergic TD) and naturally non-saturating (it learns a *prediction*, bounded by the discount).
- **Why it is relevant + the deep link.** The SR is, formally, a near-relative of PMI/word2vec: the search surfaced *Equivalence of Personalized PageRank and Successor Representations* (arXiv 2512.24722), and the SR's **top eigenvectors/SVD give a graded code** (Stachenfeld-Botvinick-Gershman 2017; Machado et al. eigenoptions) — the same SVD-of-a-normalized-co-occurrence-matrix object as PPMI+SVD. A neurally-plausible online SR learner exists (Geerts et al.; the arXiv 1906.09480 "A neurally plausible model learns successor representations" / the TD-SR in CA1). So SR is a *second principled route to the same graded structure*, learned by TD instead of similarity-matching.
- **Biological grounding.** Strongest of the four for the hippocampal/entorhinal substrate the project already builds (place/grid cells as the SR's eigenbasis; the trisynaptic loop is validated, CLAUDE.md P1). Dayan 1993; Stachenfeld-Botvinick-Gershman 2017 (*Nature Neuroscience*, the hippocampus as a predictive map); Gershman 2018 (*J Neurosci* TechSights).
- **Spiking-realizability.** MODERATE-HIGH — TD learning is already on the bridge (the dopamine-RPE / `td_value_critic` machinery, CLAUDE.md), and the SR is a value-function-like quantity. But producing a *graded similarity over concepts* from a spiking SR (vs over spatial states) is less directly demonstrated than Pehlevan's spiking similarity-matching, so it ranks just below L1 on *directness of the spiking embedding* while ranking ABOVE on *fit to the existing hippocampal substrate*. **Strong candidate to run as the second de-risk arm** (the project already has TD machinery + a place-code).

### Option L3 (the dendritic route — now a COMPLEMENT, not the lead) — dendritic predictive coding / per-compartment normalization learning the graded code

- **Mechanism.** The D1/D2 dendritic per-compartment divisive gain (or the fuller Mikulasch-Priesemann local-balance), but with the gain modulating the **recurrent Hebbian growth during co-fire** (the reframe the D2 finding flagged: "the gain modulates the LEARN, not just the forward read-out"), so the learned `W` itself is marginally normalized and does not saturate.
- **Why it dropped from lead to complement.** The D2 clean-readout CORRECTION showed the gain is NOT load-bearing for the spiking *forward pass* (threshold + integration substitute for it). Its residual value is specifically *inside the learning rule* (preventing the recurrent saturation diagnosed in b.1.1) — which is a real possibility but is **exactly what a similarity-matching fixed-point rule (L1) also achieves, more cheaply and without a protected `NeuronModel` edit.** So L3 is reserved for the case where L1+log-compression on the point neuron returns BOUNDARY (partial) and the dendritic marginal-normalization is needed to close it.
- **Biological grounding / spiking-realizability / fit.** As in the dendritic doc (Mikulasch-Priesemann 2021; Urbanczik-Senn 2014; committed `sim/dendritic_*.py`). HIGHEST fidelity, HIGHEST cost (the months-scale D2 build). **Gated behind L1.**

### Option L4 (the embedding-target reference, not a spiking mechanism) — explicit PPMI+SVD / GloVe / word2vec as the LEARNED-EMBEDDING CEILING and target

- **Mechanism.** Compute PPMI+SVD (or train word2vec/GloVe) on the counts. By Levy-Goldberg 2014, word2vec/SGNS *implicitly factorizes a (shifted) PMI matrix*, and GloVe factorizes a *log-count-shifted* PMI matrix — so all three are the SAME object the host control already uses (+0.532/+0.957).
- **Role.** NOT a brain-based deliverable (it is the host ceiling / labelled instrument, exactly as the project uses PPMI+SVD now). Its value is (1) it *defines the target* the spiking learner (L1/L2) must converge to, and (2) it confirms the target is a *factorization of a log-and-marginally-normalized count matrix*, which tells the de-risk precisely what input encoding (log + marginal) the spiking learner needs. **Keep it as the ceiling; do not mistake it for the mechanism.**
