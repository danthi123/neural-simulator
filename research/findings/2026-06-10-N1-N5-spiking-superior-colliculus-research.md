## 1. Diagnosis — exactly what is host-computed, and why the bar requires converting it

The owner's BRAIN-BASED-ONLY standard (MEMORY `feedback_brain_based_only_standard`): anything done by host (non-neural) computation **between sensation and action** is a shortcut, *even if the host calculation is biologically correct*. Host code is legitimate ONLY for (1) the environment (world state + rendering the agent's sensory input) and (2) the body (acting on the motor output). Perception, salience, orienting, reward, value, dopamine, and action selection MUST be neurons/synapses.

Two host functions still sit in that forbidden zone. Both read the **rendered retinal image** — which is legitimate (it is the agent's sensory input, channel-(1) of the bar) — but they then **compute a cognitive quantity in host numpy** and inject the *answer* as a current, which is the violation.

### N1 — the superior-colliculus orienting reflex (host pixel→cardinal)

- **Function:** `sc_orienting_cardinal_from_image(image)` — `g11_bg_runner.py:124–155`.
  It thresholds the ON channel into a bright **agent blob** (`on >= 0.65`) and a dimmer **goal blob** (`0.35 <= on < 0.65`), takes each blob's pixel **centroid** (`agent_xs.mean()`, `goal_xs.mean()`, …), computes the offset `dx, dy`, and returns the **cardinal** `"E"/"W"/"N"/"S"` by `abs(dx) >= abs(dy)` then sign (`:149–155`).
- **Injection:** `g11_bg_runner.py:6342–6365`. When `sc_orienting_reflex` is on, the returned cardinal selects a cortex pool and a strong current is written: `bridge.cp_external_input_current[region_indices_cp[f"cortex_{_sc_card}"]] = cp.float32(_sc_eff)` (`:6363–6365`). It is a weanable teaching scaffold (`sc_reflex_wean_start/_steps`, the linear ramp-to-zero at `:6354–6359`; declared `:2965–2966`).
- **What is host (the violation):** the *centroid extraction*, the *vector subtraction*, the *argmax-of-|dx|,|dy| → cardinal* — i.e. the entire "where is the salient target and which way should I orient" computation — is `np.where` + `.mean()` + Python `if`. The brain receives only the **answer** (a one-hot cardinal as a current). The retinotopic salience map, the winner-take-all over it, and the spatial→motor read-out that biology performs in the superior colliculus are all done by the host.

### N5 — the reward VALUE / approach signal (host distance-formula)

- **Function:** `sc_salience_offset_from_image(image, grid_size, image_size)` — `g11_bg_runner.py:158–180`. Same two-blob centroid read, but returns the **graded offset** `(dx, dy)` in grid-cell units (the goal's retinal **eccentricity** relative to the agent).
- **Reward logic:** `g11_bg_runner.py:6611–6635`. It renders the image at the agent's **old** and **new** positions, reads the offset at each (`_ob`, `_oa`, `:6626–6627`), computes the **eccentricity magnitude** `_eb = (dx²+dy²)**0.5`, `_ea = …` (`:6628–6629`), and sets `reward = +1 / −1 / 0` by `sign(_ea − _eb)` (`:6630–6635`) — i.e. **+1 if the goal got closer in the retinal image**.
- **Delivery (already spiking):** when `spiking_reward_us` is on, this scalar drives a PPN-like `reward_us` population that FIRES into the SNc (`reward_us` region `:1022–1028`; `reward_us → snc` excitatory pathway `:1766–1771`; the per-step drive `bridge.cp_external_input_current[region_indices_cp["reward_us"]] = cp.float32(reward_us_drive_pa * max(0, reward))` at `:6831–6839`).
- **What is host (the violation):** the **VALUE** — *"did the goal get closer?"* — is the host `sign(eccentricity_after − eccentricity_before)` (`:6630`), the bar's explicitly named cheat **"a reward computed by a distance formula."** Only the **delivery** of that scalar (the `reward_us` burst into the SNc) and the **dopamine error** `δ = r − V` (the spiking SNc + striosome GABA_B critic) are neural. The `r` term's *content* is host arithmetic.

### The shared-SC insight (one structure closes both)

In biology, the superior colliculus (catalog **A.07**, **H.25**) holds a single retinotopic map that (a) selects the orienting target by winner-take-all and (b) carries the target's retinal position and its frame-to-frame change. Both N1 (orienting direction) and N5 (is the target getting closer) are read-outs of **the same map's activity bump**: N1 = *where* the bump is (which direction to move), N5 = *how the bump moves over time* (toward the map centre/rostral pole = the target is foveating/approaching). So one spiking SC region — a retinotopic sheet with WTA — can feed **both** the orienting drive into the cortex pools **and** the approach signal that gates `reward_us`. This is the recommended build: **close N1 and N5 with one mechanism.**

**Critical honest subtlety about this gridworld (load-bearing for §6, §7).** `render_gridworld_to_image` (`sim/visual_cortex.py:155–207`) paints the goal as a **fixed 3×3 dim block** at its grid cell — it does **NOT grow** as the agent approaches (`:189–199`). So "approach" here is **NOT classical looming/expansion** (the angular-subtense increase that drives the cat SC rho/eta cells and the locust LGMD). It is the goal blob's **retinal position moving toward the agent blob's position** — i.e. the goal's **eccentricity decreasing** on an agent-centred retina. The correct biological homologue is therefore the SC **foveation / fixation-cell + buildup-cell + rostral-pole** mechanism (the population bump moving toward the rostral/foveal pole as a target nears the fovea: Munoz & Wurtz 1993 J Neurophysiol; rostral-pole fixation cells), **not** a looming/collision detector. A looming detector would be the right tool only if the render is changed to scale the goal blob with proximity (a possible future variant; §6 Option D).

## 2. Ranked biology-grounded options

Each option states: the biology (catalog ID + ≥1 literature citation, trust-but-verified against source), how it maps onto the project's substrate, and its cost (runner-only vs. a byte-reviewed `sim/` edit). The cost picture is favorable because the regions framework **already** supports retinotopic 2D sheets and topographic connectivity (`sim/regions.py:148–174` `coordinate_dim`/`coordinate_extent`/`coordinate_center`; `:296–306` `distance_sigma`) — **all runner-only, no `sim/` edit** — and the project already has the full saccade-WTA spiking idiom built (`sel_X`/`sel_FS_X`/`commit_X`/`commit_OPN`, `g11_bg_runner.py:1959–2068`).

### Option A — **Spiking SC retinotopic salience map + Mexican-hat WTA, read for BOTH orienting (N1) and rostral-shift approach (N5). [RANKED #1 — closes both]**

**Biology.** The intermediate/deep SC is a topographic motor map: stimulating a site evokes a fixed-vector orienting movement; the SC integrates visual salience into a "where to orient next" decision by **winner-take-all** competition on the map (catalog **H.25** "Superior colliculus saccade map — topographic motor map", `feature-catalog.md:3209–3219`, Kandel 6e Ch 35 p 875–882; catalog **A.07** SNr→SC orienting, `:169–179`). Spiking-network SC models that do exactly this are well established: **strong short-range excitatory + weak long-range inhibitory (Mexican-hat) lateral connectivity implements a dynamic soft winner-take-all**, the population *location* encodes the orienting vector (Marino et al., PLOS Comp Biol / *A spiking neural network model of the midbrain superior colliculus*, PMC5506246; *A spiking model of superior colliculus for bottom-up saliency*, PMC3704631; Trappenberg-style neural-field SC, ResearchGate 51669970). For the **approach** read-out: rostral-pole **fixation cells** discharge tonically when the target is foveated and the population bump sits rostral as a target nears the fovea (Munoz & Wurtz 1993, *J Neurophysiol* 70:559, PMC/PubMed 8410157; **buildup cells**, Munoz & Wurtz 1995). So **eccentricity decreasing → bump moves toward the rostral/foveal pole**; the *temporal change* of bump-position-toward-centre is the neural "getting closer" signal.

**Mapping onto the substrate.**
- A new `BrainRegion name="sc_map"` with `coordinate_dim=2`, `coordinate_extent=(1,1)` (a 2D retinotopic sheet), `exc_fraction=1.0` (`sim/regions.py:148–174`). Size ~16×16 = 256 to match the visual hierarchy's spatial grid.
- A `sc_FS` inhibitory pool (or use internal inhibition) wired with `distance_sigma` so that excitation is short-range and inhibition long-range — the Mexican-hat (`RegionPathway.distance_sigma`, `sim/regions.py:296–306`). This is **the project's `sel_FS_X` Rutishauser selective-inhibition idiom** (`g11_bg_runner.py:1986–1995, 2042–2051`) generalized from 4 discrete pools to a 2D sheet.
- **Afferent:** the rendered image already drives the neural `retina` region (`g11_bg_runner.py:6325–6334`). Wire `retina → sc_map` (and/or `cortex_v1_complex → sc_map`) as a **topographic** plastic pathway (`distance_sigma`), so the goal blob's retinal position lights up the matching SC site. This is the *visual* path the host centroid-read replaces. (The SC's defining input is direct retinal/superficial-SC drive — McHaffie et al. 2005, cited at catalog A.07.)
- **N1 read-out (orienting):** the SC bump's *direction from map-centre* must become a push on `cortex_{N,E,S,W}`. Two clean realizations, both reuse existing idiom: (i) wire four **fixed topographic pooling pathways** `sc_map → cortex_{N,E,S,W}`, where `sc_map → cortex_N` collects synapses from the *northern* half of the sheet (a hand-set, fixed, retinotopy-respecting fan-in — the SC→cortex/brainstem motor read-out), so whichever SC quadrant wins drives the matching cortex pool **by neuron firing, not host argmax**; or (ii) feed `sc_map` into the existing `sel_X`/`commit_X` accumulate-then-commit layer. Realization (i) is simplest and most faithful (SC→premotor is a fixed topographic projection, not a learned one).
- **N5 read-out (approach):** a small `sc_rostral` (foveal-pole) read-out pool that fires when the bump is near map-centre, plus a **temporal-difference** element so the *signal is the rate of bump-toward-centre*, not the static position. The temporal-difference is the one part that benefits from the substrate's slow channels (see Option C); the minimal version is "rostral-pole firing rose vs the previous step → gate `reward_us`."

**Cost.** **Runner-only for the map, the Mexican-hat WTA, the afferent, and the orienting read-out** — every piece is `BrainRegion`/`RegionPathway` vocabulary that already exists (`coordinate_dim`, `distance_sigma`, the FS-inhibition idiom). **No `sim/` edit** for N1. The N5 approach read-out's *temporal-difference* is the only piece that may want a slow channel (Option C / a tiny runner-side two-step comparison); see §6 for the cheapest split.

**This single mechanism closes BOTH N1 and N5** — the shared-SC insight realized.

### Option B — **`commit_X`-style discrete 4-pool SC (reuse the existing saccade-WTA layer verbatim). [RANKED #2 — N1 only, cheapest, lower fidelity]**

**Biology.** Same H.25/A.07/H.24 substrate, but collapsed to four discrete orienting channels. Catalog **H.24** ("Saccade generator — EBN/IBN/OPN burst circuit", `:3197–3207`, Kandel 6e Ch 35 p 868–880) is the burst-generator the project *already* models as `commit_X` (burst pool) + `commit_OPN` (omnipause), explicitly cited in-code as "SC / saccade-generator EBN analogue, H.24/H.25" (`g11_bg_runner.py:1997–2025`).

**Mapping.** Wire `retina`/`cortex_v1_complex → sel_{N,E,S,W}` via four fixed topographic pooling pathways (northern retina → `sel_N`, etc.), and let the existing `sel_FS_X` cross-inhibition + `commit_X`/`commit_OPN` produce the winning cardinal as an **all-or-none burst** (`g11_bg_runner.py:2026–2068`). The winning `commit_X` *is* the orienting decision — read exactly as the action read-out already is: "the host argmax merely OBSERVES which commit pool bursted" (`g11_bg_runner.py:6548–6550, 6563–6577`), a tie-break of last resort, not the selection mechanism.

**Cost.** **Runner-only, and the *least* new code** — it reuses the built WTA layer; only the four topographic afferent pathways are new. Lower fidelity than A (4 cardinals, not a continuous map) and **does not on its own give N5** (a 4-cardinal discrete winner has no graded eccentricity for the approach read-out). Good as the **first de-risk stepping-stone** (§5).

### Option C — **Approach as a temporal-difference of the SC bump, via the substrate's slow-NMDA / coincidence channels. [RANKED #3 — the N5 piece that pairs with A]**

**Biology.** The "getting closer" signal is intrinsically temporal: SC rho/eta looming cells and buildup/fixation cells encode *change over time* (discharge rising as a target approaches: cat SC rho/eta cells, So & Shen / Westby; PubMed 21546772; *Neural Representation of Object Approach*, PMC6673849). For this non-looming gridworld it is the **bump moving toward the rostral pole over frames** (Munoz & Wurtz 1993/1995). Computing a temporal difference in spikes wants a slow trace: a population whose firing reflects *recent* SC-rostral activity, subtracted from the *current* — a neural derivative.

**Mapping onto the substrate.** The engine already has the slow channels: `RegionPathway.exc_receptor="nmda_slow"` (slow NR2B-NMDA reverberatory current, `sim/regions.py:271–282`) for a slow "previous-frame" trace, and `RegionPathway.receptor="gaba_b"` (slow GIRK K⁺, `:259–269`) for a subtractive comparison — the **same GABA_B/GIRK mechanism the spiking SNc critic already uses** to subtract V (`g11_bg_runner.py:3037`, `cfg.enable_gabab` set at `:3903`). A clean realization: `sc_rostral_now` (fast) minus `sc_rostral_slow` (an `nmda_slow`-fed lagged copy) → an `approach` pool whose firing = positive temporal difference of rostral activity = "the goal is foveating/approaching." `approach → reward_us` (excitatory) gates the reward burst **neurally**, replacing the host `sign(_ea − _eb)` (`:6630`). Coincidence detection (`coincidence_detector`, `sim/regions.py:284–294`; `cfg.enable_coincidence_detection` set at `:3928`) is an alternative for a sharp threshold.

**Cost.** The **slow channels exist and are already runner-enabled** (`cfg.enable_gabab`, `cfg.enable_nmda_recurrent`, `cfg.enable_coincidence_detection` are all set from runner flags — `g11_bg_runner.py:3903, 3924–3929`), so this is **runner-only wiring** of new regions/pathways that *use* already-merged `sim/` machinery — **no new protected `sim/` edit**. This is the recommended N5 companion to Option A. (The absolute-minimum N5 stand-in — a single runner-side "rostral pool firing this step > last step" comparison that gates `reward_us` — is even cheaper and is the right *de-risk* before committing the slow-channel circuit; §6.)

### Option D — **True looming detector (render the goal blob to expand with proximity), classic rho/eta / LGMD. [RANKED #4 — only if the render is changed; not recommended now]**

**Biology.** The canonical approach detector: angular subtense 2θ expands non-linearly as an object approaches; rho/eta SC cells and the locust LGMD/DCMD fire with rising rate peaking at/before collision (catalog **E.14** motion-energy/direction-selectivity `:1499–1509`; cat SC PubMed 21546772; LGMD: Gabbiani et al.; *Invariance of Angular Threshold*, PMC6762430). This is a multiplicative η(t)=θ̇·exp(−αθ) computation.

**Mapping/cost.** Requires changing the **environment render** (`render_gridworld_to_image`) so the goal block scales with distance — which is a *legitimate* environment/body edit (channel-(1) of the bar), not a brain edit. Then a motion-energy front end (E.14) on V1/MT-like cells feeds the SC. **More machinery, and it changes the task's visual statistics** — out of scope for the immediate N1/N5 conversion, but the principled long-term answer if the gridworld is upgraded to a richer egocentric render. **Not recommended now** because (a) it needs an environment change, and (b) this gridworld's "approach" is genuinely positional (foveation), not looming, so Option A+C is the faithful model.

## 4. The recommended cheapest-first de-risk (prove-or-kill before any full build)

Mirror the spiking-SNc de-risk methodology exactly: a **CPU, `SIM_BACKEND=numpy`, no-GPU, no-nav-build** falsifier on a minimal bridge, *before* committing the full navigation integration. Build a tiny bridge with just `retina` + `sc_map` (+`sc_FS`) + the four `sc_map → cortex_{N,E,S,W}` topographic read-outs + an `sc_rostral`/`approach` pool, and feed it **hand-set rendered images** (the same `render_gridworld_to_image`) at a handful of agent/goal positions. New runner: `research/runners/sc_map_orienting_probe.py` (read-only research runner, not a `sim/` edit).

**Two falsifiers, both behavioral-equivalence vs the host functions (the N5 "8/8 label-agreement" precedent):**

**Falsifier 1 — N1 orienting (vs `sc_orienting_cardinal_from_image`).** For ~8–12 hand-set (agent, goal) pairs spanning all four cardinals + diagonals + on-goal:
- **PASS:** the SC map produces a clean activity bump at the goal's retinal site, and the **winning `cortex_X` pool by neuron firing** matches `sc_orienting_cardinal_from_image(img)` on **≥ N−1 of N** positions (target 8/8, allow 1 diagonal tie). The winner must be a **firing** winner (`commit_X` burst or `cortex_X` spike-count), NOT a host argmax that the body reads. On-goal (both blobs co-located) → no clear winner (matches the host `None`).

**Falsifier 2 — N5 approach (vs `sign(eccentricity_after − eccentricity_before)`).** For ~8 (old→new) agent-position transitions toward and away from a fixed goal:
- **PASS:** the `approach` pool's firing **rises** on closer-transitions and **falls/zeros** on farther-transitions, agreeing in **sign with the host reward** on **≥ 7/8** transitions (the N5 label-agreement bar). The signal must be **graded SC-bump-motion**, not a host distance.

**Discriminator that the host functions can't fake:** Falsifier 2's *graded, frame-to-frame* approach signal from SC dynamics is the single thing that proves the temporal-difference works in spikes at gridworld scale. If it passes, build Option A+C into the flagship nav; if the orienting (Falsifier 1) passes but approach (Falsifier 2) is too noisy, ship Option B for N1 and keep N5 host-scaffolded while iterating on Option C / a slow-channel comparison.

**Only after both falsifiers pass at CPU:** the GPU nav-integration test, head-to-head vs the host scaffolds, on the established metric `sum_finalQ` (lower better), **6 seeds** (MEMORY `feedback_6seed_validation`), inside the biologized flagship config — the same protocol the spiking-SNc Stage A used to reach its 2.00 vs 4.24 GO.

## 5. Anti-cheat controls (what must hold for this to be a genuine conversion, not a re-hidden shortcut)

1. **Image-only afferent (no coordinates).** The SC map and the `approach` pool must receive input **solely** from the rendered image via the neural `retina`/`cortex_v1_complex` regions. Assert in the probe that `(x, y)`, `(gx, gy)`, Manhattan distance, and the host `sc_orienting_*`/`sc_salience_offset_*` outputs **never** enter the SC drive (a provenance assertion, exactly as the spiking-SNc B′ de-risk requires "no host `V`/`reward_ema` reaches the SNc drive"). The image render itself may use `goal_pos` (that is N2, the world's visible goal — legitimate environment/perception), but the *cardinal/eccentricity/sign* must be computed by neurons.
2. **Orienting + approach produced by neuron firing.** The orienting cardinal must be read as **which `cortex_X`/`commit_X` pool fired** (the "argmax merely observes the spiking winner" convention, `g11_bg_runner.py:6548–6550`), and the approach signal as **`approach`-pool firing rate** — never a host argmax over pixels or a host distance formula.
3. **Reward still tracks real approach (behavioral equivalence).** The neural N5 must agree in sign with the host `sign(_ea − _eb)` on a held-out set (the **≥ 7/8 label-agreement** bar), so the conversion preserves *what* is rewarded while changing *who computes it* — the N5 precedent (the host docstring notes N5 was "8/8 label-agreement with the Manhattan reward").
4. **Lesion / shuffle control (the decisive anti-cheat).** **Scramble the retinotopy** of the `sc_map` afferent (permute the topographic source→target assignment so neighbouring retinal pixels no longer map to neighbouring SC sites) → **both** the orienting winner **and** the approach signal must **break** (orienting accuracy → chance; approach sign-agreement → chance). If they survive a scrambled map, the signal is leaking from somewhere non-retinotopic (a hidden shortcut) and the build is rejected. Complementary lesion: zero the `sc_map → cortex_X` (orienting) and `approach → reward_us` (reward) edges → the corresponding capability must vanish, proving it is carried by **synaptic transmission**, not host arithmetic (the spiking-SNc "relay lesion" precedent).
5. **Wean-to-zero parity for N1.** Because N1 is currently a weanable teaching scaffold (`sc_reflex_wean_*`), the spiking SC must be able to **stand alone** once the learned cortico-striatal policy matures (i.e. the agent still navigates with the SC orienting drive present, and ideally after it too is weaned) — otherwise the SC is just a renamed scaffold, not a perceptual organ.

## 6. Honest risks / what could make this a NEGATIVE

1. **Rate-coded WTA may not give a clean enough orienting winner at gridworld scale.** The SC literature's WTA assumes a reasonably large sheet with tuned Mexican-hat gains; at 16×16 with a 3×3 goal blob, the bump may be broad and the four-quadrant pooling may tie on diagonals or near map-centre. Mitigation: the project's `sel_FS_X` Rutishauser **selective** inhibition (validated for the 4-pool case) generalized to the sheet; if it still ties, fall back to Option B (4 discrete pools), which is the regime the existing WTA layer is already tuned for. **This is the single most likely failure point for N1.**
2. **The temporal-difference approach signal may be too noisy frame-to-frame.** A neural derivative of a spiking population is inherently jittery; at one gridworld step per nav step the SC bump moves by ~1 cell, a small change against spike noise. If `sign(approach_now − approach_prev)` flips spuriously, the reward becomes noisy and the spiking-SNc critic (already sensitive) could destabilize — echoing the *original* N5+SNc NEGATIVE (`2026-06-08-spiking-snc-N5-nav-derisk-NEGATIVE.md`), though that was ultimately a bridge bug, not the signal. Mitigation: the `nmda_slow` (tau ~100 ms) lagged trace smooths the derivative; a small dead-band (no reward when |Δ| below threshold) matches the host's `1e-6` guard. **Falsifier 2 exists precisely to catch this before the nav build.**
3. **"Approach ≠ looming" framing risk.** If a reviewer expects a *looming* detector (E.14/rho-eta), note this gridworld's goal does not expand — the faithful model is **foveation/rostral-shift**, not collision-looming (§1). Getting this wrong (building an expansion detector for a non-expanding stimulus) would be a category error that fails Falsifier 2. (Option D is the looming path, and it needs an environment-render change first.)
4. **Integration-vs-isolation gap (the established pattern).** The spiking SNc "passed the isolated Pavlovian falsifiers but failed in the full nav cascade" until a bridge bug was fixed (`2026-06-08-…-NEGATIVE.md`). A spiking SC could likewise pass both CPU falsifiers yet interact badly with the BG cascade / spiking-WTA readout (e.g. the SC orienting drive and the `sel_X` accumulator fighting). Mitigation: the 6-seed GPU nav test head-to-head vs the host scaffold is mandatory before claiming GO; an honest negative there **is** the deliverable (it maps a substrate limit), per the bar.
5. **Topographic read-out is hand-wired (a residual idealization).** The four `sc_map → cortex_X` pooling pathways are *fixed* (a designed retinotopy-respecting fan-in), not learned. This is biologically defensible (SC→premotor projections are genetically/topographically specified, chemoaffinity — catalog I-cluster ephrin/Eph map formation, `:4378–4390`), but it is a designer-set map, analogous to the innate V1 Gabor RFs (N7) already accepted as legitimate innate perception. Flag it as such; it is not a *hidden* shortcut (no cognitive quantity is host-computed), but it is innate structure, not learned.

## 7. Bottom line

The two remaining host computations between sensation and action — N1's `sc_orienting_cardinal_from_image` pixel→cardinal argmax (`g11_bg_runner.py:124–155`, injected `:6363`) and N5's `sign(eccentricity_after − eccentricity_before)` distance-formula reward (`:6611–6635`) — are **read-outs of the same latent quantity** (the goal's retinal position and its motion), and biology computes both in **one structure**, the superior colliculus (catalog A.07, H.24, H.25). The recommended build is **one spiking retinotopic SC map with Mexican-hat winner-take-all (Option A) + a slow-channel temporal-difference approach read-out (Option C)** — it **closes BOTH N1 and N5**, needs **zero new protected `sim/` edits** (the regions framework already supports 2D retinotopic sheets `coordinate_dim=2`/`distance_sigma`, and the slow GABA_B/NMDA channels are already merged + runner-enabled), and reuses the project's existing saccade-WTA `commit_X`/`sel_FS_X` idiom and the already-spiking `reward_us`→SNc→GABA_B-critic reward leg. The cheapest-first de-risk is a CPU `numpy` probe feeding hand-set rendered images to a minimal `retina→sc_map→cortex_X`/`approach` bridge, with two behavioral-equivalence falsifiers (N1: ≥7/8 cardinal-agreement by *neuron firing*; N5: ≥7/8 reward-sign-agreement from *graded bump motion*) plus the decisive **scrambled-retinotopy lesion** (both must break). The top risk is that rate-coded WTA on a 16×16 sheet with a 3×3 goal blob gives a too-broad bump (mitigation: the discrete 4-pool Option B fallback, which the existing WTA layer is already tuned for) and that the frame-to-frame approach derivative is noisy (mitigation: the `nmda_slow` smoothing + a dead-band; Falsifier 2 catches it pre-build). Honest framing: in *this* gridworld "approach" is foveation/eccentricity-decrease, **not** looming — the faithful model is the SC rostral-shift, and a true looming detector (Option D) is only correct if the environment render is later changed to make the goal expand with proximity.
