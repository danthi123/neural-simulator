# GNW N-organ ignition bus — SCAFFOLD-RETIREMENT of the covered-class organ-combination (`gate_via_bus` never computes the host verdict)

## What this moves (faculty-map T1-1, Phase-B — the one-substrate step, `scaffold_retired` rung)
The 2026-08-13 FLIP (`789481fc2`, finding `2026-08-13-gnw-bus-default-flip-substrate-authors-organ-combination.md`) promoted the GNW N-organ ignition bus to the DEFAULT organ-combination on `webapp/server.py::brain_chat`: the substrate's consensus-ignition + WTA authored the combine verdict, replacing the host `if recalled == p`. Its **#1 declared residual was `scaffold_retired: NO`** — the wrapper ran the FULL original `gate()` (whose `if recalled == p` combination was COMPUTED) and then OVERRODE its result with the bus decision. Per `docs/TERMS.md` **scaffold-retired** requires the host shortcut GONE from the default path, not overridden. This finding builds the design §3 follow-on — a `gate_via_bus` that NEVER computes the host combination on the covered class — and earns it.

## The retirement (surgical, additive, escape-flagged, byte-identical-when-covered)
`ChatBrain.gate()` is factored (byte-identical) into an EXTRACTION + SIDE-EFFECT phase and a COMBINATION phase:
- `ChatBrain._extract_route(q)` — the (agent, action) COMPREHENSION only (neural BridgeParser on the onebrain default, host heuristic on the rf escape), returning `[a, v]` for a routable factual query, `None` for a self/identity/short turn, or `"__DECLINE__"` for a parser-declined factual-shaped question. It STOPS before the recall (`what_does` is never called).
- `ChatBrain.gate_extract(q)` — runs the SAME open-ended / acquisition / anaphora side effects `gate()` runs, then returns a discriminated tuple: `('done', svo)` (out-of-scope class already authored: open-ended hypothesis / acquisition), `('route', q, a, v, anaphora_used)` (the covered class), `('decline', ...)`, or `('router', q)` (unroutable → host router).
- `ChatBrain._gate_router_combine(q)` — the host QuestionRouter fallback + spiking VERIFY (`if recalled == p`), factored out of `gate()` and reached ONLY for out-of-scope classes.
`gate()` itself is UNCHANGED in behaviour (it still calls `_substrate_recall`, which the production lesion probe patches) — the factoring is byte-identical. `_substrate_recall` now delegates its comprehension to `_extract_route` (no duplication).

`webapp/gnw_bus_shadow.gate_via_bus(chat, question)` consumes `gate_extract`: for the COVERED `('route', …)` class it runs the substrate ignition bus (`bus_combine` — 3 organ reads → consensus-ignition + shared-inhibition WTA) and the ignited patient IS the answer, no ignition IS the abstain — WITHOUT ever calling `_substrate_recall` or `_gate_router_combine`. `install_bus_gate` now wraps `chat.gate` with `gate_via_bus` instead of the old "run `orig_gate` then override" flip. ESCAPE `BRAIN_GNW_BUS_HOST=1` reverts to the original `gate()` per-call; on any bus exception the turn degrades to the host gate() (never crashes); `BRAIN_GNW_BUS_LESION=1` is the honest-negative lever. Reuse-by-import of the de-risk workspace/hop — NO `sim/` edit.

The covered-class surfaced "brain activity" (`composer.last_trace`) is preserved byte-identically WITHOUT the host `what_does`: `bus_combine(..., surface_forward_trace=True)` leaves ORGAN A's forward-recall trace (which IS `composer.query_patient(agent, action)` == what the host `what_does` would surface) as `last_trace`, while the reverse-binding probe never surfaces.

## The retirement gate — earned on the SAME broad real-query panel + a call-count proof
`research/runners/_gnw_bus_scaffold_retire_verify.py` builds the REAL production ChatBrain (numpy-CPU, rf recall) and compares the ORIGINAL host gate() decision to `gate_via_bus` on every panel query. Result (cites `research/findings/raw/_gnw_bus_shadow/scaffold_retire_verify.json`):
- **RETIREMENT PROOF (the new gate)** — on a covered STORED recall (`what does dog chase?`) driven through the installed bus gate, the two host-combination methods are called **ZERO** times (`_substrate_recall`: 0, `_gate_router_combine`: 0), the per-turn audit reads `authored_by='bus'` + `host_combination_computed=False`, and the answer is `['dog','chase','cat']`. On a self/identity turn (`what are you`) the HOST router IS called (`_gate_router_combine`: 1, `authored_by='host_router'`) — the out-of-scope residual is honestly KEPT. This is the difference between OVERRIDDEN (flip) and RETIRED (here). <!--derived-->
- **BYTE-IDENTICAL 22/22** across every class — stored 5/5, self/identity 3/3, unstored 4/4, inconsistent 4/4, open-ended 2/2, acquisition 2/2, anaphora 2/2. Retiring the redundant host combination changed no answer (it was already overridden). Note the honest scope shift vs. the flip: self/identity is now authored by the host router (out-of-scope), where the flip happened to route it through the bus — same bytes, more honest attribution. <!--derived-->
- **NO MOAT REGRESSION** — every unstored/inconsistent query still ABSTAINS on both arms. <!--derived-->
- **LESION-LOAD-BEARING on the ANSWER** — through `gate_via_bus`, a bus lesion (workspace self-recurrence zeroed) makes the consensus unable to ignite → the delivered ANSWER collapses to abstain (intact commits `['dog','chase','cat']`), WHILE the forward-recall reflex (`composer.query_patient`, never routed through the workspace) still returns `cat`. Attribution to the workspace ignition = 1.0. <!--derived-->
- **ESCAPE byte-identical (real handler)** — through the REAL `brain_chat` handler, `BRAIN_GNW_BUS_HOST=1` (host) is byte-identical to the retirement default on the covered panel (answer, recalled_svo, abstained, activity — all identical, no `gnw_bus` key). The `surface_forward_trace` fix keeps the surfaced activity identical without the host `what_does`. <!--derived-->

## What the anti-cheats establish
- The CALL-COUNT proof (not just answer parity): a host shortcut that only reproduced answers would still RUN the host combination and override it (the flip). Zero calls to `_substrate_recall`/`_gate_router_combine` on the covered class proves the host combination is not computed — RETIRED, not overridden.
- BYTE-IDENTICAL across classes: matching all 22 (answers) plus the handler full-JSON escape check (activity included) shows the retirement reproduces the WHOLE decision + observable surface.
- LESION collapses the delivered ANSWER (not a shadow block); ESCAPE byte-identical: the retirement is reversible with no behavioural cost — a verified MECHANISM change, not a behavioural gamble.

## Honest scope + residual (why SCOPED, not YES)
1. **The covered-class host combination is RETIRED** — on a routable factual recall the host `if recalled == p` (and `_substrate_recall`'s recall verdict) is never computed; the substrate ignition authors commit/veto. Per `docs/TERMS.md`, the covered-class combination is now **scaffold-retired** (gone from the default path, call-count-verified).
2. **The host combination is KEPT for the OUT-OF-SCOPE classes** the bus never claimed, so the module is not FULLY scaffold-retired: self/identity turns (routed by the host QuestionRouter — no substrate (agent, action) to route), open-ended GENERATION (a flagged `HypothesisSVO` guess, not a recall combination), in-loop ACQUISITION (a store side effect), and the anaphora-abstain fall-through. These reach `_gate_router_combine`. Retiring them is a DISTINCT capability (a substrate self-model organ for identity; the emerge stream-cortex for open-ended prose), not this combination.
3. **Extraction/comprehension stays the host's** — `_extract_route`'s neural BridgeParser (onebrain) / heuristic (rf) names the (agent, action); the substrate authors only the COMBINATION. This is the standing brain-based-only residual for comprehension, mapped elsewhere.
4. **Reverse-binding veto** remains the mapped divergence class (a fact with an ambiguous reverse binding could veto a host answer → abstain); none exists in the tiny-demo (22/22). A brain with an ambiguous reverse binding is the follow-on probe.
