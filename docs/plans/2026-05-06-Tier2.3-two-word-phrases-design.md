## Hypothesis

After Tier 2.1 (verb binding) and Tier 2.2 (noun binding), composing
words requires working memory: "go to goal" needs to hold "go" while
parsing "to goal" and binding the composite to a specific action plan.

PFC working memory infrastructure exists (`dlpfc_wm` region with
NMDA-bistable attractors at 500-1000ms timescale). Tier 2.3 binds
two words sequentially via PFC and tests action plan output.

## Mechanism

Two-word phrase: "go" + DIRECTION (e.g., "go north")

Training trials:
1. **t = 0-100ms**: drive language_input["go"] + dlpfc_wm WORK pool
   (verb-encoding sub-region). PFC NMDA holds "go" representation.
2. **t = 100-200ms**: drive language_input[direction_word] (e.g.
   "north") + corresponding motor pool (teacher).
3. **t = 100-300ms**: PFC activity (still holding "go") + language
   activity (currently parsing direction) + motor co-fire.
4. STDP at:
   - language_input["go"] → PFC verb-pool
   - language_input[direction] → motor[target]
   - PFC verb-pool × motor → action gate (modulator)

After training, the agent should:
- Hear "go north" → execute motor_N
- Hear "go" alone → no action (PFC holds context, awaiting completion)
- Hear "north" alone → motor_N (Tier 2.1 binding still works)

## Architecture additions

### A. PFC verb pool

Sub-region of dlpfc_wm specifically for verb representation:

```python
regions.append(BrainRegion(
    name="dlpfc_verb",
    n_neurons=200,
    exc_fraction=0.8,
    internal_density=0.15,  # high recurrence for working memory
    exc_weight_mean=3.0,    # strong recurrent excitation
    inh_weight_mean=4.0,
    plastic_internal=False,
    izh_neuron_type=NeuronType.IZH2007_RS_CORTICAL_PYRAMIDAL.name,
))
```

NMDA-bistable: persistent activity for verb context across the next
direction word.

### B. language_input → dlpfc_verb pathway

```python
pathways.append(RegionPathway(
    from_region="language_input", to_region="dlpfc_verb",
    density=0.30, weight_mean=2.0, plastic=True,
    plasticity_gate="language_input_to_dlpfc_verb",
))
```

### C. dlpfc_verb → motor "gate" modulator

PFC activity should ENABLE the motor pool whose direction the
language_input is currently parsing. Implementation: PFC fires a
neuromodulator (e.g. excitability_drive) on the motor pools when
the verb context is active. Without PFC verb activity, motor pools
have higher threshold (don't act on direction alone).

```python
# Neuromodulator config
NeuromodulatorConfig(
    name="action_gate",
    baseline=0.0,
    decay_tau_ms=300,  # NMDA-aligned working memory window
    targets=[
        ModulatorTarget(target_type="excitability_drive",
                        scope="group:motor_N"),
        # ... E, S, W
    ],
    production_rules=[
        ProductionRule(rule_type="from_region_activity",
                       region="dlpfc_verb",
                       sensitivity=0.01),
    ],
)
```

This means: motor pools fire normally only when PFC verb context is
active; otherwise are quieter. Adds the "must hear 'go' for action
to happen" gating.

## Training curriculum

Mix of trial types:
1. **Phrase trials (60%)**: "go" + direction → motor target
   (verb teacher + direction teacher + motor teacher)
2. **Direction-only trials (30%)**: just direction → motor target
   (no verb context — should still work via Tier 2.1 binding)
3. **Verb-only trials (10%)**: just "go" → no motor (verb context
   alone shouldn't drive action)

Tests:
- Composition: "go north" → motor_N (specific binding)
- Backward compat: "north" alone → motor_N (Tier 2.1 still works)
- Inhibition: "go" alone → motor pools quiet

All three conditions tested.

## Why this is harder

Tier 2.3 introduces **temporal compositionality**: the meaning of
"north" depends on whether "go" came first. This requires:
1. PFC working memory to hold "go" context (~500ms)
2. Time-dependent binding (verb context modulates direction-word
   interpretation)
3. Anti-binding (verb alone doesn't act)

If Tier 2.3 fails, it might mean:
- PFC NMDA bistability isn't tuned for this timescale
- Compositional generalization needs dendritic learning (Tier 3)
- Need richer architecture (separate verb/noun cortical layers)

In either failure mode, decision becomes: stop at Tier 2.2 ceiling
OR move to Tier 3 dendritic learning. Tier 1+2.2 alone gives a real
working interface (verb-noun bidirectional binding without
compositional sentences).

## Why this might succeed without dendritic

Tier 2.3 still uses local STDP + Hebbian — but now with PFC working
memory adding a "context" channel. The binding is between
(verb-context × direction-word) → action. Hebbian still works because
the third factor (PFC activity) is just another co-active site.

The mechanism remains biology-plausible (Pulvermüller + working
memory + somatotopic verb-action binding). Tier 2.3 success would
demonstrate that 2-word compositional commands emerge from the
embodied paradigm + PFC scaffolding without needing dendritic
learning.

## Scope: 2 verbs × 4 directions = 8 phrases

Initial vocabulary:
- 2 verbs: "go", "stop"
- 4 directions: north, east, south, west
- Pairs: "go north", "go east", "go south", "go west", "stop north",
  "stop east", "stop south", "stop west"

"stop [direction]" phrase: should INHIBIT motor[direction] (test
of opposite-action binding).

If 8 phrases work, scale to 4 verbs × 8 directions (16 nouns) in a
follow-up. Tier 3 territory beyond that.
