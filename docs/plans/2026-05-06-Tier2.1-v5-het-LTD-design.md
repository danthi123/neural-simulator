# Tier 2.1 v5 — Heterosynaptic LTD design (Pulvermüller-Felix Eq B4)

**Date:** 2026-05-06
**Status:** Design ready. Implementation pending v4 scale-up result.
**Source:** Tomasello et al. 2018 (Frontiers Comp Neuro) Eq. B4 +
2026 NEST port. Survey top pick.

---

## Problem

Tier 2.1 v1-v6 all show STDP winner-take-all per synapse: when
two synonyms compete for the same motor target, ONE wins
("north" → motor_N strong; "up" → motor_N essentially zero).

Tomasello-Felix's heterosynaptic LTD (het-LTD) directly addresses
this: during co-firing trial for word A, synapses from word B
(inactive) ALSO get weakened. Both synonyms get balanced down
during off-trials, then strengthened during paired trials. Net
result: equal binding strength.

## The Eq. B4 rule

For each post-synaptic neuron j with high voltage V_j > θ_post:
- For each pre-synaptic neuron i:
  - If pre-input I_i > θ_pre (homosynaptic, pre is active):
    - LTP: Δw_ij = +α × (post fired) × (pre fired)  (standard STDP)
  - **If pre-input I_i ≤ θ_pre (heterosynaptic, pre inactive):**
    - **LTD: Δw_ij = -β × (V_j > θ_post) × (I_i ≤ θ_pre)**

Key: het-LTD fires when post is HIGH but pre is LOW. This
weakens synapses from inactive pre to active post.

## Implementation: runner-side (cheaper) vs kernel-level (cleaner)

### Option A: Runner-side het-LTD in bio_three_factor.py

**Pros:** Self-contained. No bridge changes. Easy to disable/tune.
**Cons:** Doesn't use existing STDP infrastructure efficiently.

```python
# After forward-prop in each event, before custom updates:
if heterosynaptic_ltd_rate > 0 and embodied_hebbian:
    # Edges from INACTIVE lang_input to ACTIVE motor
    # post_active_mask: which neurons fired during this event
    # lang_active_mask: which lang_input neurons received drive
    inactive_lang_mask = is_lang & ~lang_active_mask
    edges_to_weaken = (
        inactive_lang_mask[edge_src] & post_active_mask[edge_dst]
    )
    if xp.any(edges_to_weaken):
        # Het-LTD: multiplicative weakening
        weight_data[edge_off[edges_to_weaken]] *= (
            1 - heterosynaptic_ltd_rate
        )
        # Floor at weight_min
        weight_data[edge_off[edges_to_weaken]] = xp.clip(
            weight_data[edge_off[edges_to_weaken]],
            weight_min, weight_max,
        )
```

**Cost:** ~3-4 hours implementation + 30 min smoke + ~70 min
6-seed validation. Total ~5 hours wall clock.

### Option B: Kernel-level in sim/kernels.py (deeper)

Add `fused_heterosynaptic_ltd` kernel. Operates on bridge.cp_connections
directly. Better integration with existing STDP infrastructure.

**Cost:** ~1-2 days. Risk of breaking existing tests.

**Recommendation:** Start with Option A (runner-side). If results
warrant, port to kernel-level later for performance.

## CLI flag design

```python
ap.add_argument("--heterosynaptic-ltd-rate", type=float, default=0.0,
                help="Tier 2.1 v5: heterosynaptic LTD rate. After "
                "each embodied-Hebbian event, synapses from INACTIVE "
                "lang_input to ACTIVE motor neurons weaken by this "
                "factor (multiplicative). Pulvermüller-Felix Eq. B4 "
                "(Tomasello 2018). Range [0, 0.1]. 0 = disabled. "
                "Try 0.005-0.02. Higher = stronger pruning of "
                "non-coincident synapses, prevents WTA between "
                "synonym codes.")
```

## Tuning expected

- 0.001: minimal effect, probably no change vs v2
- 0.005: gentle pruning, might help mildly
- 0.01: moderate pruning, expected sweet spot per Tomasello
- 0.05: aggressive, might destabilize forward pathway
- 0.1: probably too strong

Start at 0.01 for smoke. Sweep [0.005, 0.01, 0.02] if needed.

## Compatibility check

post_active_mask / lang_active_mask which are only computed in that
mode). 3-factor mode unaffected.

Combines with:

- synonym_mode: yes (the whole point)
