### Branch T2.3-B: Mean phrase 35-50%, mixed seed PASS rate

**Outcome:** Architecture works but parameters need tuning.

**Action:**
1. Commit partial findings
2. Launch parameter sweep:
   ```
   python -m research.experiment_runner \
       experiments/tier_2_3_parameter_sweep.yaml
   ```
   Sweeps n_phrase_events (100, 200, 400) at 3 seeds each = 9 runs.
3. Whichever condition shows >=4/6 seeds at >= 50% phrase becomes
   the "tuned" config -> launch full 6-seed at that config.
4. Defer Phase 1.5 until tuning lands.

If sweep shows no condition reaches 50%, escalate to Branch T2.3-C.

### Branch T2.3-C: Mean phrase < 35%, similar across seeds

**Outcome:** Architecture mismatch; PFC + action_gate alone
insufficient for compositional binding at our scale.

**Possible interpretations:**
1. PFC NMDA bistability not tuned for the 100ms gap
2. Action gate is too coarse a mechanism (per design Sec 7,
   alternatives include inhibitory PFC->motor pathway or
   PFC->striatum modulation)
3. Compositional binding requires dendritic learning (Tier 3
   territory)

**Action:**
1. Commit failure findings
2. Try alternative gating mechanism (per design Sec 4):
   - Option B: inhibitory PFC -> motor pathway (verb context
     RELEASES inhibition rather than boosts excitability)
   - Option C: PFC -> striatum cascade modulation
3. If alternatives also fail, declare Tier 2.3 a Tier 3 problem
   (dendritic learning needed)
4. **Revert to documented stop point**: per master plan,
   "Tier 1 + 2.1 alone gives a real working interface" — defer
   compositional sentences to future work, proceed to
   Phase 2.1 path-f branch.
