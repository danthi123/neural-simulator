# Step-3 cortex: the fork is resolved — the dendritic substrate is the validated escape for a learned, generalizing cortex; the D2 on-substrate build is warranted (owner decision)

**Date:** 2026-06-14. **Status:** DECISION DOC (owner-facing synthesis of a completed cheap-first de-risk arc; the months-scale build it recommends is explicitly OWNER-GATED and was NOT started autonomously). **Synthesizes:** `research/findings/2026-06-14-option-c-stageB-fair-test-mechanism-wall.md`, `-dendritic-substrate-deep-research.md`, `-dendritic-D1-cheap-derisk-GO.md` (incl. the D1.5 follow-on). **Fork it resolves:** `docs/plans/2026-06-11-cortex-build-plan-decorrelate-then-bind.md`.

## The question
"Step 3" is the project's standing goal of replacing the conversational composer's idealized exact-inverse vector-symbolic binding algebra with a **learned, brain-based, semantically-structured cortex that GENERALIZES** — infers "cat is like a dog" from a learned similarity, the way a real cortex reads whatever messy code arrives. The 2026-06-11 fork framed two routes:
- **(A) a semantically-FLAT cortex** — generated decorrelated codes + the validated binder + cleanup + the no-confab gate. Achievable on the point-neuron substrate; **cannot** generalize across similar concepts.
- **(B) a semantically-STRUCTURED cortex** — learns the similarity from raw experience, so similar concepts get similar codes → generalization. Suspected to need the dendritic substrate.

## What this arc established (both sides of the fork are now closed)
**(A) is DELIVERED.** The 2,048-concept flat cortex passes the full within-bridge conversational matrix (32/32 bridges) + meaningful generalization (16/16 scored, 0.988–1.000) + cross-bridge composition + the no-confab moat (`2026-06-14-phase1-production-32bridge-2048-concept-cortex-DELIVERED.md`). Its similarity is host-CURATED — a principled stepping-stone, not a cortex that learns structure from experience.

**(B) cannot be done on the point-neuron substrate — confirmed, cleanly.** Option C (learn paradigmatic similarity from real TinyStories co-occurrence on the project's spiking-Hebbian substrate) is the decisive test, and it is a **clean mechanism negative**: the host distributional-semantics control proves the structure is in the data (Pearson **+0.532**), but the brain-based learn recovers **none of it** (Pearson **−0.008**, generalization at chance). The read-out/mechanism discriminator localizes the failure to the LEARN, not the read-out (the learned weights' hub-profiles carry no category structure — the high-frequency common hubs dominate every profile). This is the **fifth** mechanistically-distinct point-neuron NEGATIVE, all converging on the documented **Mikulasch-Priesemann limit**: removing the common mode that blurs category structure is a per-input, analog, dendritic computation a single-soma point neuron cannot perform.

**(B) IS achievable with one extra compartment — validated cheaply, two ways.** The dendritic deep-research pass diagnosed the escape and recommended a cheap-first de-risk; it landed decisively:
- **D1 = GO (multi-seed, rate level).** A dendritic per-compartment gain (each input/hub is its own compartment with a local online-adapted divisive gain — the biologically-local realization of the per-input normalization the point neuron lacks) recovers the a-priori category structure (mean Pearson **+0.845**, host ceiling +0.959) while the point-neuron single-global-gain control fails on the identical pipeline (**+0.052**), every gate green, all anti-cheats clean (point-neuron-must-fail, host-carries, permuted-similarity collapses, lesion→point-neuron, gains converge + track hub frequency, S_true a-priori).
- **D1.5 = SURVIVES (multi-seed, spiking-noise).** Reading the residual as a finite Poisson spike count (swept clean→noisy), the dendritic advantage clears the σ-equivalent reproducibility floor (structure +0.835 at the floor) while the point-neuron fails at **every** noise level. The specific spiking-noise floor that buried the five prior attempts is cleared by the per-compartment SNR boost.
- **D1.6 = SURVIVES (multi-seed, conductance-membrane).** Realizing the divisive gain as the actual biophysics — conductance-based **shunting inhibition** on a settled, noisy leaky membrane (`V = x/(g_leak + g_inh)`) — per-compartment shunting recovers +0.842 (== D1's algebraic +0.845) while the global-shunting point neuron fails (+0.045). The de-risk ladder is complete and maximally hardened (algebraic → spike-read → conductance-membrane); the point neuron fails at every rung. The biophysical mechanism D2 would build is validated at the toy level.

## The decision
The dendritic substrate is the validated, biology-faithful escape for the learned-structured cortex (B). The recommended next step is the **D2 on-substrate build** — a two-compartment neuron on the bridge whose dendritic compartment performs the per-input normalization, producing a learned graded-but-reproducible cortical embedding that plugs into the already-validated dual/CLS pipeline (encode → bind → recall identity → cortical reinstatement → generalization are all GO, waiting only on this learned embedding).

**This is the owner's call, with eyes open:**
- **Cost:** ~1.5–2 months (floor). A protected edit on the hottest code path — a new two-compartment `NeuronModel` + apical/dendritic plasticity gate + per-compartment routing + validation. The byte-identity-when-off discipline (the `fused_coincidence_plateau` guarded-precedent at `bridge.py:5805–5849`) is the mitigation, and the owner's standing byte-level-diff-review rule applies.
- **Honest precedent:** a *prior* dendritic arc terminated in a sound-instrument VOID on a *different* question (`2026-05-18-dendritic-fairscale-SOUND-instrument-VOID`). D1+D1.5's GO/SURVIVES is the strongest cheap evidence to date that this question is the right one and the substrate is the answer — but the months-scale commit is high-variance and deliberately gated.
- **Recommended de-risk-before-commit (cheaper than full D2):** an **on-substrate spiking two-compartment single-neuron probe** (real membrane dynamics, gains learned from spikes) on the D1 toy, to confirm the rate+spike-read result carries to a genuine spiking compartment before the full `NeuronModel` + pipeline build.

**If the owner declines the months-scale build:** ship (A), the delivered 2,048-concept flat cortex, as the conversational product (curated similarity is the pragmatic answer for the conversational goal), and reserve (B)/D2 for the artificial-life / biology-translatable goal where learning structure from raw experience is the point.
