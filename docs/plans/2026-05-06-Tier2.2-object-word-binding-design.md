# Tier 2.2 — Object-word binding via visual cortex co-firing

**Date:** 2026-05-06
**Status:** Design only. Conditional on Tier 2.1 (synonym binding) passing.

---

## Hypothesis

The Tier 1 mechanism (3-site teacher signals + STDP on co-active
synapses) can bind word codes to spatial/visual concepts, not just
motor actions. Specifically: when "goal" is presented while the
agent SEES a goal in the visual field, Hebbian co-firing should
bind the word "goal" to the visual representation of the goal cell.

This extends the agent's vocabulary from action verbs (Tier 2.1) to
object nouns. Combined with phrase parsing (Tier 2.3), enables
commands like "go to goal".

## Mechanism

Each training trial during navigation:
1. Agent perceives goal at position (gx, gy) via Cluster K v2 visual
   cortex. Specific V1/V2/IT neurons fire encoding the goal.
2. Drive `language_input["goal"]` simultaneously.
3. Drive `language_output["goal"]` simultaneously (output teacher).
4. Forward-prop. STDP at:
   - language_input → IT_goal_neurons (input concept binding)
   - IT_goal_neurons → language_output (output generation)
   - language_input ↔ language_output (auto-association)

After N trials of "see goal + hear goal", the network should:
- W→I: drive language_input["goal"] → activate IT goal-encoding neurons
- I→W: see goal in visual field → language_output produces "goal"

## Architecture changes

### A. Extend brain region builder

Add IT region's bidirectional pathways to/from language regions:

```python
# In build_biological_brain_regions:
if enable_object_binding:
    # IT → language_output (perception generates word)
    pathways.append(RegionPathway(
        from_region="IT", to_region="language_output",
        density=0.15, weight_mean=2.0, plastic=True,
        plasticity_gate="IT_to_language_output",
    ))
    # language_input → IT (word evokes visual concept)
    pathways.append(RegionPathway(
        from_region="language_input", to_region="IT",
        density=0.15, weight_mean=2.0, plastic=True,
        plasticity_gate="language_input_to_IT",
    ))
```

But the bio_three_factor architecture doesn't currently have IT —
it has only language_input + motor pools. So we'd need to either:
- Use the g11_bg_runner architecture (has full visual cortex stack)
- Add a "visual_concept" region to the bio_three_factor builder

For Tier 2.2, use g11_bg_runner since it has the full retina → V1 →
V2 → IT visual cortex pathway (Cluster K v2). The 32×32 navigation
result already shows IT learns spatial features.

### B. Embodied training curriculum (modify g11_bg_runner)

In the navigation loop, when the agent VISIBLY perceives the goal:
- Periodically (e.g. every 50 steps) drive language_input["goal"] +
  language_output["goal"] for ~10 sub-steps
- STDP fires on co-active visual cortex × language synapses
- Action selection unaffected (just additional inputs)

Cost: ~3 days to integrate the language drive into the nav loop +
add ablation (compare with/without language drive on nav metric).

### C. Eval

Two new evals after navigation training:
1. **W→I**: drive language_input["goal"], read IT activity, check
   if it matches the spatial pattern from agent-sees-goal trials
2. **I→W**: present visual stimulus at goal location, read
   language_output cosine match — should be "goal"

Add eval to g11_bg_runner. Cost: ~2 days.

### D. Pass criterion

I→W aligned ≥4/6 seeds. Drive goal-image → language_output produces
"goal" pattern.

## Why this needs Tier 2.1 first

Tier 2.1 tests whether multiple synonyms can bind to the same motor
pool. If that fails, the embodied paradigm doesn't generalize beyond
trivial 1:1 mapping, and Tier 2.2 (which adds another binding type)
is unlikely to work.

If Tier 2.1 passes (≥6 of 8 synonyms bound correctly), then Tier 2.2
is well-motivated: the binding mechanism scales.

## Cost

- A. Architecture: add IT↔language pathways to g11_bg_runner: ~2 days
- B. Curriculum: language drive during navigation: ~3 days
- C. Evals: W→I and I→W tests: ~2 days
- D. Smoke + 6-seed validation: ~1 day compute
- Total: ~8 days (1.5 weeks)

## Scope

For Tier 2.2 minimum viable: ONE object word ("goal") bound to ONE
visual concept (goal location). If this works, scale to 4-8 object
words (goal, wall, agent, empty, near, far, edge, corner) in a
follow-up.

## Success path

If Tier 2.2 passes: agent has bidirectional binding for both
verbs (Tier 1) and nouns (Tier 2.2). Tier 2.3 (compositional phrases)
becomes the next test.

If Tier 2.2 fails: investigate whether the mechanism extends to
visual cortex at all. Likely fixes:
- Topographic prior on language ↔ IT pathways
- Stronger weights (0.5 → 2.0 like Tier 1 fix)
- Longer training
