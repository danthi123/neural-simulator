## What surrogate-gradient backprop is

Real spike functions are non-differentiable (Heaviside step at
threshold). Backprop requires gradients. The surrogate-gradient
trick: in the FORWARD pass, use the real Heaviside (binary spikes).
In the BACKWARD pass, replace the gradient with a smooth surrogate
function (e.g., ATan or fast-sigmoid).

Standard surrogate functions:

- **ATan (Zenke 2018, used by SuperSpike):**
  `surrogate_grad(v - threshold) = (1 / pi) * (1 / (1 + (alpha * (v - threshold))^2))`
  where alpha is a slope hyperparameter (typically 2.0 or 5.0)

- **Fast sigmoid (Zenke 2021):**
  `surrogate_grad(v - threshold) = 1 / (1 + |alpha * (v - threshold)|)^2`

Both have similar properties. ATan tends to be more stable for deep
networks; fast sigmoid is slightly cheaper. We'll use ATan.

This gives gradients that flow backward through spike events,
allowing standard backprop training of multi-layer SNNs.

## Architecture: which regions get backprop?

**Phase 2.1 first pass:** train ONE multi-layer cortex stack via
surrogate-grad backprop. The simplest test bed:

```
input embedding -> cortex_l1 -> cortex_l2 -> output
       (256)        (256)        (256)        (32)
```

This is a 4-layer SNN. Each cortex layer is plastic via backprop.
The input/output are fixed encoders/decoders for the toy task.

**Phase 2.2** (next phase) extends this to actual cortex regions
in our existing architecture (motor cortex, language cortex), with
the rest of the brain (BG, hippocampus) frozen.

## Implementation plan

### Step 1: New module `sim/surrogate_grad.py`

```python
import cupy as cp

def atan_surrogate(v_minus_threshold: cp.ndarray, alpha: float = 2.0):
    """ATan surrogate gradient for spike non-differentiability.

    Forward: spike = (v >= threshold).astype(float32)
    Backward: dspike/dv = (1/pi) * (1 / (1 + (alpha * (v-threshold))^2))

    This module computes the BACKWARD gradient only. The forward
    pass uses Heaviside (already in fused_*_dynamics_update kernels).
    """
    return (1.0 / cp.pi) * (1.0 / (1.0 + (alpha * v_minus_threshold) ** 2))


def fast_sigmoid_surrogate(v_minus_threshold: cp.ndarray, alpha: float = 5.0):
    """Fast-sigmoid alternative."""
    return 1.0 / (1.0 + cp.abs(alpha * v_minus_threshold)) ** 2
```

### Step 2: Backward-through-time (BPTT) framework

We don't need full PyTorch / JAX autodiff. Manual BPTT for a
4-layer SNN over T=20 timesteps is tractable:

```python
class CortexBPTTTrainer:
    """Manual BPTT over a multi-layer SNN cortex stack.

    Unrolls T timesteps forward, computes loss at output, then
    backprops through unrolled time.

    Forward state stored at each timestep:
      - membrane potentials v[layer][t]
      - spikes s[layer][t]
      - synaptic currents I[layer][t]

    Backward pass:
      - dL/ds[output][T] from output loss
      - dL/dv[output][T] = dL/ds * surrogate_grad(v - threshold)
      - dL/dW[layer-1] += s[layer-1][t] * dL/dv[layer][t]   (per timestep)
```

### Step 3: Loss function for next-token prediction

```python
def cross_entropy_loss(logits: cp.ndarray, target_idx: int) -> float:
    """Logits: (vocab_size,). Target: int."""
    log_probs = logits - cp.log(cp.sum(cp.exp(logits)))
    return -log_probs[target_idx]


def softmax_grad(logits: cp.ndarray, target_idx: int) -> cp.ndarray:
    """dL/d_logits."""
    probs = cp.exp(logits) / cp.sum(cp.exp(logits))
    grad = probs.copy()
    grad[target_idx] -= 1.0
    return grad
```

### Step 4: Toy task — predict next token

Train on the sequence "ABCABCABC..." (3-token cycle). Input: previous
token. Target: next token. 3-class classification.

Vocab encoding: A=0, B=1, C=2. Input layer is one-hot. Output layer
has 3 neurons. Training data: 1000 sequences of length 30.

Pass criterion: >= 80% accuracy on next-token prediction within
1000 training events.

## Risks + mitigations

| Risk | Mitigation |
|---|---|
| Manual BPTT memory blow-up at T=20 timesteps | Use Tier 2.1 v4 scale-up arch as max; T=10 if memory tight; gradient checkpointing optional |
| Surrogate grad numerically unstable | Start with ATan alpha=2.0 (well-tested); switch to fast-sigmoid if needed |
| BPTT slow vs PyTorch | Acceptable: this is one-time pretraining. Speed matters but we have RTX 3090 24 GB and 1B-param Nord pretrained on RTX 5070 8GB. Our toy scale should be trivial. |
| Bugs in manual gradient code | Rigorous gradient checks (finite-difference vs computed); compare against PyTorch autograd reference on first 1-2 runs |
| Conflict with biology-grounded plasticity on main | Strict gating: `cfg.enable_surrogate_grad_pretraining` defaults False; tests verify no impact when disabled |
