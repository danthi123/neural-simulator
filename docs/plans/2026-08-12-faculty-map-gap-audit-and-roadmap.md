# Faculty-Map Gap Audit → Prioritized Build Plan (2026-08-12)

**Provenance.** A 12-agent grounded audit (owner-requested): 10 faculty-domain audits — each checking the ACTUAL
codebase/findings/ledger for HAVE/PARTIAL and the neuroscience literature for a complete map — plus an adversarial
completeness critic and a synthesis. This is the forward-looking FACULTY roadmap; the roadmap §7 wall-ledger and
`docs/BURN_DOWN_LIST.md` remain the mechanism-level boards. Nothing here is a verdict on a run — it is a map of what to
build next and in what order.

---

## 0. The honest reckoning (read this before the aspirational tiers)

The audit is honest that summing ten HAVE lists OVER-STATES the live brain. Against the project's own DONE bar
(production-default + scaffold-retired), the true tally is **~one integrated spiking faculty family** (spiking semantic
recall/CHOOSE + in-loop LEARN + a handful of read-out organs: GENERATE, MOAT, AFFECT, SURPRISE/D2, COMPREHENSION/D4,
METACOG/E1, WORLD-MODEL/E2, CURIOSITY landing) **plus a large bench of ~40 unwired de-risk demonstrations (GO in the findings)**. This is the
owner's own diagnosed "~40 default-off GOs beside a host pipeline" drift, reproduced at audit scale. Four caveats temper
even the wired core, each a real brain-based-only residual:

- **"One brain" is CO-RESIDENCY, not one substrate.** Each wired organ is a Python function in `server.py` that snapshots
  its own co-resident bridge, computes a read, and returns; the routing/sequencing/combination is HOST control flow and the
  organs communicate through Python, not synapses. Genuine cross-synaptic interaction is proven for exactly ONE pathway
  (acquisition). The project's own memory (`project_one_brain_substrate_vs_functional`) disqualifies co-location with zero
  cross-synapses as "one brain."
- **Spiking recall is resonate-and-fire over a HOST-DESIGNED VSA bind/unbind algebra + hand-assigned assemblies** — a lookup
  dressed as resonance (frac_fired ~1.7%, a numpy oracle underneath), not emergent structure.
- **AFFECT's appraisal cognition is HOST** — the bistable ladder holds/reads back a valence a Warriner sentiment lexicon
  computed and injected into a neuromodulator; under brain-based-only the between-sensation-and-action computation being host
  is the shortcut.
- **METACOG/E1 is a decision-variable (parse-confidence) readout, not a dissociable second-order monitor** (the dissociable
  comparator is seed-fragile 0/6).

**The single most important STRUCTURAL gap** subsumes the rest: the production "brain" is a host-orchestrated pipeline of
separately-validated spiking modules — not one substrate whose own dynamics produce the conversation. This is simultaneously
the real one-brain failure, the reason emergence stays early (composition + routing + organ internals are host, so faculties
are PLACED not emergent), and the thing that undercuts the self-model at the root (a self-schema "reading what is broadcast"
is reading a host orchestration variable, not the substrate's own global state). The fix is already de-risked and unwired:
the GNW ignition/broadcast stack — the neural bus that would let organs write/read a shared workspace via ignition instead of
Python (see T1-1).

## 1. State of the faculty map (one paragraph)

A real but THIN spiking conversational core (the one wired family above), a DEEP reserve of unwired mechanisms (episodic
one-shot + CA3 completion, SWR/sleep replay, multi-slot WM, reconsolidation, the whole GNW workspace stack,
false-belief/recursive/affective ToM, transitive/analogical reasoning, self-schema + agency organs — all de-risked, none
wired), and a structural gap (host orchestration + host-designed organ internals) that keeps emergence early. The job now
is to convert the bench into wired continuity, install the structural keystone, and run the genuine research frontier in
parallel.

## 2. TIER-1 — load-bearing for reasons-to-own-conclusions + affective-self-aware genuine conversation

Seven items, each consolidating 2–4 raw nominations across domains; ordered by north-star leverage.

- **T1-1 · Neural workspace bus + re-entrant deliberation loop (metacog/conflict as CONTROL, not readout).** THE keystone.
  "Reasons to its OWN conclusions" IS multi-step working-through — ignite a partial conclusion, feed it back as the next
  premise, iterate; today deliberation is single-shot and METACOG only REPORTS confidence while the raw conflict/margin
  signal (E1/D4) is computed on spikes but nothing acts on it. Also the structural fix: a shared workspace lets organs
  write/read via IGNITION instead of Python control flow. Mechanism: GNW rung1–4 ignition/mutual-exclusion/broadcast
  (de-risked, unwired) as the production bus; re-broadcast the ignited conclusion as next input,
  sequenced by theta-gamma buffers; an ACC conflict unit reads the WTA competition → gates an extra deliberation cycle /
  raises the abstain threshold / routes to curiosity; a hyperdirect STN→GPi STOP-SIGNAL veto (BG presets exist, unused) as
  the effector that can abort an already-mobilized response — the motor of the honesty boundary. Tractability MEDIUM (all
  pieces de-risked; the work is closing the loop + adopting the workspace as the bus).
- **T1-2 · Autobiographical episodic memory + temporal self-continuity (the narrative self on a timeline).** "Earlier you
  told me X," relationship continuity across sessions, reasoning from remembered SPECIFICS, and a stable self to reason
  FROM. Mechanism: wire the already-GO gap5 converse→sleep-replay→converse capstone (de-risked) into the default turn;
  add a Howard–Kahana drifting temporal-context code (LEC time cells) bound at encode via BTSP for recency+contiguity
  (replaces the host `ec_context` shortcut, sidesteps the order-intrinsic negative by a new method); bind a persistent
  self-token re-instantiated each episode → an autobiographical timeline; consolidate recurring self-facts into an mPFC
  self-schema (retires host QuestionRouter self/identity, F1). Residual inside the build: EMERGENT-assembly CA3 completion
  (gap5 E5 boundary) — attack via dendritic-plateau readout + mossy-detonator gain, not point-neuron WTA. Tractability MEDIUM.
- **T1-3 · Multi-referent working memory with a LEARNED spiking gate (PBWM).** Multi-clause reasoning + tracking ≥2 referents
  is IMPOSSIBLE with the current single-attractor anaphora store (it TIES on 2+), and the emergence engine fails a subject-verb dependency at chance once intervening tokens vary (memorizes surfaces, can't carry a latent across a span).
  Mechanism: theta-gamma phase multiplexing (Lisman–Idiart ~7 items) + the de-risked gated bistable slot-binder (de-risked), closing the residual with a striatal PBWM Go/NoGo write-gate (O'Reilly–Frank) trained by
  DA-RPE instead of the host timing marker; input-vs-output gating for selective read-out; bind the latent by indirection +
  a TEM factorised relational code so it survives intervening material. Reuses nav BG-disinhibition. Tractability MEDIUM.
- **T1-4 · Learned causal forward model (s,a→s′) + belief-consistency / dissonance resolution.** Causal inference,
  counterfactual reasoning, and complete deliberation ALL bottleneck here; today every "why" deflects (the production causal
  answer is a host JOIN of triples, no forward model). And an honest mind can't silently hold p and ¬p — the
  non-contradiction gate is currently addressed by the B3 assertion-gate but belief revision is not wired. Mechanism: a
  learned predictive HTM/cortico-striatal forward model on the shared substrate; directed edges via DA-RPE + temporal-order
  STDP; hippocampal-entorhinal successor representation for transition structure; cause-vs-correlation from teacher DO-
  interventions; a consistency engine that uses the D2/ACC conflict signal to trigger RECONSOLIDATION (the PE-gated in-place
  update is GO but unwired; the production KB is append-only). Tractability LOW–MEDIUM (residual = the Izhikevich read-regime,
  not the concept; gap#4 is NOT the conversation blocker → a parallel research track, never a gate on T1-1/T1-2).
- **T1-5 · Affect that is reason-giving and revisable: multi-dimensional appraisal + discrete emotions + regulation, with
  BRAIN-BASED appraisal.** Affect is currently a signed SCALAR — no discrete emotions, no appraisal structure, no
  reappraisal, and the appraisal cognition is HOST (Warriner lexicon). An emotion is reason-giving only when it carries WHY;
  reappraisal literally IS reasoning about one's own feelings. Mechanism: OFC/vmPFC/ACC appraisal pools each sourced from an
  existing organ (goal-congruence from limbic value, agency from the self/other tag, control from METACOG, certainty from
  SURPRISE/COMPREHENSION) converging (Scherer/Barrett) onto the Namburi–Tye opponent valence map; ~5 categorical emotion
  attractors (Panksepp) via the existing Wong-Wang WTA; a vmPFC→amygdala inhibitory reappraisal gate; wire the de-risked
  learned distributional valence (DR-2, a de-risked learned valence) as the appraisal source and RETIRE the lexicon (closes a
  brain-based shortcut immediately). Tractability MEDIUM.
- **T1-6 · Conversational agency: repair + question-generation + self-initiated output.** Genuine conversation is two-way; a
  curious agent that reasons to its own conclusions must ASK and INITIATE, not only answer. Today the system only ABSTAINS
  (a proto-repair, no repair sequence), never asks a question, never initiates — the whole pipeline is request→response.
  Mechanism: a Levelt perceptual loop (efference copy of the intended spiking-Broca utterance back through D4; an ACC low
  margin triggers self-repair via a pre-SMA suppress-and-replan gate reusing the T1-1 veto, or other-repair — a
  clarification naming the unresolved role); gate the curiosity learning-progress signal into an interrogative Broca slot
  for wh-emission; add a DEFAULT-MODE intrinsic-activity stream (endogenous attractor wandering biased by curiosity/affect)
  for self-initiation + topic-return. Tractability MEDIUM.
- **T1-7 · Intuitive world-model / core common-sense (naive physics + naive psychology).** The biggest faculty NO domain
  owns: you cannot reason to your own conclusions about a world you have no GENERATIVE MODEL of. Reasoning owns mechanisms,
  memory owns facts, perception owns percepts — nobody owns the intuitive model (object permanence, containment, intuitive
  causality, agency-of-objects, naive psychology). The repo "world-model" (E2) is a Markov-1 two-channel VALENCE predictor,
  not a world-model in any Spelke/core-knowledge sense. Mechanism: generalize E2 from valence to a STRUCTURED state forward
  model (shares the T1-4 build); a relational/cognitive-map substrate (TEM / successor rep, grid→relational→conceptual) as
  the generative backbone; acquire core-knowledge priors from teacher-scaffold interaction. Tractability LOW — the least
  de-risked tier-1; a genuine research frontier, paired with T1-4.

## 6. Recommended SEQUENCING (given what's already wired)

**Guiding principle:** integration-is-the-spine → wire the most-de-risked, highest-leverage GOs first; do the structural
keystone once the organs it broadcasts among are richer; run the genuine research frontier in parallel; defer embodiment.

- **Phase A — Wire what is already GO (cheap; burns down the drift fastest).** Wire the gap5 autobiographical episodic loop
  (converse→sleep-replay→converse) and the multi-referent slot-binder into the default turn; swap host Warriner appraisal
  for DR-2 learned valence; add the TCM drifting-context order/recency code as a fast-follow. Delivers autobiographical
  continuity (T1-2), multi-clause reasoning (T1-3), and brain-based affect (T1-5's cheapest slice) — each an integration
  job, not new biology.
- **Phase B — The structural keystone (highest single leverage).** Stand up the GNW workspace bus + re-entrant deliberation
  loop + metacog/conflict-as-control + inhibitory veto (T1-1). Subsumes the most tier-1 leverage AND fixes structural gap
  §5.2 — turning the host-orchestrated pipeline into one substrate whose own dynamics author a turn. Do it AFTER Phase A so
  it broadcasts among the richer organ set.
- **Phase C — The reasoning / world-model frontier (genuine research; start early, in parallel).** The learned causal
  forward model + variable-binding generalization + belief-consistency (T1-4, T1-3 residual) and the longer-horizon
  intuitive world-model (T1-7). Residuals are the Izhikevich read-regime + variable-context binding — real research; gap#4
  is NOT the conversation blocker, so this feeds the track without gating Phases A/B.
- **Parallel throughout (composition-heavy, cheap):** T1-5 affect deepening, T1-6 conversational agency (repair +
  question-gen + self-initiation), Tier-2 affective empathy + joint attention + intrinsic-conversational-reward.
- **Deferred:** embodiment-gated perception/motor + prosody (Tier-3).

**One-line rationale:** Phase A converts the biggest existing asset (the ~120-finding bench) into wired continuity at
near-zero research risk; Phase B is the one move that both unlocks self-directed reasoning and repairs the
"pipeline-not-a-brain" root cause; Phase C is where the genuine walls are, so it starts early but never blocks the wiring
that makes the live brain measurably more complete each cycle.
