# Post Phase 1.4 6-seed validation runbook

**Date:** 2026-05-06
**Purpose:** Concrete commands to run when 6-seed validation
completes. Reduces wakeup-time decision overhead.

---

## Phase 1.4 v3 6-seed status (live)

Master log: `research/findings/raw/g11_bg/continual-forgetting-validation.master.log`
Per-seed JSONs: `research/findings/raw/g11_bg/forgetting_seed{N}.json`

When master log shows all 6 `OK` markers, run:

```bash
python -m research.runners.forgetting_summarize \
    --out-md research/findings/2026-05-XX-Phase-1.4-v3-6seed-PASS.md
```

(Replace XX with the actual day if it bleeds past midnight.)

The summarizer prints the verdict line. Three branches:

---

## Branch A (>= 4/6 retention >= 80%) -- biology validated

**Action 1:** commit the findings doc:
```bash
git add research/findings/2026-05-XX-Phase-1.4-v3-6seed-PASS.md
git commit -m "research: Phase 1.4 v3 6-seed PASS -- BRANCH A confirmed"
git push origin main
```

**Action 2:** launch Tier 2.3 smoke (single seed):
```bash
python -m research.runners.phrase_trainer \
    --seed 42 \
    --out-stats research/findings/raw/g11_bg/phrase_smoke_seed42.json \
    > research/findings/raw/g11_bg/phrase_smoke_seed42.log 2>&1 &
```
Wall-clock ~13min train + ~3min tests = ~16 min/seed.

**Action 3:** if Tier 2.3 smoke shows non-zero on all 3 conditions
(phrase, direction-only, verb-only), launch 6-seed:
```bash
python -m research.experiment_runner \
    experiments/tier_2_3_phrase_validation.yaml
```
ETA ~50min.

**Action 4:** advance Phase 1.5 unified eval (4 benchmarks):
```bash
python -m research.runners.continual_eval_suite \
    --benchmarks sequential_expansion retention_over_time \
                  interference long_tail \
    --seed 42 \
    --out-stats research/findings/raw/continual_eval/seed42.json
```
Wall-clock ~2-3 hr per seed (4 heavyweight benchmarks). Defer until
Tier 2.3 6-seed completes.

**Action 2:** launch Phase 1.3 smoke (consolidation as mitigation):
