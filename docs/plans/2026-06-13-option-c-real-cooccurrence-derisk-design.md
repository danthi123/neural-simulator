# Option C de-risk design — can the brain-based spiking-Hebbian learn extract graded semantic structure from REAL text co-occurrence?

**Date:** 2026-06-13. **Status:** DESIGN (controller-verified; implementation + run pending). **Context:** the Phase-1 corpus-source decision (`2026-06-13-phase1-production-corpus-source-design.md`) — Option B (hand-curated within-cluster semantic sub-taxonomy) vs Option C (learn the similarity from real distributional co-occurrence, the brain-faithful path). Per the owner's durable goal (proper brain analogue; honest negatives under strict biology ARE the deliverable; capabilities instrumental), de-risk C cheaply BEFORE committing the multi-day build.

## 0. The decisive insight (verified)
The entire validated learned-graded-embedding GO chain (NEGATIVE → diagnosis → desaturate → divnorm → confirm → homeostasis) ran on the **synthetic** `build_toy_cooccurrence` (`learned_graded_embedding_derisk_probe.py:132`), where `S_true` is the cluster-block matrix **injected by construction** (`:176-180`) and the corpus is generated *from* that block. So every prior GO is "the brain-based learn recovers a structure we planted" — it tested the MECHANISM, never **whether real text co-occurrence carries independent semantic category structure the learn can extract.** That is exactly the Option-C question, and it is a clean **one-function swap**: replace the synthetic corpus + injected `S_true` with (a) real windowed co-occurrence and (b) an INDEPENDENT semantic reference. Everything downstream (learn, read-out, gate harness, anti-cheats) is reused verbatim.

## 1. Source + vocabulary + extraction (verified suitable)
- **Corpus: `data/corpus/tinystories.txt`** — 7.99 MB / 1.59M tokens, simple modern child-register English with rich everyday-concept co-occurrence. Rejected: `tinyshakespeare.txt` (archaic, poor modern-concept overlap), `research/datasets/distill_corpus.txt` (~70× smaller, too sparse). Literature-supported: child-directed/simple corpora yield CLEANER category structure (Lexical-category-acquisition, PMC6310260). **Verified:** all 34 sampled test-vocab words present, none below a freq-floor of 30 (lowest "eye" 48).
- **Test vocab: 8 categories × 8 = 64 common words** with an INDEPENDENT a-priori taxonomy: animals (dog/cat/bird/fish/frog/bear/mouse/duck), food (apple/cake/bread/milk/egg/soup/candy/cookie), body (hand/eye/foot/head/hair/arm/leg/face), family (mom/dad/girl/boy/baby/friend/sister/brother), actions (run/jump/walk/play/look/eat/sleep/sing), colors (red/blue/green/yellow/black/white/pink/brown), places (house/park/room/garden/tree/road/school/beach), toys/objects (ball/toy/book/doll/box/blocks/kite/bell). The runner verifies per-word frequency at load and reports/swaps any below floor.
- **`S_true` = the category-block matrix over this a-priori taxonomy** (within-category 1.0, between 0.0) — **NOT corpus-derived** (the single most important correctness property; a corpus-derived reference would be circular and only re-confirm the mechanism).
- **Extraction (`build_real_cooccurrence`, new ~60 LOC):** stream → lowercase → split on `<|endoftext|>` → in-story token list → restrict to vocab → slide a symmetric **W=5** window → each window's distinct in-vocab word set = one co-occurrence scene → one fact tuple (dedup; singletons dropped). **Per-pair repeat cap `R`** so high-frequency words don't saturate the recurrent. Compute the real `second_order_pairs` (within-category pairs with ZERO direct windowed co-occurrence — the genuine cat~dog case) from the actual `direct_cooccur` set. Return the `build_toy_cooccurrence`-shaped dict so the learn/read-out/gates are reused unchanged. No `hub` concepts (real text has none; shared within-category context words play the hub role naturally).

## 2. The falsification (reuse the validated stack verbatim)
```
TinyStories ─build_real_cooccurrence→ {facts, S_true(independent), labels, second_order_pairs}
  ├→ learn_W_homeostatic(oja) → divnorm_spreading_readout(ch/interleave) → learned graded CODES   [GPU, VERBATIM]
  ├ G1 structure_recovery(codes, S_true, second_order_pairs): Pearson(sim,S_true) + is_graded + 2nd-order margin
  ├ G2 architecture_generalization(codes, labels, props, 8,8): held-out-neighbour inference + A2(orth) + A3(perm-prop)
  ├ HEADLINE anti-cheat: permute_corpus(facts) → re-learn → structure + generalization MUST collapse
  └ CEILING (labelled, NOT a deliverable): host_ceiling_codes (PPMI+SVD over the SAME real facts)
```
- **HEADLINE = permuted co-occurrence** (`permute_corpus:235`): redraw each scene's members at random → destroy word↔context pairing → structure must collapse. Conditional logic: a collapsed permuted control is only meaningful if the INTACT result is above chance (else NEGATIVE_no_structure regardless — the NEGATIVE doc's caveat).
- **CEILING = host PPMI+SVD over the same real facts** (`host_ceiling_codes:380`): the load-bearing disambiguator between "the mechanism can't" (host recovers S_true, brain-based doesn't) vs "data too thin" (host ALSO fails). **Do not run this de-risk without it.**
- **Gate the headline anti-cheat on the MARGIN/Pearson conjunction, not the brittle `is_graded` boolean** — reuse the `_g5_robust` logic (`multibridge_graded_derisk.py:237`; the carried-forward fix: 2nd-order margin < +0.10 AND Pearson < 0.3 AND gen ≤ 1.5×chance), since real-corpus permuted matrices are structureless and would coin-flip the bare boolean.
- **Multi-seed 42/43/44.** Beats a `random_gaussian_codes` baseline (`:367`). Anti-cheat that learning ≠ pass-through: `Pearson(W, raw_counts) < 0.99` (faithful band ~0.3-0.7 via `offdiag_pearson`).

## 3. Verdicts (multi-seed) → the B-vs-C decision
- **GO** — G1 Pearson ≥ 0.5 + graded + 2nd-margin ≥ +0.10; G2 gen ≥ 0.7 + A2/A3 collapse; HEADLINE permuted collapses; beats random. ⇒ **Build on C** (learned-from-experience, brain-faithful).
- **BOUNDARY_weak_graded** — permuted collapses + Pearson > 0 (real, co-occurrence-driven) BUT gen marginal (chance<gen<0.7) or 2nd-margin in [0,+0.10); especially if the host ceiling PASSES while the brain-based lags. ⇒ **Build on B now; report the brain-vs-host gap as the deliverable** (real co-occurrence has the structure; the point-neuron Hebbian extracts only a coarse version) + test what closes it. *This is the most likely honest outcome per the Mikulasch-Priesemann point-neuron limit (MEMORY).*
- **NEGATIVE_no_structure** — brain-based fails G1 (collapse to ~uniform, gen ≤ chance) AND host ceiling PASSES. ⇒ **Build on B; the honest negative maps the learned-vs-curated gap** on REAL data (a stronger, more general claim than the synthetic NEGATIVE). B's curated similarity is then the justified stepping-stone; the dendritic-substrate rewrite is the genuine-distributional path.
- **NEGATIVE_data_too_sparse** — host ceiling ALSO fails. ⇒ inconclusive for the mechanism; enlarge corpus subset/window/vocab or accept local corpora can't support C. (The ceiling control exists precisely to detect this.)
- **NEGATIVE_not_cooccurrence_driven** — gen passes but the permuted control ALSO passes → read-out artifact, not data. (Guarded by the headline control.)

## 5. Cost + risks
- **~1-1.5 GPU-hours, 3-seed decisive** (the learn is unchanged from the validated ~4.5-25 GPU-min/seed; permuted re-learn doubles it). CPU smoke: seconds-to-2-min. Truly cheap-first (≈1 GPU-hr to resolve a multi-day build-source decision).
- **Risks (controller-affirmed):** (1) the host-ceiling control is non-optional — it IS the experiment's validity; (2) `S_true` MUST be the independent taxonomy, never corpus-derived; (3) gate on margin (`_g5_robust`), not the brittle `is_graded`; (4) real co-occurrence is denser + hub-less → watch saturation (repeat_cap + Oja ceiling + divnorm are the guards; check `Pearson(W,raw_counts)` in the faithful band, sweep `homeo_target` on one seed first); (5) freq-floor the vocab (verified clean); (6) scope: a toy-scale (64-word) GO/BOUNDARY/NEGATIVE is the cheap-first source signal, NOT a production-scale proof.

**Precedents:** Garagnani & Pulvermüller 2018 (spiking-Hebbian category-graded assemblies); Hultén 2021 / arXiv 2503.02057 (Hebbian over co-occurrence); the project's own Phase-2.3a "~4-orders-too-small" negative + the Mikulasch-Priesemann point-neuron decorrelation limit (which predicts BOUNDARY_weak_graded as the most likely honest outcome — a valuable biology-translatable negative localizing learned-from-experience to the deferred dendritic substrate).
