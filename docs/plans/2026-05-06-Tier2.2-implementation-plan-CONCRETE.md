## What needs to change

The runner currently uses R-STDP and reward signals. Tier 2.2 adds
embodied co-firing:

### Change 1: During each nav step, drive language teachers when
applicable

When agent EXECUTES action `a` (chosen by BG cascade):
- Drive `language_input[ACTION_TO_WORD[a]]` (input teacher)
- Drive `language_output[ACTION_TO_WORD[a]]` (output teacher)

When agent PERCEIVES goal at goal_pos (visual cortex sees the goal):
- Drive `language_input["goal"]` (input teacher)
- Drive `language_output["goal"]` (output teacher)

When agent IS AT goal (proprioceptive feedback of arrival):
- Drive `language_input["goal"]` + `language_output["goal"]` again

### Change 2: Open plasticity gates during nav

Currently `language_input_to_cortex` and similar gates may be frozen.
With embodied paradigm, leave them open during nav training.

### Change 3: Add CLI flag

```python
ap.add_argument("--embodied-language", action="store_true",
```

### Change 4: Add evaluation routines

Two new evals after nav training:

**W→Action eval:**
For each direction word, drive language_input[word], measure motor pool
activations and which action argmax fires.
Already exists via existing text_eval.evaluate_word_to_action.

**Action→W eval (drive motor → read word):**
Already exists via similar logic in bio_three_factor's inline eval.
Port the same logic.

**W→I eval (drive "goal" → check IT activation):**
NEW. Drive language_input["goal"], measure firing pattern in cortex_it.
Compare to spatial pattern produced when agent SEES goal at known
position (from training data). Cosine similarity test.

**I→W eval (place agent at goal → read language_output):**
NEW. Set agent_pos = goal_pos in nav context, run forward, read
language_output, cosine match against vocab.

## Pass criteria

**Object word "goal":**
- W→I: drive "goal" → cortex_it activates spatial-goal pattern
  (cosine similarity to perceiving-goal pattern > 0.5)
- I→W: at goal location → language_output produces "goal" pattern
  (top-1 cosine match across vocabulary)

**Direction words "north/east/south/west":**
- W→A: drive direction word → motor activates correct direction
  (already validated in Tier 1 via bio_three_factor)
- A→W: when agent moves direction → language_output produces word
  (extends Tier 1 to navigation context)

≥4/6 seeds passing both W↔I (goal) and W↔A (directions) = Tier 2.2 success.

## Risks

1. **Visual cortex + BG cascade dynamics may interfere with language
   STDP.** During nav, many regions fire simultaneously. STDP timing
   windows may not cleanly capture word-action coincidence as in
   isolated bio_three_factor training.
   - Mitigation: drive language with strong current (200 pA) so it
     reliably fires the language regions even amid other activity.

2. **Goal perception trigger might be too narrow.** "When dist <= 1"
   only fires when adjacent to goal. Maybe should be wider (dist <= 3)
   or graded (drive intensity proportional to inverse distance).
   - Mitigation: tune the trigger condition; start with dist <= 1, fall
     back to dist <= 3 if too few binding events.

3. **Reward-driven plasticity (existing nav training) may conflict
   with embodied teacher signals.** The reward signal modulates STDP
   for cortex→motor learning; when language teachers also fire, the
   resulting weight changes might be noisy.
   - Mitigation: tune embodied teacher pA relative to reward
     modulation strength. Start with 200 pA (Tier 1 default), adjust.

## What this gives the user

After Tier 2.2:
- User: "go north" → agent moves N (W→A as in Tier 1)
- User: "show me the goal" → agent's IT activates → user sees goal
  representation (W→I)
- Agent at goal → spontaneously emits "goal" pattern (I→W)
- Agent moves N → spontaneously emits "north" pattern (A→W)

This is real bidirectional embodied language at the 8-15 word level
within the navigating agent. Bridges Tier 1 (text-only flashcards)
to Tier 3 (compositional sentences).
