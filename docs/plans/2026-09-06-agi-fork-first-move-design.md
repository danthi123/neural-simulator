I make it *cheap* by collapsing it to a `--units {rate,spike}` flag on ONE substrate module (spiking = Heaviside forward + hard reset, `atan_surrogate` backward — the code already exists in `sim/surrogate_grad.py` and `sim/bptt_snn.py`), so only the unit nonlinearity changes and everything else is held identical.
- **From Candidate 2 (embodied-continual-RL):** grounded **interoceptive drive-reduction as reward** (`SpikingHunger`/`TwoPoolDrive` in `research/runners/_tier3_live_and_remember_derisk.py`) instead of a host distance formula, and **learning-progress** (not raw error) curiosity as the noisy-TV cure — while *rejecting* its sensory channel.

**Top fatal flaws fixed:**
1. **The `render_egocentric_goal` trap (Candidate 2's flaw, and it silently compromises 1 & 5 too).** I read the code: `render_egocentric_goal` (g11_bg_runner.py:228) computes `ddx = goal[0]-agent[0]` and paints the goal at its bearing from the agent — a **pre-solved goal-compass**, recomputed every step. A reactive memory-free policy solves the task, so any "place code" or "value" would be a decorative correlate, not a load-bearing faculty. **Fix:** the sensory channel is an **agent-centered egocentric CROP** of `render_gridworld_to_image` (visual_cortex.py:155, which takes a `landmarks=` arg) through the fixed Gabor V1 front end (`build_v1_simple_weights`). The agent is always at crop-center → absolute (x,y) is in NO single frame → position must be path-integrated; the goal appears only when inside the crop → it must be remembered off-view (permanence); fixed landmarks appear locally → localization requires integrating over motion.

## (a) Substrate ARCHITECTURE

**ONE shared rate-recurrent predictive core** — the whole brain between sensation and action — `sim/pcs_substrate.py`, backend-agnostic via `sim.backend.get_backend`.

- **Shared state:** `h_t = (1-α)·h_{t-1} + α·φ(W_h h_{t-1} + W_e e_t + W_a a_{t-1} + W_d d_t)`, leaky-integrator, α≈0.2, ~512–1024 units, φ = saturating ReLU/tanh. `a_{t-1}` = efference copy of last action (the input that makes path-integration learnable); `d_t` = interoceptive drive afferent.
- **Encoder (fixed, world/body boundary):** egocentric pixel crop → `sim.visual_cortex.build_v1_simple_weights` Gabor V1 → small learned linear compression `e_t` (~128-d). V1 is a fixed sensory transducer, not learned — legitimate per the BRAIN-BASED boundary (rendering sensory input).
- **Heads (thin, off the SAME `h_t`):** (H1) next-latent predictor `ê_{t+1}` (JEPA — predict against `sg(EncEMA(view_{t+1}))`, not pixels); (H2) reward predictor `r̂_{t+1}`; (H3) action-logit head π(h_t) over the 4 moves.
- **One objective:** `L = ‖ê_{t+1} − sg(EncEMA(view_{t+1}))‖² + β·(r̂−r)²`, trained **online by truncated BPTT (T≈16–20)** over a never-ending stream. π(H3) is trained by policy-gradient on the shared `h_t` using the intrinsic reward. Never epoched, never frozen (except stop-gradient during a probe read).

**Relaxations named (each with its buy/cost banked):**
- **all-spiking → rate units** *(the headline hypothesis)*. Buys: one gradient objective shapes the whole substrate at once. Cost: not spike-exact. **Made a `--units {rate,spike}` dial** so the cost is *measured*, not asserted (see thesis test).
- **local credit → truncated BPTT.** Buys: correct temporal credit for path-integration (which local Hebbian provably could not self-organize here). Cost: weight-transport non-locality → named recovery rung: feedback-alignment (`sim/dendritic_plasticity.py`) or e-prop (`_onbridge_eprop_port_derisk.py`).
- **bit-exact → JEPA predict-in-latent + EMA.** Buys: cheaper, avoids pixel pathology.
- **compute = reference not cap.** First move deliberately fits the 3090; whether emergence *needs* more scale is itself a deliverable.

## (b) EXPERIENCE STREAM

The **existing** g11_bg grid world + 4-move body, reused by import — no new world. The single sensory channel is fixed:

- **Sensation:** agent-centered **egocentric crop** (radius R cells) of `render_gridworld_to_image(agent, goal, grid_size, landmarks=…)`, re-centered so the agent is always at crop-center → through Gabor V1. K=4 distinct object types at fixed cells + fixed landmarks + the goal all appear *locally* (only when inside the window). Absolute position is in no frame; the goal leaves the frame when the agent moves away.
- **Action:** H3 samples a move; the host applies it to the body (legitimate).
- **Consequence (grounded reward, NOT a host distance formula):** reaching the goal/food reduces the interoceptive drive (`SpikingHunger`/`TwoPoolDrive`); drive state enters as afferent `d_t`. Reward is a physical fact of the world the body moved through.
- **Self-generated & online:** H3 (driven by curiosity, below) steers where the agent goes, so its data is a consequence of its own acting; one env step = one online TBPTT update. Episodes chain forever (goal respawns). **No text** in the first move (cleanest grounding; text is the named second rung).

## (c) EMERGENT FACULTIES + how we SEE emergence

Nothing faculty-specific is trained into the substrate; faculties are read post-hoc. **Each faculty needs BOTH a presence read AND a behavioral-dependency (driving) read** — the anti-hollow fix.

| Faculty | Presence (frozen probe) | Behavioral-dependency (must DRIVE) |
|---|---|---|
| **Allocentric place code** | ridge-decode abs (x,y) from `h_t` | lesion top place-units → nav-success/reward-rate drops ≫ random-unit lesion; next-frame loss rises |
| **Object/perceptual category** | RSA of `h_t` vs 4 object labels (labels used only to score) | lesion category-units → object-contingent prediction error rises |
| **Goal permanence** | decode goal (x,y) *after it left the crop* | lesion → agent fails to return to a remembered goal |
| **Value** | decode discounted future drive-reduction | lesion value-units → foraging collapses to random-walk floor |
| **Curiosity / intrinsic drive** | learning-progress unit read off `h_t` | freeze the learning-progress term → distinct-cell coverage drops |

**Controls (kept from Candidates 1 & 5):** untrained-random core; raw-V1-of-current-crop decode (must be ~chance for abs-position and off-view goal — kills "it's trivially in the frame"); temporal-shuffle; shuffle-label; **recurrent-core lesion** (zero `W_h` → every faculty collapses, proving they live in the shared recurrence). Per-unit spatial rate maps as the visually-convincing bonus.

## (d) MINIMAL DECISIVE FIRST EXPERIMENT

**Built:** `sim/pcs_substrate.py` (rate/spike core + 3 heads + TBPTT step + lesion hooks), `research/runners/fork_pcs_world.py` (egocentric-crop world+body+drive adapter), `research/runners/_fork_pcs_emergence_derisk.py` (online curiosity loop + full probe/lesion battery, `--seeds`, `--units {rate,spike}`, pre-registered GO JSON).

**Run:** live the world online ~200k–500k steps (curiosity policy), training every step by TBPTT; then freeze `h_t` and run the presence decodes + behavioral-dependency lesions, 6 seeds (42/43/44/100/101/102).

**Measured:** the (c) table + all controls + core-lesion + curiosity-vs-random coverage + rate maps.

**GO signals (two, both pre-registered):**
- **EMERGENCE GO (rate arm, Day-3 verdict):** ≥3 of {place, object, permanence, value} clear their presence bar (abs-position R²≥0.6; RSA ρ≥0.4; permanence R²≥0.4; value R²≥0.4) **AND beat all three floors AND pass the behavioral-dependency lesion**, on ≥5/6 seeds; core-lesion collapses all; curiosity coverage ≥1.5× random on ≥5/6. Rate arm: minutes–low-hours/seed; spike arm ~5–10× slower but still tractable. 6 seeds via `tools/gpu_queue.sh` (0 agent tokens). **Day 1** build + smoke (loss drops, one probe beats its floor); **Day 2** probe + behavioral-dependency lesions + single-seed signal; **Day 3** 6-seed rate + EMERGENCE GO/NO-GO; **Days 4–5** matched spike arm + `verify-go` skeptics + FORK-THESIS verdict + honest ledger. Fits the fork's few-day time-box.

## (e) How each of the 6 INVARIANTS is satisfied

1. **Continual learning** — online TBPTT, one update/step, unbounded chained episodes, never frozen except the probe stop-gradient. A room-A→B→A retention test guards catastrophic forgetting (a failure here is a banked negative that local plasticity was load-bearing).
2. **Grounding** — egocentric pixels through the real Gabor V1 (sense) + efference (act) + drive-reduction (consequence). Partial observability makes grounding load-bearing; no isolated text-prediction.
3. **Integration** — literally ONE recurrent `h_t`; every faculty is a read-out of the same population, *measured* by the core-lesion collapsing all faculties at once (not asserted).
4. **Emergence** — the only objective is next-experience prediction; faculties are discovered post-hoc against floors + core-lesion, none hand-coded — the anti-thesis of the strict path's organ-by-organ retirement.
5. **Intrinsic motivation** — the action head is the substrate's OWN (π reads `h_t`, trained on `r_int = drive-reduction + β·learning-progress`); the curiosity signal is the core's own prediction-error reduction, read off `h_t`, not a host oracle (fixes Candidate 1's "host argmax wrapper" concern). Uses learning-progress (noisy-TV cure). Lesion: freeze it → coverage drops.
6. **Honesty** — every read is a functional instrument reading ("a linear decoder reads my position at R²=X; my learning-progress unit is high here"), never "I perceive/feel/experience." `verify-go` runs before any GO is written.

## (f) RISKS + what would FALSIFY it

- **Object category may not separate at tiny scale** → use 4 clearly-distinct objects/viewpoints; if still null, bank as a *scale requirement* (a fork deliverable), not a design failure.
- **TBPTT catastrophic forgetting across rooms** → fails invariant #1; that failure is the banked "local plasticity was load-bearing" negative.
- **Value/permanence may not emerge from prediction alone even if place does** → partial result meaning the predictive objective underdetermines value; informs the second move.
- **BPTT non-locality is a real fidelity cost** → named recovery rung (feedback-alignment / e-prop); if emergence dies under biologized credit, that prices how load-bearing exact credit is.
- **Rate arm may under-perform strict hand-built organs in absolute accuracy** → acceptable; the thesis is rate-of-emergence + integration + continual-learning, and honest under-performance prices the relaxation.
- **"Emergent" could be epiphenomenal decodability** → the whole point of the behavioral-dependency gate; a faculty that decodes but whose lesion doesn't change behavior is *not counted* (this is the explicit fix for Candidate 5's flaw).
- **FALSIFIED if:** no faculty beats its own control + behavioral lesion at ≥5/6; OR only ONE faculty emerges (then it's a world-model, not multi-faculty emergence, and the fork's specific bet is unsupported on this test); OR the matched spike arm matches/beats rate at equal or less compute (all-spiking was not the bottleneck — bank and return to the strict path with the learning).
