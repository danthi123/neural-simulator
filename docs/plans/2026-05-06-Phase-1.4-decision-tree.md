## Decision branches

### Branch A: retention_pct >= 80% (single seed)

**Diagnosis:** Biology-grounded continual learning likely works.
**Confidence:** Single seed, need 6-seed validation.

**Action:**
1. Launch 6-seed validation:
   ```
   python -m research.experiment_runner experiments/continual_forgetting_validation.yaml
   ```
2. While 6-seed runs (~3 hours), continue Phase 1.5 implementation work
   on the remaining stubs (interference + long_tail are done; multimodality
   and composition need Tier 2.2 / 2.3).
3. When 6-seed completes: aggregate retention_pct and decide.

**If 6-seed >= 4/6 retention >= 80%:**
- Path F's biology premise validated.
- Skip Phase 1.4b (no mitigations needed).
- Proceed to Phase 1.2 (Tier 2.3 PFC verb pool) per master plan.
- Document: `research/findings/2026-05-XX-phase-1.4-PASS-biology-continual-validated.md`

**If 6-seed < 4/6:** treat as Branch B for the failing seeds.

### Branch B: retention_pct 50-80% (single seed)

**Diagnosis:** Moderate forgetting. Biology-grounded learning preserves
SOME old knowledge but not 80%. Consolidation may help; some Phase 1.4b
mitigation work is warranted before Phase 2.

**Action:**
1. Launch 6-seed validation (same YAML).
2. While 6-seed runs, design Phase 1.4b mitigations:
   - **Heterosynaptic LTD** (Pulvermuller-Felix Eq B4): when synapse i->j
     potentiates, neighboring i->k synapses depress. Prevents one-way
     monopolization.
   - **Replay-based interleaving**: during Phase B training, occasionally
     replay primary-word events from buffer.
   - **Sleep consolidation** (Phase 1.3 advance): trigger SWR replay
     between Phase A and Phase B, transferring primaries to cortex
     before synonyms can disrupt.
3. After 6-seed completes, implement the mitigation that addresses the
   specific failure mode observed.

### Branch C: retention_pct < 50% (single seed)

**Diagnosis:** Catastrophic forgetting confirmed. Biology-grounded
mechanisms alone insufficient at our scale.

**Action:**
1. Launch 6-seed validation to confirm not seed-specific.
2. While 6-seed runs, advance Phase 1.3 (hippocampus consolidation)
   to head of queue. This is the biology-grounded fix:
   - Closed-loop SWR replay during sleep phase
   - CA1 -> cortex pathway with plastic gates
   - Hippocampus stores, cortex consolidates
3. If Phase 1.3 also doesn't prevent forgetting at biological scale, then
   the architecture genuinely cannot continual-learn without:
   - Surrogate-gradient backprop (path-f), OR
   - EWC (elastic weight consolidation, non-strictly-bio but standard CL)
4. In Branch C + Phase 1.3 fail case, surface to user before adding EWC
   (would cross the biology-grounded line on main).

### Branch D: smoke crashed or no JSON output

**Diagnosis:** Implementation bug, not a science result.

**Action:**
1. Read log file `research/findings/raw/g11_bg/forgetting_smoke_seed42.log`
2. Read err file for exception
3. Diagnose, fix, re-launch smoke
4. Re-enter decision tree from top
