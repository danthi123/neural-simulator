## Phases

### Phase 0 — final numpy gate (NON-protected): a full spiking two-compartment neuron
**Question the de-risk ladder hasn't yet answered:** D1 (algebraic), D1.5 (spike read), D1.6 (conductance membrane) all kept the soma's output as a *rate*. Runner: `research/runners/dendritic_d1p7_spiking_twocompartment_derisk.py` — a dendritic shunting compartment (D1.6) feeding a leaky integrate-and-fire soma per hub-compartment; code = spike counts; gains learned online; point-neuron = single global shunting + LIF. **GATE: SURVIVES** (dendritic structure ≥ bar, point-neuron ≈0, threshold doesn't clip the signal) → Phase 1. **COLLAPSES** → surface the NEGATIVE (the spiking soma breaks it) BEFORE any protected edit.

### Phase 1 — the protected `sim/` edit: a two-compartment neuron on the bridge
Add a dendritic compartment to a bridge neuron: a second per-neuron state `v_dend` (+ a per-neuron inhibitory shunting conductance) computing the analog divisive-normalized drive BEFORE the soma integrates, in the current-accumulation phase (where the coincidence-plateau already sits). Realized as `NeuronModel.TWO_COMPARTMENT` (or a guarded extension), **default OFF = the bridge byte-identical** (Izhikevich/HH/AdEx byte-unchanged; the full conversational suite + the no-confab moat pass verbatim when off). Route through `sim.backend` (CuPy + NumPy). **GATE:** a single-neuron on-bridge probe reproduces Phase 0 on the real spiking substrate; the protected-set diff is byte-reviewed; byte-identity-when-off proven by the existing suite. 

### Phase 2 — the learned graded cortex embedding
Scale the two-compartment units into a cortex that LEARNS its per-compartment gains from a real co-occurrence stream (the Option-C corpus) and emits **graded-but-reproducible** concept codes. **GATE:** the learned codes recover the paradigmatic category structure the point-neuron substrate failed at (Option-C Stage-B: brain −0.008 → dendritic well above 0), Pearson ≥ bar + reproducibility ≥ the σ floor, multi-seed, full anti-cheats (point-neuron control fails on the identical learn; permuted-co-occurrence collapses; lesion collapses; S_true a-priori; host ceiling carries).

### Phase 3 — plug into the validated dual/CLS pipeline + conversational gates
The learned graded codes → the already-validated bind/unbind → attractor cleanup → the full conversational matrix. **GATE:** generalization-in-conversation (answer about a held-out concept via a *similar* known one — what the idealized composer algebra could NOT) WITH the no-confab moat intact (zero false-accepts), multi-seed. This is the capability the whole arc targets.
