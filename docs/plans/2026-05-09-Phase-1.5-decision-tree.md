# 2026-05-09 — Phase 1.5 strategic decision tree

After the v400 hypothesis was REFUTED (0.340 → 0.345, architectural
not dose-bound), the path forward depends on the n_motor=2000 result
+ long_tail_relaxed result. This doc maps the four possible outcome
combinations + the recommended response per master plan.

## The two pending hypothesis tests

| Test | Question | Time |
|---|---|---|
| `phase_1_5_interference_only_n_motor_2000` | Is the interference 0.34-0.45 ceiling at n_motor=1000 a CAPACITY bottleneck (same shape as 12-word default→scaled fix)? | ~45-50 min single seed |
| `phase_1_5_long_tail_relaxed` | Is long_tail rare-word 0.17 a DOSE+TEACHER issue (rare-ratio 20→4 + teacher 300→1500 pA)? | ~50 min single seed |

Both auto-chained. Total ~100 min total wall clock from launch.

## The four outcomes

### Outcome A: BOTH PASS (n_motor=2000 ≥ 0.50 AND long_tail_relaxed rare ≥ 0.30)

**Interpretation:** Phase 1.5 failure was tunable, not architectural.
Two distinct fixes (capacity for interference, dose+teacher for
long_tail) needed but both work.

**Recommended next:**
1. Build a combined preset `phase_1_5_unified_scaled_v400_n_motor_2000_lt_relaxed`
   (long name, but precise) that runs all 4 benchmarks at:
   - events_per_word=400 (validated Tier 2.1 dose)
   - n_motor_per_action=2000 (capacity scale-up)
   - long_tail rare-ratio=4, teacher=1500 pA (relaxed few-shot)
2. Single-seed smoke (~5-6 hr) to confirm all 4 benchmarks pass
   together at the combined config
3. If smoke confirms: 3-seed multi-seed at this config (~15-18 hr)
   for the master plan threshold milestone
4. If 3-seed clears 0.70: declare Phase 1.5 milestone validated;
   proceed to 16-word smoke per master plan

**Master plan implication:** Phase 1.5 milestone reachable. Capacity
scaling rule extends from 12-word vocab to 8-word interleaved
training. Few-shot rare-word binding works at relaxed dose. The
foundation is broader than the original Phase 1.4 BRANCH A scope.

### Outcome B: n_motor=2000 PASSES, long_tail_relaxed FAILS

**Interpretation:** Capacity hypothesis extends to interference
(architectural lever works). Few-shot binding has a deeper structural
limit even at relaxed dose+teacher.

**Recommended next:**
1. Document n_motor=2000 success — capacity hypothesis VALIDATED at
   8-word interleaved binding scale.
2. Document long_tail relaxed FAIL — few-shot binding requires more
   than dose tuning. Possibly needs:
   - Synaptic tag-and-capture (eligibility persistence)
   - Replay during rare-word training (consolidation-style)
   - Architectural change (separate rare-word pool? dedicated
     few-shot eligibility?)
3. Decide: demote Phase 1.5 (3/4 PASS as a tier report) OR invest
   in few-shot architecture work (~weeks of research)
4. If demote: master plan milestone now is "Phase 1.5 sequential
   regime + interleaved binding validated; few-shot is a separate
   research cluster not on the gating path"

**Master plan implication:** Strong partial. The interleaved-training
ceiling is solved. Few-shot becomes a parked-for-later cluster that
doesn't block Phase 2 path-f-hybrid 10M-param work.

### Outcome C: n_motor=2000 FAILS, long_tail_relaxed PASSES

**Interpretation:** Capacity is NOT the issue for interference (it's
truly architectural — interleaved training has a per-word competition
limit that more neurons don't solve). Few-shot binding works at
relaxed dose+teacher.

**Recommended next:**
1. Document n_motor=2000 failure — capacity hypothesis does NOT
   extend to interleaved training. Different architectural problem.
   Possible follow-ups:
   - Different plasticity rule (decoupled per-word eligibility)
   - Sequential not interleaved (curriculum)
   - Different drive-pattern allocation (less collision between
     similar words like "right"/"east" or "left"/"west")
2. Document long_tail relaxed PASS — few-shot is dose-bound. Adopt
   relaxed config as default for Phase 1.5 long_tail.
3. Phase 1.5 still won't pass milestone (interference is one of two
   ceiling benchmarks). Demote Phase 1.5 from gate to tier report.
4. Consider running a different interference variant (sequential
   8-word with curriculum from 4-word base, vs all-interleaved)
   to characterize the ceiling more precisely.

**Master plan implication:** Different ceiling than 12-word vocab. The
"more capacity" lever doesn't apply universally. Need different
mechanisms for interleaved learning. Stronger case for demoting
Phase 1.5 to tier report and proceeding to Phase 2.

### Outcome D: BOTH FAIL

**Interpretation:** Neither tunable lever helps. Phase 1.5's
interference + long_tail benchmarks have real architectural
constraints. The standard Tier 2.1 BREAKTHROUGH config (n_motor=1000
sequential 8-word) hits a ceiling under these stress tests.

**Recommended next:**
1. Document both failures definitively. The negative is robust.
2. Demote Phase 1.5 from milestone gate to tier report. Capture
   the validated capability boundary as:
   - 4-word vocab (Tier 1): full multi-seed
   - 8-word vocab sequential (Tier 2.1): full multi-seed
   - 12-word vocab sequential (Tier 2.1+): scaled n_motor multi-seed
   - 8-word vocab INTERLEAVED: ceiling at 0.34-0.45 (architectural)
   - few-shot rare-word: ceiling at 0.17-0.28 (architectural)
3. Pivot to Phase 2.2b 10M-param overnight per resumption plan.
   Phase 1.5 partial doesn't block Phase 2 — they test orthogonal
   things (path-f-hybrid is gradient-based pretraining; Phase 1.5
   tests biology-grounded interleaved/few-shot).

**Master plan implication:** Phase 1.5 is the boundary of the
biology-grounded learning regime. Both interleaved and few-shot are
architecturally hard. The Phase 1.4 BRANCH A + Phase 1.3 + Tier 2.1
12-word scaled foundation REMAINS validated; Phase 1.5 just defines
the cluster of stress tests where the foundation hits real limits.
This is honest documentation of the architecture's empirical
capability boundary.

## Decision matrix (executive summary)

| n_motor=2000 | long_tail_relaxed | Outcome | Action |
|---|---|---|---|
| PASS | PASS | A — both fixes work | Build combined preset; multi-seed Phase 1.5 milestone |
| PASS | FAIL | B — capacity solves interleaved | 3/4 PASS demote; capacity rule extended; few-shot parked |
| FAIL | PASS | C — capacity doesn't help; dose does | Demote; document interleaved as architectural; pivot |
| FAIL | FAIL | D — neither lever helps | Demote definitively; pivot to Phase 2.2b |

In all 4 cases the foundation (Phase 1.4 BRANCH A + Phase 1.3 + Tier
2.1 12-word scaled) is unchanged — it's already validated for
sequential continual learning. Phase 1.5's outcome only changes
whether interleaved-training and few-shot binding extend the
validated regime or define its boundary.
