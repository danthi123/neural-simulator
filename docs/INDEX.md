## How To Read The Docs

The newest public summary is not allowed to erase older evidence. Older findings
may use stronger language than the current roadmap would use, because the project
was realigned on 2026-08-02 away from narrow test-passing and toward grounded
whole-brain integration.

When documents disagree:

1. Trust the specific raw artifact for exact measurements.
2. Trust the dated finding for what that run meant at the time.
3. Trust `ROADMAP.md` and `CURRENT-STATE.md` for the current plain-language
   interpretation.
4. Trust the 2026-08-02 charter for the current goal and standards.
