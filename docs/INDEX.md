## When Documents Disagree

1. Trust the raw artifact for exact measurements.
2. Trust the dated finding for what a run meant when it was banked.
3. Trust `README.md`, `ROADMAP.md`, `CURRENT-STATE.md`, and
   `SCAFFOLD-LEDGER.md` for the current plain-language interpretation.
4. Trust the project charter for the current goal and standards.
