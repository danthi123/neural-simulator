## 2. Biology it follows

**Primary mechanism (ONE):** homeostatic synaptic scaling of the taught property-block's afferents — Turrigiano 2008 multiplicative scaling toward a target firing-rate setpoint, the Kandel Ch-17 normalization companion process realized synaptically. The property assembly is co-active and over-fires on every training premise, so a rate-based homeostat multiplicatively scales its incoming excitatory weights DOWN toward a setpoint, keeping the block's effective total drive (its afferent weight sum) ~constant while PRESERVING the relative weight pattern. The residual is a global additive shift (a common-mode offset on the afferents); multiplicative scaling removes the offset but leaves the cue-specific RATIOS (the w2 < 2*w1 soft-bound concavity the coverage effect rides) intact — exactly 'keep total incoming weight ~constant while the cue-specific pattern changes.'

**Why brain-based, not a host shortcut:** the substrate SHIPS this mechanism inside the step dynamics (sim/bridge.py ~12117–12161: enable_synaptic_scaling, synaptic_scaling_rate, homeostasis_target_rate; per-postsynaptic-neuron multiplicative scaling of cp_connections.data, gated by the per-pathway cp_plasticity_rate_gain). The runner only SETS config flags and lets _run_one_simulation_step do the biological work — no Python-side weight rescale, no post-hoc normalization from outside the emulation. In this bridge the concept->property pathway is the ONLY weighted pathway (both regions have internal_density=0.0), so the scaling acts on precisely the property block's afferents where the residual lives. Companion precedent: 2026-09-05-affect-noise-robust-homeostatic-three-factor-convergence-clears-strict-bar-derisk-GO.md (runner _affect_noise_robust_homeostatic_convergence_derisk.py) already used this homeostatic-scaling + divisive-normalization family as load-bearing companions elsewhere in the project.

**Rejected alternatives (named; no-defer banks, never drops):** (2) subtractive/divisive normalization of the property REGION's ACTIVITY during training — rejected as primary: the residual is stored in the WEIGHTS (per the finding), so an activity-side normalization is undone by the dynamic-state reset and does not touch the stored shift; banked as a readout-side variant if (3) falsifies the weight hypothesis. (3) presynaptic resource / bounded-release (vesicle-depletion) competition among the block's afferents — plausible but acts on transient transmission efficacy, MASKING not REMOVING the stored shift; no shipped substrate rule; would need a sim/ edit (forbidden here). (4) heterosynaptic depression companion active only during plasticity ('keep total constant, change pattern') — arguably most target-specific, but the substrate ships no heterosynaptic-depression rule, so it needs a sim/ edit or host-side weight edit (both forbidden in a draft); synaptic scaling is the substrate-native multiplicative normalization with the same total-constant/pattern-preserved effect. Named follow-up if scaling under-binds.

## 7. Risks and failure modes

1. **Operating-point knife-edge (rows 2/5):** the same multiplicative scaling that removes the global offset also rescales the coverage pattern; too tight and the coverage margin collapses (row 2) or all learning dies (row 5). Guard = seed-7 calibration + probe B.
2. **Root-cause hypothesis may be wrong (row 3):** if the residual is NOT a common-mode afferent shift (a dynamic-state leak the reset misses, or a co-drive artifact), rate-based scaling will not remove it. Row 3 is an honest method negative, not a dead end — named follow-ups (heterosynaptic depression / weight-sum normalization) under no-defer.
3. **Rate-based vs weight-sum mismatch:** Turrigiano scaling holds firing RATE, not weight SUM; if the property block's training-window firing is dominated by the external prop_scale drive, the bound may over/under-compensate the afferent shift. Probe A measures the shift directly so this is visible, not assumed.
4. **Foil-side inflation:** scaling acts on both property blocks; the quiet foil block's afferents scale UP, inflating the taught−foil subtraction. The untrained floor baseline (same block, same cue, bound-off read) + probe A control for this; if the floor distorts, re-read the floor with the bound on.
5. **Scope creep into a re-derivation:** the coverage effect is established; the temptation to re-tune the effect instead of the residual wastes the run. Keep the premise/held-out construction and the readout FIXED; change only the bound.
