About the 3D visualization

Each glowing sphere is a brain region; size proportional to log(neuron count). Color coded by functional family — sensory green, V1/V2/IT blue gradient, premotor purple, striatum direct/indirect red/orange, pallidum amber, thalamus cyan, motor yellow, PFC teal, hippocampus pink, dopamine magenta.

Lines between regions are declared synaptic pathways — blue for excitatory (glutamate), red for inhibitory (GABA), magenta for dopamine. They brighten when their pre- or post-region is active.

Activity is currently synthesized from action + reward at each replay step (e.g. action=N lights up cortex_N → str_D1_N → motor_N). Phase 2 will replace this with per-region firing rates recorded by the bridge. See the full design doc for the roadmap.

Anatomically-inspired layout

Sensory in (retina) on the left; motor out on the right. Cortex on top, subcortical below. The 4-action BG cascade laid out as parallel lanes (cortex_N → str_D1_N → ... → motor_N).

Color-coded by function

Visual cortex: blue gradient. Striatum direct/indirect: red/orange. Thalamus: cyan. PFC: teal. Hippocampus: pink. Dopamine: magenta. Colorblind-aware.

Traveling action potentials

When a region fires, particles spawn at its edge and travel along synaptic pathway curves, with timing matching the configured propagation_delay_ms. Color codes neurotransmitter type (glutamate, GABA, dopamine, ACh).

Plasticity overlay

Pathway color saturation tracks current weight magnitude. Reward events flash gold across all eligible pathways, visualizing the dopamine moment.

Drill-in to neurons

Click a region to fly the camera in. Individual neurons appear as instanced glowing dots with per-spike streaming from the bridge data bus.

Live & replay modes

Same renderer reads either a WebSocket stream from a currently-running simulator or a recorded HDF5 file from a past run.

About this project

Brain-inspired AI that learns by spike timing, not gradient descent. ~5,000 neurons across 50+ regions, ~175,000 synapses, with biology-grounded plasticity (STDP + reward modulation).
