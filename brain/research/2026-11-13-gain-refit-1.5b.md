# Pre-registration: refit the reinstatement gain at 1.5B with the fixed scorer (oracle routing, unslept cortex)

Written 2026-11-13 before the run. Capability: episodic recall (the hippocampus makes the cortex ANSWER with a fact
told today, before any sleep).

**Record brief.** The gain 4 (grid at 0.1B, 11-02) was confirmed at 1.5B on 11-03 (`hippo_gain_probe.py`, oracle
routing: told 0/2/3/8/10 of 12 at gain 0-4). The scorer then credited general statements about the key word; it now
rejects them (`strict_scorer.is_generic`, `results/2026-11-13-mixed-day-1.5b.md`). Re-scoring that same gain JSON with
the fixed scorer (same replies): told **0/2/1/2/1**, para 0/3/3/2/3 at gain 0/1/2/3/4. At gain 4, 10 of 12 told replies
name the right word, but as "Pixel is a name for a cat.", not as an answer. Live 1.5B arms b and g (11-05) re-scored:
0.50 of 12. So no gain in the 0-4 grid works on held-out facts.
New here: a finer and wider grid, fitted on the dev bank, with reply classes recorded.

**Prerequisites.** Met: 1.5B cortex, the episode store as the live Brain does it. Routing is oracle (the right episode),
so this tests only whether the reinstated episode can make the cortex answer. Host decision: none (the gain is a
scalar constant of the existing reinstatement). Seeds: the probe is deterministic (greedy, CPU fp32, no sampling, no
training), so it has no seed axis; generalization is over facts (36 dev, 12 held-out).

**Method.** `brain/experiments/hippo_gain_refit.py`, 1.5B, CPU fp32, on pool42 (pool41 has no torch; pool40's host key
is unresolved). Gains 0, 0.5, 1, 1.5, 2, 2.5, 3, 4, 6, 8. Dev = DEV_FACTS36 (orig, para_a, para_b = 108 cues).
Test = the 12 FACTS (orig + para), all gains, but the verdict reads only G*. Table:
`brain/experiments/hippo_gain_refit_table.py` (tested).

**Criteria.**
- G* = the dev gain with the most right replies over 108 cues (ties go to the smaller gain).
- R0 instrument: gain 0 right on dev <= 3 of 108 (the cortex has not seen the facts; else VOID).
- R1 some gain works: dev right at G* >= 27 of 108 (25%). If it fails: NO GAIN WORKS.
- R2 held-out told at G* >= 6 of 12 (vs live b/g 0.50, oracle gain 4 now 1).
- R3 held-out para at G* >= 4 of 12.
- LEAD = R0-R3. Then: set the gain to G* behind a switch (default OFF) and run it live on six seeds on AWS (mixed day,
  M1 again).

**Expected.** NO GAIN WORKS (most likely): the re-scored 0-4 curve peaks at 2 of 12, and higher gains turned answers into
talk about the word. If so, the verdict is on the METHOD (adding the whole stored state change at one scalar), not
the capability. Next methods to rank before building: reinstate only some layers (the deep layers carried the routing
signal, S17), or store the episode as the reply-side state change ("Assistant: <fact>") instead of the user's
sentence.

**Addendum (2026-11-13, before the 0.1B run).** The same probe, grid, bank split and criteria R0-R3 are applied
unchanged to the 0.1B cortex (default `Hippocampus.GAIN` 4 was fitted there with the old scorer, 11-02). Results in
`results/2026-11-13-gain-refit-0.1b/`. Run on pool42.
