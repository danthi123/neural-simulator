# Pre-registration: the refit gain (0.5) in the live 1.5B brain on a mixed day (routed recall, six seeds)

Written 2026-11-13 before the run. Capability: episodic recall. A fact told today, still held only by the
hippocampus, is answered.

**Record brief.** Oracle routing, unslept cortex (`results/2026-11-13-gain-refit-1.5b.md`, LEAD, skeptics NARROWED):
gain 0.5 answers held-out told facts 7/12 vs 1/12 at the live gain 4. A wrong episode at 0.5 injects nothing (0/24).
Live, the 11-13 mixed day (re-scored, `results/2026-11-13-mixed-day-1.5b/table_rescored.txt`) had arm f (S_all key,
size bar, gain 4) at new-fact told 0.83 of 6 and c (hippocampus off) at 0.17: M1 failed, VOID. What remains untested:
routing errors, the slept cortex (day 1 facts), a cortex that has been through one night (adapters on) for the new
facts, and false recall.

**Prerequisites.** Met: 1.5B cortex, sleep, S_all routing with the size bar. Gain switch `Brain(gain="size")` (default
OFF, `brain/tests/test_gain_switch.py`). Host decision: none (a scalar constant fitted on the dev bank).

**Method.** `brain/experiments/mixed_day_probe.py --gain-arm`, same as the 11-13 mixed day (1.5B, `--steps 480 --lr
5e-4 --kl-weight 3`, seeds 42/43/44/100/101/102, slept half even/odd counterbalanced, AWS g5 A10G). Per question:
c hippocampus off, f S_all + size bar at gain 4, **r** S_all + size bar at gain 0.5. Scored with the fixed
`strict_scorer.correct_answer`. Table: `brain/experiments/live_gain_table.py` (tested).

**Criteria (exact six-seed means, `fractions.Fraction`; new / slept = told facts, of 6; false = never-told, of 12).**
- L0 instrument: r's recall decision equals f's (same episode or none) on >= 95% of rows (the gain must not change
  routing), and n_pending 6 / sleeps == 1 (asserted in the probe). Else VOID.
- L1 primary: new facts r - c >= 1.5 and r > c on >= 5/6 seeds.
- L2 beats the current gain: new facts r - f >= 1 and r >= f on >= 5/6 seeds.
- L3 false recall: never-told r <= f + 0.5.
- L4 no added cost on slept facts: slept r >= f - 0.5.
- GO for the switch = L0-L4. Then the land-result checks (a fresh-context skeptic, an answer-rate check) before
  any default flip, and the weekly transcript shows it.

**Expected.** r new about 2-3 of 6: oracle 0.58 x routing (S_all fires on 5-7 of 12, right on almost all), c about
0.2, f about 0.8. Slept: r at or above f, because at 0.5 the reinstated episode pushes the slept cortex less. L3 is
the uncertain one: when S_all routes a wrong episode, the oracle control says 0.5 injects nothing, but a never-told
question could still pull a told fact in. Report-only: paraphrase, the answer rate (abstention replies) of r vs f
vs c, and the told total.
