Written 2026-11-17 before any run with the switch. Record: `brain/experiments/results/2026-11-16-onset-baseline.md`
and `2026-11-16-onset-2.9b.md`: the 1.5B cortex alone loops in 18/72 day-2 conversations on the pool CPU (registered
rule; 11/72 on open turns); output-side levers and a bigger cortex did not help; the prereg named the format or the
sampling as the next target. The rwkv7-g1 model card (local `/home/dant123/models/rwkv7/README.md`) recommends
"Fake think prompt (great result, highly recommended)": `User: ...\n\nAssistant: <think></think`. The brain prompts
with `Assistant:` only, which may be off the distribution the chat model was post-trained on.

Switch `Brain(fake_think=True)` (default OFF): prompt `Assistant: <think></think`; the cortex continues ">" + reply; ">"
is not spoken; the exchange enters the state as `Assistant: <think></think>reply`. Host decision: the prompt format of
the body's interface (as `Assistant:` already is), no reply text.

Run: `echo_onset_probe.py --home fresh --fake-think`, pool CPU, the same 12 scripts x 6 sampling seeds as the CPU
baseline (paired). Scored by the same snippet (registered rule; open-turn rule of the 2.9B addendum; non-answers on open
turns). Lead: registered <= 9/72 AND open-turn <= 5/72 AND non-answers on open turns not above the baseline's 21 AND a
reading of samples 0-1 of scripts 1113 and 1115 (the most loop-prone) finds answers, not a template. A lead goes to
open_conv on fresh AWS (GPU) seeds with memory and sleep on, prereg addendum first. Expected: uncertain; one greedy
smoke showed fluent replies after the prefix and one broken byte on a greeting.
