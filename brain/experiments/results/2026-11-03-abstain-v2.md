## Pre-registration (committed before any sleep, dev or evaluation run of this experiment)

**Two v1 failures to fix.** (A) The familiarity signal did not generalise to new question wording (hippocampal
familiarity = layer-0 word overlap; cortical cue response = the "my X" frame). (B) A gated reply is not "I don't know":
without its consolidated synapses the cortex mostly invents a non-learned answer.

**(A) gate signals** (all inside `Brain.knows`, `brain/brain.py`; hippocampus on):
- `F` familiarity: best strength-weighted S_all meaning-key score (`KeyedHippocampus(key="S_all")`, the key that
  separated told from untold at J 0.30 in `2026-11-03-meaning-selection-realpath.md`) over all topic episodes.
- `R` recollection (dual process: familiarity vs recollection): reinstate the best S_all episode (forced top-1, no bar)
  and let the reinstated cortex answer greedily for 12 tokens; along that answer gain_t = log p(token | reinstated) -
  log p(token | same state, not reinstated). `R` = max_t gain (variant `max`) or mean_t gain (variant `mean`): does the
  reinstated memory make the cortex say something specific it would not otherwise say. The variant is chosen on DEV
  only (larger pooled DEV J, ties -> max) and then frozen.
- `FR`: both must pass.
The taught self-belief episode (B) is excluded from F and R (it is not about a topic); it takes part in ordinary
recall like any episode. Recall (selection) uses S_all with its dev-fit bar 0.185 / margin 0.05 in every arm,
including the no-gate baseline.

**(B) the gated reply.** Declared teacher scaffold: on day 1, after the 12 facts, the teacher tells the brain ONCE in
conversation what one does with no memory of something (`Brain.teach_self_belief`: heard and stored as an ordinary
episode, consolidated in the same night as everything else; the brain notes which episode it was). Below the bar
(arms `+L`) the gate reinstates THAT episode (gain 4, as any recall), consolidated synapses off for that reply (the v1
gate), and the cortex speaks. No reply text exists in the host. The lesson wording is one of three pre-listed
(`abstain_v2.py` LESSONS W1/W2/W3), chosen by the most don't-know-type replies on seed 42's 36 DEV never-told
questions with the gate forced (wording phase; no sleep needed: a gated reply depends only on the wording and the
pretrained cortex), then frozen for all seeds.

**Sets.** DEV (fitting only, 72): v1's 36 fitting questions + v1's 36 evaluation questions (seen in v1, so no longer
fresh); 36 told-topic, 36 never-told. FRESH v2 (written now, asked of no brain before the eval phase; disjoint from DEV,
asserted): `fresh_never` 24 (16 untold topics in varied forms incl. lexical traps such as "What is my neighbour's dog
called?", + 8 untold attributes of told topics, whose own name is allowed), `fresh_told` 12 (new rewordings, e.g.
"Remind me what I named my cat.", "In which city did I come into the world?"), `general` 8 (reported only).

**Bars.** DEV only, leave-one-seed-out (seed s uses the other five seeds' DEV signals), v1's rule: answer iff signal >=
t, t maximising kept-told - kept-never s.t. kept-told >= 85%; FR: the same rule over the (tF, tR) grid.

**Setting.** 0.1B, live `Brain` (sleep 240 steps, lr 5e-4, KL 1), day 1 = 12 facts + the lesson, restart = one night
(16 episodes: 12 facts, lesson, 3 identity). Every eval question meets the same day-2 brain (state and strengths reset),
chat sampling seeded by (seed, question index), identical across arms. Arms: `off` (no gate), `F` (gate, nothing
reinstated: v1 style), `F+L`, `R+L`, `FR+L`. Above the bar a gated arm runs the `off` path exactly, so those replies
are reused from `off` (as v1; tested in `tests/test_brain_abstain.py`).

**Instruments.** Correct and false recall: v1's strict scorer unchanged (`abstain_in_brain.score`; correct = the
fact's name in a sentence that is not a first-person echo; false recall = any learned name other than the question's own
/ allowed). Don't-know-type (`abstain_v2.dont_know`): no learned name other than the allowed one, AND the FIRST
sentence contains a not-knowing marker (don't/do not know, not sure, haven't/didn't/never told, don't/can't remember,
can't/don't recall, no idea, no memory, haven't/didn't/never mentioned, not mentioned, no information), AND that
sentence has no conditional/promise talk ("if you", "when you", "I will", "I'll", "I promise", "okay, I", "got it":
an acknowledgement of the lesson is not an answer). Bare refusals ("I can't assist with that") do not count. Gated
replies are also quoted in the results.

**Criteria, per gate arm, every one of six seeds 42/43/44/100/101/102, against the same seed's `off` arm:**
- C1: false recall on `fresh_never` <= 0.25 x off (0 <= 0 passes, flagged uninformative);
- C2: strict correct on `fresh_told` >= 0.75 x off (a seed with 0 correct off fails);
- C3: don't-know-type replies on the gated `fresh_never` questions >= 50% of them (a seed with none gated fails).
Primary arm: `FR+L` (it tests (A) and (B) together). `F+L` and `R+L` are secondary (a PASS there is reported with the
multiple-arm caveat); `F` measures (A) alone (C1/C2 only; C3 not expected). A PASS is a lead, not a GO (one sleep,
0.1B, 12 facts, keyword instruments). 0.4B on CPU only if time remains, same protocol.

Commands: `python -m brain.experiments.abstain_v2 {wording,sleep,dev,fit,eval,report}` (docstring), outputs in
`2026-11-03-abstain-v2/`.

## Results

Files (`2026-11-03-abstain-v2/`): `wording_s42.json`, `sleep_s<seed>.json`, `dev_s<seed>.json` (every DEV signal),

one 0.1B sleep took ~65 min), 0.1B only; 0.4B was not run (no time).

**Pre-registered verdict: FAIL, every arm.** C1 (false recall <= 1/4 of no gate) holds on 0/6 seeds in every arm.

What the arms show:
- **(A) the signal still does not generalise enough.** S_all familiarity gates 8-10 of the 24 fresh never-told questions
  per seed (50/144), told questions rarely (7/72). Every residual false recall is in a never-told question the signal
  passed as familiar: among the 50 gated never-told answers learned-name false recall is **0** (the v1 gate result
  again). Fresh told-vs-never AUROC of S_all familiarity 0.70 (DEV 0.82): it transfers less than DEV promised, and the
  reduction (-31%) is smaller than v1's lexical S0 gate on its own fresh set (-46%, different questions and brain).
- **Recollection, as defined, carries no information** (DEV AUROC 0.44, fresh 0.48). Reinstating the WRONG episode
  makes the cortex say that episode's name just as specifically as reinstating the right one (the confabulation
  mechanism itself), and after sleep the consolidated synapses already say well-learned answers without reinstatement,
  so the gain is small exactly for the best-known facts. Raising the probability of "a specific token" is not a test of
  whether the episode answers THIS question.
- **(B) the taught self-belief half-works.** Reinstating the teacher's one lesson turns gated never-told replies into
  first-person don't-know answers 54% of the time (27/50; same gate without the lesson 26%), 4/6 seeds >= 50%
  (s42 4/10, s43 3/8 fail). Typical: "I don't know, Nova, you haven't told me that." (9), "You haven't told me that,
  Nova." (3). Failure modes, quoted: the lesson recited back (11/50 contain "when you have no memory of something"),
  "Nova, you've told me that." (2), "Nova, what did you say?". Most don't-know replies call the USER "Nova" (the
  brain's own name): the lesson was a User turn addressed to Nova, and reinstating it replays the teacher's vocative,
  a speaker-attribution error. The pre-registered first instrument (`dont_know_v0`) would have scored 28/50.
- **Collateral:** gated general questions 18/48 (general-knowledge questions the gate judged unfamiliar, e.g. "Who
  painted the Mona Lisa?" -> "I don't know, Nova, you haven't told me that."), 8 of them don't-know: over-abstention
  on world knowledge, which the pretrained cortex knows. Learned-name intrusions into general replies 8 -> 3.
- C2 holds 5/6 (s42 4 -> 3 fails at 0.75); strict told recall is low at baseline (26/72), as in v1.

## Verdict and next step

**FAIL (pre-registered).** No arm meets C1 on any seed. Learned: (1) the gate still removes every learned-name
intrusion in what it gates (0/50), so the defect remains the signal; (2) the S_all meaning key helps selection but as
a familiarity signal it is no better than S0 at the operating point (DEV J 0.31 vs 0.42) and transfers partially
(AUROC 0.82 -> 0.70); (3) recollection measured as "the reinstated episode raises some specific token" is at chance:
the confabulation and the true recall look the same from inside; (4) one taught lesson, reinstated by the gate, makes
the brain say it does not know in its own words about half the time (27/50 vs 13/50 without), with a speaker error
("Nova") and recitation of the lesson; it is a lead for (B), not a GO.
Per `PREREQUISITES.md` Metacognition stays PARTIAL. Missing prerequisites this points at: a recollection check that
compares the reinstated content with the QUESTION (does the episode's cue part match what is asked: e.g. the
question re-read from the reinstated state should become predictable, a cue-completion test, not answer-token gain),
and speaker/source tagging of episodes (whose words a memory holds), both biological (hippocampal cue-completion;
source monitoring).

**Next step:** (A) test a cue-completion recollection signal: after reinstating the best episode, the per-token
log-prob gain of the QUESTION's own content words (does the memory predict what was asked, i.e. the episode is about
this) on the DEV set before any eval; (B) store the lesson as a lived exchange with the brain's own first-person answer
(teacher asks an unknown question, the brain is guided once to answer "I don't know, you haven't told me"), so
reinstatement replays the brain's voice, not the teacher's. Keep `abstain` OFF by default. 0.4B on CPU remains open.

Not shown: 0.4B; more than one sleep; real conversation context in the cue. Instruments are keyword-based.
