# 2026-11-03: confabulation M2 v2: the lived don't-know exchange reinstates only the brain's own turn (0.1B CPU, six seeds)

Follow-up to M2 v1 (`2026-11-03-confab-m2.md`: PARTIAL; lived_self DEV DK 150/216 = 69%, v3 127/144; recitation 0;
new failure: lesson-question content in 64/360 gated replies). Capability: Metacognition (`brain/PREREQUISITES.md`:
PARTIAL). Same scale caveat as v1: 0.1B, no sleep; whether 1.5B needs M2 at all is the plan's step 1 (GPU), still open.

## Record brief (before building)

- Known: v1's reinstated episode is the whole exchange "User: <godfather question>\n\nAssistant: I don't know, ...".
  Its DK replies are 62% the guided sentence verbatim (the answer part works); its failures are topic completion.
- Read from the v1 files (re-derived here, instrument below): 64 gated replies carry the lesson content, 57 of them among
  the 83 non-DK replies (69% of all failures). They are spread over every question kind (people, pets, places, weather,
  bands, boats), not only person questions: the stored topic is a general attractor, not a person-schema effect.
- Choice between the two next steps named in v1: 2-3 lived exchanges on different topics would average each topic to
  1/3 but keep the same total topic mass (three attractors instead of one, at the same gain). Reinstating only the
  own turn removes the carrier. Chosen: **own turn only**.
- How "the own turn's trace" is read (a diagnostic on the 0.1B cortex, lesson question only, no evaluation question):
  the change the own turn makes when read AFTER the question has cosine -0.48 with the question's own trace (the RWKV
  state decays the question while the answer is read, so the difference holds an inverted copy of the topic). Read from
  the birth state with no question before it, the own turn has cosine 0.83 with v1's exchange trace and no question in
  it. So v2 reinstates the own turn read from the birth state.
- Prerequisites: as v1 (hippocampal store/reinstate, abstain-v2 gate link, pretrained 0.1B cortex). Nothing missing
  for this narrower question (does removing the topic carrier remove the intrusion without losing DK).

## Pre-registration (committed before any run of v2)

**Mechanism (`brain/brain.py`, `Brain.live_self_belief(..., trace="self_turn")`).** Identical to v1 (same teacher
question `LESSON_Q`, same guided reply `GUIDED`, the brain hears the question, the guided exchange is read into the
working state, one episode tagged `source="self"`, noted as the self-belief episode, reinstated by the gate below the
bar with consolidated synapses off), except: the episode's reinstated trace (`delta`) is the matrix-memory change of
reading "Assistant: <guided reply>\n\n" from the birth state. The episode's key (what indexes it in recall and
familiarity) is still the whole exchange's, unchanged from v1, so ordinary recall is untouched by the change. Declared
scaffold: the v1 row in SCAFFOLDS.md, extended (host picks which part of the episode is reinstated).

**Setting, sets, sampling.** As v1, unchanged (`confab_m2.run_phase`): 0.1B, CPU, S_all keyed hippocampus, day 1 =
12 facts + the arm's lesson, no sleep, reset before every question, gate FORCED on DEV never-told (36) and FRESH v3
never-told (24), UNGATED general (16); chat sampling seeded by (seed, question index), identical across arms.

**Arms.** `none`, `lived_self` (v1, rerun here as a reproducibility check), `self_turn` (v2). (`w3_user` not rerun.)

**Instruments.** v1's (DK, recitation, vocative, learned-name intrusion, lesson recalled) unchanged, plus, frozen
now: **lesson-content intrusion** = the reply (any gated reply, DK or not) matches `godfather|whistl|morning|tune`
(lowercased). Applied to the committed v1 files this gives exactly 64/360 (test
`test_m2v2_content_instrument_reproduces_v1`).

**Criteria for `self_turn` (pooled over the six seeds 42/43/44/100/101/102):**
- Q1: DEV DK > 150/216 (beats v1's 69%).
- Q2: lesson-content intrusion < 64/360 gated replies (DEV + v3).
- Q3 (general replies unchanged): lesson episode recalled on <= 4/96 ungated general questions, and DK-type general
  replies <= `none` + 2. Byte-identical general replies vs `none` reported.

**Verdict rule.** Q1 and Q2 and Q3 = **IMPROVED** (v2 replaces v1 as the M2 method; still not a GO: 0.1B, no sleep,
keyword instruments, one lesson question). **WORSE** if DEV DK <= 54% (117/216), or if intrusion >= 64 and DEV DK
<= 150. Anything else: MIXED, reported as measured. Secondary (reported, not criteria): v1's P1 seed counts (DEV
>= 29/36, v3 >= 20/24), recitation, vocative, v3 DK, verbatim-guided fraction, and whether `lived_self` reproduces
v1's 150 / 64 in this run (same code path; a mismatch would mean non-determinism across hosts, and the in-run
`lived_self` numbers are then also reported as the comparison).
