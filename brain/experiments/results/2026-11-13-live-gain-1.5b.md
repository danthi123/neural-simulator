Capability: episodic recall in the live brain. Pre-registration `brain/research/2026-11-13-live-gain-1.5b.md` (L0-L4,
commit 3a5658dc, pushed before the run). Data: `results/2026-11-13-live-gain-1.5b/livegain_s*.json` (+ logs,
`run.log`, `table.txt`, `identity_check.json`). Where ran: AWS g6.xlarge (L4 24 GB; g5 had no capacity in our zone, a
deviation from the registered A10G), instance i-0f67ad496934e65d9, batch 20261113-2034, ~11 min per seed, all rc 0.
The JSONs record only `device: cuda` (`tools/where_ran.py`: unknown=6); the identity check ran on pool42
(`node-dl5d243`). All arms of a seed ran in one process on one machine, so the comparison is within-run. Cost ~$1.

## Skeptics (three, fresh context, sonnet): all NARROWED, none REFUTED

- Instrument: hand grading reproduces the table exactly (r new 21/36, f 7/36, c 1/36); every r new-fact credit is a
  genuine answer. The false-recall count is not informative on this probe: c is already 10-11/12 on seeds 42/44
  (the slept cortex confabulates a slept fact for a never-told question, "Your uncle lives in Oslo"). No arm intrudes
  a hippocampus-held new fact on a never-told question (0 in every arm), but L3 holds mostly because f is worse.
- Control: one variable (gain recorded per row, f 4.0 / r 0.5, routing identical). The slept-fact claim is "no cost
  against hippocampus-off" (4.50 vs 4.67, r < c on one seed), not a gain; L4 only compared r with f.
- Flip safety: a bare default `gain="size"` would raise at 0.1B and in weekly/chat/night; the gain also applies to
  the permanent self episodes, which the probe did not ask about. Both addressed below.

## Identity check (pool42, fresh 1.5B brain, no sleep; 8 self questions, `brain/experiments/gain_identity_check.py`)

With the default S0 key the self episodes fire on 7/8 questions at both gains. At gain 4 the replies garble the
episode ("Nova, what's your name?" to "What's your name?"); at 0.5 they answer ("My name is Nova." twice, "Yes, I
am.", "I'm a digital brain."). The friend's name is not said under S0 at either gain. With S_all the self episodes
fire on 1/8 at both gains ("Yes, Dan, my friend." at 4, "It's Daniel." at 0.5). No identity answer gets worse.

## What changed

`Brain(gain=...)` default is now "auto": the per-size gain where `Brain.GAIN_BY_SIZE` has a row (1.5B: 0.5), else
`Hippocampus.GAIN` 4.0, so 0.1B (the default cortex, the weekly transcript) is unchanged. "fixed" = the old
behaviour (flag-off arm). The S_all key and size bar stay a default-OFF switch: this GO used them, and the S0 key's
1.5B routing is the known weak spot (11-03: 7/12 right episodes). Probes that ran at 1.5B before 11-14 with the default
gain used 4; re-runs now use 0.5 unless they pass `gain="fixed"`.

Next: the confidence gate on top (the 11-13 gate removed f's slept-fact cost; with r that cost is gone, so the gate
must now earn its place on the remaining false recall), and the S_all default at 1.5B with this gain.
