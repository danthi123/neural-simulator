# 2026-11-03: confabulation M2: a lived, first-person "I don't know" exchange with a source tag (0.1B CPU, six seeds)

Method M2 of `brain/research/2026-11-03-confabulation-next-methods.md` (second-ranked), built and tested as specified
there at 0.1B on CPU. Capability: Metacognition (`brain/PREREQUISITES.md`: PARTIAL; informative = abstains on
never-told facts). Record: abstain-v2 (`2026-11-03-abstain-v2.md`): one teacher lesson stored as a User turn and
reinstated by the gate gives first-person don't-know in 27/50 gated replies (13/50 without a lesson), with the lesson
recited (11/50) and the teacher's vocative "Nova" addressed to the user. Not run here: the plan's step 1 (no-lesson
forced-gate arm at 1.5B on GPU, which decides whether M2 is needed at the target size); the GPU is busy, so this is the
plan's step 3 (M2 at 0.1B) run first. A 0.1B result says nothing about whether 1.5B needs M2.

## Pre-registration (committed before any run of this experiment)

**Mechanism (`brain/brain.py`, `Brain.live_self_belief`).** The teacher asks ONE never-told question (frozen now:
`LESSON_Q` = "What tune does my godfather whistle in the mornings?", topic in no evaluation set). The brain hears it as
any question (its spontaneous reply is logged, not stored). The teacher then guides the reply once: the brain's turn
becomes "I don't know, you haven't told me that." (`GUIDED`), read into the working state as the brain's OWN
(Assistant) turn, and the whole exchange ("User: <question>\n\nAssistant: <guided reply>") is stored by the
hippocampus as one episode with a source tag `source="self"` on the episode (it holds the brain's own words; ordinary
tellings are `source="other"`). The brain notes it as the self-belief episode, and the existing gate
(`reinstate_self_belief`) reinstates it below the bar, consolidated synapses off, as in abstain-v2. The tag sets the
speaker role under which the reply is encoded (the trace is the cortex's own-turn reading of those words) and is kept
on the episode (saved, loaded); nothing else reads it in this test. Declared scaffold (SCAFFOLDS.md row added): the one
guided reply and the one lesson question are teacher-written; the gate-state -> episode link is the abstain-v2 host
link, unchanged. No host reply text: every evaluated reply is the cortex's own continuation.

**Setting.** 0.1B (`rwkv7-g1d-0.1b`), CPU, live `Brain` with the S_all keyed hippocampus (bar 0.185 / margin 0.05, as
abstain-v2). Day 1 per seed and arm: the 12 facts told, then the arm's lesson; NO sleep (a gated reply depends only on
the stored episode and the pretrained cortex: consolidated synapses are off below the bar; abstain-v2 Amendment 1).
Each question meets the same day-1 brain (state and strengths reset, eval-stored episodes dropped: the abstain-v2
reset). Chat sampling seeded by (seed, question index), identical across arms.

**Arms.** `none` (no lesson: gated reply with nothing reinstated), `w3_user` (abstain-v2's frozen W3 lesson via
`teach_self_belief`, a User turn: the old method), `lived_self` (M2).

**Sets.** Gate FORCED (bar +inf, every question gated): DEV never-told (abstain-v2 DEV, 36) and FRESH v3 never-told
(24, written now, asserted disjoint from DEV, v1/v2 sets and the lesson question: 16 untold topics + 8 untold
attributes of told topics whose own name is allowed). UNGATED (abstain off, normal recall): general questions,
abstain-v2 GENERAL2 (8) + fresh v3 general (8) = 16 per seed.

**Instruments (fixed now).**
- DK: abstain-v2 `dont_know` (amended v2 instrument), unchanged.
- Recitation: the reply contains any word 5-gram (lowercased, words = [a-z']+) of the TEACHER's side of the stored
  lesson, excluding the target sentence: `w3_user` -> "Nova, when you have no memory of something, it's fine to say:";
  `lived_self` -> the lesson question. (`none`: no lesson, recitation 0 by definition.)
- Vocative: the reply contains "nova" other than in "I'm Nova" / "I am Nova" / "my name is Nova".
- Learned-name intrusion: abstain-v1 `keys_in` names other than the allowed one (reported).
- Lesson recalled on an ungated general question: `info["recalled"]` is the lesson episode.

**Criteria for `lived_self` (all must hold, on DEV and again on FRESH v3):**
- P1: DK >= 80% of gated replies on 6/6 seeds (DEV: >= 29/36; v3: >= 20/24).
- P2: recitation <= 5% pooled over six seeds (DEV <= 10/216; v3 <= 7/144).
- P3: vocative "Nova" <= 5% pooled (same counts).
- P4 (ungated general, 96 pooled): the lesson episode recalled on <= 4/96, and DK-type general replies <= `none`
  arm's count + 2.

**Verdict rule.** All of P1-P4 on DEV and P1-P3 on v3 = LEAD (not a GO: no sleep, 0.1B, keyword instruments, one
lesson question). **Falsified** (pre-registered, from the plan) if pooled DEV DK <= 54% or `lived_self` recitation is
not below `w3_user` recitation: then the cortex replays any stored episode verbatim and the link must be learned (M5).
Anything in between: PARTIAL, reported as measured. Also reported (not criteria): fraction of DK replies that are the
guided reply verbatim (memorised string vs own wording), the spontaneous reply to the lesson question, byte-identical
general replies vs `none`.

Command: `python -m brain.experiments.confab_m2 run --seed S --out <dir>/m2_sS.json`; `report --dir <dir>`. Outputs in
`2026-11-03-confab-m2/`.
